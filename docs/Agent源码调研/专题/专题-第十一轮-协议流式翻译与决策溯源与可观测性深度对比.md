## 四、deepseek-harness：Typert 协议 + Tracing + Cordis 遥测

### 4.1 Typert 协议

**核心发现**: deepseek-harness 的 **Typert** 是协议翻译层。

```typescript
// Typert 协议翻译
class TypertTranslator {
  // Anthropic → 内部
  anthropicToInternal(chunk: AnthropicChunk): InternalEvent {
    return {
      type: this.mapEventType(chunk.type),
      payload: this.transformPayload(chunk),
    }
  }

  // 内部 → Anthropic
  internalToAnthropic(event: InternalEvent): AnthropicChunk {
    return {
      type: this.reverseMap(event.type),
      data: this.reverseTransform(event.payload),
    }
  }
}
```

### 8.2 录制回放

**核心发现**: hermes-agent 支持**事件回放**。

```typescript
// 事件回放
class EventReplay {
  private events: EventLog[] = []

  // 录制
  record(event: EventLog): void {
    this.events.push(event)
  }

  // 回放
  replay(from: number, to: number): EventLog[] {
    return this.events.filter(e => e.timestamp >= from && e.timestamp <= to)
  }
}
```
