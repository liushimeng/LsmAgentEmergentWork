## 四、跨项目共性模式（7大结论）

1. **崩溃恢复标配**：所有工程都有多层防御，claudecode/openclaw/deepseek-harness 都有 3-5 层纵深防御
2. **多租户隔离**：所有工程都实现了 Session 级隔离，openclaw/deepseek-harness 实现了更细粒度的租户隔离
3. **Skill 系统**：所有工程都有 Skill/Hook/Plugin 系统，openclaw 最完善（3000+行）
4. **Turn 锁机制**：所有工程都有某种形式的并发控制，deepseek-harness 的 Agent Inbox 双队列最精妙
5. **HTTP 安全**：所有工程都有 SSRF 防护，openclaw 的 DNS 钉扎+IP 验证最全面
6. **模型路由**：所有工程都支持多 Provider，openclaw 的 Failover 分类器最精细
7. **Pregel 图执行**：仅 deepseek-harness 和 openclaw 有类 Pregel 实现，其余工程未实现
