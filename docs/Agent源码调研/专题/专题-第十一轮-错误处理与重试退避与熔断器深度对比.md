## 二、atomcode：四层防御 + panic hook + circuit-breaker

### 2.1 四层防御

**核心发现**: atomcode 实现**四层错误防御**。

```
Layer 1: panic hook — 捕获 panic，记录堆栈
Layer 2: signal_restore — 恢复信号处理
Layer 3: circuit-breaker — 熔断器，防止级联失败
Layer 4: error report — 错误上报
```

```rust
// panic hook
std::panic::set_hook(Box::new(|info| {
    let backtrace = Backtrace::capture();
    log::error!("Panic: {}\n{}", info, backtrace);
    // 写入崩溃转储
    write_crash_dump(info, backtrace);
}));
```

### 2.2 指数退避

**核心发现**: atomcode 使用**指数退避 + 抖动**。

```rust
// 指数退避
fn exponential_backoff(attempt: u32) -> Duration {
    let base = 2u64.pow(attempt);
    let jitter = rand::random::<u64>() % base;
    Duration::milliseconds((base + jitter) * 100)
}
```

**核心发现**: atomcode 的熔断器有**三态**。

## 四、deepseek-harness：InvariantRegistry + TimeoutPolicy

### 4.1 InvariantRegistry

**核心发现**: deepseek-harness 的 **InvariantRegistry** 注册不变量。

```typescript
// 不变量注册
class InvariantRegistry {
  private invariants: Map<string, Invariant> = new Map()

  register(name: string, invariant: Invariant): void {
    this.invariants.set(name, invariant)
  }

  check(): void {
    for (const [name, invariant] of this.invariants) {
      if (!invariant.check()) {
        throw new InvariantViolationError(name)
      }
    }
  }
}
```
