```typescript
export function matchLocale(input: string) {
  const value = parse(input)
  if (!value) return null
  if (value.startsWith("zh")) {
    if (value.includes("hant") || value.includes("-tw") || value.includes("-hk") || value.includes("-mo"))
      return "zh-tw"
    return "zh-cn"
  }
  if (value in localeAlias) return localeAlias[value as keyof typeof localeAlias]
  if (value.startsWith("pt")) return "pt-br"
  if (value.startsWith("no") || value.startsWith("nb") || value.startsWith("nn")) return "nb"
  return starts.find((item) => value.startsWith(item[0]))?.[1] ?? null
}
```

**范式要点**：
1. **prefix table + zh 特殊判定**（hant / tw / hk / mo → zh-tw）
2. **`localeAlias` 是单一真相源**，避免字符串比较散落

### 6.2 openclaw 范本（`ui/src/i18n/lib/translate.ts:54-74`）

```typescript
async setLocale(locale: Locale) {
  if (locale === this.currentLocale) return;
  if (locale === DEFAULT_LOCALE) {
    // 直接卸载懒加载模块，避免 bundle 持续膨胀
    this.translations = { ...this.translations, [locale]: {} };
  } else {
    const loader = LAZY_LOCALE_REGISTRY[locale as LazyLocale];
    if (!loader) return;
    const mod = await loader();
    this.translations = { ...this.translations, [locale]: mod.default };
  }
  this.currentLocale = locale;
  document.documentElement.lang = locale;
  document.documentElement.dir = (locale === "ar" || locale === "fa") ? "rtl" : "ltr";
  // 持久化 + 通知订阅者
  window.localStorage.setItem("openclaw.i18n.locale", locale);
  this.subscribers.forEach((cb) => cb());
}
```

**范式要点**：
1. **lazy chunk**：非默认 locale 按需 import
2. **RTL 自动切换**：`document.documentElement.dir = "rtl"`
3. **localStorage 持久化**

```typescript
  // 每个非英语 locale 必须是英语超集
  expect(keys.size).toBeGreaterThanOrEqual(reference.size);
}
```

## 17. 结语

9 工程调研后，我们看到 laew 的 i18n 是**从 0 到 1** 而非从 1 到 N：

- **L54 TUI 中文化硬编码** 是 P0（最影响非中文用户体验）。
- **L55 文档双语** 是 P1（README.en.md 是开源项目标配）。
- **L56-L58** 是中长期演进。

**一句话总结**：「**rust-i18n + YML 资源 + parity test**」是 laew i18n 最小落地路径，参考 opencode 的 dict-as-contract 范式。
