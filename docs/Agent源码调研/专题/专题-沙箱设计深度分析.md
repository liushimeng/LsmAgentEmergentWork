## 2. AtomCode：trust 元数据 + WorkerScopeGate + subagent 隔离（Rust）

> 源码根路径：`/usr/local/LsmGitOpenSource/atomcode/`（Rust，约 150k 行）
> 核心理念（`crates/atomcode-kernel/src/tool.rs` 模块文档）：
> ```text
> The kernel is a neutral, embeddable SDK. It does NOT sandbox the tools it hosts.
> MOUNTING a tool GRANTS its execute the host process's full ambient authority.
> ```
> 沙箱是**嵌入者责任**，kernel 仅提供 advisory metadata + composable gate。

### 2.1 进程级隔离：`setsid() + TIOCNOTTY` 三步脱离控制终端

**文件**：`crates/atomcode-capabilities/src/tools/bash.rs:60-85`

```rust
#[cfg(unix)]
unsafe fn detach_child_from_controlling_tty() {
    use std::ffi::c_char;
    extern "C" {
        fn setsid() -> i32;
        fn open(path: *const c_char, oflag: i32, ...) -> i32;
        fn close(fd: i32) -> i32;
        fn ioctl(fd: i32, request: u64, ...) -> i32;
    }
    setsid();
    const O_RDWR: i32 = 2;
    #[cfg(target_os = "macos")]
    const TIOCNOTTY: u64 = 0x20007471;
    #[cfg(not(target_os = "macos"))]
    const TIOCNOTTY: u64 = 0x5422;
    let tty_fd = open(c"/dev/tty".as_ptr(), O_RDWR);
    if tty_fd >= 0 {
        ioctl(tty_fd, TIOCNOTTY);
        close(tty_fd);
    }
}
```

**作用**：
1. `setsid()`：子进程脱离父会话，成为新会话领头
2. `open("/dev/tty")` + `ioctl(TIOCNOTTY)`：macOS `setsid()` 偶尔 `EPERM` 失败时的兜底
3. **同步应用到两条 shell 路径**（`BashTool::execute` 和 `run_shell`），防止「Agent 路径有 setsid，shell 路径没有」的漂移

**非交互环境注入**（`bash.rs:36-44`）：

```rust
fn non_interactive_env_vars() -> &'static [(&'static str, &'static str)] {

        ("TERM", "dumb"),
        ("PAGER", "cat"),
        ("GIT_PAGER", "cat"),

```

### 2.2 工具层沙箱：`Tool` trait 元数据 + 三层 Gate

**文件**：`crates/atomcode-kernel/src/tool.rs`

```rust
pub trait Tool: Send + Sync {
    fn name(&self) -> &str;
    fn description(&self) -> &str;
    fn parameters_schema(&self) -> serde_json::Value;

    // 参数感知风险分级

}
```

### 2.5 Bash 风险分类器

**文件**：`crates/atomcode-capabilities/src/tools/bash.rs`

```rust
fn check_destructive_command(cmd: &str) -> Option<DestructiveMatch> {
    // 检测：特权提升（sudo/su/doas）
    //      递归强删（rm -rf /, find -delete, find | xargs rm）
    //      dd（覆盖块设备）
```

**BashTool 风险返回**（参数感知）：

```rust
fn risk(&self, args: &str) -> RiskLevel {
    match serde_json::from_str::<Args>(args) {
        Ok(a) => {
            if check_destructive_command(&a.command).is_some() {
                RiskLevel::Risky
            } else {
                RiskLevel::Safe
            }
        }
        Err(_) => RiskLevel::Risky,  // 解析失败保守为 Risky
    }
}
```

### 2.6 对 laew 借鉴价值

1. **`setsid() + TIOCNOTTY` 三步**应直接移植到 `src/agent/tools/bash.rs`（约 30 行 Rust）
2. **`TERM=dumb/PAGER=cat/GIT_TERMINAL_PROMPT=0`** 应作为 `Bash` 工具的强制环境注入（防 git 阻塞）
3. **`Tool::risk(&str) -> RiskLevel`** 元数据应加到 `src/agent/tools/mod.rs` 的 `Tool` trait
4. **`WorkerScopeGate`** 是 SubAgent-Work 的写入范围约束（glob + 非重叠验证）范本

```typescript
export async function withFileMutationQueue<T>(env: ExecutionEnv, path: string, fn: () => Promise<T>) {
  const state = getState(env);
  const key = await getMutationQueueKey(env, path);  // canonicalPath 作为 key
  const currentQueue = state.queues.get(key) ?? Promise.resolve();

  await currentQueue;  // 等待前一个操作完成

  } finally {
    releaseNext();  // 释放下一个操作
```

```rust
    setsid();

        const TIOCNOTTY: u64 = 0x20007471;

        ioctl(tty_fd, TIOCNOTTY);
        close(tty_fd);
    }
```

#### 9.1.2 doom_loop 检测（精确重复 3 次）

**目标文件**：`src/agent/subagent.rs`

```rust
//! src/agent/subagent.rs 新增（非完整代码，仅关键部分）

const DOOM_LOOP_THRESHOLD: usize = 3;

#[derive(Debug, Clone)]
pub struct ToolCallRecord {
    pub tool: String,
    pub args: String,  // 标准化后的 JSON 字符串
}

/// 标准化参数（深度 key 排序后 JSON.stringify），确保 {"b":1,"a":2} == {"a":2,"b":1}
fn canonicalize_args(args: &Value) -> String {
    let mut value = args.clone();
    sort_keys(&mut value);  // 递归排序所有 key
    serde_json::to_string(&value).unwrap_or_default()
}

fn sort_keys(v: &mut Value) {
    match v {
        Value::Object(map) => {
            let mut sorted: std::collections::BTreeMap<String, Value> = std::collections::BTreeMap::new();
            for (k, vv) in map.drain() {
                let mut vv = vv;
                sort_keys(&mut vv);
                sorted.insert(k, vv);
            }
            for (k, vv) in sorted {
                map.insert(k, vv);
            }
        }
        Value::Array(arr) => {
            for item in arr.iter_mut() { sort_keys(item); }
        }
        _ => {}
    }
}

/// 检测最近 N 次调用是否精确重复
pub fn detect_doom_loop(history: &VecDeque<ToolCallRecord>) -> bool {
    if history.len() < DOOM_LOOP_THRESHOLD { return false; }
    let last_n: Vec<&ToolCallRecord> = history.iter().rev().take(DOOM_LOOP_THRESHOLD).collect();
    last_n.iter().all(|r| r.tool == last_n[0].tool && r.args == last_n[0].args)
}

// 在 SubAgentRunner::run_unit 主循环中
loop {
    // ... 现有 LLM 调用 + tool 执行逻辑

    let record = ToolCallRecord {
        tool: call.name.clone(),
        args: canonicalize_args(&call.args),
    };
    recent_calls.push_back(record);
    if recent_calls.len() > DOOM_LOOP_THRESHOLD * 2 {
        recent_calls.pop_front();
    }

    if detect_doom_loop(&recent_calls) {
        return Err(SubAgentError::DoomLoopDetected {
            tool: call.name.clone(),
            count: DOOM_LOOP_THRESHOLD,
```

```rust
    pub fn check_bash_command(&self, command: &str) -> Result<()> {
        if check_destructive_command(command).is_some() {
            return Err(AgentError::SandboxViolation {
                tool: "Bash".into(),
                path: command.chars().take(100).collect::<String>(),  // 截断
                work_dir: self.work_dir.display().to_string(),
                temp_dir: self.temp_dir.display().to_string(),
            });

fn check_destructive_command(cmd: &str) -> Option<&'static str> {
    // 1. 特权提升
    if cmd.contains("sudo ") || cmd.contains(" su -") { return Some("privilege-escalation"); }
    // 2. 递归强删
    if cmd.contains("rm -rf /") || cmd.contains("rm -rf ~") { return Some("recursive-delete"); }
    if cmd.contains("find -delete") { return Some("find-delete"); }
    if cmd.contains("find . -exec rm") { return Some("find-exec-rm"); }
    // 3. dd 覆盖块设备
    if cmd.contains("dd if=") && (cmd.contains("of=/dev/") || cmd.contains("of=/proc/")) {
        return Some("dd-block-device");
    }
    // 4. fork bomb
    if cmd.contains(":(){ :|:&};:") || cmd.contains("fork bomb") { return Some("fork-bomb"); }
    // 5. 远程脚本管道到 shell
    if (cmd.contains("curl ") || cmd.contains("wget ")) && (cmd.contains("| bash") || cmd.contains("| sh")) {
        return Some("remote-script-pipe");
    }
    // 6. 写入敏感设备
    if cmd.contains("> /dev/sda") || cmd.contains("> /proc/") || cmd.contains("> /sys/") {
        return Some("device-write");
    }
    None
}
```

#### 9.2.2 ToolRegistry 5 段执行管道

**目标文件**：`src/agent/tools/mod.rs::ToolRegistry`

```rust
//! 5 段执行管道: pre-execute → guard → execute-around → tool-body → post-execute → finalize

pub struct ToolRegistry {
    pub tools: HashMap<String, Arc<dyn Tool>>,
    pub pre_execute_hooks: Vec<Arc<dyn PreExecuteHook>>,
    pub post_execute_hooks: Vec<Arc<dyn PostExecuteHook>>,
    pub max_output_chars: usize,
}

#[async_trait]
pub trait PreExecuteHook: Send + Sync {
    async fn call(&self, tool: &str, args: &Value, ctx: &ToolContext) -> Result<()>;
}

#[async_trait]
pub trait PostExecuteHook: Send + Sync {
    async fn call(&self, tool: &str, args: &Value, result: &mut String, ctx: &ToolContext) -> Result<()>;
}

impl ToolRegistry {
    pub async fn execute_with_hooks(&self, name: &str, args: Value, ctx: &ToolContext) -> Result<String> {
        let tool = self.tools.get(name).ok_or_else(|| AgentError::ToolNotFound { name: name.to_string() })?;

        // 1. pre-execute waterfall
        for hook in &self.pre_execute_hooks {
            hook.call(name, &args, ctx).await?;
        }

        // 2. 工具自己的 before_execute
        tool.before_execute(&args, ctx).await?;

        // 3. tool body（执行 + 超时 + 输出截断）
        let mut result = tokio::time::timeout(
            Duration::from_millis(MAX_TIMEOUT_MS),
            tool.execute(args.clone(), ctx),
        ).await??;

        if result.len() > self.max_output_chars {
            let truncated = &result[..self.max_output_chars];
            result = format!("{}\n...[截断,省略 {} 字符]", truncated, result.len() - self.max_output_chars);
        }

        // 4. 工具自己的 after_execute
        tool.after_execute(&args, &mut result).await?;

        // 5. post-execute waterfall
        for hook in &self.post_execute_hooks {
            hook.call(name, &args, &mut result, ctx).await?;
        }

        Ok(result)
    }
}
```

```rust
use std::collections::HashSet;
use url::Url;

#[derive(Debug, Clone, Default)]
pub struct NetworkAcl {
    pub allowed_domains: HashSet<String>,   // 白名单
    pub denied_domains: HashSet<String>,    // 黑名单
    pub allow_localhost: bool,              // 默认 false
    pub allow_private_ips: bool,            // 默认 false（10.0.0.0/8, 192.168.0.0/16）
}

impl NetworkAcl {
    pub fn check(&self, url: &str) -> Result<()> {
        let parsed = Url::parse(url).map_err(|e| AgentError::NetworkAclViolation { url: url.to_string(), reason: format!("parse error: {}", e) })?;

        // localhost / 私有 IP 检查
        if !self.allow_localhost && parsed.host_str().map_or(false, |h| h == "localhost" || h == "127.0.0.1" || h == "::1") {
            return Err(AgentError::NetworkAclViolation { url: url.to_string(), reason: "localhost denied".into() });
        }

        // 黑名单优先
        if let Some(host) = parsed.host_str() {
            if self.denied_domains.contains(host) {
                return Err(AgentError::NetworkAclViolation { url: url.to_string(), reason: format!("{} in denied list", host) });
            }
            // 白名单（如有）
            if !self.allowed_domains.is_empty() && !self.allowed_domains.contains(host) {
                return Err(AgentError::NetworkAclViolation { url: url.to_string(), reason: format!("{} not in allowed list", host) });
            }
        }

        Ok(())
    }
}
```

```rust
use async_trait::async_trait;
use tokio::process::Command;

const DEFAULT_TIMEOUT_MS: u64 = 120_000;
const MAX_TIMEOUT_MS: u64 = 600_000;
const MAX_OUTPUT_CHARS: usize = 30_000;

pub struct BashTool;

#[async_trait]
impl Tool for BashTool {
    fn name(&self) -> &str { "Bash" }
    fn description(&self) -> &str { /* 未强约束 */ }
    fn parameters(&self) -> Value { /* 手写 JSON Schema */ }

    async fn execute(&self, args: Value) -> Result<String> {
        let command = args["command"].as_str().ok_or(...)?;
        let timeout_ms = args.get("timeout_ms").and_then(|v| v.as_u64()).unwrap_or(DEFAULT_TIMEOUT_MS);

        let mut cmd = Command::new("bash");
        cmd.arg("-c").arg(command);
        // ❌ 无 setsid / TIOCNOTTY / 非交互环境注入
        // ❌ 无 sandbox check
        // ❌ 无参数预处理
        // ❌ 无 timeout via tokio::time::timeout（虽然有 MAX_TIMEOUT_MS 但未生效？）

        let output = cmd.output().await?;
        Ok(format_output(output))
    }
}
```

### A.3 `src/agent/tools/read.rs`（**无路径沙箱**）

```rust
pub struct ReadTool;

#[async_trait]
impl Tool for ReadTool {
    fn name(&self) -> &str { "Read" }
    async fn execute(&self, args: Value) -> Result<String> {
        let path = args["path"].as_str().ok_or(...)?;
        // ❌ 无 sandbox check（可读取 /etc/shadow 等敏感文件）
        let content = tokio::fs::read_to_string(path).await?;
        Ok(content)
    }
}
```

### A.4 整体现状

| 工具 | 沙箱措施 | 缺失 |
|------|---------|------|
| Bash | 仅超时 + 输出截断 | setsid / 危险命令检测 / 注入防御 / 命令审计 |
| Read | 无 | 路径白名单 / 敏感文件保护 |
| Write | `SandboxConfig` 路径白名单 | 风险分级 / 审计日志 |
| Edit | `SandboxConfig` 路径白名单 | 风险分级 / 并发保护 |
| Glob | 无 | 路径白名单 |
| Grep | 无 | 路径白名单 |

**laew 沙箱短板**：仅 Write/Edit 有路径白名单，其余 6 个工具完全裸奔。
