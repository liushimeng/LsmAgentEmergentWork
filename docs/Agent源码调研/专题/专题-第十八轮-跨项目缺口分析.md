## 二、7 工程共性模式（关键发现）

### 模式 1：所有工程都实现的「基础套件」（**6 维共识**）

1. **4 条 token 边界规则**（D1）：`@` 前空白 / 后续无空白 / 路径或 quote 边界 / 延伸至下个空白
2. **YAML frontmatter + Markdown 命令模板**（D2）：`.md` + frontmatter 是 de facto 标准
3. **lazy refresh 或事件总线驱动**（D4）：7 工程无一例外**避免全局 chokidar 监听**
4. **ANSI + BIDI sanitize**（D5）：7 工程都在 sanitize 控制字符
5. **15ms paste-burst coalescing**（D6）：terminal chunked paste 间隙典型 5-10ms
6. **`^H`/`^?` 归一化**（D6）：SSH / `stty erase ^H` 必备

### 模式 2：4+ 工程都实现的「进阶套件」（**4 维共识**）

1. **HistoryEntry 三元组**（D6）：text + images + pastes 分离持久化（解决 paste 召回丢失）
2. **5 档 FilterMode 或同等 tree 视图**（D3）：过滤 toolResult / user-only / labeled-only
3. **commit-or-compensate 所有权 token**（D3）：Rust 风格 API 边界（防止双重回退）
4. **themed syntax highlight + table 列宽**（D5）：marked + shiki 是事实标准

### 模式 3：各工程「独特设计」（**最大差异化**）

### 7.5 推荐 5：**可访问性（Accessibility / a11y）**
