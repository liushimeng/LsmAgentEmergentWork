### 2.2 Tool trait 定义

AtomCode 的 `Tool` trait 是六项目中**元数据最丰富**的：

```rust
// crates/atomcode-kernel/src/tool.rs
#[async_trait]
pub trait Tool: Send + Sync {
    fn name(&self) -> &str;
    fn description(&self) -> &str;
    fn parameters_schema(&self) -> serde_json::Value;

    // 风险分级（参数感知）
    fn risk(&self, _args: &str) -> RiskLevel { RiskLevel::Safe }

    // 只读标记（计划模式用）
    fn read_only_hint(&self) -> bool { false }

    // 自限输出（免截断）
    fn self_bounds_output(&self) -> bool { false }

    // 并行安全（参数感知，默认 = read_only_hint）
    fn parallel_safe(&self, _args: &str) -> bool { self.read_only_hint() }

    // "总是批准"作用域
    fn always_grant_scope(&self, args: &str) -> String { args.to_string() }

    // 策略干预上提
    fn take_policy_intervention(&self, _result: &mut ToolResult) -> Option<PolicyIntervention> { None }

    async fn execute(&self, args: &str, ctx: &ToolContext) -> ToolResult;
}
```

**关键设计点**：
- `risk()` 是**参数感知**的：`bash` 工具可对 `rm -rf` 返回 `Risky`、对 `ls` 返回 `Safe`
- `parallel_safe()` 默认回退到 `read_only_hint()`，实现"只读即可并行"的简洁契约
- `execute` 接收 `&str`（原始 JSON），工具自行解析——这是 laew 当前的策略

### 2.3 ToolRegistry 与挂载机制

AtomCode 采用**两阶段**注册：`register()` 注册到全局池 → `mount(names)` 选择暴露给模型的子集。

```rust
// crates/atomcode-kernel/src/tool.rs
#[derive(Clone, Default)]
pub struct ToolRegistry {
    tools: Arc<RwLock<BTreeMap<String, Arc<dyn Tool>>>>,
}

impl ToolRegistry {
    pub fn register(&mut self, tool: Arc<dyn Tool>) {
        let mut tools = self.tools.write().unwrap();
        tools.insert(tool.name().to_string(), tool);
    }

    // 选择子集暴露给 LLM
    pub fn mount(&self, names: &[&str]) -> MountedTools { ... }

    // 可原子更新的挂载（运行时热替换）
    pub fn mount_updatable(&self, names: &[&str]) -> (MountedTools, MountedToolsPublisher) { ... }
}
```

**`MountedToolsSnapshot`** 是 Agent 一轮使用的不可变快照：

```rust
pub struct MountedToolsSnapshot {
    revision: ToolCatalogRevision,
    selected: BTreeMap<String, Arc<dyn Tool>>,
    defs: Arc<[ToolDef]>,  // 预计算的 ToolDef 数组
}
```

**设计亮点**：
- `BTreeMap` 保证**确定性字典序**，prompt 稳定
- `mount()` 与 `register()` 解耦：注册所有工具，按角色挂载子集
- `mount_updatable()` 支持运行时热替换（如模型切换时 `read_file` 的 vision 标志）

### 2.4 信任模型（Trust Model）

AtomCode 在 `tools/mod.rs` 模块文档中明确声明：

> The kernel is a neutral, embeddable SDK. It does **NOT sandbox** the tools it hosts. MOUNTING a tool GRANTS its `execute` the host process's **full ambient authority**.

- `RiskLevel` 是**纯元数据**，内核不强制执行
- 唯一内置安全机制：`max_tool_result_bytes`（默认 64 KiB），超限截断
- OS 级隔离（seccomp/容器/受限用户）是**嵌入者**的责任

### 3.2 Tool 类型定义

Claude Code 的 `Tool` 是**对象类型**（非 trait），泛型参数化：

```typescript
// src/Tool.ts
export type Tool<
  Input extends AnyObject = AnyObject,
  Output = unknown,
  P extends ToolProgressData = ToolProgressData,
> = {
  readonly name: string
  readonly inputSchema: Input                    // Zod schema
  readonly inputJSONSchema?: ToolInputJSONSchema // MCP 工具可直接用 JSON Schema
  outputSchema?: z.ZodType<unknown>
  aliases?: string[]                             // 向后兼容别名
  searchHint?: string                            // ToolSearch 关键词

  call(args: z.infer<Input>, context: ToolUseContext,
       canUseTool: CanUseToolFn, parentMessage: AssistantMessage,
       onProgress?: ToolCallProgress<P>): Promise<ToolResult<Output>>

  description(input: z.infer<Input>, options: {...}): Promise<string>
  checkPermissions(input: z.infer<Input>, context: ToolUseContext): Promise<PermissionResult>
  validateInput?(input: z.infer<Input>, context: ToolUseContext): Promise<ValidationResult>

  isConcurrencySafe(input: z.infer<Input>): boolean
  isReadOnly(input: z.infer<Input>): boolean
  isDestructive?(input: z.infer<Input>): boolean
  isEnabled(): boolean
  interruptBehavior?(): 'cancel' | 'block'
  maxResultSizeChars: number
  readonly shouldDefer?: boolean     // 延迟加载（需先 ToolSearch）
  readonly alwaysLoad?: boolean      // 永不延迟
}
```

**关键设计点**：
- `inputSchema` 是 **Zod schema**，自动推导 TypeScript 类型和 JSON Schema
- `call()` 是执行入口（非 `execute()`），接收 `canUseTool` 回调做权限检查
- `description()` 是**动态的**，可根据 input 返回不同描述
- `maxResultSizeChars` 控制结果持久化阈值（超限存文件）

```typescript
export function assembleToolPool(
  permissionContext: ToolPermissionContext,
  mcpTools: Tools,
): Tools {
  const builtInTools = getTools(permissionContext)
  const allowedMcpTools = filterToolsByDenyRules(mcpTools, permissionContext)
  // 按名排序（prompt cache 稳定），uniqBy 去重（内置优先）
  return uniqBy(
    [...builtInTools].sort(byName).concat(allowedMcpTools.sort(byName)),
    'name',
  )
}
```

### 4.2 ToolRuntime 与五段式 Pipeline

DeepSeek-Harness 拥有六项目中**最复杂**的工具执行管道：

```
tools/pre-execute  →  guards  →  tools/execute(around)  →  tool body  →  tools/post-execute  →  finalizeContent
```

```typescript
// packages/core/tools/src/index.ts
export class ToolRuntime extends Service {
  register(definition: ToolDefinition): () => void    // 注册工具
  restrict(filter: ToolRestriction): () => void       // 作用域限制
  guard(guard: ToolGuard): () => void                 // 单调守卫
  execute(exec: ToolExecutionInput): Promise<ToolExecutionResult>  // 执行入口

  // 内部调度器
  readonly [TOOL_RUNTIME_SCHEDULER]: ToolRuntimeScheduler = {
    prepare: exec => this.prepareScheduledExecution(exec),
    dispatch: exec => this.dispatchScheduledExecution(exec),
    finalize: (exec, result) => this.finalizeScheduledExecution(exec, result),
    finish: (exec, result) => this.finishScheduledExecution(exec, result),
  }
}
```

**执行流程**：

```typescript
async execute(exec: ToolExecutionInput): Promise<ToolExecutionResult> {
  // 1. createExecution: 创建执行对象，冻结参数
  // 2. prepareExecution: 运行 tools/pre-execute waterfall + guards
  // 3. dispatchScheduledExecution: 运行 tools/execute around + tool body
  // 4. finalizeScheduledExecution: 运行 tools/post-execute + finalizeContent
  // 5. 返回 ToolExecutionResult（成功/失败判别）
}
```

### 4.3 Scoped 分层注册

DeepSeek-Harness 支持**作用域隔离**的工具注册：

```typescript
// packages/core/tools/src/index.ts

  private readonly layers = new ScopedLayers(
    scope => new ToolLayer(scope),

class ToolLayer implements ScopeLayer {
```

**设计亮点**：

- `guard()` 注册单调守卫（返回 string 即拒绝）

### 4.5 PTC 模式（Program-Then-Code）

DeepSeek-Harness 独有的 **PTC 折叠**：

```typescript
export type ToolPresentationMode = 'native' | 'ptc' | 'both'
```

- `native`：所有工具直接暴露
- `ptc`：仅暴露 `run_code`，其他工具通过 SDK 子调度调用
- `both`：两种形式都发送

```typescript
private collapses(name: string, scope: ScopeKey | undefined, nested: boolean): boolean {
  return !nested && this.modeFor(scope) === 'ptc' && name !== RUN_CODE_NAME

```

### 4.6 并行调度

```typescript
export type ToolExecutionMode =
  | { kind: 'parallel' }     // 可与兄弟并发
  | { kind: 'exclusive' }    // 独占运行，形成屏障

executionMode(exec: ToolExecutionInput): ToolExecutionMode {
  const tool = this.resolveExecution(exec.name, exec.agent, exec.parent !== undefined)
  if (!tool?.isConcurrencySafe) return { kind: 'exclusive' }
  const concurrencySafe: unknown = tool.isConcurrencySafe(exec.arguments)
  return concurrencySafe === true ? { kind: 'parallel' } : { kind: 'exclusive' }
}
```

**`wrap()`** 是核心包装函数：

```typescript
function wrap<Parameters extends Schema.Decoder<unknown>, Result extends Metadata>(
  id: string,
  init: Init<Parameters, Result>,
  truncate: Truncate.Interface,
  agents: Agent.Interface,
) {
  return () => Effect.gen(function* () {
    const toolInfo = typeof init === "function" ? { ...(yield* init()) } : { ...init }
    const decode = Schema.decodeUnknownEffect(toolInfo.parameters)  // 编译一次
    const execute = toolInfo.execute
    toolInfo.execute = (args, ctx) => Effect.gen(function* () {
      const decoded = yield* decode(args).pipe(
        Effect.mapError((error) => new InvalidArgumentsError({ tool: id, detail: ... })),
      )
      const result = yield* execute(decoded, ctx)
      // 截断处理
      const truncated = yield* truncate.output(result.output, {}, agent)
      return { ...result, output: truncated.content, metadata: { ... } }
    }).pipe(Effect.orDie, Effect.withSpan("Tool.execute", { attributes: attrs }))
    return toolInfo
  })
}
```

**设计亮点**：
- `decode` 编译一次，避免每次调用重新创建闭包
- `InvalidArgumentsError` 是 tagged error，可被上游匹配
- 自动截断（`truncate.output`）

## 8. 设计模式提炼

### 8.1 模式一：注册表分离（Register vs Mount）

| 项目 | 模式 | 说明 |
|------|------|------|
| AtomCode | 两阶段 | `register()` 全局池 → `mount(names)` 暴露子集 |
| DeepSeek-Harness | Scoped 分层 | 全局层 + 作用域链，子可遮蔽 |
| OpenCode | builtin + custom | 内置工具 + 插件工具拼接 |
| laew | 多注册表 | `builtin_registry` / `yolo_registry` / `plan_registry` 等 |

**对 laew 启示**：当前 laew 的多注册表模式与 AtomCode 的 mount 异曲同工。可引入"挂载"语义，让同一注册表按角色暴露不同子集。

### 8.2 模式二：执行管道（Pipeline）

| 项目 | 管道段数 | 关键扩展点 |
|------|---------|-----------|
| DeepSeek-Harness | 5 段 | pre-execute → guards → execute(around) → body → post-execute |
| Claude Code | 3 段 | PreToolUse → call → PostToolUse |
| OpenClaw | 2 段 | beforeHook → execute |
| OpenCode | 2 段 | decode → execute |
| laew | 1 段 | execute |

**对 laew 启示**：当前 laew 是单段执行。可引入 before/after 钩子，为 QC Agent 的自动质检提供拦截点。

### 8.3 模式三：权限拦截光谱

| 级别 | 项目 | 机制 |
|------|------|------|
| 0 - 无 | AtomCode（内核） | 仅元数据 |
| 1 - 采样约束 | Pi | `constrainedSampling` |
| 2 - 路径拦截 | laew | `SandboxConfig` |
| 3 - Ruleset | OpenCode | `Permission.evaluate()` |
| 4 - Hook | Claude Code | 27 种 Hook |
| 5 - Waterfall | DeepSeek-Harness | 5 段 waterfall |

**对 laew 启示**：当前 laew 是级别 2（路径拦截）。可升级到级别 3（Ruleset），为多 Agent 架构提供细粒度权限。

### 8.4 模式四：Schema 生成策略

| 策略 | 项目 | 优劣 |
|------|------|------|
| 手写 JSON Schema | AtomCode/DeepSeek/Pi/laew | 灵活但易出错 |
| Zod 自动推导 | Claude Code | 类型安全，TS 友好 |
| Effect Schema | OpenCode | 运行时 + 编译时双重保障 |

**对 laew 启示**：Rust 生态可用 `schemars` 派生 JSON Schema，或保持手写但增加校验。

### 8.5 模式五：并行安全分类

| 项目 | 机制 |
|------|------|
| AtomCode | `parallel_safe(args)` 参数感知 |
| DeepSeek-Harness | `isConcurrencySafe(args)` + `executionMode` |
| Claude Code | `isConcurrencySafe(input)` |
| laew | 无（串行） |

**对 laew 启示**：当前串行执行。可引入 `is_read_only()` 标记，让 Read/Glob/Grep 并行。

### 8.6 模式六：结果处理

| 项目 | 机制 |
|------|------|
| AtomCode | `max_tool_result_bytes` 截断 |
| Claude Code | `maxResultSizeChars` + 存文件 |
| OpenCode | `truncate.output()` |
| DeepSeek-Harness | `spillPath` 溢出存储 |
| laew | `MAX_OUTPUT_CHARS` 截断（Bash） |

```rust
impl ToolRegistry {
```

```rust
    }

    /// 执行工具（带统一截断）
    pub async fn execute(&self, name: &str, args: Value, ctx: &ToolContext) -> Result<String> {
        let tool = self.get(name)?;
        let output = tool.execute(args, ctx).await?;
        if output.len() > self.max_output_chars {
            let truncated = &output[..self.max_output_chars];
            Ok(format!("{}\n...[截断,省略 {} 字符]", truncated, output.len() - self.max_output_chars))
        } else {

        }
    }
```

### C.3 并行执行（P2）

```rust
// src/agent/mod.rs
async fn execute_tools_parallel(&self, calls: Vec<ToolCallReq>) -> Vec<(String, String, bool)> {
    let mut results: Vec<(String, String, bool)> = vec![(String::new(), String::new(), false); calls.len()];

    // 分类
    let mut read_only_indices = vec![];
    let mut write_indices = vec![];
    for (i, call) in calls.iter().enumerate() {
        if self.profile.tools.get(&call.name).map(|t| t.is_read_only()).unwrap_or(false) {
            read_only_indices.push(i);
        } else {
            write_indices.push(i);
        }
    }

    // 并行执行只读
    let ro_futures: Vec<_> = read_only_indices.iter().map(|&i| {
        let call = &calls[i];
        async move {
            let result = self.execute_single_tool(call).await;
            (i, result)
        }
    }).collect();
    for (i, result) in futures::future::join_all(ro_futures).await {
        results[i] = result;
    }

    // 串行执行写
    for &i in &write_indices {
        results[i] = self.execute_single_tool(&calls[i]).await;
    }

    results
}
```

### C.4 权限 Ruleset（P2）

```rust
// src/agent/tools/permission.rs
#[derive(Debug, Clone)]
pub enum PermissionAction {
    Allow,
    Deny,
    Ask,
}

#[derive(Debug, Clone)]
pub struct PermissionRule {
    pub tool: String,           // 支持通配符 "Bash*" / "*"
    pub action: PermissionAction,
    pub pattern: Option<String>, // JSON Path 模式
}

pub fn evaluate(tool: &str, args: &Value, rules: &[PermissionRule]) -> PermissionAction {
    for rule in rules.iter().rev() {  // 后匹配优先
        if wildcard_match(tool, &rule.tool) {
            if let Some(ref pattern) = rule.pattern {
                if !evaluate_pattern(args, pattern) {
                    continue;
                }
            }
            return rule.action.clone();
        }
    }
    PermissionAction::Allow  // 默认允许
}
```
