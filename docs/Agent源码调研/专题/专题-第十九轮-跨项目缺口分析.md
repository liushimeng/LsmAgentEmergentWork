## 三、6 大维度共性模式提炼

### 模式 1：多层防御（Defense in Depth）

所有工程在 D9 安全维度都采用多层防御：
- **应用层**：Prompt 注入检测 + Bash 检测 + 输入校验
- **进程层**：Landlock + Seccomp + cgroup + 进程树管理
- **网络层**：DNS pinning + SSRF 防护 + TLS 钉扎
- **数据层**：AES-256-GCM 加密 + Keychain/DPAPI 凭证管理

### 模式 2：双栈渲染（Dual Stack Rendering）

D10 多模态输出维度，主流工程都采用双栈：
- **Web 端**：原生 HTML/CSS/JS + Web Components + Canvas/SVG
- **TUI 端**：ANSI 转义 + 终端协议（iTerm2/sixel/kitty）+ 自研渲染

### 模式 3：协议 IR + 翻译层（Protocol IR + Translation）

D11 A2A 维度，主流工程都采用协议 IR：
- **内部 IR**：统一消息模型（ContentBlock / ToolCall / ToolResult）
- **翻译层**：协议差异封闭在翻译层（Anthropic / OpenAI / A2A / MCP）
- **服务发现**：Agent 注册表 + 健康检查 + 故障转移

### 模式 4：渐进增强（Progressive Enhancement）

D12 可访问性维度，主流工程都采用渐进增强：
- **基础层**：键盘可达 + 高对比度主题
- **增强层**：RTL 布局 + 屏幕阅读器 + 减动效
- **高级层**：盲文 + 多模态提示 + 自定义字号

### 模式 5：离线优先（Offline First）

D13 离线模式维度，主流工程都采用离线优先：
- **检测层**：navigator.onLine + heartbeat ping
- **队列层**：请求队列 + 指数退避 + 熔断器
- **缓存层**：本地缓存 + Write-Behind 一致性
- **同步层**：CRDT + 事件溯源 + 冲突合并

### 模式 6：端到端加密（E2E Encryption）

D14 跨设备同步维度，主流工程都采用端到端加密：
- **设备层**：设备指纹 + 配对 + Tailscale
- **传输层**：TLS + mTLS + 证书钉扎
- **数据层**：AES-256-GCM + HKDF + AAD
- **应用层**：CSP + OG/Twitter Card
