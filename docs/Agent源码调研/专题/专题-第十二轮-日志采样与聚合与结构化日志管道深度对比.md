## 2. 采样策略

### 2.1 五种采样模式

| 模式 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **头部采样** | 高吞吐、调试期 | 实时、覆盖广 | 偶发错误可能漏掉 |
| **尾部采样** | 生产环境 | 保留错误 | 需要临时缓冲 |
| **速率采样** | 中等吞吐 | 简单 | 不可预测 |
| **自适应采样** | 复杂场景 | 智能调节 | 实现复杂 |
| **错误全采** | 关键场景 | 不漏错误 | 错误率高时压力大 |

### 2.2 各工程的实现

#### atomcode — 头部采样 + 错误全采

```rust
// atomcode 的采样策略
pub struct SamplingConfig {
    pub info_rate: f64,      // 0.0-1.0
    pub warn_rate: f64,
    pub error_rate: f64,     // 通常为 1.0
    pub debug_rate: f64,
}

impl Default for SamplingConfig {
    fn default() -> Self {
        Self {
            info_rate: 0.1,
            warn_rate: 0.5,
            error_rate: 1.0,  // error 全采
            debug_rate: 0.01,
        }
    }
}

// 决策
pub fn should_sample(level: Level, config: &SamplingConfig, ctx: &SamplingCtx) -> bool {
    // 1. 错误永远全采
    if level == Level::ERROR { return true; }

    // 2. 决策审计永远全采
    if ctx.is_decision_audit { return true; }

    // 3. 特定用户/会话追踪全采
    if ctx.is_traced_user { return true; }

    // 4. 概率采样
    let rate = match level {
        Level::INFO => config.info_rate,
        Level::WARN => config.warn_rate,
        Level::DEBUG => config.debug_rate,
        _ => 1.0,
    };
    rand::random::<f64>() < rate
}
```

### 3.2 atomcode 的 telemetry 队列

**核心源码**：

- `atomcode-telemetry/src/runtime.rs`（后台 runtime）
- `atomcode-telemetry/src/sender/`（OTLP/HTTP 发送）

```rust
// 后台 runtime 处理日志事件
pub struct TelemetryRuntime {
    tx: mpsc::Sender<TelemetryEvent>,
    rt: tokio::runtime::Runtime,
}

impl TelemetryRuntime {
    pub fn spawn(config: TelemetryConfig) -> Self {
        let (tx, mut rx) = mpsc::channel::<TelemetryEvent>(32_000);

        let rt = tokio::runtime::Builder::new_multi_thread()
            .worker_threads(2)
            .enable_all()
            .thread_name("atomcode-telemetry")
            .build()
            .unwrap();

        rt.spawn(async move {
            // 批处理
            let mut batch = Vec::with_capacity(100);
            let mut flush_interval = tokio::time::interval(Duration::from_secs(5));

            loop {
                tokio::select! {
                    Some(event) = rx.recv() => {
                        batch.push(event);
                        if batch.len() >= 100 {
                            flush(&mut batch).await;
                        }
                    }
                    _ = flush_interval.tick() => {
                        if !batch.is_empty() {
                            flush(&mut batch).await;
                        }
                    }
                }
            }
        });

        Self { tx, rt }
    }
}
```

### 3.3 背压处理

当消费者处理不过来时的策略：

```rust
// 策略 1: 丢弃最旧（FIFO 满时丢头）
let policy_drop_oldest = mpsc::Sender::channel(32_000);

// 策略 2: 阻塞（最简单，但影响业务）
let policy_block = mpsc::channel(32_000);

// 策略 3: 采样降级（保留所有错误，降级 info）
async fn adaptive_log(rx: &mut Receiver<Event>) {
    let mut sampling_rate = 1.0;
    while let Some(event) = rx.recv().await {
        // 当队列占用 > 80% 时降级
        if rx.capacity() < rx.max_capacity() / 5 {
            sampling_rate *= 0.5;
        }
        if event.level == ERROR || rand::random::<f64>() < sampling_rate {
            emit(event);
        }
    }
}
```

### 12.2 src/logging/mod.rs

```rust
use tracing_subscriber::{
    fmt, prelude::*, EnvFilter, Registry,
};
use tracing_appender::{non_blocking, rolling::{daily, Rotation}};
use tracing_bunyan_formatter::{BunyanFormattingLayer, JsonStorageLayer};
use std::path::Path;

pub fn init(home: &Path) -> Result<()> {
    let log_dir = home.join("logs");
    std::fs::create_dir_all(&log_dir)?;

    // 文件输出：按天轮转
    let file_appender = rolling::daily(&log_dir, "laew.log");
    let (file_writer, _guard) = non_blocking(file_appender);

    // 控制台输出：彩色
    let stdout_layer = fmt::layer()
        .with_writer(std::io::stdout)
        .with_target(true)
        .with_level(true)
        .compact();

    // 文件输出：JSONL
    let file_layer = BunyanFormattingLayer::new(
        "laew".to_string(),
        file_writer,
    );

    // 日志级别
    let filter = EnvFilter::try_from_default_env()
        .unwrap_or_else(|_| EnvFilter::new("info"));

    // 组装
    let subscriber = Registry::default()
        .with(filter)
        .with(stdout_layer)
        .with(JsonStorageLayer)
        .with(file_layer);

    tracing::subscriber::set_global_default(subscriber)?;
    Ok(())
}

pub mod scrub {
    use once_cell::sync::Lazy;
    use regex::Regex;

    static API_KEY: Lazy<Regex> = Lazy::new(|| {
        Regex::new(r"\b(sk-|gsk_|ghp_|xai-)[A-Za-z0-9_\-]{16,}\b").unwrap()
    });

    pub fn redact(s: &str) -> String {
        API_KEY.replace_all(s, "${1}<REDACTED>").into_owned()
    }
}
```

### 12.3 使用

```rust
use tracing::{info, warn, error, instrument};

#[instrument(skip(args), fields(tool = "bash", args_len = args.len()))]
async fn execute_bash(args: &str) -> Result<String> {
    info!("executing bash command");
    let result = tokio::process::Command::new("bash")
        .arg("-c")
        .arg(args)
        .output()
        .await?;

    if !result.status.success() {
        warn!(exit_code = ?result.status.code(), "command failed");
    }

    info!(
        exit_code = ?result.status.code(),
        stdout_len = result.stdout.len(),
        "command executed"
    );
    Ok(String::from_utf8_lossy(&result.stdout).into_owned())
}
```
