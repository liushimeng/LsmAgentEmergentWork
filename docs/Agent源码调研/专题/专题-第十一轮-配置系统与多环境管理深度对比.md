## 2. 配置发现链（8 层）横向对比

### 2.1 8 层配置发现链定义

```
Layer 1: CLI flags          — 命令行参数（最高优先级）
Layer 2: Environment        — 环境变量
Layer 3: Workspace          — 工作区配置（项目级）
Layer 4: User               — 用户级配置（~/.config/）
Layer 5: System             — 系统级配置（/etc/）
Layer 6: Default            — 代码内硬编码默认值
Layer 7: Builtin            — 编译期内置预设
Layer 8: Remote             — 远程配置中心（最低优先级）
```

### 2.3 关键发现

1. **atomcode 和 claudecode 实现了完整的 8 层发现链**，是所有工程中配置发现最完善的
2. **Switchyard 和 undici 仅有 3 层**，但这是有意为之（网关/库的定位决定）
3. **hermes-agent 独有 Layer 5 System（/etc/hermes）+ Layer 8 外部密钥源（Bitwarden/1Password）**
4. **agent-core 和 jiuwenswarm 仅 4 层**，主要依赖 CLI + env + 配置文件 + 默认值
5. **远程配置中心（Layer 8）** 仅 atomcode、claudecode、openclaw、opencode、TencentDB-Agent-Memory 支持

pub fn resolved_api_key(&self) -> Option<String> {
    if let Some(key_str) = self.api_key.as_deref() {
        let trimmed = key_str.trim();
        if !trimmed.is_empty() {
            if trimmed.contains('$') {
                return Some(expand_env_vars(trimmed));  // 1. $VAR / ${VAR:-default}
            } else if let Ok(env_val) = std::env::var(trimmed) {
                return Some(env_val);                    // 2. env var 名
            } else {
                return Some(trimmed.to_string());        // 3. 字面量
            }
        }
    }
    // 4. 协议特定 env（OPENAI_API_KEY / ANTHROPIC_API_KEY）
    // 5. 全局回退 ATOMCODE_API_KEY
}

### 5.4 RFC 7396 Merge Patch（openclaw）

**openclaw 的 RFC 7396 Merge Patch**:
```typescript
export function applyMergePatch(base, patch, options = {}): unknown {
  if (!isPlainObject(patch)) return patch;
  const result = isPlainObject(base) ? { ...base } : {};
  for (const [key, value] of Object.entries(patch)) {
    if (!isMergePatchObjectKeyAllowed(key, options.path)) continue;
    if (value === null) { delete result[key]; continue; }  // null = 删除
    if (options.mergeObjectArraysById && Array.isArray(result[key]) && Array.isArray(value)) {
      const mergedArray = mergeObjectArraysById(result[key], value, options, path);
      if (mergedArray) { result[key] = mergedArray; continue; }  // id 键合合并
    }
    if (isPlainObject(value)) {
      result[key] = applyMergePatch(isPlainObject(result[key]) ? result[key] : {}, value, { ...options, path });
      continue;
    }
    result[key] = value;
  }
  return result;
}
```

### 17.3 最终结论

本轮调研覆盖 15 个源码工程的配置系统与多环境管理机制，从 12 个维度深度分析各项目的配置发现链、优先级模型、安全隔离、ApplyPolicy、Schema 校验、dotenv 加载、多环境切换、workspace 继承、远程配置中心、变更监听、配置回滚和配置测试机制。

**核心结论**：

1. **atomcode 和 claudecode 是配置系统的最佳实践**：8 层发现链 + 5 源优先级 + 完善的安全隔离 + ApplyPolicy + Schema 校验 + Hot Reload + 配置回滚
2. **Switchyard 和 undici 是"有意简化"的典范**：单文件/构造函数选项，适合网关/库的定位
3. **laew 当前配置系统是 PoC 级别**：单一 SQLite 存储，无发现链、无优先级、无安全隔离、无 Schema 校验、无 Hot Reload、无配置回滚
4. **升级路径清晰**：P0（API Key 加密/原子写入/Schema 校验/跨进程安全/配置回滚）→ P1（8 层发现链/dotenv/多环境/Workspace 继承/Hot Reload）→ P2（远程配置/审计日志/配置测试/配置签名）
5. **Rust crate 生态完善**：config-rs/figment/dotenvy/serde_yaml/notify/fs2/aes-gcm/keyring/schemars/jsonschema 等 crate 可直接使用

impl ProviderConfig {
    /// Resolve the API key for this provider.
    ///
    /// Resolution order:
    /// 1. Literal `$VAR` / `${VAR:-default}` in the `api_key` field
    /// 2. The `api_key` field value taken as an environment variable name
    /// 3. The literal `api_key` field value
    /// 4. Provider-type-specific env vars (OPENAI_API_KEY, ANTHROPIC_API_KEY, OLLAMA_API_KEY)
    /// 5. Global fallback `ATOMCODE_API_KEY`
    pub fn resolved_api_key(&self) -> Option<String> {
        if let Some(key_str) = self.api_key.as_deref() {
            let trimmed = key_str.trim();
            if !trimmed.is_empty() {
                if trimmed.contains('$') {
                    // 1. $VAR / ${VAR:-default} expansion
                    return Some(expand_env_vars(trimmed));
                } else if let Ok(env_val) = std::env::var(trimmed) {
                    // 2. env var name resolution
                    return Some(env_val);
                } else {
                    // 3. literal value
                    return Some(trimmed.to_string());
                }
            }
        }
        // 4. protocol-specific env vars
        let env_var = match self.provider_type.as_str() {
            "openai" => "OPENAI_API_KEY",
            "anthropic" => "ANTHROPIC_API_KEY",
            "ollama" => "OLLAMA_API_KEY",
            _ => return None,
        };
        if let Ok(val) = std::env::var(env_var) {
            return Some(val);
        }
        // 5. global fallback
        if let Ok(val) = std::env::var("ATOMCODE_API_KEY") {
            return Some(val);
        }
        None
    }
}

pub struct ConfigRevision(String);

impl ConfigRevision {
    fn from_bytes(bytes: &[u8]) -> Self {
        let digest = Sha256::digest(bytes);
        Self(format!("{digest:x}"))
    }
}

/// A snapshot of the config at a particular revision.
pub struct ConfigSnapshot {
    pub config: Config,
    pub revision: ConfigRevision,
}

/// A commit that updated the config from one revision to another.
pub struct ConfigCommit {
    pub snapshot: ConfigSnapshot,
}

impl ConfigStore {
    /// Apply a delta only when the file still has `expected_revision`.
    pub fn update_if_revision<F>(
        &self,
        expected_revision: &ConfigRevision,
        mutate: F,
    ) -> Result<Option<ConfigCommit>>
    where
        F: FnOnce(&mut Config) -> Result<()>,
    {
        self.with_lock(false, |disk| {
            if &disk.revision != expected_revision {
                return Ok(None);  // 已被其他进程修改，放弃
            }
            let mut next = disk.config.clone();
            mutate(&mut next)?;
            let snapshot = self.persist_locked(&next, Some(&disk.config))?;
            Ok(Some(ConfigCommit { snapshot }))
        })
    }
    
    /// Restore an exact TOML document only if no process has changed the file
    /// since `expected_revision`. Intended for compensating a successful disk
    /// commit whose runtime application subsequently failed.
    pub fn replace_document_if_revision(
        &self,
        expected_revision: &ConfigRevision,
        content: &str,
    ) -> Result<Option<ConfigCommit>> {
        self.with_lock(false, |disk| {
            if &disk.revision != expected_revision {
                return Ok(None);  // 修订号不匹配，拒绝覆盖
            }
            let snapshot = self.persist_document_locked(content)?;
            Ok(Some(ConfigCommit { snapshot }))
        })
    }

/// Atomically replace a file's contents via tempfile + fsync + rename + dir sync.
fn atomic_replace(path: &Path, bytes: &[u8]) -> Result<()> {
    let parent = path.parent().unwrap_or_else(|| Path::new("."));
    // 1. 创建临时文件
    let mut temp = tempfile::NamedTempFile::new_in(parent)?;
    // 2. 写入内容
    temp.write_all(bytes)?;
    // 3. fsync 临时文件
    temp.as_file().sync_all()?;
    // 4. 原子 rename
    temp.persist(path)?;
    // 5. fsync 目录项
    #[cfg(unix)]
    File::open(parent).and_then(|d| d.sync_all())?;
    Ok(())
}

    if (Array.isArray(objValue) && Array.isArray(srcValue)) {

    return undefined;  // 让 lodash 默认 deep merge

    settings: SettingsJson,

        if (srcValue === undefined && object && typeof key === 'string') {
            delete object[key];
            return undefined;

        if (Array.isArray(srcValue)) return srcValue;

/**
 * Walk a value according to a schema, stripping fields marked role('secret').
 * Returns the stripped value and a list of secrets found.
 */
export function redactSecrets(schema: z<never>, value: unknown): RedactedValue {
    const secrets: RedactedSecret[] = [];
    const stripped = walk(schema, value, [], secrets);
    return { value: stripped, secrets };
}

function walk(
    node: SchemaNode | undefined,
    value: unknown,
    path: string[],
    secrets: RedactedSecret[],
): unknown {
    if (node === undefined) return value;
    
    // 摘除敏感字段，不传过 wire
    if (node.meta?.role === 'secret') {
        secrets.push({ path, set: value !== undefined });
        return undefined;  // 摘除
    }
    
    // 递归 object/dict/array
    if (node.type === 'object' && typeof value === 'object' && value !== null) {
        const result: Record<string, unknown> = {};
        for (const [key, child] of Object.entries(node.children)) {
            if (key in (value as Record<string, unknown>)) {
                result[key] = walk(child, (value as Record<string, unknown>)[key], [...path, key], secrets);
            }
        }
        return result;
    }
    
    if (node.type === 'array' && Array.isArray(value)) {
        return value.map((item, i) => walk(node.child, item, [...path, `[${i}]`], secrets));
    }
    
    return value;
}

// src/config/merge-patch.ts

export function applyMergePatch(base: unknown, patch: unknown, options = {}): unknown {
    if (!isPlainObject(patch)) return patch;
    const result = isPlainObject(base) ? { ...base } : {};
    
    for (const [key, value] of Object.entries(patch)) {
        if (!isMergePatchObjectKeyAllowed(key, options.path)) continue;
        
        // null = 删除
        if (value === null) { delete result[key]; continue; }
        
        // 数组按 id 合并
        if (options.mergeObjectArraysById && Array.isArray(result[key]) && Array.isArray(value)) {
            const mergedArray = mergeObjectArraysById(result[key], value, options, path);
            if (mergedArray) { result[key] = mergedArray; continue; }
        }
        
        // 对象递归合并
        if (isPlainObject(value)) {
            result[key] = applyMergePatch(isPlainObject(result[key]) ? result[key] : {}, value, { ...options, path });
            continue;
        }
        
        // 标量直接覆盖
        result[key] = value;
    }
    
    return result;
}

// 数组按 id 合并
function mergeObjectArraysById(base: unknown[], patch: unknown[], options: MergePatchOptions, arrayPath: string): unknown[] | undefined {
    if (!base.every(isObjectWithStringId)) return undefined;  // 回退到替换
    const merged = [...base];
    const indexById = new Map<string, number>();
    for (const [index, entry] of merged.entries()) indexById.set(entry.id, index);
    
    for (const patchEntry of patch) {
        const existingIndex = indexById.get(patchEntry.id);
        if (existingIndex === undefined) { merged.push(structuredClone(patchEntry)); continue; }
        merged[existingIndex] = applyMergePatch(merged[existingIndex], patchEntry, { ...options });
    }
    
    return merged;
}
