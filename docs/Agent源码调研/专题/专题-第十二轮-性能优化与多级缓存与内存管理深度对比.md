### 0.2 关键发现（横向抽象）

1. **三种缓存淘汰哲学**：atomcode/claudecode 走 **TTL + 版本号失效**（per-item）；openclaw/opencode 走 **LRU + 容量上限**（per-pool）；pi/TencentDB 走 **TTL + 自适应读者计数**（per-actor）。
2. **三种并发原语**：atomcode 用 std `Mutex` + `fs2` 跨进程；claudecode 用 `Promise.all` + identity guard；pi/openclaw/TencentDB 用 **手写 promise-chain mutex**（最轻量并发控制）。

5. **三种 SQLite 调优**：opencode 6 PRAGMA（标准）、pi 3 PRAGMA（WAL+FULL+busy_timeout）、TencentDB 5 PRAGMA（+64MB cache + 128MB mmap + autocheckpoint）。

```ts
type Sink = { buf: Buffer; len: number; cap: number }
function sinkWrite(s: Sink, src: Buffer, start: number, end: number): void {
  const n = end - start
  if (n <= 0) return
  if (s.len + n > s.buf.length) {
    const grown = Buffer.allocUnsafe(
      Math.min(Math.max(s.buf.length * 2, s.len + n), s.cap),  // 2x 扩容
    )
    s.buf.copy(grown, 0, 0, s.len)
    s.buf = grown
  }
  src.copy(s.buf, s.len, start, end)
  s.len += n
}
```

```ts
class CborWriter {
  private buffer: Uint8Array;
  private offset = 0;
  private readonly maxByteLength: number;

  constructor(maxByteLength: number) {
    this.maxByteLength = maxByteLength;
    this.buffer = new Uint8Array(Math.min(256, maxByteLength));  // 初始 256 字节
  }

  private ensureCapacity(additionalBytes: number): void {
    const required = this.offset + additionalBytes;
    if (required > this.maxByteLength) throw new CborError(...);
    if (required <= this.buffer.byteLength) return;
    let capacity = Math.max(1, this.buffer.byteLength);
    while (capacity < required) capacity = Math.min(this.maxByteLength, Math.max(required, capacity * 2));  // 2x 扩容
    const expanded = new Uint8Array(capacity);
    expanded.set(this.buffer);  // 复用已有 buffer
    this.buffer = expanded;
  }
}
```

```ts
export class WorkerPermitPool {
  readonly capacity: number;
  private _inFlight = 0;
  private readonly waiters: Array<{
    resolve: () => void;
    reject: (err: Error) => void;
  }> = [];

  acquire(): Promise<void> {
    if (this.destroyed) return Promise.reject(...);
    if (this._inFlight < this.capacity) {
      this._inFlight++;
      return Promise.resolve();
    }
    return new Promise<void>((resolve, reject) => {
      this.waiters.push({ resolve, reject });
    });
  }

  release(): void {
    if (this._inFlight <= 0 && this.waiters.length === 0) {
      throw new Error("release() called with no in-flight permit (unbalanced)");  // 主动暴露 bug
    }
    const next = this.waiters.shift();
    if (next) next.resolve();  // FIFO 唤醒
    else this._inFlight--;
  }
}
```

```ts
async function withSessionMutex<T>(sessionKey: string, fn: () => Promise<T>): Promise<T> {
  const prev = pendingMutexes.get(sessionKey) ?? Promise.resolve();
  let resolve!: () => void;
  const next = new Promise<void>((r) => { resolve = r; });
  pendingMutexes.set(sessionKey, next);

  try {
    await prev;
    return await fn();

      pendingMutexes.delete(sessionKey);
    }
  }
}
```

```ts
  cache.statements.delete(sql); cache.statements.set(sql, cached);  // touch LRU

} else {
  statement = db.prepare(sql);
  if (!cached && cache.candidates.delete(sql)) {  // 候选人晋升
    cache.statements.set(sql, statement);
    pruneMapToMaxSize(cache.statements, statementCacheCapacity);
  } else if (!cached) {
    cache.candidates.add(sql);
    if (cache.candidates.size > statementCacheCapacity) {

  }
}
```

```rust
type FileReadCache = moka::future::Cache<PathBuf, (String, Instant)>;

async fn read_with_cache(path: &Path) -> Result<String> {
    if let Some((content, ts)) = cache.get(path).await {
        let mtime = fs::metadata(path)?.modified()?;
        if mtime == ts { return Ok(content); }
    }
    let content = fs::read_to_string(path).await?;
    cache.insert(path.to_path_buf(), (content.clone(), fs::metadata(path)?.modified()?)).await;
    Ok(content)
}
```

## 15. 关键模式总结

### 15.1 10 个最值得借鉴的设计模式

1. **内容寻址 artifact + sha256 修订号**（atomcode）—— 用 sha256 而非 mtime，让"信任内容"做实。
2. **`_CACHED_MAY_BE_STALE` 命名约定**（claudecode）—— 强制提醒调用方值可能 stale，避免误用。
3. **LRU-with-pinning 三态保护**（openclaw DatabaseSync）—— `isTransaction || borrowers.size || incognito.has` 三态 pinning。
4. **Scope-driven eviction 替代 LRU**（opencode InstanceState）—— 业务实例销毁时自动 invalidate，无需显式 LRU。
5. **Lane 三态并发 + LaneBusy 单写者**（pi）—— `running / suspended / aborting` 三态 + SQL 原生 UPDATE 抢占。
6. **Writer Lease + Fence 乐观锁**（pi）—— fence 单调递增 + 30s TTL + 10s 心跳，比悲观锁高效。
7. **PipelineWorker 60 协程 + 锁冲突指数退避**（TencentDB）—— 200 → 600 → 1800 → 5000ms 阶梯退避。
8. **RRF over-retrieve ×3 客户端融合**（TencentDB）—— 先取 `limit * 3` 候选，融合后用 RRF 重排，再二次过滤。
9. **ESM Resolve Fast Path**（openclaw）—— `Module.registerHooks` 拦截 dist 内相对导入，省秒级冷启动。
10. **Kysely-on-SQLite Prepared Statement 候选人晋升模式**（openclaw）—— 首条 SQL 仅入 `candidates`，第二次出现才升级。

### 15.2 5 个反模式警示

1. **❌ 全局 LRU Map 无显式容量上限**（opencode `tool/edit.ts:32-39`）—— 长生命周期下 Map 无限增长（已在第七轮识别为风险）。
2. **❌ 一律 HTTP/2 启用**（undici 8 默认）—— openclaw 强制 `HTTP/1.1` 是因为 ALPN 不可靠路径。
3. **❌ row-level string diff**（atomcode 早期实现）—— UTF-8 规则字符让 row diff 失效，改为 cell-based diff。
4. **❌ Persisting single-threaded mode globally**（claudecode 早期实现）—— EAGAIN 后全局 -j 1 会让大型仓库 timeout，应仅对单次 retry。
5. **❌ Prepared statement 全量 cache**（无候选人晋升）—— 一次性变长 SQL 撑爆原生 cache，openclaw 用 `candidates → statements` 二级。
