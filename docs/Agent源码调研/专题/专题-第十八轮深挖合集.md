## 八、与前 17 轮 5 大交叉点

### 交叉点 1：D3 Rewind × 第七轮 Git Checkpoint

- **互补关系**：第七轮 Git checkpoint 提供"代码侧快照底层"（commit/hash/fast-forward）；本轮 D3 提供"对话侧用户级恢复"（revert/branch/fork UI）
- **整合方案**：D3 的 rewind 操作触发第七轮的 git stash + `agent::session_truncate` 原子双操作

### 交叉点 2：D6 Paste × 第十六轮 Session 持久化

- **互补关系**：D6 大粘贴截断生成 `[paste #N +123 lines]` 标记 + 落盘为临时文件；第十六轮 Session 持久化机制接收落盘文件引用进 WAL
- **整合方案**：`tui/input.rs` 截断时落盘 `/tmp/laew-paste-{N}.txt`，`session_log` 记录路径而非原文

### 交叉点 3：D7 Onboarding × 第十一轮配置系统

- **互补关系**：第十一轮的 8 层发现链 / 5 源合并是 D7 Onboarding 的"完成态"配置；D7 引导用户配置后持久化
- **整合方案**：`onboarding_wizard.rs` 末步把 wizard 结果写入第十一轮的 5 个配置源

### 交叉点 4：D8 Statusline × 第八轮 Telemetry

- **互补关系**：第八轮 Telemetry 提供 trace 收集；D8 statusline 把 trace 摘要实时渲染给用户
- **整合方案**：`statusline.rs` 订阅 `telemetry::events`，按 1s 节流渲染

### 交叉点 5：D4 File Watch × 第十五轮 OS 内核交互

- **互补关系**：第十五轮 OS 内核交互轮次覆盖 inotify/FSEvents 跨平台；D4 文件监视是该能力在应用层的具体应用
- **整合方案**：D4 用 `notify` crate（第十五轮推荐），事件触发后调用本轮 D1 的 mtime 失效
