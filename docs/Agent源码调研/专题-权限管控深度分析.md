### 3.3 ApprovalMiddleware 核心

// crates/atomcode-capabilities/src/tools/approval.rs:32-42
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct ApprovalRequest {
    #[serde(default)]
    pub call_id: String,
    pub tool: String,
    /// 实际会执行的字节(approve-what-runs 契约)
    pub args: String,
}

// approval.rs:155-190
pub struct ApprovalMiddleware {
    store: Arc<dyn PermissionStore>,
    kind: String,
}

impl ApprovalMiddleware {
    fn grant_key(call: &ToolCall, tool: &dyn Tool) -> String {
        format!("{}::{}", call.name, tool.always_grant_scope(&call.arguments))
    }
}

// approval.rs:238-270 — before 钩子
async fn before(&self, call: &mut ToolCall, tool: &Arc<dyn Tool>, rt: &RequestCtx) -> BeforeOutcome {
    if tool.risk(&call.arguments) == RiskLevel::Safe {
        return BeforeOutcome::Proceed;
    }
    let key = Self::grant_key(call, tool.as_ref());
    if self.store.is_granted(&key) {
        return BeforeOutcome::Proceed;
    }
    match request_approval_decision(rt, &self.kind, call, tool.name()).await {
        Err(degraded) => degraded, // Null → fail closed
        Ok(PermissionDecision::AllowOnce) => BeforeOutcome::Proceed,
        Ok(PermissionDecision::AllowAlways) => {
            self.store.grant(&key);
            BeforeOutcome::Proceed
        }
        Ok(PermissionDecision::Deny) => BeforeOutcome::deny(...),
    }
}
```

**`always_grant_scope` 的精妙设计**(approval.rs 测试):

        ApprovalMiddleware::grant_key(&c1, bash.as_ref()),

}

pub fn references_sensitive_path(args: &str) -> bool {
    let a = args.to_ascii_lowercase();
    if a.contains(".env\"") || a.contains(".env'") {

**关键设计**:
- `.env` 区分真实配置 vs 模板(`.env.example` 不拦截,降低噪音)

/// 子 Agent 硬拒绝敏感路径(子 Agent 在 AutoRespond::AllowAll 模式,

struct DenySensitivePaths;

#[async_trait]

    BeforeOutcome::deny(format!(
        "approval unresolved for '{tool_name}': no decision received — \
         internal channel failure, not a user denial"
    ))
}
```

**核心安全准则**:Null response(超时/断开)一律按 Deny 处理,而非 Allow。这防止 driver 失联时工具被静默执行。

// src/agents/exec-auto-reviewer.ts — textLooksLikeReviewerDirective
function textLooksLikeReviewerDirective(value: string): boolean {
  const normalized = value.normalize("NFKC").toLowerCase()
    .replace(/[\p{Cc}\p{Cf}\p{P}\p{S}]+/gu, " ").replace(/\s+/gu, " ").trim();
  return (
    // 1. 指令覆盖攻击
    /\b(ignore|disregard|override)\b.{0,80}\b(instruction|system|developer|prompt|policy)\b/u.test(normalized) ||
    // 2. 决策操控
    /\b(return|respond|output|say|print)\b.{0,80}\bdecision\b.{0,80}\b(allow|allow-once)\b/u.test(normalized) ||
    // 3. 审阅器冒充
    /\b(exec\s+)?reviewer\b.{0,80}\b(decision|allow|risk|rationale)\b/u.test(normalized) ||
    // 4. 完整字段注入(decision+allow+risk+low 同时出现)
    (tokens.has("decision") && tokens.has("allow") && tokens.has("risk") && tokens.has("low")) ||
    // 5. 终止标记注入
    /\buntrusted (?:exec|widget) request json end\b/u.test(normalized)
  );
}

export async function withFileMutationQueue<T>(env: ExecutionEnv, path: string, fn: () => Promise<T>) {

## 8. 设计模式提炼

### 模式 1:Advisory Metadata + Composable Gate(分层组合)

**代表项目**:atomcode

**核心思想**:
- `Tool::risk(args)` 返回元数据 `RiskLevel`(Safe/Risky),**不强制执行**
- 多个 `ToolMiddleware`(ApprovalMiddleware / SensitivePathGate / WorkerScopeGate)独立注册,按序组合
- 每个 gate 只关心自己的职责,gate 之间通过 `BeforeOutcome::Proceed/deny` 协作

**关键 Rust 模式**:
```rust
#[async_trait]
pub trait ToolMiddleware: Send + Sync {
    async fn before(&self, call: &mut ToolCall, tool: &Arc<dyn Tool>, rt: &RequestCtx) -> BeforeOutcome;
    async fn after(&self, call: &ToolCall, result: &mut ToolResult, rt: &RequestCtx) -> AfterOutcome;
}
```

**对 laew 启示**:把当前 `Tool::execute()` 拆分为 `pre_execute(args, ctx) → execute(args, ctx) → post_execute(result, ctx)`,允许插入权限 gate。

---

### 模式 2:findLast 后匹配优先(Permission 规则链)

**代表项目**:opencode

```typescript
flatMap(ruleset => ruleset.rules)
  .findLast(rule => matches(rule, call))
```

**核心思想**:基础规则在前,精细规则在后,后定义的规则覆盖前面的。这比"白名单 > 黑名单"更灵活。

**对 laew 启示**:PermissionRule 支持 source 字段(`user/project/global/command-line`),`evaluate()` 用 findLast 匹配。

---

### 模式 3:Arg-Aware Risk(参数感知风险分级)

**代表项目**:atomcode

```rust
fn risk(&self, args: &str) -> RiskLevel {
    if check_destructive_command(args).is_some() { RiskLevel::Risky }
    else { RiskLevel::Safe }
}
```

**核心思想**:同一个工具(`Bash`),根据参数内容返回不同风险等级。`ls` 是 Safe,`rm -rf /` 是 Risky。

**对 laew 启示**:`Tool::risk(&self, args: &Value) -> RiskLevel` 让 BashTool 自报风险,ApprovalMiddleware 据此询问。

---

### 模式 4:SubAgent 权限继承(权限边界而非继承)

**代表项目**:opencode / atomcode

```typescript
// opencode:每个 Agent 独立 ruleset
explore: { permission: Permission.merge(defaults, { "*": "deny", grep: "allow", ... }) }

// atomcode:WorkerScopeGate 限定子 Agent 写入范围
struct WorkerScopeGate { globs: globset::GlobSet, dir_prefixes: Vec<PathBuf> }
```

**核心思想**:子 Agent **不继承**父 Agent 的完整权限,而是有自己的权限边界(deny-by-default + 显式 allow)。

**对 laew 启示**:当前 `MultiAgentOrchestrator` 中所有 Agent 共享同一个 ToolRegistry,应该按角色拆分:`QualityRegistry`、`SubAgentWorkRegistry` 等,且 SubAgent 应 deny-by-default。

---

### 模式 5:Fail-Closed Default(失败即拒绝)

**代表项目**:atomcode / opencode / claudecode

**核心思想**:
- Null response(超时/断开) → Deny(不是 Allow)
- 解析失败的命令 → Ask(不是 auto-allow)
- 配置损坏 → untrusted(不是 trusted)

**反例**:某些框架默认"prompt 缺失时跳过",这是**漏洞**,不是特性。

**对 laew 启示**:权限模块必须 fail-closed。`grep_match(rule)` 返回 None 时,默认 deny。

---

### 模式 6:Sensitive Marker 路径形匹配(防误报)

**代表项目**:atomcode / openclaw

**核心思想**:敏感路径标记是**路径形**(`/.ssh`、`/.aws`、`/.env`),不是敏感词(`secret`、`password`、`token`)。

**原因**:`grep "secret" src/main.rs` 不应触发"读取敏感文件"的确认——这会让 grep 失去作用。

**对 laew 启示**:`SECRET_PATTERNS` 用 `starts_with("/.ssh/")` 而非 `contains("ssh")`。

### 模式 7:Tool-wide vs Per-command always_grant_scope

**代表项目**:atomcode

    // bash: command 原文 → per-command,一次只覆盖一个命令

**核心思想**:`Always` 的粒度应与工具的语义匹配。文件编辑是"工具级会话契约",Bash 是"单次命令审计"。

**对 laew 启示**:ReadTool 用 file path 作为 scope,WriteTool 用 tool-wide,EditTool 用 tool-wide,BashTool 用 command 原文。

### 模式 8:Voice/Sound Confirmation(多模态确认)

//! 敏感路径检测(移植自 atomcode sensitive_path.rs)

const SENSITIVE_MARKERS: &[&str] = &[
    "/.ssh", "id_rsa", "id_ed25519", "id_ecdsa", "id_dsa",
    "/.aws", "/.gnupg", "/.kube", "/.config/gcloud",
    ".netrc", ".git-credentials", ".npmrc", ".pypirc",
    ".pem", ".p12", ".pfx", ".keystore",
    "/secrets/", "/.terraform.d",
];

pub fn references_sensitive_path(args: &str) -> bool {
    let a = args.to_ascii_lowercase();
    // .env 文件(非模板)
    if a.contains(".env\"") || a.contains(".env'") {
        return true;
    }
    // .env.<variant> 非 example/sample/template/dist/defaults
    if env_dot_reference_is_sensitive(&a) { return true; }
    // markers 匹配
    SENSITIVE_MARKERS.iter().any(|m| a.contains(m))
}

```rust
use serde::{Deserialize, Serialize};
use std::collections::HashSet;
use std::sync::{Arc, Mutex};

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum PermissionDecision {
    AllowOnce,
    AllowAlways,
    Deny,
}

impl PermissionDecision {
    pub fn from_value(v: &serde_json::Value) -> Self {
        let decision = v.get("decision").and_then(|x| x.as_str()).unwrap_or("deny");
        let remember = v.get("remember").and_then(|x| x.as_bool()).unwrap_or(false);
        match decision {
            "allow_always" => PermissionDecision::AllowAlways,
            "allow" if remember => PermissionDecision::AllowAlways,
            "allow" => PermissionDecision::AllowOnce,
            _ => PermissionDecision::Deny,  // FAIL CLOSED
        }
    }
}

pub trait PermissionStore: Send + Sync {
    fn is_granted(&self, key: &str) -> bool;
    fn grant(&self, key: &str);
}

#[derive(Default)]
pub struct InMemoryPermissionStore {
    granted: Mutex<HashSet<String>>,
}

impl PermissionStore for InMemoryPermissionStore {
    fn is_granted(&self, key: &str) -> bool {
        self.granted.lock().unwrap_or_else(|e| e.into_inner()).contains(key)
    }
    fn grant(&self, key: &str) {
        self.granted.lock().unwrap_or_else(|e| e.into_inner()).insert(key.to_string());
    }
}
```

```rust
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PermissionRule {
    pub tool: String,                  // "Bash" | "Read" | "Write" | "*"
    pub action: PermissionAction,
    pub pattern: Option<String>,       // glob: "Bash(git:*)" / "Read(/home/**)"
    pub source: RuleSource,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum PermissionAction {
    Allow,
    Deny,
    Ask,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum RuleSource {
    GlobalSettings,    // ~/.config/laew/settings.toml
    ProjectSettings,   // .laew/settings.toml
    CommandLineFlag,   // --allow-all
    Session,           // 运行时 grant
}

#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct PermissionRuleset {
    pub rules: Vec<PermissionRule>,
}

impl PermissionRuleset {
    pub fn evaluate(&self, tool: &str, pattern: Option<&str>) -> PermissionAction {
        // findLast 后匹配优先(借鉴 opencode)
        for rule in self.rules.iter().rev() {
            if wildcard_match(tool, &rule.tool) {
                if let (Some(p), Some(rp)) = (pattern, &rule.pattern) {
                    if !wildcard_match(p, rp) { continue; }
                }
                return rule.action.clone();
            }
        }
        // 默认 Ask(fail-closed)
        PermissionAction::Ask
    }
}
```

pub fn redact_output(output: &str) -> String {
    let mut redacted = output.to_string();
    // API Key (sk-... / sk_live_...)
    redacted = redact_pattern(&redacted, r"sk[-_][a-zA-Z0-9]{20,}", "sk-***REDACTED***");
    // AWS Access Key
    redacted = redact_pattern(&redacted, r"AKIA[0-9A-Z]{16}", "AKIA***REDACTED***");
    // GitHub Token (ghp_...)
    redacted = redact_pattern(&redacted, r"ghp_[a-zA-Z0-9]{36}", "ghp_***REDACTED***");
    // 私钥 PEM
    redacted = redact_pattern(&redacted, r"-----BEGIN [A-Z ]+PRIVATE KEY-----", "***PRIVATE KEY REDACTED***");
    redacted
}

fn redact_pattern(s: &str, pattern: &str, replacement: &str) -> String {
    let re = regex::Regex::new(pattern).unwrap();
    re.replace_all(s, replacement).to_string()
}
