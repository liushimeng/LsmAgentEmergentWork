# 42 - 纯文字按钮与真实键盘事件动作集补齐(2026-10-23)

> 实测驱动:百度地图公交路线规划任务(Chrome 侧)。本篇记录 Chrome 工具在
> 「无稳定选择器的纯文字按钮 / 联想与回车提交 / 大页面 inspect」三类场景的
> 动作集补齐。总体设计见 `docs/双浏览器工具架构/01-设计与解决方案.md`。

## 一、实测问题

### 1.1 纯文字按钮无稳定选择器

百度地图路线面板确认起终点时出现纯文字按钮「选为终点」「公交」「驾车」。
这些按钮没有稳定 `id`,class 也随版本变化。模型只能反复猜 CSS 选择器
(`.ui3-suggest-item:first-child` 等),24 轮迭代内未命中,最终如实记录失败。

### 1.2 联想列表与回车提交无法触发

`type` 走「原生 setter 赋值 + input/change 事件」,只改值不产生键盘事件;
站点按 `keydown`/`keyup` 触发的地址联想与回车提交不会被触发。模型只能
`eval_js` 手搓 `KeyboardEvent`,既不可发现也不稳定。

### 1.3 `inspect(html)` 忽略选择器且无上限

`inspect(info="html")` 返回整页 HTML;百度地图首页约 **40 万字符**直灌
上下文。`params.selector` 被忽略(与 Lsm 版行为不一致),大页面任务有
撑爆上下文的风险。

## 二、新增/变更动作

### 2.1 `control_action="click_text"`

按**可见文字**点击,取文本最短的命中节点(容器文本更长,最小者最接近按钮)。

```json
{"action":"control","control_action":"click_text","page_id":"c_00000000",
 "params":{"text":"选为终点","selector":"#left-panel","exact":false}}
```

返回:`{hit, tag, id, cls, text}`;`exact=true` 时要求整段文本完全相等;
`selector` 可限定作用域。不可见元素(`getBoundingClientRect` 宽高为 0)跳过。

### 2.2 `control_action="key_press"`

发送**真实 CDP 键盘事件**(`Input.dispatchKeyEvent`,keyDown + keyUp),
可先聚焦 `params.selector`。

```json
{"action":"control","control_action":"key_press","page_id":"c_00000000",
 "params":{"key":"Enter","selector":".route-end-input"}}
```

支持 `Enter` / `Tab` / `Escape` / `Backspace` / `Delete` / `ArrowUp|Down|Left|Right`
/ `Home` / `End` / `PageUp` / `PageDown` / `Space` 与单字符。
`Enter` 带 `text="\r"`,表单提交与联想确认都能收到。

### 2.3 `inspect(text|html)` 支持 `params.selector` + 输出上限

```json
{"action":"inspect","info":"html","page_id":"c_00000000",
 "params":{"selector":"#left-panel","max_chars":40000}}
```

* `selector`:只取命中的第一个元素(`innerText` / `outerHTML`);
* `max_chars`:默认 **20000**,夹在 `[1000, 200000]`;
* 返回 `{text|html, chars, truncated, selector}`,截断时附提示。

## 三、配套的提示词分流

`orchestrator/workflows.rs::build_subflow_input` 的「批量优先」硬约束原先
无条件写死 `MCP_Web_LsmAgentBrowser_Use(action=explore/batch)`,在
「全程只用 MCP_Web_Chrome_Use」的任务里持续诱导换工具(F1 回归)。

现在按用户原始提示词里的**强制工具**分流:

* 强制 Chrome → 注入 Chrome 专属范式(`eval_js` 合并读取 / `click_text` /
  `key_press` / `screenshot save_path`);
* 强制 Lsm → 保留原 explore/batch 范式;
* 未声明强制工具 → 不注入任何工具专属范式。

`mandated_tool` 只认「只使用/仅使用/只用/全程使用/必须使用」后**同一子句**内
出现的工具名,避免把「不得使用 B」误判成强制 B。
