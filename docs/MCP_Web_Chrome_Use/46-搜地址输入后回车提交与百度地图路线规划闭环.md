## 二、根因:输入没有提交,站点拿原始文本做地理编码

Agent 的实际操作序列(日志逐条):

```
control(type,  .route-start-input, "北京市沙河镇民院小区")   ← 只打字
control(eval_js, 找 [class*=sug] li / .poi-list li …)        ← 查了联想项,但没用
control(type,  .route-end-input,  "北京市环球影城度假区")     ← 只打字
control(click, .tab-item.bus-tab, mode=real)                 ← 直接切出行方式
control(inspect, text) → 189 字符(只有页脚版权,没有方案)
```

站点行为:搜索框输入后弹**联想下拉**;只有**回车**或**点下拉里的条目**,
才会把下拉里的**规范 POI**(百度自动纠偏:民院小区 → 民园小区-5号楼)提交出去。
直接切出行方式 = 把输入框里的**原始文本**丢给地理编码 → 地理编码不认 →
「未找到相关地点」→ 没有方案 → 整条路线规划做不下去。

**旁证(站点侧)**:本机直接打百度两个联想端点,行为不一致——

| 端点 | 结果 |
|------|------|
| `map.baidu.com/?qt=s&wd=…`(旧接口) | `{"result":{"anti_session":{"need_recaptcha":true}},"content":[[]]}` —— **本 IP 已被验证码闸住**,三次重试全一样 |
| `map.baidu.com/su?wd=…&cid=131&type=0&pc_ver=2`(新接口) | 正常返回建议列表,含「民园小区-5号楼」「北京民康医院」等 |

→ 站点新旧两套联想接口风控策略不同;**走页面联想下拉(新接口)这条路是通的**,
失败纯粹是 Agent 没提交。

## 三、修复(本轮落地)

补一个「输入后回车」的一步式能力,双工具**同名同义**:

| 工具 | 参数 | 行为 |
|------|------|------|
| `MCP_Web_Chrome_Use` | `type`/`input_text` 带 `params.submit=true`(同义 `params.pick_suggestion`) | 输入后走 **CDP 真实 Enter 键**(`Input.dispatchKeyEvent`),把联想下拉里的规范 POI 提交出去;无下拉时回车等价于提交表单 |
| `MCP_Web_LsmAgentBrowser_Use` | `control(input_text/human_input)` 带 `params.submit=true` | 走已有的 `key_press(Enter)` 通道(先派发 `submit` 事件,可被 `preventDefault` 拦下) |

**可发现性**(D6 的老教训:能力不可发现 = 等于没有):
两个工具的 `description` 都点明「搜地址/填地点建议带 `params.submit=true`」,
并把**后果**写出来(「只输入不回车,站点会用原始文本做地理编码,报『未找到相关地点』」)。

**向后兼容**:默认行为不变(不传 `submit` 就只输入);`params.submit` 是纯增量。

### 落点

- `src/agent/tools/mcp_chrome_use/mod.rs`:`type`/`input_text` 分支 + schema + description
- `src/agent/browser/api.rs`:`input_text`/`human_input` 分支
- `src/agent/tools/mcp_web_lsm_browser_use/mod.rs`:description

## 六、与内核侧的关系

本篇只解决**交互闭环**;底图画不出来是另一回事(内核无 WebGL,见
`docs/MCP_Web_LsmAgentBrowser_Use/26-活集合语义与视口高度根因修复.md` §五)。
两者合起来的完整结论:

1. **像素级地图底图 → 必须 `MCP_Web_Chrome_Use`**(真 Chromium;Lsm 内核无 WebGL)。
2. **路线方案等 DOM 文本 → Lsm 内核也能读**,但路线面板本身在 Lsm 侧未打开
   (路线 widget 的 DOM 落地路径问题,见 26 篇 §五),故实务上仍以 Chrome 侧为准。
3. **地址输入必须提交** → 两边工具都支持 `params.submit=true`。
