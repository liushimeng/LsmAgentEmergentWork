### CI01 三点估算 + PERT：估算脚本与历史回归校验

- **预期档位**: medium
- **考察维度**: 三点估算 + PERT + 回归校验
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write 三点估算脚本 `tmpPlan/agent-test/ci01_pert.py`：输入 CSV `(task, O, M, P)`，计算 `E = (O+4M+P)/6`、`sigma = (P-O)/6`、总 E 与总 sigma，输出 PERT 表（任务 / O / M / P / E / sigma）+ 项目在 X 天内完成的概率（基于正态近似，Z=(X-E_total)/sigma_total）。
  2. Write 历史项目数据 `tmpPlan/agent-test/ci01_history.csv`：10 个任务，含估算 E 与实际耗时，运行 `python3 tmpPlan/agent-test/ci01_pert.py tmpPlan/agent-test/ci01_history.csv 50`（50 天目标），断言输出含 Z 值与完成概率。
  3. Read 输出，Write python3 `tmpPlan/agent-test/ci01_regression.py`：读取历史数据，计算「估算偏差率 = |实际-E|/实际」「平均偏差」「高估/低估任务数」；断言平均偏差 ≤ 30%。
  4. Bash 复检：`grep -c '^| ' tmpPlan/agent-test/ci01_regression.py` 不对（脚本无表），改为 `python3 tmpPlan/agent-test/ci01_regression.py tmpPlan/agent-test/ci01_history.csv` 输出含「平均偏差」，`grep -F '偏差'` 应 ≥ 1。
