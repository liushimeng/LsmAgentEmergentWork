### A02 周报撰写助手
- **预期档位**: simple
- **考察维度**: 工作汇总 + 格式化输出
- **对话脚本**:
  1. 这周我做了三件事：完成了用户登录模块开发、修复了 3 个 bug、参加了 2 个评审会。请帮我写一份周报。
  2. 周报里要体现每件事的完成度和下周计划，语气要专业但不死板。
  3. 帮我检查一下有没有遗漏的常规周报要素（如风险、协作、学习成长）。
  4. 把周报保存到 `tmpPlan/本周周报.md`，控制在 500 字以内。

### A03 邮件沟通模板
- **预期档位**: simple
- **考察维度**: 职场沟通 + 语气把控
- **对话脚本**:
  1. 我要给产品经理写一封邮件，委婉地拒绝一个需求变更请求，请帮我起草。

  3. 把这封邮件改写成更简洁的版本（不超过 100 字），适合在企业微信里发。
  4. 总结一下"委婉拒绝"这类邮件的三个写作要点。

### A05 需求文档分析
- **预期档位**: medium
- **考察维度**: 需求理解 + 问题发现
- **对话脚本**:
  1. 这是一份产品需求文档（PRD）的摘录，请帮我分析这个需求的完整性和可行性。
  2. 指出需求中模糊或矛盾的地方，列出需要产品澄清的问题。
  3. 从技术实现角度，评估这个需求的复杂度（简单/中等/复杂）并说明理由。
  4. 给出技术方案的初步建议（包含技术选型、实现思路、预估工时）。

### A06 流程优化建议
- **预期档位**: medium
- **考察维度**: 流程分析 + 改进建议
- **对话脚本**:
  1. 我们团队的代码发布流程是：开发 → 自测 → 提 PR → 评审 → 合并 → 手动部署。请分析这个流程的瓶颈。
  2. 针对每个瓶颈给出具体的优化建议，按投入产出比排序。
  3. 如果要引入 CI/CD，最小可行方案应该包含哪些环节？
  4. 把优化方案保存到 `tmpPlan/发布流程优化方案.md`。

### A07 跨部门协作沟通
- **预期档位**: simple
- **考察维度**: 协作场景 + 沟通策略
- **对话脚本**:
  1. 我需要向运维部门申请一台测试服务器，但对方响应很慢。请帮我写一封正式的协作邮件。
  2. 如果运维回复"资源紧张，需要排队"，我该怎么回应？请给出两个策略。
  3. 如何建立长期的跨部门协作关系？给出三条实用建议。
  4. 总结一下"技术向非技术沟通"的三个要点。

### A09 时间管理矩阵
- **预期档位**: simple
- **考察维度**: 优先级管理 + 个人效率
- **对话脚本**:
  1. 解释一下艾森豪威尔矩阵（重要/紧急四象限），每个象限应该怎么处理？
  2. 我今天有以下任务，请帮我按四象限分类并排序：修复线上 bug、写技术文档、回复邮件、准备下周分享、代码审查。
  3. 对于"重要但不紧急"的任务，怎么避免它们变成"重要又紧急"？
  4. 推荐三个适合程序员的时间管理工具或方法，说明各自适用场景。
