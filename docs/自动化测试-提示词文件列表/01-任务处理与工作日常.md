## 维度说明
本维度考察 Agent 在**职场任务处理、日常工作、项目协作**场景下的多轮迭代与产物落盘能力。所有任务固定 4 轮，要求至少 1 轮 Bash 执行并断言、至少 1 轮 Write 落盘产物到 `tmpPlan/agent-test/` 沙盒，工具链限于 Bash/Read/Write。衡量重点：把抽象需求（纪要/周报/计划/复盘）转化为可核对的结构化产物（Markdown + 校验脚本/grep 断言），并保持 Session 上下文连续引用前轮产物。

- **预期档位**: simple

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
