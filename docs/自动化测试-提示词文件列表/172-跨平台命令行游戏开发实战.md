>
> 与现有维度互补说明：
> - `57-经典小游戏复刻与游戏编程实战`（BF 维）聚焦**通用 GUI/SDL/Unity** 等图形界面游戏；本文件聚焦**纯 CLI/TUI 终端**游戏开发，覆盖 ncurses/blessed/ratatui 等终端 UI 库。
> - `97-HTML5小游戏与Canvas编程实战`（CO 维）聚焦**浏览器**游戏；本文件聚焦**终端/SSH 环境**下的游戏，与 laew 自身的 TUI 同源。
> - `119-游戏品类与系统编程进阶（放置/卡牌/棋类/猜词/数值）`（DK 维）聚焦**游戏系统机制**（数值/经济/卡牌效果）；本文件聚焦**终端渲染与玩法实现**，强调 laew 自身 TUI 引擎可借鉴的渲染技术。
> - `172` 不与 `161-文字冒险与互动叙事游戏编程` 冲突：161 维聚焦**剧情与叙事引擎**；本文件聚焦**其他类玩法**（贪吃蛇/俄罗斯方块/Roguelike 等）。
>
> **本文件独特主题**：TUI 游戏循环与帧率控制 / 字符画与彩块终端渲染 / ANSI 转义码颜色与光标控制 / 键盘实时输入（cbreak 模式）/ 跨平台 ncurses/PDCurses/blessed 抽象 / 状态机驱动玩法 / 随机地图生成 / AI 算法（minimax/蒙特卡洛树搜索）/ 文件存档兼容 / 局域网联机（Unix socket / TCP）。

### FL01 终端贪吃蛇

- **预期档位**: medium
- **考察维度**: 游戏循环 / 输入 / 碰撞检测
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/fl01_snake.py`：终端贪吃蛇游戏，输出：(a) TUI 渲染（ratatui 或 blessed，支持彩色 + Unicode 方块 `██`）/ (b) 主循环 10 FPS（asyncio + 控制帧率）+ (c) 键盘实时输入（方向键/WASD，无回显）+ (d) 碰撞检测（墙壁/自身）+ 食物随机生成（避免与蛇身重叠）+ (e) 分数与历史最高分（JSON 存档）。
  2. Bash：`python3 -m py_compile tmpPlan/agent-test/fl01_snake.py`，断言退出码为 0。
  3. Read `tmpPlan/agent-test/fl01_snake.py`，再 Write `tmpPlan/agent-test/fl01_snake_test.json`：测试场景（蛇身坐标序列 + 食物位置 + 期望下一步结果）。本轮必须显式复用第一轮的循环频率与碰撞规则。
  4. Bash：`python3 tmpPlan/agent-test/fl01_snake.py --selftest tmpPlan/agent-test/fl01_snake_test.json 2>&1 | tee tmpPlan/agent-test/fl01_test.log`，断言 `grep -F 'ratatui\|blessed\|curses'` 命中、`grep -F 'FPS\|帧率'` 命中、`grep -F '碰撞\|collision'` 命中、`grep -F 'JSON\|存档'` 命中。
