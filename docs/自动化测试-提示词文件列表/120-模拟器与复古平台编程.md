### DL01 模拟器原理地图：模拟、虚拟机与高级仿真

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 三个常被混淆的概念：模拟器（emulator，模仿另一台机器的硬件行为让原版程序无改动运行）、虚拟机（virtual machine，定义一套新指令集让同一程序跨平台）、高级仿真（HLE，不模仿硬件只重实现系统调用/API 层）。

  3. 动手：写一个 100 行的"寄存器机"玩具模拟器（4 个寄存器 + 8 条指令 + 程序计数器），实现取指-译码-执行主循环与停机条件；它是后续 DL02~DL09 的脚手架。实现到文件 `tmpPlan/agent-test/dl01_regmachine.py`。
  4. 继续：在模拟器中加入 PC 自增时机与指令副作用顺序的断言（每条指令执行后自动校验 PC 与寄存器），跑一段故意写错的程序验证断言能捕获错误；阅读源码 `tmpPlan/agent-test/dl01_regmachine.py`，指出哪条指令的实现顺序错了并修正，重新跑全指令用例通过。
