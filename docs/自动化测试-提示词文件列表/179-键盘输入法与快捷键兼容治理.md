# 179 键盘输入法与快捷键兼容治理

> 编号段 FR01–FR10 · 聚焦「键盘布局、输入法编辑、死键、快捷键冲突、终端编码与无障碍输入」。
>
> 与现有维度互补说明：
> - `43-国际化工程与 RTL 布局` 偏语言文案与界面方向；本文件偏物理按键到字符的输入链路。
> - `44-无障碍 a11y 与包容性设计` 偏整体可访问性；本文件聚焦键盘替代操作与输入辅助。
> - `06-界面设计与用户体验` 偏界面组织；本文件把快捷键当作跨平台契约测试。
>
> **本文件独特主题**： keycode 差异 / 布局映射 / IME composition / dead key / Ctrl-Alt 变体 / 终端 ESC 序列 / 快捷键冲突 / 输入审计 / 可自定义映射 / 键盘回归包。
>
> 环境约束：不安装驱动、不修改用户键盘配置、不拦截真实全局按键。所有模拟事件写入 `tmpPlan/agent-test/`；Python 仅标准库，Windows/macOS/Linux 差异用数据表表达。

### FR01 键盘布局事件映射

- **预期档位**: medium
- **考察维度**: keycode / layout / modifrers
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/fr01_layout.py`：定义 US、GB、German、French、Turkish-Q、Japanese 六布局；输入 keycode、shift、altgr、caps_lock，输出字符或 `NoSymbol`；区分字母区、数字区、标点区和方向键。
  2. Bash：`python3 -m py_compile tmpPlan/agent-test/fr01_layout.py`，断言退出码为 0。
  3. Read `tmpPlan/agent-test/fr01_layout.py`，再 Write `tmpPlan/agent-test/fr01_events.jsonl`：至少 18 条事件，覆盖 Shift+1、AltGr 变体、Caps Lock、Umlaut、日文假名占位和方向键。本轮必须复用第一轮布局名。
  4. Bash：`python3 tmpPlan/agent-test/fr01_layout.py --events tmpPlan/agent-test/fr01_events.jsonl --out tmpPlan/agent-test/fr01_result.json`，断言 JSON 有效且无布局缺表。
