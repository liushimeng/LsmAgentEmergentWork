> 编号段 FS01–FS10 · 聚焦「金融核心系统 + 银行账务 + 支付清算 + 风控合规」：核心银行系统架构 / 总账与复式记账引擎 / 支付路由与清算对账 / 贷款生命周期管理 / 信用卡授权与账单 / 外汇交易与汇率管理 / 反洗钱 AML 监控 / 银行监管报送 / 开放银行 API / 金融数据加密与脱敏

> - `101-金融账务与量化回测编程`（CS 维）聚焦**量化交易与回测**（K线/技术指标/策略）；本文件聚焦**银行核心系统**（账务/支付/信贷），是该维度的银行核心版。
> - `61-企业业务系统开发实战`（BJ 维）聚焦**通用企业系统**（进销存/工单/OA）；本文件聚焦**金融业务系统**（银行/支付/风控），是该维度的金融垂直版。
> - `80-隐私计算与数据合规工程`（CA21 维）聚焦**通用数据合规**；本文件聚焦**金融监管合规**（AML/KYC/监管报送），是该维度的金融合规版。
> - `181` 不与 `166-程序员财务规划与税务计算工程` 重叠：166 维聚焦**个人理财**；本文件聚焦**机构级金融系统**。

> **本文件独特主题**：核心银行 CBS 模块划分 / 借贷平衡与会计科目树 / 支付路由智能选择 / 日终批处理与对账 / 贷款五级分类与拨备 / 信用卡授权与清算 / 实时汇率与外汇头寸 / AML 可疑交易监测 / 央行监管报送 1104 / 开放银行 PSD2/OpenAPI。
