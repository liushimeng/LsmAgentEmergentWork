### EY01 编码探测与诊断工具

- **预期档位**: medium
- **考察维度**: BOM 表 / UTF-8 严格 / GBK 启发式
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `ey01_detect.py`：字节三级判定——BOM（UTF-8 `\xef\xbb\xbf`、UTF-16LE `\xff\xfe`、UTF-16BE `\xfe\xff`）→ `decode('utf-8')` 严格尝试 → GBK 启发式（可解码率 + U+4E00–U+9FFF 占比得 confidence）；输出 `{file, encoding, confidence, bad_bytes}` JSON。
  2. Bash：python3 内联造三样例于 `ey01_samples/`（utf8.txt、gbk.txt、u16le.txt=BOM_UTF16_LE+utf-16-le 字节）；`python3 ey01_detect.py ey01_samples/ | tee ey01_result.json`；断言 `grep -F '"encoding": "utf-8"'`、`'gbk'`、`'utf-16le"'` 各命中。
  3. Read 脚本与结果，Write `ey01_report.md`：逐样例引用三字段实测值，总结三级策略边界与误判风险。本轮必须显式复用第一轮字段命名与第二轮探测结论，不允许另起无关主题。
  4. Bash：`python3 -m json.tool ey01_result.json >/dev/null`；`test "$(grep -c '"file"' ey01_result.json)" -eq 3`；`grep -F 'ey01_samples' ey01_report.md`。

### EY03 GBK↔UTF-8 批量安全转换

- **预期档位**: medium

- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `ey03_convert.py`：遍历 `*.txt`：同跑 `iconv -f GBK -t UTF-8`（subprocess）与 python3 双实现，sha256 一致才写回；任一失败（含无效字节）跳过记 `{file, reason, bad_byte_offset}`；写回前断言**行数一致**否则中止；成功记 `{file, lines_before, lines_after, dual_impl_match}`。
  2. Bash：python3 构造 `ey03_in/`：ok1.txt/ok2.txt + broken.txt（GBK 后拼 `b'\xff\xff'`）；`python3 ey03_convert.py ey03_in ey03_out | tee ey03_result.json`；断言 `grep -F 'broken.txt' ey03_result.json` 命中 failed；`test -f ey03_out/ok1.txt` 且 `test ! -f ey03_out/broken.txt`。
  3. Read `ey03_result.json` 与 ey03_out，Write `ey03_audit.md`：逐文件审计表，broken.txt 的 reason 与 bad_byte_offset 原样引用，总结两实现容错差异。本轮必须显式复用第一轮 failed/reason/bad_byte_offset 字段命名，不允许另起无关主题。
  4. Bash：`python3 -c "open('ey03_out/ok1.txt', encoding='utf-8').read()"`；`test "$(wc -l < ey03_in/ok1.txt)" -eq "$(wc -l < ey03_out/ok1.txt)"`；`grep -F 'bad_byte_offset' ey03_audit.md`。

- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `ey06_gen.py`：字节层写 `ey06_broken.sh` 为 `b'#!/bin/bash\r\necho crlf_fixed_ok\r\n'`，打印字节数与前 16 字节 hex 预览。
  2. ### EY10 大文件流式转换与校验

- **预期档位**: hard
- **考察维度**: 跨界缓冲 / sha256 与行数双校验 / 断点续转
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `ey10_stream.py`：流式 GBK→UTF-8 转换器——按 1MB 块读源；多字节跨界用 `codecs.getincrementaldecoder('gbk')`（块尾落在字符中间时缓冲尾部、与下一块拼接再解码），统计 boundary_hits；断点续转：每块写完 offset 落盘 `ey10_offset.txt`，重入从 offset 续转；完成写 `{src, dst, chunks, boundary_hits, lines, sha256}` 到 `ey10_verify.json`。
  2. Bash：python3 生成 5MB+ GBK 源 `ey10_big_gbk.txt`（中文句子按行循环至超 5000000 字节）；`python3 -m py_compile ey10_stream.py && python3 ey10_stream.py ey10_big_gbk.txt ey10_big_utf8.txt | tee ey10_log.txt`；断言 `test "$(wc -l < ey10_big_gbk.txt)" -eq "$(wc -l < ey10_big_utf8.txt)"`；`python3 -c "open('ey10_big_utf8.txt', encoding='utf-8').read()"` 全文严格解码；`test "$(stat -c%s ey10_big_utf8.txt)" -gt 5000000`。
  3. Read `ey10_log.txt` 与 `ey10_verify.json`，Write `ey10_report.md`：流式转换报告——块大小/chunks/boundary_hits（原样引用）、sha256 与行数双校验结论、offset 断点续转机制与手动恢复步骤。本轮必须显式复用第一轮字段命名与第二轮实测数值，不允许另起无关主题。
  4. Bash：`grep -F "$(sha256sum ey10_big_utf8.txt | cut -d' ' -f1)" ey10_verify.json` 断言哈希一致；`grep -F 'boundary_hits' ey10_report.md`；`test -s ey10_offset.txt`；`grep -F 'offset' ey10_report.md`。
