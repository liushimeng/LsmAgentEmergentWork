- **预期档位**: medium
- **考察维度**: 大图存储结构 / 缓存友好 / 构建流程
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 用 Python 写 `tmpPlan/agent-test/cx01/csr.py`：实现 CSR 压缩稀疏行结构——（1）`build_csr(edges, n)` 输入边列表 + 节点数，计数排序两遍（统计每点出度 → 前缀和得 offsets → 按序填 edges），返回 `(offsets, edges)` 两个扁平数组；（2）`neighbors(csr, u)` 返回 u 的邻居列表；（3）验证无向图要正反各插一次。
  2. 用 Write 构造 `tmpPlan/agent-test/cx01/graph.txt`：一个 6 节点 8 边的无向图（边列表格式：每行 `u v`）。
  3. 用 Bash 跑 csr.py 构建 CSR 并打印 offsets 与 edges 数组；Read 输出断言 offsets 长度 = n+1、edges 长度 = 2*m（无向图双向）；再调用 `neighbors` 验证某节点的邻居集合与输入一致。
  4. 用 Bash 写断言：`python3 -c "from csr import *; ... assert list(neighbors(csr, 0)) == [1,2]"`（具体邻居值按输入图硬编码），全部邻居关系正确则 echo "PASS: CSR 构建与查询正确"。
