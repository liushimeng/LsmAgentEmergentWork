# 39 性能调优与 Profiling 实战

> 编号段 AN01–AN10 · 聚焦性能分析、Profiling 工具、调优方法论与实战案例

### AN01 性能分析基础：指标与工具链
- **预期档位**: medium
- **考察维度**: 性能指标 + 工具选型
- **对话脚本**:
  1. 性能分析的四个核心指标：延迟（Latency）、吞吐（Throughput）、利用率（Utilization）、饱和度（Saturation），各怎么度量？
  2. 用 `top`、`htop`、`vmstat`、`iostat` 观察一个运行中系统的资源使用，解释每个指标的含义。
  3. 用 `perf stat` 统计一个程序的 CPU 周期、指令数、缓存命中率，解读 IPC（每周期指令数）的意义。
  4. 对比 perf、eBPF、DTrace、Instruments 四款 Profiling 工具在 Linux/macOS 上的适用场景。

### AN02 CPU Profiling：火焰图与热点定位
- **预期档位**: medium
- **考察维度**: 采样分析 + 可视化
- **对话脚本**:
  1. 用 `perf record` 对一个 CPU 密集型程序采样 30 秒，生成火焰图（FlameGraph），描述完整流程。
  2. 火焰图怎么看？X 轴、Y 轴、颜色分别代表什么？怎么从火焰图里找到热点函数？
  3. 用 pprof 对一个 Go 程序做 CPU Profiling：HTTP 端点、生成火焰图、定位慢函数。
  4. 用 async-profiler 对一个 Java 程序做 Profiling：区分 CPU、内存、锁竞争三种模式。

### AN03 内存 Profiling：泄漏与碎片
- **预期档位**: medium
- **考察维度**: 内存分析 + 泄漏检测
- **对话脚本**:
  1. 用 Valgrind 的 Memcheck 检测一个 C 程序的内存泄漏、未初始化读、越界写，解读报告。
  2. 用 jmap + jhat 或 VisualVM 分析一个 Java 堆 dump：找到占用内存最大的对象与引用链。
  3. 用 Chrome DevTools 的 Memory 面板分析一个前端页面的内存泄漏：Detached DOM、闭包引用、定时器。
  4. 内存碎片是什么？用 jemalloc 或 tcmalloc 替换默认分配器怎么缓解？给出配置与验证方法。

### AN04 I/O Profiling：磁盘与网络
- **预期档位**: medium
- **考察维度**: IO 分析 + 瓶颈定位
- **对话脚本**:
  1. 用 `iostat -x 1` 观察磁盘 IO：%util、await、avgqu-sz 分别代表什么？怎么判断磁盘是瓶颈？
  2. 用 `blktrace` + `blkparse` + `btt` 分析一个进程的 IO 模式：随机/顺序、读写比例、队列深度。
  3. 用 `tcpdump` + Wireshark 分析一个 HTTP 请求的网络行为：TCP 握手、TLS、请求/响应、关闭。
  4. 用 `bpftrace` 或 `biosnoop` 实时追踪块 IO：哪个进程在写什么文件、延迟多少。

### AN05 数据库慢查询分析与优化
- **预期档位**: medium
- **考察维度**: SQL 优化 + 索引设计
- **对话脚本**:
  1. 用 `EXPLAIN ANALYZE` 分析一条慢查询：解读执行计划中的 Seq Scan、Index Scan、Nested Loop、Hash Join。
  2. 这条查询为什么没走索引？从选择性、统计信息、隐式类型转换三个角度分析。
  3. 为这条查询设计一个复合索引：列顺序怎么排？覆盖索引怎么减少回表？
  4. 用 pg_stat_statements 或 MySQL 的 slow query log 找出系统中耗时最长的 10 条查询。

### AN06 Web 应用性能：前端与后端
- **预期档位**: medium
- **考察维度**: 全链路性能 + 优化手段
- **对话脚本**:
  1. 用 Lighthouse 跑一个网页的性能评分：FCP、LCP、TBT、CLS 四个指标分别代表什么？
  2. 前端优化：代码分割、懒加载、图片格式（WebP/AVIF）、HTTP/2 推送，各怎么落地？
  3. 后端优化：连接池、缓存（Redis）、异步处理、数据库索引，给出一个 API 的优化清单。
  4. 用 WebPageTest 或 Chrome DevTools 的 Performance 面板录制一次页面加载，分析主线程活动与长任务。

### AN07 并发性能：锁竞争与无锁设计
- **预期档位**: hard
- **考察维度**: 并发分析 + 锁优化
- **对话脚本**:
  1. 用 `perf c2c` 检测一个多线程程序的伪共享（False Sharing）：怎么从报告里识别？
  2. 用 `mutex_profiler` 或 Java 的 JFR 分析锁竞争：哪个锁最热、持有时间多长、争用率多少？
  3. 把一个互斥锁保护的临界区改成无锁（lock-free）结构：用 CAS 或原子操作实现一个无锁队列。
  4. 对比互斥锁、读写锁、RCU、seqlock 四种同步机制在读写比例不同时的性能表现。

### AN08 分布式系统性能：追踪与瓶颈
- **预期档位**: hard
- **考察维度**: 分布式追踪 + 性能分析
- **对话脚本**:
  1. 用 Jaeger 或 Zipkin 对一个微服务调用链做追踪：怎么从 span 树里找到最慢的环节？
  2. 用 OpenTelemetry 给一个服务加埋点：trace、metric、log 三者的关联怎么实现？
  3. 一个请求经过 5 个服务，总延迟 500ms 但每个服务都 < 100ms，中间的时间花在哪了？
  4. 用 Prometheus + Grafana 搭建性能监控：RED 指标（Rate/Errors/Duration）怎么定义与采集？

### AN09 性能调优方法论：从测量到验证
- **预期档位**: medium
- **考察维度**: 调优流程 + 实验设计
- **对话脚本**:
  1. 性能调优的标准流程：定义目标 → 测量现状 → 定位瓶颈 → 实施优化 → 验证效果，每步的关键点是什么？
  2. 怎么设计一个可靠的性能基准测试？从环境控制、预热、多次采样、统计方法四个角度说明。
  3. 优化后性能反而变差了，怎么排查？从回归测试、A/B 对比、回滚机制三个角度给出方案。
  4. 用统计学方法分析性能数据：均值 vs 中位数 vs P99，为什么长尾延迟比平均值更重要？

### AN10 实战案例：一个慢接口的调优全过程
- **预期档位**: hard
- **考察维度**: 综合调优 + 问题解决
- **对话脚本**:
  1. 一个列表接口 P99 延迟 3 秒，给出从监控报警 → 定位瓶颈 → 分析根因的完整排查路径。
  2. 定位到是数据库慢查询 + N + 1 问题，给出从代码改写到索引优化再到缓存的三层优化方案。
  3. 优化后 P99 降到 200ms，但并发一高又飙到 1 秒，分析连接池、线程池、限流器的配置问题。
  4. 写一份性能优化报告：问题、分析、方案、效果、后续建议，给出完整模板。
