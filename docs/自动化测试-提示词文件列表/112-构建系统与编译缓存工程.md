### DD01 Makefile 依赖图与增量构建

- **预期档位**: medium
- **考察维度**: Makefile 机制 / 依赖推导 / mtime 增量
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/dd01/` 下用 Write 生成 `main.c`（调用 util.c 的函数）、`util.c`（含加法函数）、`util.h`；再用 Write 生成 `Makefile`：含自动头依赖 `-MMD -MP`（gcc 生成 .d 文件记录真实头依赖）+ 隐式规则 `%.o: %.c` + `.PHONY: clean`。
  2. 用 Write 构造 `tmpPlan/agent-test/dd01/build.sh`：先全量构建，输出 `tmpPlan/agent-test/dd01/log_full.txt`；第二次空跑（无变更），输出 `log_noop.txt`；修改 `util.h` 后构建，输出 `log_hdr.txt`；只改 `main.c` 后构建，输出 `log_main.txt`。
  3. 用 Bash 跑 build.sh 四次，Read 输出各 log 断言：全量构建 → 3 个目标文件都生成；空跑 → 0 编译动作；改头文件 → 2 个目标都重编；只改 main.c → 仅 main.o 重编。
  4. 用 Bash 断言：`grep -c '^gcc' log_full.txt` 应 = 3，`grep -c '^gcc' log_noop.txt` 应 = 0，`grep -c '^gcc' log_hdr.txt` 应 = 2，全部命中则 echo PASS。

  2. 用 Write 构造 `tmpPlan/agent-test/dd03/sources/`：3 个不同 C 文件 + 1 个「相同源改注释」（应命中同一 key 因为预处理后等价）。
