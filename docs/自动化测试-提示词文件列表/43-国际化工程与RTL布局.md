# 43 国际化工程与 RTL 布局

> 编号段 AR01–AR10 · 聚焦 i18n / l10n 工程、ICU MessageFormat、RTL 双向文本、字体工程与多语言测试

### AR01 i18n 与 l10n 的本质区别
- **预期档位**: simple
- **考察维度**: i18n/l10n 概念 + 工程边界
- **对话脚本**:
  1. i18n（国际化）与 l10n（本地化）的区别是什么？各举 3 个具体工程化例子说明。
  2. 一个软件要"国际化"，源码层面需要做哪些改造？时间格式化、货币、复数形式各举一例。
  3. 用 GNU gettext 或 ICU MessageFormat 实现一个多语言欢迎语，支持英语、中文、阿拉伯语三种。
  4. 提取字符串时常见的坑：复数形式、性别变体、数字格式，列出 5 个真实生产事故案例。

### AR02 ICU MessageFormat：复数、性别与选择
- **预期档位**: medium
- **考察维度**: ICU 语法 + 复数规则
- **对话脚本**:
  1. 用 ICU MessageFormat 写一个购物车提示："您有 {count, plural, =0 {无商品} one {1 件商品} other {# 件商品}}"。
  2. 阿拉伯语（ar）有 6 种复数形式（zero/one/two/few/many/other），英文只有 2 种，规则差异有多大？
  3. 用 `select` 语法实现性别变体："{gender, select, male {他} female {她} other {他/她}} 已登录"。
  4. 在 JavaScript 里用 FormatJS（react-intl）实现多语言日期格式：阿拉伯语用 Hijri、希伯来语用 Hebrew calendar。

### AR03 RTL 双向文本：从逻辑到物理
- **预期档位**: medium
- **考察维度**: BiDi 算法 + 布局镜像
- **对话脚本**:
  1. Unicode BiDi 算法是什么？一段混排阿拉伯语 + 英文 + 数字 "ABC 123 مرحبا def" 实际怎么渲染？
  2. CSS `direction: rtl` 和 `unicode-bidi` 怎么组合使用？给出 3 个常见陷阱（图标方向、阴影、动画方向）。
  3. 表单镜像：label、输入框、提交按钮在 RTL 下应该怎么布局？画出 LTR 与 RTL 两套布局对比图。
  4. 数字、邮箱、文件名在 RTL 下需要嵌入 LTR 段落（Unicode 控制字符 U+202D–U+202E）才能正确显示，怎么处理？

### AR07 文化适配：颜色、图标与隐喻
