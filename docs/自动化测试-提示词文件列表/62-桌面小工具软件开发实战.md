### BK01 截图与标注工具：区域选择、放大镜与马赛克
- **预期档位**: medium
- **考察维度**: 全屏截屏 + 区域选择 + 标注图层
- **对话脚本**:
  1. 用 Rust + `xcap`(Windows) / `xcb`(Linux) / `CoreGraphics`(macOS) 写一个截图工具：捕获全屏 → 显示半透明覆盖层 → 鼠标拖拽选择矩形 → 选中后隐藏覆盖层 → 用 `image::RgbaImage` 裁剪并写入 PNG。要求给出关键 API 调用与多平台分支。
  2. 基于上面的实现，加放大镜功能：鼠标移动时在光标旁绘制 200x200 的放大窗口，按 4 倍采样最近像素，用 `image::imageops::resize` 做最近邻插值。
  3. 加上马赛克功能：用户在已选区域上拖一个矩形，工具按 10x10 像素块采样平均色后填回，实现「不可逆打码」（避免简单像素化被还原）。
  4. 在标注工具里加箭头、文字、矩形三种图元：维护一个 `Vec<Annotation>` 列表（图层栈），undo/redo 用命令模式保存到 `Vec<Command>`。最后给 laew 的 `-debug` DebugReport 加一个截图附件接口。

### BK02 剪贴板管理器：历史、搜索与敏感内容过滤
- **预期档位**: medium
- **考察维度**: 系统剪贴板监听 + 持久化 + 隐私过滤
- **对话脚本**:
  1. 写一个 Rust 剪贴板管理器：用 `arboard` crate 读取 / 写入系统剪贴板，跨平台抽象（Windows 用 `OpenClipboard` + `GetClipboardData`，macOS 用 `NSPasteboard`，Linux 用 X11 `XConvertSelection` + Wayland `wlr-data-control`）。
  2. 基于上面的实现，启动一个后台线程每 200ms 轮询剪贴板变化（`get_text` 与上次缓存比对），把新内容写入 SQLite `clipboard_history` 表（字段：id, content, content_type, copied_at, app_name），限制最近 1000 条。
  3. 加敏感内容过滤：检测信用卡号（Luhn 校验 + 正则 `\b\d{13,19}\b`）、邮箱、身份证号、手机号，命中后用 `****<末4位>` 脱敏存储并在历史列表里显示「敏感」标签，避免明文落盘。
  4. 加全文搜索（FTS5 虚拟表 + `MATCH` 查询）与快捷键唤起（全局热键 Ctrl+Shift+V，用 `global-hotkey` crate）。最后评估能否给 laew 加一个 `/paste-from-history` 命令复用同样的 SQLite 存储。

### BK03 番茄钟：托盘常驻、通知与专注统计
- **预期档位**: simple
- **考察维度**: 状态机 + 系统托盘 + 本地通知
- **对话脚本**:
  1. 写一个 Rust 番茄钟（25 分钟工作 + 5 分钟休息 + 4 番茄后长休息 15 分钟）：用 enum `Phase { Work, ShortBreak, LongBreak }` + tokio interval 实现，状态持久化到 SQLite `pomodoro_sessions` 表（start_at, end_at, phase, completed）。
  2. 基于上面的实现，加系统托盘：用 `tray-icon` crate 创建托盘图标，菜单包含「开始 / 暂停 / 跳过 / 今日统计 / 退出」五项，菜单点击通过 `mpsc::channel` 通知主线程状态变更。
  3. 加系统通知：用 `notify-rust` 在每个阶段切换时弹原生通知（标题 + 正文 + 5s 自动消失），并播放短音效（用 `rodio` 解码 WAV 流播放）。
  4. 加专注统计页面：按天 / 周 / 月聚合 SQLite 数据，用 `egui` 画柱状图（每日番茄数）+ 热力图（365 天格子），给出 SQL 聚合查询与 egui 绘图代码。最后给 laew 加一个 `/pomodoro 25m` 命令让 AI 在任务执行时跑番茄钟。

### BK04 批量重命名 GUI：规则链、预览与撤销
- **预期档位**: medium
- **考察维度**: 文件系统操作 + 规则引擎 + 可逆性
- **对话脚本**:
  1. 写一个批量重命名 GUI（用 `egui`）：左侧目录树（递归读取，深度限制 5），右侧文件列表，每行显示「原名 → 新名」预览，规则支持：正则替换、序号填充（`{n:03d}`）、日期前缀、扩展名转换、大小写转换。
  2. 基于上面的实现，设计规则链：用户可拖拽多个规则按顺序组合，每条规则接收 `FileEntry { path, name, ext }` 返回新 `FileEntry`，链尾输出最终新名；预览列实时计算（不真改文件）。
  3. 加上撤销机制：执行前把「原路径 → 新路径」映射写入 SQLite `rename_journal` 表，撤销时反向 `std::fs::rename`，支持任意中间状态回退（不只回退一步）。
  4. 处理冲突：目标名已存在时自动追加 `_1` `_2` 后缀，给出冲突检测算法（HashMap<新名, Vec<原名>> 分组）。最后评估能否给 laew 的 Bash 工具加一个 `--dry-run` 模式用同样的规则链做危险操作预演。

### BK05 看图工具：大图加载、缩放与 EXIF 读取
- **预期档位**: medium
- **考察维度**: 大图分块加载 + 缩放渲染 + 元数据
- **对话脚本**:
  1. 写一个 Rust 看图工具：用 `image` crate 解码 PNG / JPG / WebP / GIF，用 `image::imageops::resize` 做缩放，但 100MB+ 大图直接全解码会 OOM（5000x5000 RGBA = 100MB）。给出分块解码策略：用 `image::ImageDecoder` + `set_limits(50_000_000)` 限制内存峰值。
  2. 基于上面的实现，加视口（viewport）渲染：只渲染当前可见区域 + 周围 100 像素 buffer，配合鼠标滚轮缩放（步长 1.2 倍）和拖拽平移，用 `egui` 的 `ScrollArea` + 自定义 paint callback。
  3. 加 EXIF 读取：用 `kamadak-exif` 解析 JPEG APP1 段，显示相机型号、镜头、焦距、快门、ISO、GPS 坐标（在地图上用 `egui::Painter` 画一个 marker），支持按拍摄日期排序缩略图网格。
  4. 加图片格式批量转换：多线程（`rayon`）把目录里所有图片转 WebP（质量 85），进度条用 `indicatif`。最后评估能否给 laew 的 Read 工具加一个「读图」能力，把图片作为多模态输入喂给支持视觉的模型。

### BK06 本地音乐播放器：解码、播放列表与歌词同步
- **预期档位**: hard
- **考察维度**: 音频解码 + 播放控制 + LRC 解析
- **对话脚本**:
  1. 写一个 Rust 本地音乐播放器：用 `symphonia` 解码 MP3 / FLAC / OGG（pure Rust，跨平台），用 `cpal` 输出 PCM 流（自动选默认输出设备），后台线程解码 → 通道送 → 播放线程消费。
  2. 基于上面的实现，加播放列表：扫描用户目录（递归 3 层 + 扩展名白名单 mp3/flac/ogg/m4a），写入 SQLite `playlist` + `tracks` 两表（外键关联），支持拖拽排序、循环模式（顺序 / 单曲 / 列表循环 / 随机）。
  3. 加 LRC 歌词同步：解析 `[mm:ss.xx]lyric` 格式为 `Vec<(Duration, String)>`，播放时用 `Instant::now() - play_start` 找到当前行，时间误差超过 50ms 跳到下一行；在 GUI 上高亮当前行 + 上下滚动。
  4. 加可视化：把 PCM 采样送 `rustfft` 做 1024 点 FFT，输出 64 个频段强度，画到 `egui` 顶部的柱状频谱（30 FPS 刷新）。最后评估能否给 laew 加一个 `/play <query>` 命令用同样的 symphonia 链路解码 + TTS 播报任务结果。

### BK07 密码管理器：主密钥派生、加密存储与自动填充
- **预期档位**: hard
- **考察维度**: KDF + AES-GCM 加密 + 安全 UX
- **对话脚本**:
  1. 写一个 Rust 密码管理器：主密码用 Argon2id 派生（`argon2` crate，m=64MB t=3 p=4，盐值随机 16 字节存文件头），派生 32 字节密钥用 `aes-gcm` 加密 vault.db（SQLite 整体加密）。
  2. 基于上面的实现，建表 `entries(id, name, username, password_enc, url, notes_enc, created_at, updated_at)`，新增条目时对 password 字段单独再加密一次（key = 主密钥的 SHA256 派生子密钥），实现「字段级加密」防止 SQL 泄漏。
  3. 加自动填充：监听浏览器焦点事件（用 `rdev` 全局键盘 / 鼠标钩子，识别 Ctrl+\\），弹出小型窗口列出匹配当前域的条目，回车后 5 秒内把剪贴板填充（之后清空，避免泄漏）。
  4. 加密码生成器：长度 16 + 大小写 + 数字 + 符号 + 用 `rand::thread_rng()`，并给出强度评分（zxcvbn 算法，Rust port `zxcvbn-rs`）。最后评估 laew 已有的「凭证加密(L1600)」是否可以用同样的 Argon2id + AES-GCM 重构。

### BK08 串口与网络调试助手：十六进制视图与协议脚本
- **预期档位**: medium
- **考察维度**: 串口 / TCP / 协议解析 / 脚本化
- **对话脚本**:
  1. 写一个串口调试助手：用 `serialport` crate 列出可用串口（`available_ports()`），打开后 `read` / `write` 字节流，UI 显示 ASCII 视图 + 十六进制视图（用 `egui::TextEdit` 多行，hover 显示字节值）。
  2. 基于上面的实现，加 TCP / UDP 网络调试：`tokio::net::TcpStream` + `UdpSocket`，可作为客户端连接或服务端监听（本地 0.0.0.0:port），同样双视图显示，给出连接状态栏（已连接 / 断线 / 重连中）。
  3. 加协议脚本：内置 Modbus RTU（功能码 01/03/06/10，CRC16-MODBUS 计算）与简单自定义帧 `[length][type][payload][crc8]`，用户选协议 + 配置参数后点「发送」自动组帧，接收后自动校验 + 解析显示。
  4. 加历史记录与脚本录制：所有收发包写入 SQLite `protocol_log` 表，可导出 CSV；脚本录制把操作序列存为 JSON，重放时按时间戳回放。最后评估能否给 laew 的 SubAgent 加一个 `serial-tool` 用来读写硬件调试串口。

### BK09 Markdown 笔记本：本地全文搜索与双向链接
- **预期档位**: medium
- **考察维度**: 文件系统监听 + FTS5 + 双向链接解析
- **对话脚本**:
  1. 写一个 Markdown 笔记本（用 `egui`）：笔记存为本地 `.md` 文件（每篇一文件，UTF-8 编码），目录约定 `~/notes/{YYYY-MM-DD}-{slug}.md`，启动时全量索引，编辑时 debounce 300ms 后增量更新。
  2. 基于上面的实现，加全文搜索：用 SQLite FTS5 虚拟表 + `unicode61` 分词器（中文再外挂 `jieba-rs`），查询支持短语（`"exact phrase"`）、字段限定（`title:keyword`）、布尔运算（`A AND B OR C`），结果按 BM25 排序。
  3. 加双向链接（`[[WikiLink]]` 风格）：解析 Markdown 文本里的 `[[note-name]]`，建立 `links` 表（source_path, target_path, line_no），反向链接面板显示「哪些笔记链向我」。重命名 / 删除笔记时级联修复链接。
  4. 加标签 + 时间线：每篇笔记 frontmatter 可写 `tags: [rust, project]`，按标签聚合视图；时间线视图按 `updated_at` 倒序显示最近 30 天编辑记录。最后评估能否给 laew 加一个 `/note <query>` 把 SessionContext 摘要写入同一个 notes 目录并用 FTS5 索引。

### BK10 系统监控挂件：低开销采样与迷你图表
- **预期档位**: medium
- **考察维度**: 系统信息采样 + 实时图表 + 资源开销控制
- **对话脚本**:
  1. 写一个系统监控挂件（Windows / macOS / Linux）：用 `sysinfo` crate 每秒采样一次 CPU 整体 + 各核心、内存（used / total / swap）、磁盘读写速率、网络上下行，进程列表（按 CPU / 内存排序 top 20）。
  2. 基于上面的实现，加迷你图表：用 `egui::Painter` 画 sparkline（128x32 像素），CPU / 内存 / 网络各一条，60 秒滑动窗口（环形缓冲 `VecDeque<f32>` 容量 60）；要求整个应用空闲时 CPU 占用 < 1%，内存 < 30MB。
  3. 加桌面挂件模式：用 `tao` 创建无边框 + 透明背景 + always-on-top 窗口，可拖拽定位 + 自动吸附屏幕边缘，鼠标穿透用平台特定 API（Windows `WS_EX_TRANSPARENT`，X11 `shape_input`）。
  4. 加告警阈值：CPU > 90% 持续 30s 或磁盘 < 5GB 时弹通知（`notify-rust`），告警规则存 SQLite。最后评估能否给 laew 加一个 `--statusbar` 实时显示当前 Session 的 CPU / 内存 / LLM token 速率。
