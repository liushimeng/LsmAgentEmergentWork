- **预期档位**: medium

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 用 Python 写 `tmpPlan/agent-test/cy02/backoff.py`：实现四种抖动策略——（1）full jitter：`random(0, cap)`；（2）equal jitter：`cap/2 + random(0, cap/2)`；（3）decorrelated jitter：`min(cap, random(base, prev*3))`；（4）decorrelated jitter v2：`min(cap, base * 2^n * random())`；base=100ms、cap=30s。
  2. 用 Write 构造一个测试脚本 `tmpPlan/agent-test/cy02/test_backoff.py`：对每种策略仿真 1000 次重试，记录延迟分布。

  4. 用 Bash 断言：`test -s histogram.png && python3 -c "import json; d=json.load(open('stats.json')); assert all(d[s]['mean']>0.1 and d[s]['mean']<30 for s in ['full','equal','decorrelated','decorrelated_v2']), '延迟应在 0.1~30s'"` 图片生成且延迟合理则 echo PASS。
