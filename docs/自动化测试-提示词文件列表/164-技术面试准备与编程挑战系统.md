### FD01 面试题库自动生成器

- **预期档位**: hard
- **考察维度**: 模板引擎 / 知识点覆盖 / 难度控制
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/fd01_question_bank.py`：面试题库生成器，输入岗位 JD 与技能要求，按知识点分类生成题目（选择题/简答题/编程题/系统设计题），支持难度标签（简单/中等/困难）和知识点标签，输出 Markdown 题库 + JSON 索引。规则：每个知识点至少 3 题，难度分布 3:4:3。
  2. Bash：`python3 -m py_compile tmpPlan/agent-test/fd01_question_bank.py`，断言退出码为 0。
  3. Read `tmpPlan/agent-test/fd01_question_bank.py`，再 Write `tmpPlan/agent-test/fd01_jd.json`：一份后端开发工程师 JD（含 5 个核心技能点），字段沿用第一轮。本轮必须显式复用第一轮的题型分类与难度分布规则，不允许另起无关主题。
  4. Bash：`python3 tmpPlan/agent-test/fd01_question_bank.py tmpPlan/agent-test/fd01_jd.json 2>&1 | tee tmpPlan/agent-test/fd01_bank_output.txt`，断言 `grep -c '简单'` ≥ 5、`grep -c '中等'` ≥ 5、`grep -c '困难'` ≥ 3、`grep -c '知识点'` ≥ 5。
