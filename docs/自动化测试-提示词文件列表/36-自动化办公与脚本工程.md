### AK01 Python 自动化：Excel 报表批量生成

- **考察维度**: 办公文档 + 批量处理
- **对话脚本**:
  1. 用 openpyxl 读取一个含多 Sheet 的 Excel 文件，汇总各 Sheet 的销售数据到一个总表，写出完整代码。
  2. 给汇总表加条件格式：销售额 > 10000 标绿、< 1000 标红，并插入一个柱状图。
