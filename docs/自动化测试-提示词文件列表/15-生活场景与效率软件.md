# 自动化测试提示词 — 生活场景与效率软件（O01–O10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**日常生活化电脑问题、大众效率软件、数字生活整理**等
非开发者场景中的表现，与 C 维度（服务器/运维视角）、D 维度（开发者工具链）
互补：本维度面向"普通用户的电脑与软件"。
涵盖家庭网络排查、换机迁移、账号安全、Excel 透视表、PDF 处理、浏览器效率、
远程办公设备、个人媒体库、收件箱整理、纸质文档数字化等主题。

---

### O01 家庭 Wi-Fi 故障排查
- **预期档位**: simple
- **考察维度**: 生活化网络排查流程
- **对话脚本**:
  1. 家里 Wi-Fi 能连上但网页打不开，给一份从简到繁的排查清单（区分"是手机问题还是宽带问题"）。
  2. 光猫和路由器重启的正确顺序是什么？为什么顺序错了常常白等？
  3. 双频路由器的 2.4G 和 5G 信号怎么选？家里隔两堵墙该连哪个？
  4. 如果只有某个房间信号差，对比"电力猫 / Mesh 组网 / 换路由器位置"三种方案的优劣。

### O02 换手机数据迁移
- **预期档位**: simple
- **考察维度**: 数据迁移清单思维
- **对话脚本**:
  1. 安卓换安卓、iPhone 换 iPhone、跨平台互转，三种迁移路径各是什么？
  2. 官方迁移工具容易漏掉哪些数据（如微信聊天记录、双因素验证器、银行 App 登录态）？列一份易漏清单。
  3. 微信聊天记录跨设备迁移的具体步骤和常见失败原因是什么？
  4. 给出"迁移完成后旧手机处置"的安全清单：退出账号、抹除数据、SIM/SD 卡处理。

### O03 个人账号安全加固
- **预期档位**: simple
- **考察维度**: 安全习惯养成（与 J07 密码学理论角度不同）
- **对话脚本**:
  1. 为什么"所有网站用一个密码"很危险？解释撞库攻击的原理。
  2. 密码管理器的工作原理是什么？主密码忘了怎么办？选型时该看哪三点？
  3. 两步验证（2FA）的短信、TOTP、硬件钥匙三种方式安全性怎么排？分别防住什么攻击？
  4. 给我一份"今晚就能做完"的账号安全加固清单，按 15 分钟能完成的粒度拆分。

### O04 Excel 函数与透视表实战
- **预期档位**: medium
- **考察维度**: 大众软件深度使用 + 界面操作表达
- **对话脚本**:
  1. 一张订单表（订单号/日期/城市/品类/金额），用 VLOOKUP 把另一张"城市→大区"映射表匹配进来；顺带说明 XLOOKUP 比 VLOOKUP 好在哪。
  2. 用数据透视表统计"每个大区每个品类的月度销售额"，描述操作步骤（拖拽字段的过程要具体）。
  3. 给透视表结果加"界面美化"：条件格式色阶、冻结首行、数字千分位，各在哪个菜单里设置？
  4. 同样的需求改用"Power Query"做可刷新的管道，和手动透视表相比好处是什么？什么时候没必要上它？

### O05 PDF 日常处理
- **预期档位**: simple
- **考察维度**: 文档格式日常操作
- **对话脚本**:
  1. 合并、拆分、压缩 PDF 各怎么做？给出免费工具方案（本地命令行 + 在线工具各一）。
  2. 扫描版 PDF（图片型）想复制文字，怎么办？解释 OCR 的原理和识别率影响因素。
  3. 收到一份要签字回传的 PDF，不打印怎么完成"签名→嵌入→回传"？
  4. 讨论 PDF 和 Word/Markdown 各适合什么场景，为什么"PDF 是最终态、不是编辑态"？

### O06 浏览器效率与标签管理
- **预期档位**: simple
- **考察维度**: 浏览器深度使用
- **对话脚本**:
  1. 30 多个标签页卡到浏览器崩溃，怎么办？给一套"立刻自救 + 长期习惯"两步方案。
  2. 标签分组、固定标签、稍后读三类功能分别适合什么使用模式？怎么组合？
  3. 推荐 5 个提升效率的浏览器扩展，说明每个解决什么问题，并提示扩展权限的隐私风险怎么看。
  4. 多设备间同步书签/密码/扩展，各浏览器生态怎么选？密码该不该交给浏览器管？

### O07 远程办公设备与环境设置
- **预期档位**: simple
- **考察维度**: 会议软件与外设配置
- **对话脚本**:
  1. 视频会议里对方总说听不清我说话，按"硬件→系统→软件"三层排查麦克风问题。
  2. 背景杂音大，系统级降噪、会议软件降噪、外置麦克风三种方案分别怎么配？
  3. 逆光导致脸黑，用"灯光位置三原则"给出低成本补光方案（不用买专业设备）。
  4. 家庭网络下视频会议卡顿，怎么给会议流量做 QoS 优先？家里其他人看 4K 视频总打架怎么办？

### O08 个人媒体库整理与家庭影音
- **预期档位**: medium
- **考察维度**: 媒体文件规范 + 软件搭建（与 G01 通用重命名角度不同）
- **对话脚本**:
  1. 电影/剧集/音乐的文件名应该怎么规范命名？给出参考模板，说明为什么"规范命名"是媒体库软件识别的前提。
  2. 想在家里电视上看 NAS 里的电影，Jellyfin / Plex / Emby 三者怎么选？
  3. 写一个脚本：把下载目录里按模板命名的电影文件移动到 `媒体库/电影/{标题} ({年份})/` 目录结构，要求 dry-run 预览。
  4. 海报和元数据没刮削到（识别成了错误的片子），常见原因和手动修复的方法是什么？

### O09 收件箱整理与邮件过滤
- **预期档位**: simple
- **考察维度**: 邮件管理方法论（与 A03/A07 的"写邮件"角度不同）
- **对话脚本**:
  1. 解释 Inbox Zero 的核心理念，"每封邮件只碰一次"具体指什么？
  2. 邮箱里订阅邮件、通知邮件、真人邮件混在一起，设计一套过滤规则体系（规则条件→动作），用表格呈现。
  3. 怎么找出"我从来不看的订阅"并批量退订？给出识别标准和操作步骤。
  4. 讨论"邮件归档 vs 删除 vs 打标签"三种习惯，给一套"三个月后还能找到任何一封邮件"的最小规则集。

### O10 纸质文档数字化归档
- **预期档位**: medium
- **考察维度**: 数字化流程设计 + 长期可检索性
- **对话脚本**:
  1. 把家里十年的合同、发票、证书扫描归档，设计端到端流程：扫描参数、命名规范、目录结构。
  2. 扫描件只是图片，怎么做到"全文可搜索"？给出 OCR 批处理方案（含中文识别注意点）。
  3. 写一个脚本：把 `扫描件/` 里按 `YYYYMMDD_类型_关键词.pdf` 命名的文件自动归类到 `归档/{类型}/{年份}/`，异常命名的移到 `待人工/`。
  4. 讨论本地 + 云端的同步备份策略：重要证件类文档该不该放公有云？加密后再上传怎么做？
