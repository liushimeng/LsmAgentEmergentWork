# 自动化测试提示词 — 生活场景与效率软件（O01–O10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**日常生活电脑问题、大众效率软件、数字生活整理**等非开发者场景下的"可执行脚本化"能力：把家庭网络/换机/账号加固/PDF/媒体库/邮件/扫描等真实任务落成"现场跑通"的脚本与产物。全部产物落 `tmpPlan/agent-test/`。

---

### O01 家庭 Wi-Fi 故障排查脚本化
- **预期档位**: simple
- **考察维度**: 生活化网络排查 / 脚本闭环
- **工具链**: Write → Bash → Bash → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/o01_diagnose.sh`：用 `ip route show default` + `ip addr show` + `ping -c 1 -W 2 1.1.1.1` 三步定位（"路由是否拿到 → 接口是否拿到 IP → 外网是否可达"），把每步结果落到 `o01_step.txt`。
  2. Bash 跑 `bash o01_diagnose.sh`；若某步 fail，断言 `o01_step.txt` 含 `fail` 关键字（落到 stdout 报告），并对应给出"光猫/路由器"重启顺序（按 OFF→ON 30s 间隔）。
  3. Write `o01_signal_test.py`：用 python3 + `subprocess` 调用 `iwconfig`（无 iwconfig 时降级为 `iw dev`）检测本机 Wi-Fi 信号强度 RSSI，Bash 跑一遍断言输出含 `RSSI` 与 dBm 值。
  4. Write `tmpPlan/agent-test/o01_solution.md`：列出"只有某房间信号差"的 3 种方案对比表（电力猫 / Mesh / 换路由器位置），含成本与延迟。

### O05 PDF 日常处理：合并/拆分/OCR
- **预期档位**: simple
- **考察维度**: 文档格式日常操作 / 跑通产物
- **工具链**: Write → Bash → Bash → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/o05_make.py`：用 python `reportlab`（无则降级为生成纯文本 `.txt` 重命名）生成 3 页 A.pdf，再生成 2 页 B.pdf，共 5 页内容占位。
  2. Write `o05_merge.py`：调用 `PyPDF2`（无则降级为二进制拼接并标注"降级版"）合并 A.pdf+B.pdf 为 merged.pdf；Bash 跑后用 `python3 -c "import PyPDF2; r=PyPDF2.PdfReader('merged.pdf'); print(len(r.pages))"` 断言页数=5（降级时断言文件存在）。
  3. Write `o05_split.py`：把 merged.pdf 拆回 A_part.pdf (1-3)、B_part.pdf (4-5)；Bash 跑后断言 A_part 页数=3、B_part 页数=2。
  4. Write `tmpPlan/agent-test/o05_report.md`：解释 OCR 原理（图片→文本）与识别率影响因素（分辨率/字体/中英文混排）、PDF 与 Word/Markdown 的关系（PDF 是最终态/Word 是编辑态/Markdown 是源码态），并讨论"PDF 用于签字回传"的最小可行流程（签名→嵌入→回传 3 步）。
