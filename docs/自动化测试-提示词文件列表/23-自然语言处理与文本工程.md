# 自动化测试提示词 — 自然语言处理与文本工程（W01–W10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**中文分词、词性标注、命名实体识别、
文本分类、情感分析、机器翻译、文本摘要、问答系统、
语言模型推理、文本相似度**等"自然语言处理"垂直领域中的实战表现，
与 B 维度（知识问答）和 S 维度（AI 工程）互补：
B 考察"通用知识问答"，S 考察"LLM 应用工程化"，
本维度考察"传统 NLP 技术与文本处理工程"。
所有主题都以"动手写 NLP 代码或设计文本处理方案"为核心，强调文本工程能力。

### W01 中文分词：jieba 与分词算法
- **预期档位**: medium
- **考察维度**: 分词技术 + 词典 + 歧义消解
- **对话脚本**:
  1. 解释中文分词的难点：为什么中文需要分词而英文不需要？列举 3 种分词歧义例子。
  2. 用 Rust 的 `jieba-rs` 库实现一个中文分词工具：输入一段中文，输出分词结果和每个词的词性。
  3. 加上自定义词典：让"大语言模型"作为一个整体词被切分，而不是切成"大/语言/模型"。
  4. 讨论：jieba 的分词算法原理是什么（基于前缀词典 + HMM）？和最大匹配法相比有什么优势？

### W02 词性标注与命名实体识别
- **预期档位**: medium
- **考察维度**: 序列标注 + NER + 实体抽取
- **对话脚本**:
  1. 解释词性标注（POS Tagging）和命名实体识别（NER）的区别，各解决什么问题。
  2. 用 Python 的 `spaCy` 实现 NER：从一段新闻文本中人名、地名、机构名、时间实体。
  3. 把抽取结果导出为结构化 JSON，包含实体文本、类型、起止位置。
  4. 讨论：NER 的 BIO/BILOU 标注方案是什么？"嵌套实体"（如"北京大学计算机系"包含"北京大学"）怎么处理？

### W03 文本分类：从 TF-IDF 到深度学习
- **预期档位**: medium
- **考察维度**: 文本分类 + 特征工程 + 模型选择
- **对话脚本**:
  1. 解释文本分类的经典流程：分词 → 特征提取（TF-IDF）→ 分类器（SVM/朴素贝叶斯）。
  2. 用 Python 实现一个新闻主题分类器：训练数据是 1000 条标记为"科技/体育/财经"的新闻，用 TF-IDF + 朴素贝叶斯训练。
  3. 加上交叉验证：用 5 折交叉验证评估模型准确率，输出混淆矩阵。
  4. 讨论：什么时候该用传统机器学习（TF-IDF + SVM）而不是深度学习（BERT）？各自的适用场景？

### W04 情感分析：判断文本的情绪倾向
- **预期档位**: medium
- **考察维度**: 情感分析 + 词典方法 + 机器学习
- **对话脚本**:
  1. 解释情感分析的三种粒度：文档级、句子级、方面级（Aspect-based），各举一个例子。
  2. 用 Python 实现一个基于词典的情感分析器：给定一个情感词词典（正面词 + 负面词），计算文本的情感得分。
  3. 处理否定词和程度副词："非常好"应该比"好"得分高，"不好"应该反转情感。
  4. 讨论：为什么"这个手机不贵"在词典方法下容易被误判？怎么用机器学习解决这个问题？

### W05 文本摘要：抽取式与生成式
- **预期档位**: medium
- **考察维度**: 摘要算法 + 信息压缩 + 评估指标
- **对话脚本**:
  1. 解释抽取式摘要和生成式摘要的区别，各举一个典型算法（TextSeq / BERTSUM / T5）。
  2. 用 Python 实现一个抽取式摘要器：基于 TextRank 算法，从长文中提取最重要的 3 个句子。
  3. 加上 ROUGE 评估：对比机器摘要和人工参考摘要的 ROUGE-1/ROUGE-L 分数。
  4. 讨论：抽取式和生成式摘要各适合什么场景？为什么新闻摘要通常用抽取式而论文摘要用生成式？

### W06 文本相似度：余弦相似度与语义匹配
- **预期档位**: medium
- **考察维度**: 相似度计算 + 向量化 + 语义匹配
- **对话脚本**:
  1. 解释文本相似度的两种计算方式：基于词频（TF-IDF + 余弦相似度）和基于语义（Sentence-BERT）。
  2. 用 Python 实现一个基于 TF-IDF 的文本相似度计算器：输入两段文本，输出 0-1 的相似度分数。
  3. 加上 Sentence-BERT 版本：对比两种方法在"同义词改写"和"字面相似但语义不同"两类样本上的表现差异。
  4. 讨论：余弦相似度和欧氏距离在文本相似度任务上有什么区别？为什么通常用余弦相似度？

### W07 机器翻译：从统计翻译到神经翻译
- **预期档位**: hard
- **考察维度**: 翻译技术 + 注意力机制 + BLEU 评估
- **对话脚本**:
  1. 解释机器翻译的三个时代：基于规则的（RBMT）、基于统计的（SMT）、基于神经网络的（NMT），各有什么特点。
  2. 用 Python 的 `transformers` 库调用 Hugging Face 的中英翻译模型（如 `Helsinki-NLP/opus-mt-zh-en`），实现翻译功能。
  3. 加上 BLEU 评估：对比机器翻译和参考翻译的 BLEU 分数。
  4. 讨论：Transformer 的注意力机制是怎么解决长距离依赖问题的？"注意力可视化"能帮助我们理解翻译过程吗？

### W08 问答系统：检索式与生成式
- **预期档位**: hard
- **考察维度**: QA 系统 + 阅读理解 + 生成式问答
- **对话脚本**:
  1. 解释检索式 QA 和生成式 QA 的区别，各自的典型架构是什么。

### W09 语言模型推理：量化与加速

- **考察维度**: 模型推理 + 量化 + KV Cache + 推理框架
- **对话脚本**:
  1. 解释大语言模型推理的两个阶段：Prefill（预填充）和 Decode（自解码），哪个阶段更耗时？

  4. 讨论：INT4/INT8/FP16 量化各损失多少精度？什么场景下值得牺牲精度换速度？
