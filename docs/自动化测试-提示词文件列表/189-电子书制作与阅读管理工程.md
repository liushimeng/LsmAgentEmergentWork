> 编号段 GA01–GA10 · 聚焦「EPUB 生态全链路」：EPUB 结构解剖 / EPUB 生成器 / 格式对比与转换决策 / Calibre CLI 批量处理 / 元数据与封面治理 / 目录与导航 / 字体嵌入与排版 / 书库全文检索 / 阅读进度管理 / OPDS 订阅分发
>
> 与现有维度互补说明：
> - `64-文件格式解析与序列化编程`（BM 维）覆盖 PNG/ZIP/WAV/xlsx/Protobuf/CBOR/SQLite/CSV/YAML **不含 EPUB**；本文件 GA01 从 ZIP 容器角度解剖 EPUB，是该维度的电子书垂直版。
> - `134-办公自动化与文档处理工程实战`（DZ 维）聚焦 Excel/PDF/Word **办公文档**；本文件聚焦**电子书格式生态**（EPUB/mobi/阅读器/书库），不做办公文档。
> - `111-排版渲染与打印引擎编程`（DC 维）聚焦**断行分页渲染算法**；本文件聚焦**EPUB 制品结构与工具链**，不实现排版引擎。
