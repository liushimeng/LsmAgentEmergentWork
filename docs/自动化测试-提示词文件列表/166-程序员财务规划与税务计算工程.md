### FF01 薪资结构与谈判策略计算器

- **预期档位**: medium
- **考察维度**: 薪资构成分析 / 谈判策略 / 对比决策
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/ff01_salary_calc.py`：薪资计算器，输入 offer 详情（基本工资/绩效/股票/期权/签字费/年终奖月数），计算：税前年收入 + 税后年收入 + 月度到手 + 总包价值。支持多 offer 对比 + 谈判策略建议（基于市场分位数）。
  2. Bash：`python3 -m py_compile tmpPlan/agent-test/ff01_salary_calc.py`，断言退出码为 0。
  3. Read `tmpPlan/agent-test/ff01_salary_calc.py`，再 Write `tmpPlan/agent-test/ff01_offers.json`：3 个 offer（大厂/外企/创业公司），字段沿用第一轮。本轮必须显式复用第一轮的薪资构成字段与计算方法，不允许另起无关主题。
  4. Bash：`python3 tmpPlan/agent-test/ff01_salary_calc.py tmpPlan/agent-test/ff01_offers.json 2>&1 | tee tmpPlan/agent-test/ff01_salary_report.md`，断言 `grep -F '税后年收入'` 命中、`grep -F '对比'` 命中、`grep -F '谈判建议'` 命中。
