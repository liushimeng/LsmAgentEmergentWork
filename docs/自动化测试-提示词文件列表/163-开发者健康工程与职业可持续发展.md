### FC01 久坐检测与运动提醒系统

- **预期档位**: medium
- **考察维度**: 健康监测逻辑 / 定时提醒算法 / 跨平台兼容
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/fc01_sedentary.py`：久坐检测器，输入工作时段日志（开始时间/结束时间/活动类型），计算连续久坐时长（超过 45 分钟未活动触发提醒），输出提醒计划表（含推荐运动：颈部放松/眼部休息/站立伸展/散步），支持 `--remind-interval` 参数自定义提醒间隔。
  2. Bash：`python3 -m py_compile tmpPlan/agent-test/fc01_sedentary.py`，断言退出码为 0。
  3. Read `tmpPlan/agent-test/fc01_sedentary.py`，再 Write `tmpPlan/agent-test/fc01_worklog.json`：一天的工作日志（8 小时，含 3 段超过 1 小时的久坐），字段沿用第一轮。本轮必须显式复用第一轮的活动类型与提醒间隔参数，不允许另起无关主题。
  4. Bash：`python3 tmpPlan/agent-test/fc01_sedentary.py tmpPlan/agent-test/fc01_worklog.json 2>&1 | tee tmpPlan/agent-test/fc01_reminders.txt`，断言 `grep -c '提醒'` ≥ 3、`grep -F '颈部放松\|眼部休息\|站立伸展'` 至少命中 2 种运动类型。
