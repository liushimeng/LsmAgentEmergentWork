# 229 远程电源与开关机治理实战

> 编号段 HP01–HP10 · 聚焦「机器电源状态的可控与可审计」：WoL 魔包构造发送 / 唤醒链路核查 / 三平台定时开关机 / 合盖与休眠策略矩阵 / 睡眠抑制保活 / 优雅关机编排 / 带外电源通道 / 电源审计与自唤醒排查 / 无人值守升级重启窗 / 断电演练恢复
>
> 与现有维度互补说明：
> - `118-Linux服务器治理进阶systemd服务化与批量运维`（DJ 维）聚焦**服务生命周期**（systemd unit/timer）；本文件聚焦**整机电源状态机**（睡眠/唤醒/关机/重启），timer 只是实现定时唤醒的手段之一。
> - `162-Homelab自托管服务与家庭实验室治理`（EA 维）的 UPS/备份是**被动应对断电**；本文件是**主动治理电源状态**（含计划外场景演练），方向相反。
> - `192-跨平台硬件诊断与设备健康巡检`（GD 维）测**电池/传感器的健康度**；本文件管**电源策略与动作**，测的是状态迁移不是硬件参数。
> - `178-跨平台通知与消息通道治理`（FN 维）提供通知管道；本文件在升级窗口与演练中消费通知能力，不重复建设。
>

  1. Write `tmpPlan/agent-test/hp01_wol.py`：魔包工具：(a) **构造**：`FF×6 + MAC×16` 共 102 字节（MAC 形态归一：冒号/横线/无分隔互转）；扩展 **SecureOn 密码**（魔包尾部 +4/6 字节口令，部分网卡支持）格式注记；(b) **发送**：`socket` UDP 广播到 `255.255.255.255:9` 与**定向子网广播**（由本机 IP/掩码算如 `192.168.1.255`——跨网段只有定向+路由器定向广播转发才可达，注记运营商网关通常拦）；(c) **发送前探测**：本机 IP/网卡列表（`socket.gethostbyname_ex` / psutil-free 方法），无网卡环境诚实报 SKIP；(d) **重发策略**：默认连发 3 次间隔 1s（首包可能在 ARP 未建时丢失）；(e) **安全边界注释**：仅对自有测试网段设备使用，写明"对他人设备发魔包=未授权访问"红线；(f) `--dry-run` 只打印 hex 不发包。
