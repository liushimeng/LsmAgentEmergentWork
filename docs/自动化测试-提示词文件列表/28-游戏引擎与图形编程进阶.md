# 自动化测试提示词 — 游戏引擎与图形编程进阶（AB01–AB10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度从 Agent 能力视角考察**游戏工程链路**：物理模拟、寻路、AI、网络同步、渲染算法。无 pygame/wgpu 可用，全部降级为 python3 纯数值模拟 + numpy 软件光栅，每条都给出数值断言（位置误差 < 1e-6、寻路长度等于 BFS、像素直方图匹配）。考察 Agent 在无图形环境下用数学与算法复现游戏系统核心逻辑的能力。

### AB01 2D 平台跳跃：手感与关卡外置
- **预期档位**: medium
- **考察维度**: 物理手感 / 数据驱动关卡
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `platformer.py`：纯 python 实现 `Player(vx, vy, on_ground)` + 重力 + 单平台 AABB 碰撞反弹。主循环 dt=1/60 跑 600 帧（10 秒），期望落到平台后 vy=0 且 y 坐标误差 < 1e-9。Bash 跑 `python3 platformer.py --test physics` 期望断言通过。
  2. 加「土狼时间」：离地后 6 帧内仍可起跳。构造「刚离地 3 帧时按跳」场景，期望 vy 重新变为负值；「离地 10 帧时按跳」期望无效。Read `platformer.py` 验证 coyote timer 计数器存在。
  3. 加「跳跃缓冲」：落地前 6 帧按跳、落地即起跳。构造「落地前 3 帧按跳」场景，期望落地后 1 帧 vy<0；「落地前 10 帧按跳」期望落地后无跳跃。Read 验证 jump_buffer 计数器。
  4. 关卡数据外置 `level.txt`：用 heredoc 生成 ASCII 关卡（`P`=平台 `S`=尖刺 `B`=出生），`python3 platformer.py --level level.txt` 加载生成场景。故意把 ASCII 写错一行（尖刺坐标压住出生点），跑 `--validate` 期望报错指出冲突坐标；修复后通过。

### AB02 固定时间步 + 插值渲染
- **预期档位**: simple
- **考察维度**: 游戏循环架构 / 数值稳定
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `fixed_step.py`：经典 accumulate 累加器循环（物理 60Hz 固定步）+ 最大步数上限防死亡螺旋。模拟低帧率场景：每帧 dt=0.05s（20FPS），跑 120 帧物理，期望步数恰好 60×6=360（累计补偿准确）；故意给 dt=2.0s 期望最大步数触发并 clamp。Read 验证 `MAX_STEPS_PER_FRAME` 存在。
  2. 加渲染插值：在上一物理状态与当前状态之间按 alpha 插值，记录 100 个插值点。期望 alpha ∈ [0,1) 且插值位置严格落在 prev/curr 之间。Read 验证 `prev_pos`/`curr_pos` 双缓冲。
  3. 跑物理确定性测试：用固定种子跑 1000 步，期望最终位置完全可复现（`run1.pos == run2.pos`）。故意在物理里加 `random.random()` 未播种，跑两次期望位置漂移，写 `non-determinism-bug.md`。
  4. 用 `time` 命令跑固定步 vs 可变步对照：固定步版 1000 帧 wall < 200ms，可变步版同样 1000 帧 wall < 250ms；写 `step-rate-choice.md` 总结格斗/平台常用步率与联机同步的耦合关系（不超过 8 行）。

### AB03 碰撞检测：AABB + CCD + SAT
- **预期档位**: hard
- **考察维度**: 碰撞体系 / 空间优化
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `collision.py`：暴力版 `brute_aabb_check`（n×n 两两判定）vs 优化版 `aabb_mtv`（单次扫描 + 最小平移向量分离响应）。对 100 个 AABB 随机位置，期望两版碰撞对列表完全一致；500 个 AABB 性能测试，期望 mtv 版 < 50ms。
  2. 实现离散 CCD 射线步进：高速子弹每帧分 8 步扫描。构造「子弹 v=2000px/s、墙厚 5px」场景，期望暴力单步版穿透（hits 列表为空），CCD 版命中。Read 验证 step 数 = `ceil(speed * dt / thickness)`。
  3. 加 SAT 旋转矩形碰撞：暴力版（两矩形 4×4 顶点对判定 O(n²)）vs SAT 版（分离轴候选 = 两矩形边法向，max 16 轴）。对 100 组随机旋转矩形期望判定一致；500 组性能测试期望 SAT 版快 5x 以上。
  4. 均匀网格 broad-phase：500 个移动物体期望网格版 < 30ms（用 `time`），暴力版 < 200ms。Read 验证网格 cell_size 自适应 `cell = obj_size * 2`。写 `collision-perf.md` 总结三种 broad-phase 适用场景。

### AB04 A* 寻路 + 启发式选择
- **预期档位**: medium
- **考察维度**: 寻路算法 / 工程扩展
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `astar.py`：暴力 BFS `bfs_path(grid, src, dst)` vs A* `astar(grid, src, dst, heuristic)`。对 100 个 30×30 随机迷宫，期望路径长度相等；当 heuristic=曼哈顿时，A* 扩展节点数 < BFS × 0.6。
  2. 三种启发式对照：曼哈顿/欧氏/切比雪夫在同一迷宫跑 100 次，统计扩展节点数。期望三种启发式都能找到最短路径（长度与 BFS 相等），扩展节点数切比雪夫 ≤ 曼哈顿。写 `heuristic-compare.md`。
  3. 处理对角穿墙坑：grid 有障碍物阻挡对角移动时强制绕直角。构造 3 处穿墙陷阱期望 A* 不会走对角穿墙。Read 验证禁止规则分支。
  4. 不同地形代价：沼泽 cost=5、大路 cost=1，期望 A* 自动避开沼泽（在 cost 允许更短时才穿）。100 个随机地形迷宫跑对拍，期望路径代价与「暴力 Dijkstra」版（同样地形代价设置）完全相等。写 `astar-dijkstra.md` 总结两种算法在地形代价场景的统一性。

### AB06 网络对战：帧同步 vs 状态同步
- **预期档位**: hard
- **考察维度**: 网络同步 / 确定性
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `sync.py`：帧同步版 `frame_sync_sim(seed)`（输入序列决定输出序列）+ 状态同步版 `state_sync_sim(state)`（状态由服务端权威）。对同一随机输入序列（100 步）跑两版 100 次，期望帧同步版每次状态完全一致，状态同步版允许浮点累积漂移 < 1e-6。Read 验证两版核心状态变量名一致。
  2. 加确定性破坏测试：故意在帧同步版加 `dict` 迭代（Python 3.7+ 有序但需注释），跑同一 seed 100 次期望完全可复现；再加 `random.random()`（无种子），跑两次期望不一致。写 `determinism-trap.md`。
  3. 实现回滚网络最小演示：本地点 0 预测 + 输入延迟 2 帧 + 预测错误时回到 `snapshot[frame-N]` 重演。构造「服务端延迟一帧纠正」场景，期望本地最终态 = 服务端最终态（误差 < 1e-6）。
  4. 用 `socket` 模拟 UDP 协议：序列号 + ACK + 超时重发 + 包序重组（本地 127.0.0.1 端口）。跑 100 帧协议，故意丢包 20%，期望接收端包序最终完整且无重复；用 `tcpdump`/`ss` 不强求，自查重组日志即可。写 `udp-vs-tcp.md` 总结实时对战为何不用 TCP。

### AB07 3D 渲染管线 + 着色器（numpy 软件光栅）
- **预期档位**: hard
- **考察维度**: 图形学数学 / 像素级断言
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `raster.py`：纯 numpy 软件光栅画第一个三角形。顶点 (10,10)/(60,10)/(35,55) 屏幕空间，扫描线 + 半空间测试填充。期望输出 200×200 RGB 数组中三角形区域非黑像素数 > 800 且三角形外区域全 (0,0,0)；用 numpy `np.where(arr.sum(axis=2)>0)` 计数。Read 验证 barycentric 重心坐标实现。
  2. 加 Lambert 漫反射 + Blinn-Phong 高光：单方向光从 (1,1,1) 入射，固定法线朝 +Z。两个片元着色器写为 numpy 向量化操作。生成两幅 200×200 渲染图，期望漫反射图最大像素值 ≈ cos(θ)·1.0、Blinn-Phong 图存在高光斑（`np.max(arr) > 0.9`）；两图差异（`np.abs` 平均）应 > 0.1。
  3. 加 MVP 矩阵与深度缓冲：立方体 8 顶点 × 6 面三角化、透视投影、Z-buffer。绕 Y 轴旋转 0/45/90 度各渲一帧，期望 45 度帧可见三角形像素数介于 0 度（少遮挡）与 90 度之间；写 `rotation-test.md` 总结视角几何意义。
  4. 故意在 MVP 里漏掉透视除法（`w` 不归一化），跑 90 度旋转期望渲染异常（像素全 0 或溢出）；定位修复后写 `w-divide-bug.md`。整套产物落在 `tmpPlan/agent-test/`，无外网依赖。

### AB09 粒子系统 + 对象池
- **预期档位**: medium
- **考察维度**: 性能优化 / 数据布局
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `particle.py`：AOS 布局（list[Particle]）+ 每帧 alloc/free。1000 粒子跑 200 帧，统计每帧 alloc 次数，期望稳定在 1000（粒子发射 + 死亡循环触发 alloc）。用 `tracemalloc` 抓 peak。
