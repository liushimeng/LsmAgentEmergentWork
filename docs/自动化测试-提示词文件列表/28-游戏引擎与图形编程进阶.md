# 自动化测试提示词 — 游戏引擎与图形编程进阶（AB01–AB10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**游戏工程深水区**的实战能力：2D 平台物理与手感、固定时间步循环、
碰撞检测体系、A* 寻路、行为树 AI、网络同步、渲染管线与着色器、程序化生成、
粒子系统、存档系统。与 Q01（终端贪吃蛇）互补：Q01 是 TUI 小游戏入门，
本维度进入图形渲染、物理模拟与网络同步等引擎级话题，
覆盖"编写游戏程序"这一重点编程场景的进阶形态。

---

### AB01 2D 平台跳跃游戏：物理与手感
- **预期档位**: hard
- **考察维度**: 游戏物理 + 手感调参
- **对话脚本**:
  1. 用 pygame 实现一个 2D 平台跳跃 Demo：玩家左右移动、重力、跳跃、平台碰撞。先设计实体结构与主循环骨架。
  2. 打磨手感：加入"土狼时间"（离地后短暂仍可跳）与"跳跃缓冲"（落地前按跳、落地即起跳），解释这两个技巧各自解决什么问题。
  3. 实现可变跳跃高度：按住跳跃键上升快、提前松开则截断上升速度，给出参数调法。
  4. 把关卡数据外置成字符画文本格式，加载解析后生成平台、尖刺与出生点，换一张新地图无需改代码。

### AB02 固定时间步与插值渲染
- **预期档位**: medium
- **考察维度**: 游戏循环架构 + 数值稳定
- **对话脚本**:
  1. 为什么游戏循环要用"固定时间步更新 + 可变帧率渲染"？解释掉帧时物理与表现为什么会分岔。
  2. 实现经典 accumulate 累加器循环：物理 60Hz 固定步、渲染跟随真实帧率，并加最大步数上限防"死亡螺旋"。
  3. 加渲染插值：在上一物理状态与当前状态之间按 alpha 插值绘制，消除高刷屏下的画面抖动。
  4. 讨论时间步选择：格斗/平台游戏常用多少 Hz？为什么物理步率与渲染帧率解耦是联机同步的前提？

### AB03 碰撞检测：从 AABB 到 CCD
- **预期档位**: hard
- **考察维度**: 碰撞体系 + 空间优化
- **对话脚本**:
  1. 实现 AABB 碰撞与基于最小平移向量的分离响应，上/下/左/右四个方向分别处理。
  2. 解释"隧穿"问题：高速子弹穿过薄墙是怎么发生的？用射线步进实现离散 CCD 解决它。
  3. 旋转物体的碰撞：分离轴定理（SAT）怎么处理 OBB？实现两个旋转矩形的碰撞判定。
  4. 空间划分优化：实现均匀网格 broad-phase，用 500 个移动物体对比暴力两两检测的耗时差异并给出数据。

### AB04 A* 寻路与导航网格
- **预期档位**: hard
- **考察维度**: 寻路算法 + 工程扩展
- **对话脚本**:
  1. 实现网格版 A*：曼哈顿/欧氏/切比雪夫三种启发式的差别；启发式的可采纳性与最优性是什么关系？
  2. 处理两个经典坑：对角移动穿墙拐角、不同地形代价（沼泽慢、大路快）。
  3. 从网格升级到导航网格（NavMesh）：三角化区域上的 A* 与漏斗算法拉直路径分别怎么做？讲清思路。
  4. 动态障碍下的重规划：局部避障（速度障碍/势场）与全局 A* 怎么组合？再讨论分层寻路（HPA*）的思路。

### AB05 行为树游戏 AI
- **预期档位**: medium
- **考察维度**: AI 架构 + 数据驱动
- **对话脚本**:
  1. 用有限状态机做游戏 AI 的局限是什么？引出行为树：选择/序列/装饰器/叶子四类节点各自的语义。
  2. 实现一个"巡逻 → 发现敌人追击 → 近身攻击"的行为树骨架，用黑板存共享状态。
  3. 加装饰器节点：冷却时间、失败重试、并行节点；讨论 running 状态下高优先级节点的抢占打断。
  4. 把行为树配置外置成 JSON，运行时解析构建；与硬编码相比，这种数据驱动给策划工作流带来什么收益？

### AB06 网络对战：帧同步 vs 状态同步
- **预期档位**: hard
- **考察维度**: 网络同步 + 确定性
- **对话脚本**:
  1. 对比帧同步与状态同步：带宽、确定性要求、反外挂能力、断线重连成本各维度的差异。
  2. 帧同步的确定性要求：浮点运算、随机数、容器遍历顺序——为什么不同机器必须逐位一致？
  3. 讲清回滚网络思路：本地预测、输入延迟、预测错误后的回退重演，实现一个最小化演示。
  4. 用 UDP 设计最小对战协议：序列号、ACK、超时重发与包序重组，并说明为什么实时对战不用 TCP。

### AB07 3D 渲染管线与着色器
- **预期档位**: hard
- **考察维度**: 图形学 + GPU 编程
- **对话脚本**:
  1. 讲解现代 3D 渲染管线的完整流程：顶点着色 → 图元装配 → 光栅化 → 片元着色 → 输出合并，每步输入输出是什么？
  2. 用 wgpu（或 WebGL + GLSL）画第一个三角形：管线状态、顶点缓冲、着色器入口点逐项讲清。
  3. 写两个片元着色器：Lambert 漫反射与 Blinn-Phong 高光，对比效果差异与开销差异。
  4. 加上 MVP 矩阵与深度缓冲让立方体可旋转；解释齐次裁剪空间与透视除法的几何意义。

### AB08 程序化生成：噪声地形与地牢
- **预期档位**: hard
- **考察维度**: 程序化算法 + 种子复现
- **对话脚本**:
  1. 实现 Perlin 噪声（梯度噪声）：晶格、随机梯度、插值与平滑函数各自的作用。
  2. 用多个八度叠加生成一维高度图地形，参数化振幅与频率控制地形的"粗糙度"，给出几组参数与效果对照。
  3. 二维噪声 + 阈值切分生成岛屿地图，用颜色梯度渲染陆地/浅海/深海。
  4. 换一类生成器：随机游走挖房间 + 走廊连接生成地牢，保证连通性；讨论随机种子与生成结果复现。

### AB09 粒子系统与对象池
- **预期档位**: medium
- **考察维度**: 性能优化 + 数据布局
- **对话脚本**:
  1. 实现一个 CPU 粒子系统：发射器、生命周期、速度/重力/颜色随时间衰减。
  2. 用对象池消除每帧分配；讨论池大小预估、预分配与归还策略。
  3. 做一个爆炸特效：一次发射 2000 粒子、混合模式与加法发光；分析瓶颈在 CPU 更新还是填充率。
  4. 把粒子数据改成 SoA（结构数组 → 数组结构）布局：对比同粒子量下两种布局的缓存命中与帧耗时差异。

### AB10 游戏存档系统
- **预期档位**: medium
- **考察维度**: 序列化 + 版本迁移
- **对话脚本**:
  1. 设计存档数据模型：进度、背包、世界状态、设置分块存储；为什么"全量一个 JSON"在长线运营游戏里撑不住？
  2. 实现版本化存档：头部带版本号，写迁移函数把 v1 存档升级到 v2，并测试旧档兼容。
  3. 原子写入：临时文件 + rename 防止写一半崩溃损坏存档；实现并模拟中途崩溃验证。
  4. 多槽位与云存档冲突：Last-Write-Wins vs 字段级合并，给一个休闲游戏选型并说明理由。
