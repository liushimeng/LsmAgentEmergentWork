## 与 laew 工程的具体对接点

1. **CA31 → 离线场景适配**：当前 laew 在 LLM 不可用时会失败，建议增加「本地模式」（仅响应本地命令如 /help / /clear / /export，不调用 LLM）。
2. **CA33 → SQLite 索引优化**：当前 `providers` / `session_memory` / `agent_memory` 表可能缺索引，建议跑 `EXPLAIN QUERY PLAN` 审计并添加缺失索引（参考 laew `专题-laew实现进度对照表.md` 数据库章节）。
3. **CA37 → 边缘 AI 集成**：在 P0/P1/P2 路线图中加入 llama.cpp 集成（参考十三轮深挖 GGUF 专题），让 laew 在无网络场景下仍有基本任务分类能力。
4. **CA38 → Provider 调用重试**：当前 `LLMClient` 无重试机制，建议加指数退避（`backoff` crate）+ Provider failover（用户配置多 Provider）。
5. **CA40 → 多设备同步**：长期路线，需引入 laew Cloud + 端到端加密，与现有单文件本地定位有冲突，需要产品决策。
