> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。
>
> 编号段 CU01–CU10 · 聚焦「数据编码与压缩」：RLE / Delta / Huffman / LZ77 / LZW / 算术编码 / CRC 校验 / Base64 / FNV / xxHash / zstd 风格字典

## 维度说明
本维度考察 Agent 做**压缩编码与数据校验**的实战能力。所有任务固定 4 轮，要求至少 1 轮 Bash 执行并断言、至少 1 轮 Write 落盘产物到 `tmpPlan/agent-test/` 沙盒，工具链限于 Bash/Read/Write + python3（**numpy 可用**）。衡量重点：把抽象的编码算法概念（RLE/Delta/Huffman/LZ/LZW/算术/CRC/Base64/哈希）转化为可由字节级别可逆性断言验证的工程产物。所有路径前缀 `tmpPlan/agent-test/`，输入数据现场生成，**产物只允许在 `tmpPlan/agent-test/` 沙盒内**。
