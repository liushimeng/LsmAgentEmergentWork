## 维度说明
本维度考察 Agent 做**电商交易与营销系统**的实战能力。所有任务固定 4 轮，要求至少 1 轮 Bash 执行并断言、至少 1 轮 Write 落盘产物到 `tmpPlan/agent-test/` 沙盒，工具链限于 Bash/Read/Write + python3（**numpy 可用；并发用 threading 模拟**）。衡量重点：把抽象的电商工程概念（购物车/SPU/SKU/防超卖/优惠券/状态机/搜索/秒杀/拼团/售后）转化为可由 python 数值断言或并发抢库存测试验证的工程产物。所有路径前缀 `tmpPlan/agent-test/`，输入数据现场生成，**产物只允许在 `tmpPlan/agent-test/` 沙盒内**。
