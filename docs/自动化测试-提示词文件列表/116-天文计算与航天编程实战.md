### DH01 天球坐标系：赤道、地平与黄道的转换

- **预期档位**: medium
- **考察维度**: 天球坐标系 / 球面三角 / 坐标转换公式
- **对话脚本**:
  1. 三套常用坐标系：地平坐标系（高度角+方位角——观测者视角，随时间地点变）、赤道坐标系（赤经 RA + 赤纬 Dec——星表通用，像地球上的经纬）、黄道坐标系（黄经黄纬——行星轨道分析用）；各解决什么问题。
  2. 赤道→地平转换：需要观测时刻的本地恒星时（LST）与观测者纬度；时角 H = LST − RA；用球面三角公式算高度角与方位角；手算一个例子（北极星在北纬 40° 的高度角≈40°，验证直觉）。
  3. 基于上面的公式，讨论岁差章动：地球自转轴像陀螺摆动（周期 25800 年），星表坐标要标注历元（J2000.0）；为什么手机星图 App 要做历元归算。
  4. 动手：用 Python 实现 ra_dec_to_alt_az(ra, dec, lat, lon, time) 函数（可用简化恒星时公式），验证北极星（RA≈2.5h, Dec≈+89.3°）在北纬 40° 全天高度角约 40°。

### DH02 行星位置：简化星历计算

- **预期档位**: medium~hard
- **考察维度**: 轨道根数 / 星历表 / 迭代计算
- **对话脚本**:
  1. 行星在哪：开普勒轨道六要素（半长轴 a / 偏心率 e / 倾角 i / 升交点经度 Ω / 近日点幅角 ω / 平近点角 M）唯一确定一个椭圆轨道；星历计算 = 根数 + 时刻 → 位置。
  2. 简化流程：平近点角 M = M0 + n(t−t0)（n 是平均角速度）→ 解开普勒方程得偏近点角 E → 得真近点角 ν → 得轨道面坐标 → 旋转到黄道/赤道系；VSOP87 是精密星历（数千项级数），简化版用低精度根数表（误差角分级，够肉眼观测用）。
  3. 基于上面的流程，讨论地球也在动：求行星相对地球的位置要「行星日心坐标 − 地球日心坐标」得地心向量；这就是为什么行星会逆行（地球内圈超车外圈行星）。
  4. 动手：用 NASA 的近似根数表实现火星位置计算——给定日期输出火星的地心赤道坐标，与手机星图 App 对照误差。

### DH03 开普勒方程与数值求解

- **预期档位**: hard
- **考察维度**: 超越方程 / 牛顿迭代 / 收敛性
- **对话脚本**:
  1. 开普勒方程 M = E − e·sin(E)：已知 M（时间均匀流逝）求 E（角度不均匀），这是超越方程没有解析解；推导一下这个方程从哪来（面积定律：扫过面积均匀 ⇒ 角度不均匀）。
  2. 牛顿迭代求解：E_{n+1} = E_n − (E_n − e·sinE_n − M)/(1 − e·cosE_n)，初值取 E0 = M（e 小）或 E0 = π（e 接近 1 时更稳）；动手实现并统计不同偏心率下的迭代次数。
  3. 基于上面的求解器，讨论收敛陷阱：e 接近 1（彗星轨道）时牛顿法在 M 接近 0 处震荡——初始值选取策略（用三次方程近似解做初值）与收敛阶数；级数解法（拉格朗日展开，仅 e<0.6627 收敛）的历史意义。
  4. 动手：实现 solve_kepler(M, e) 牛顿法（容差 1e-12），对 e ∈ {0.01, 0.5, 0.9, 0.99} 各测 1000 个 M 值，统计平均迭代次数与最大残差；画出迭代次数随 e 的增长曲线。

### DH04 日出日落与晨昏蒙影计算

- **预期档位**: medium
- **考察维度**: 太阳位置 / 大气折射 / 民用航海天文蒙影
- **对话脚本**:
  1. 日出日落定义：太阳上边缘接触地平线，且要修正两个效应——大气折射（地平处约 34 角分，光线被弯折抬升）与太阳视半径（16 角分），所以用太阳中心高度 −50′ 作标准。
  2. 计算流程：日期 → 太阳黄经近似值 → 赤纬 → 当地纬度求日落时角 H（cosH = −tanφ·tanδ 简化式）→ 时角转时刻；推导为什么高纬度夏季没有日落（cosH 无解即极昼）。
  3. 基于上面的公式，讨论晨昏蒙影三级：民用（太阳 −6°，可以户外阅读）/ 航海（−12°，能看到亮星）/ 天文（−18°，全黑）；摄影「蓝调时刻」就是民用蒙影；计算你所在城市今天的三个时刻。
  4. 动手：实现 sunrise_sunset(date, lat, lon, zenith) 函数，zenith 取 90.83°/96°/102°/108° 分别输出日出日落与三级蒙影时刻；与天气 App 对比验证误差 <2 分钟。

### DH05 卫星 TLE 解析与过境预测

- **预期档位**: medium~hard
- **考察维度**: TLE 格式 / SGP4 模型 / 过境预报
- **对话脚本**:
  1. TLE（Two-Line Element）两行根数：国际空间站的 TLE 每行 69 字符，含编号/历元/倾角/升交点/偏心率/近地点幅角/平近点角/平均运动；逐字段解析一个真实 ISS TLE（可从 CelesTrak 抄一段示例）。
  2. 传播模型：TLE 根数不是纯开普勒轨道——SGP4 模型加入了地球扁率 J2 项、大气阻力（近地轨道）；为什么不能拿 TLE 直接套 DH02 的开普勒公式（误差会快速发散到几公里）。
  3. 过境预测：卫星位置（TEME 坐标系）→ 观测者站心坐标（类似 DH01 的转换）→ 找出高度角 >10° 且满足光照条件（卫星被太阳照亮+地面够暗）的可见过境窗口；最大高度角与方位轨迹。
  4. 动手：用 Python（可实现简化传播或用 sgp4 库）计算 ISS 未来 24 小时对你所在城市的过境列表（升起/最高点/落下的时刻与方位），输出表格。

### DH06 天文摄影：星野照片对齐与叠加降噪

- **预期档位**: medium
- **考察维度**: 图像配准 / 叠加降噪 / 天文摄影流程
- **对话脚本**:
  1. 深空摄影的核心矛盾：目标暗（要长曝光）vs 地球在转（长曝光拖线）与噪声大；解决方案是「多张短曝光对齐叠加」——信噪比随张数 √N 提升，16 张叠加噪声减半再减半。
  2. 星点对齐：每张照片的星点位置不同（地球自转），先检测星点质心（阈值+连通域+质心公式），再用三角形匹配找两图同名星，解出旋转+平移变换（相似变换最小二乘）。
  3. 基于上面的对齐，讨论叠加策略：平均叠加 vs 中值叠加（中值能消飞机/卫星轨迹这种离群值）；暗场（盖镜头拍的热噪声模板）/ 平场（拍均匀光源修渐晕）/ 偏置场的定标帧三件套。
  4. 动手：用 numpy 生成模拟星野图（高斯星点+泊松噪声+一条人造卫星轨迹），实现质心检测+单点平移对齐+平均/中值叠加，对比单张与叠加 16 张的信噪比。

### DH07 系外行星凌日光变曲线分析

- **预期档位**: medium~hard
- **考察维度**: 光变曲线 / 周期检测 / 参数反演
- **对话脚本**:
  1. 凌日法找行星：行星从恒星前方经过，恒星光度周期性下降（木星凌日约遮太阳 1%，地球只遮 0.008%）；光变曲线的形状（深度=行星/恒星半径平方比、时长、周期）能反推行星参数。
  2. 周期检测：海量测光数据里找微弱周期信号——BLS（Box Least Squares）算法：尝试各周期把光变折叠成相位图，找「方盒形凹陷」最显著的周期；为什么 FFT 不适合（凌日是窄脉冲非正弦）。
  3. 基于上面的检测，讨论假阳性：食双星（两颗星互掩，凹陷深且常有二次食）、背景混杂、仪器系统误差；确认候选行星还需视向速度法交叉验证质量。
  4. 动手：生成模拟光变曲线（噪声 + 周期 3.5 天、深度 0.5% 的方盒凹陷），实现简化 BLS（周期网格搜索 + 折叠 + 凹陷显著性），验证能找回 3.5 天；再算行星半径（相对恒星）。

### DH09 天文图像 FITS 格式处理

- **预期档位**: medium
- **考察维度**: FITS 格式 / 科学数据 / 头数据单元
- **对话脚本**:
  1. FITS（Flexible Image Transport System）是天文界 40 年标准：文件 = 若干个 HDU（头 + 数据单元），头是 80 字符卡片的键值对（SIMPLE/BITPIX/NAXIS/CRPIX/CDELT…），数据是大端整数或浮点数组；为什么天文坚持用它（自描述+定标信息内嵌）。
  2. 动手解析：不依赖 astropy，手写最小 FITS 读取器——解析头卡片（每 80 字符一条，END 结束）、按 BITPIX 与 NAXIS 读出数据块（2880 字节对齐填充）；验证一个示例 FITS 图的尺寸与像素统计。
  3. 基于上面的读取器，讨论 WCS（World Coordinate System）：头里的 CRPIX/CRVAL/CD 矩阵把像素坐标映射到天球赤经赤纬——这就是「给照片标注每颗星坐标」（plate solving）的逆向工程。
  4. 扩展：把 FITS 数据线性/对数拉伸成 8bit PNG（天文图动态范围极大必须拉伸）；讨论 ZScale 自动对比度算法（基于像素值分布的自动窗宽窗位）。

### DH10 霍曼转移与轨道机动 Δv 预算

- **预期档位**: hard
- **考察维度**: 轨道力学 / 数值计算 / 任务规划
- **对话脚本**:
  1. 霍曼转移：两圆轨道间最省燃料的双脉冲机动——在近地点点火加速进椭圆转移轨道、远地点再点火圆化；推导 Δv 公式（用 vis-viva 方程 v² = GM(2/r − 1/a) 在两轨道半径处各算一次）。
  2. 手算地火转移：地球轨道半径 1AU、火星 1.52AU，转移椭圆半长轴 1.26AU，算两段 Δv 与转移时间（半个椭圆周期 ≈ 8.5 个月）；这就是为什么火星窗口 26 个月一次（会合周期）。
  3. 基于上面的计算，讨论工程修正：行星引力辅助（弹弓效应白嫖 Δv，卡西尼靠金星-地球-木星连弹到土星）、平面外机动极贵（变倾角 Δv 与速度成正比）、低推力电推进（离子发动机连喷数月，霍曼公式不再适用）。
  4. 动手：实现 hohmann_transfer(r1, r2, mu) 函数输出两段 Δv 与转移时间；批量算地球到各行星（金/火/木/土）的 Δv 表；再实现会合周期公式 1/T = |1/T1 − 1/T2|，输出各地火/地金窗口周期。
