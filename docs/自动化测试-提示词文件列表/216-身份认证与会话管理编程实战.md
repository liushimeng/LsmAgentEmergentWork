- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:

- **预期档位**: medium

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/hb03_jwt.py`：JWT 引擎（纯 python hmac/sha256，不引第三方库）：(a) `header.payload.signature` base64url 编解码与 HS256 签名验签；(b) **claims 纪律**：exp（15 分钟）/ iat / nbf / jti（唯一 id）/ 最小 payload（不放手机号等 PII）；(c) **算法混淆攻击**：把 header.alg 改 `none` 或 `RS256`（公钥当 HMAC 密钥）→ 服务端必须白名单锁定 alg；(d) **刷新令牌轮换**：refresh token 14 天 + 每次 access 刷新时 refresh 也轮换，**token family 重用检测**：被替换过的旧 refresh 再次出现 → 整族吊销（窃贼与真用户共用即同归于尽）；(e) 注销问题：短 exp + 服务端 jti 黑名单（剩余有效期 TTL）；(f) RS256/EdDSA 非对称选型（多方验签场景）说明。

  3. Read 源码，再 Bash 断言：含 S256 计算、含精确匹配、含 code 一次性。
