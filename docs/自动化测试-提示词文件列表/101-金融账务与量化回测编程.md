## 维度说明
本维度考察 Agent 做**金融账务与量化回测**的实战能力。所有任务固定 4 轮，要求至少 1 轮 Bash 执行并断言、至少 1 轮 Write 落盘产物到 `tmpPlan/agent-test/` 沙盒，工具链限于 Bash/Read/Write + python3（**numpy 可用；decimal 严格精度不可用时降级整数分**）。衡量重点：把抽象的金融工程概念（复式记账/K 线/指标/回测/滑点/夏普/组合/期权/套利/报送）转化为可由 python 数值断言或贷借平衡校验验证的工程产物。所有路径前缀 `tmpPlan/agent-test/`，输入数据现场生成，**产物只允许在 `tmpPlan/agent-test/` 沙盒内**。
