## 维度说明
本维度考察 Agent 做**地理空间数据编程**的实战能力。所有任务固定 4 轮，要求至少 1 轮 Bash 执行并断言、至少 1 轮 Write 落盘产物到 `tmpPlan/agent-test/` 沙盒，工具链限于 Bash/Read/Write + python3（**numpy 可用；OSM PBF 不可用，改用 OSM XML 子集解析**）。衡量重点：把抽象的 GIS 概念（坐标系/GeoJSON/索引/编码/距离/路网/瓦片/OSM/等值线/PostGIS）转化为可由 python 数值断言或 XML 解析验证的工程产物。所有路径前缀 `tmpPlan/agent-test/`，输入数据现场生成，**产物只允许在 `tmpPlan/agent-test/` 沙盒内**。
