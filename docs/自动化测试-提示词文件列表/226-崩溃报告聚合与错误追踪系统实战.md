  1. Write `tmpPlan/agent-test/hm01_event.py`：事件模型与模拟接入端点：(a) **schema**：`{event_id(uuid4), ts, release, platform, level(error/fatal/warning), exception:{type, value, stack:[{func, module, file, line, in_app}]}, breadcrumbs:[{ts, category, message}]≤100, contexts:{os, app}, user:{id(匿名化), locale}}`；(b) **接入校验**：必填（event_id/ts/exception）缺失拒收 `E_SCHEMA`；栈帧缺 func+file 双字段时降级为 `unknown frame`；breadcrumbs 超 100 截尾保最新（**面包屑是崩溃前线索，保头不如保尾**）；(c) **规范化**：release 归一 `app@1.2.3+build45`，platform 白名单；(d) **模拟端点**：`ingest(event) → {accepted, event_id, issue_hint}` 内存存储；(e) 生成 5 个合法 + 3 个非法样例跑全测。

### HM02 栈指纹分组

- **预期档位**: hard
- **考察维度**: 栈归一 / top-N 哈希 / 分组陷阱
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/hm02_fingerprint.py`：指纹分组器：(a) **帧归一化**：去绝对路径只留 basename、行号移除、参数与泛型剥除（`func(int, str)` → `func`）——**同 bug 不同机器行号/路径不同必须同组**；(b) **指纹**：取归一后栈中**最底 5 个 in_app 帧**（靠近异常抛出点，最稳定；系统帧噪声丢弃）拼接 sha256 取 16 hex；(c) **单帧陷阱**：栈只剩 1 帧（解释器顶层）时退化为 `type + message 前 40 字符` 指纹（否则所有顶层错误撞成一组）；(d) **动态消息陷阱**：`Connection to 10.0.0.5:6379 refused` 的 IP 部分会导致同问题爆炸成千组——消息参与指纹前先抹数字/IP/UUID（正则替换 `#N`）；(e) **显式 fingerprint 覆盖**：事件可带 `fingerprint: ["checkout", "*"]`（`*` 通配吸收变化段）优先于自动指纹；(f) 分组 API：`group(events) → {fingerprint: [events]}`。
  2. Bash：构造 3 组同 bug 变体（不同路径/行号/不同 IP 消息）+ 1 组真不同 bug，断言前三组同指纹、后组独立、单帧退化路径生效。
  3. Read 源码，再 Bash 断言：含最底 5 帧逻辑、含数字抹除正则、含 `*` 通配。

### HM03 issue 生命周期状态机

- **预期档位**: hard
- **考察维度**: 状态机 / 回归 regressed / 自动解决
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/hm03_lifecycle.py`：issue 状态机：(a) **状态**：`unresolved → resolved → regressed`（regressed = 已解决又复发，**高于新 issue 的优先级**——修复失败比未修更伤信任）；(b) **事件驱动**：新指纹首次出现 → 建 issue(unresolved)；同指纹再报 → 计数+1；人工/API `resolve(issue)` → resolved；(c) **自动解决窗口**：resolved 后 release N 内无复发，且当前 release = N+2（隔一版本验证）→ 自动确认 `auto_resolved`；resolved 后**任何**新事件 → regressed 并记录回归版本；(d) **忽略流**：`ignored` 状态（降噪决策）不参与排行但保留计数；忽略后被新版本触发可升级回 unresolved（策略开关）；(e) **计数器**：events 总数 / users 影响数（user_id 去重）/ first_seen / last_seen / regression_count；(f) 状态转移合法性表（非法转移报错，如 unresolved→regressed）。
  2. Bash：跑剧本断言：正常流 unresolved→resolved→(隔版无复发)→auto_resolved；回归流 resolved→(新事件)→regressed 且回归版本记录；非法转移 unresolved→regressed 被拒；ignored 升级分支生效。
  3. Read 源码，再 Bash 断言：含 N+2 隔版逻辑、含影响数去重、含合法性表。
