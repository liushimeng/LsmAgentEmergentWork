### EW01 Linux 用户与组生命周期脚本

- **预期档位**: medium
- **考察维度**: 用户组生命周期 / 幂等命令生成
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `ew01_lifecycle.py`：读取 inventory JSON（username/uid/extra_groups/state 取 present/absent）与内置模拟 passwd/group 片段，生成幂等 useradd/usermod/userdel 命令序列，`--dry-run` 只打印不执行；检测重复 UID、引用不存在的组与残留私有组，内置样例。
  2. Bash：`python3 -m py_compile ew01_lifecycle.py` 断言语法；`python3 ew01_lifecycle.py --dry-run | tee ew01_run.log`，`grep -F 'useradd' ew01_run.log` 断言生成。
  3. Read `ew01_run.log`，再 Write `ew01_inventory.json`：6 案例：新建、追加属组、删除、撞 UID、引用不存在组、已存在。本轮必须显式复用第一轮的字段名与 dry-run 结论，不允许另起无关主题。
  4. Bash：`python3 -m json.tool ew01_inventory.json >/dev/null` 断言合法；`python3 ew01_lifecycle.py --inventory ew01_inventory.json --dry-run | tee ew01_run2.log`，`grep -F 'userdel' ew01_run2.log` 断言删除。

### EW02 sudoers 细粒度授权片段生成

- **预期档位**: hard
- **考察维度**: 最小授权 / sudoers 风险检测
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `ew02_sudoers.py`：输入角色→命令白名单 JSON（role/user/host/commands/nopasswd），生成 /etc/sudoers.d/ 片段仅落盘 tmpPlan 绝不安装；检查 NOPASSWD: ALL、非绝对路径、通配符与危险命令；无 visudo 权限时降级内置语法断言。
  2. Bash：`python3 -m py_compile ew02_sudoers.py` 断言语法；`python3 ew02_sudoers.py --selftest | tee ew02_run.log`，`grep -F '/etc/sudoers.d/' ew02_run.log` 断言生成。
  3. Read `ew02_sudoers.py`，再 Write `ew02_roles.json`：4 角色：只读巡检（绝对路径）、发布（nopasswd 限定命令）、DBA（备份目录）、反面案例（NOPASSWD: ALL+相对路径+通配符）。本轮必须显式复用第一轮的字段与风险规则，不允许另起无关主题。
  4. Bash：`python3 -m json.tool ew02_roles.json >/dev/null` 断言合法；`python3 ew02_sudoers.py --roles ew02_roles.json | tee ew02_report.log`，`grep -F 'NOPASSWD: ALL' ew02_report.log` 断言告警。
