# 48 操作系统与内核原理

> 编号段 AW01–AW10 · 聚焦进程/线程/调度、内存管理、虚拟化、文件系统、同步原语、内核模块等底层原理
> 与现有 21 维度「系统编程与底层开发」互补：21 偏 syscall API 应用层；48 偏内核原理与机制剖析

### AW01 操作系统总览：内核架构与设计哲学
- **预期档位**: medium
- **考察维度**: 内核架构 + 设计哲学
- **对话脚本**:
  1. 操作系统的五大功能（进程/内存/设备/文件/网络）在 Linux 内核中的对应子系统，画出架构图。
  2. 单体内核（Linux / FreeBSD）vs 微内核（seL4 / Minix / QNX）的取舍：性能 vs 可靠性 vs 驱动模型。
  3. 宏内核 + 模块化（Loadable Kernel Modules）的折中：内核模块与用户态驱动的隔离边界、模块签名验证。
  4. 真实内核源码阅读路径：通读《Linux Kernel Development》《Unix 源码注释》《Linux Device Drivers》三本书的章节映射。

### AW02 进程与线程：从 fork 到 pthread
- **预期档位**: medium
- **考察维度**: 进程模型 + 线程实现
- **对话脚本**:
  1. 进程 vs 线程 vs 协程的本质区别：地址空间、调度单位、上下文切换开销三维度对比。
  2. Linux 的进程描述符 task_struct 关键字段：pid、tgid、state、files、mm、signal，画出完整结构。
  3. 线程的实现模型：N:1（Go runtime goroutine）、1:1（Linux pthread）、M:N（Go runtime hybrid）的差异与适用场景。
  4. 写一个多进程 vs 多线程的对比 demo：同样计算密集任务，绑核 1 个 vs 4 个，理论加速比的差异与现实收益。

### AW03 进程调度：CFS / BFS / 实时调度
- **预期档位**: hard
- **考察维度**: 调度器算法 + 优先级
- **对话脚本**:
  1. Linux CFS（Completely Fair Scheduler）的红黑树 + 虚拟运行时间（vruntime）机制：为什么能「近似公平」而不是「真公平」。
  2. 调度策略 SCHED_NORMAL / SCHED_BATCH / SCHED_IDLE / SCHED_FIFO / SCHED_RR / SCHED_DEADLINE 的适用边界，画出优先级矩阵。
  3. CPU 亲和性（sched_setaffinity）与 cgroup v2 CPU quota 的区别：单进程绑核 vs 整组限额的真实案例。
  4. 用 perf + schedtool 工具观测上下文切换：syscall 数、cswch/s、migrations，观察一个跑满 100% 的进程与另一个低优先级进程的调度延迟。

### AW04 内存管理：从虚拟地址到物理页
- **预期档位**: hard
- **考察维度**: 虚拟内存 + 分页机制
- **对话脚本**:
  1. 虚拟地址到物理地址的四级页表（PGD/PUD/PMD/PTE）翻译过程，TLB 命中与未命中的代价差距。
  2. MMU 的缺页中断（page fault）三种类型（次要/主要/无效）的内核处理路径，给一个 mincore 或 madvise 的例子。
  3. HugePage（2MB / 1GB）与 Transparent Huge Page（THP）的内存节省与延迟波动 tradeoff，数据库场景为何手动配 HugePage。
  4. 用 pmap / smaps / /proc/PID/status 分析一个 Redis 进程的内存：RSS / VMS / PSS / USS 四个指标的含义与差异。

### AW05 进程间通信：管道 / 信号 / 共享内存 / 消息队列
- **预期档位**: medium
- **考察维度**: IPC 机制选型 + 实现原理
- **对话脚本**:
  1. 六大 IPC 方式（管道/FIFO/信号/共享内存/消息队列/套接字）的内核实现差异：哪些走 syscall、哪些走文件系统。
  2. 共享内存（shmget/mmap）的同步难题：为什么必须配合信号量或 futex，给一段生产者-消费者的最小代码。
  3. Unix Domain Socket vs TCP loopback 的性能差距：syscall 数、内核路径、上下文切换次数的实测对比。
  4. 信号（signal）的可靠性问题：传统不可靠信号 vs POSIX 可靠信号（rt_sigaction）的内核实现差异。

### AW06 同步原语：互斥锁 / 读写锁 / 无锁结构
- **预期档位**: hard
- **考察维度**: 内核同步 + 锁-free
- **对话脚本**:
  1. 互斥锁（mutex）的内核实现：futex（Fast Userspace muTEX）的「用户态自旋 + 内核等待」混合机制，画出状态机。
  2. 自旋锁（spinlock）vs 互斥锁（mutex）vs 读写锁（rwlock）vs RCU 的适用场景与性能特征，给出三个真实选型案例。
  3. CAS（Compare-And-Swap）原语与 ABA 问题：lock-free 队列、hazard pointer、sequence lock 的解决方案。
  4. 死锁的四个必要条件与检测算法：用 lockdep / ThreadSanitizer 工具发现一个故意写错的死锁 demo。

### AW07 文件系统：从 VFS 到 ext4 / btrfs / ZFS
- **预期档位**: medium
- **考察维度**: 文件系统原理 + 设计对比
- **对话脚本**:
  1. VFS（Virtual File System）抽象层的设计：inode / dentry / file / super_block 四个核心结构的关系图。
  2. ext4 的 extent + delayed allocation + journal 机制：数据一致性如何保障、journal 满时的行为。
  3. btrfs / ZFS 的 CoW（Copy-on-Write）+ checksum + snapshot 与 ext4 的 journaling 哲学差异，各自适用场景。
  4. 用 strace / fatrace / inotifywait 跟踪一个文件的完整生命周期：open → read → write → close 内核调用链。

### AW08 设备驱动与 IO 栈：从块设备到 NVMe
- **预期档位**: medium
- **考察维度**: IO 子系统 + 驱动模型
- **对话脚本**:
  1. 块设备（block device）vs 字符设备（char device）的内核抽象差异，major/minor 号的现代分配方式（devtmpfs）。
  2. IO 调度器：CFQ / Deadline / BFQ / none / mq-deadline 在 SSD/NVMe 上的适用性变迁，机械盘时代的算法为何被淘汰。
  3. NVMe 的多队列架构：每个 CPU 一个 submission queue 的设计与 Linux blk-mq 的对应实现。
  4. 用 fio 工具压测一块 NVMe SSD：随机 4K IOPS、顺序吞吐、延迟分布，画出性能曲线与瓶颈识别。

### AW09 虚拟化与容器：从 KVM 到 cgroup + namespace
- **预期档位**: hard
- **考察维度**: 虚拟化技术栈 + 容器原理
- **对话脚本**:
  1. KVM 的硬件辅助虚拟化（Intel VT-x / AMD-V）原理：VMX non-root mode、影子页表（EPT/NPT）的硬件支持。
  2. 容器 vs 虚拟机的本质区别：namespace（6 类）+ cgroup（v2 统一 hierarchy）+ capability + seccomp 的四层隔离组合。
  3. Docker / Podman 的 rootless 模式：user namespace 映射、no_new_privs、subuid/subgid 的安全模型。
  4. 用 unshare 命令演示 namespace 隔离：UTS、PID、NET、IPC、Mount、User 六种 namespace 的可见性差异。
