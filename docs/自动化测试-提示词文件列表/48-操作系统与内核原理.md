# 自动化测试提示词 — 操作系统与内核原理（AW01–AW10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。
> 与现有 21 维度「系统编程与底层开发」互补：21 偏 syscall API 应用层；48 偏内核原理与机制剖析

## 维度说明

本维度考察 Agent 在 **操作系统工程化** 上的动手能力：proc 只读探测（/proc/self/status 解析断言）、CFS 用 python 模拟 vruntime 调度断言公平性、fork/exec/wait 用 C 或 python 演示、虚拟内存用 python 模拟页表转换 + TLB 命中率统计、eBPF 不可加载时讲原理 + 模拟统计。
所有产物落到 `tmpPlan/agent-test/` 沙盒，不碰系统路径、不装包、不加载内核模块。
与 README 其它维度互补：U 维度考察通用系统编程，AW 聚焦"内核机制"——页表/TLB/CFS 调度/IPC/fork 语义/eBPF 原理。

### AW01 操作系统总览：内核架构梳理
- **预期档位**: medium
- **考察维度**: 内核架构 + 设计哲学
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/aw01/` 写 `kernel_map.py`：把 Linux 5 大子系统（进程/内存/设备/文件/网络）按"功能→关键数据结构→典型 syscall"三列输出到 `kernel_map.md`，每子系统 ≥ 2 行。
  2. 写 `audit_kernel.py`：断言 5 子系统齐全（正则 `^## ` ≥ 5）、每子系统含 `struct` 关键字、每子系统含 syscall 名（正则 `open|read|mmap|clone|ioctl` 至少 5 命中）。
  3. 跑脚本输出 `subsystems=5 structs=syscalls=N` 到 `kernel_audit.log`，断言 N ≥ 5。
  4. 在 `arch_philosophy.md` 写"单体内核 vs 微内核 vs 混合内核"三对比：性能/可靠性/驱动模型，每档 1 行 + Linux/SeL4/QNX 代表。

### AW03 CFS 调度模拟：vruntime 公平性
- **预期档位**: hard
- **考察维度**: 调度器算法 + 优先级
- **工具链**: Write → Bash → Bash → Read
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/aw03/` 写 `cfs_sim.py`：模拟 CFS——3 个任务 A/B/C，nice 值分别 0/5/10，运行 100 个 tick，按 `vruntime += actual_runtime * (1024 / weight)` 累加，weight 用 `1024 / (1.25^nice)` 估算。
  2. 跑脚本输出每 tick 的 vruntime 状态到 `cfs.log`，用 `awk` 算 3 个任务总获得 CPU 时间，断言 nice=0 的 A 获得最多（≈ 50%）、nice=10 的 C 获得最少（≈ 15%），差异 ≥ 30 个百分点。
  3. 故意把 weight 设反（nice=0 给最低 weight），重跑断言 A 获得最少（演示 CFS 失效）→ 改回正确公式 → 全过。
  4. 在 `cfs_notes.md` 写"为什么 vruntime 不是真公平"：红黑树 O(log n) 切换粒度 / 延迟补偿 / 唤醒抢占 bias，各 1 行。

### AW04 虚拟内存：页表转换 + TLB 命中率
- **预期档位**: hard
- **考察维度**: 虚拟内存 + 分页机制
- **工具链**: Write → Bash → Bash → Read
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/aw04/` 写 `mmu_sim.py`：模拟 32 位虚拟地址 4KB 页、4 级页表（9/9/9/9/12 位划分）、TLB 容量 64 项全相联；随机生成 10000 个虚拟地址，统计 TLB hit 率。
  2. 跑脚本输出 `tlb_hits=N hit_rate=X%` 到 `mmu.log`，断言 hit_rate ≥ 80%（因 10000 地址大概率集中少数页）。

  4. 在 `page_walk.md` 写"四级页表（PGD/PUD/PMD/PTE）"：每级 9 位、offset 12 位、每级 512 项、8B/项、4 级共 4×4KB 页表内存开销，每级 1 行。

### AW05 IPC：管道 vs 共享内存 带宽
- **预期档位**: medium

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
