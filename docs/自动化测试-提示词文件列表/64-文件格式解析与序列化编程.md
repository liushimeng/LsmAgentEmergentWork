- **预期档位**: medium
- **考察维度**: PNG chunk 解析 + CRC32 校验 + zlib 流式解压
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/make_png.py` 用 PIL 生成一个 4x4 RGB 测试图（红绿蓝黄四块 2x2）保存为 `tmpPlan/agent-test/test.png`；用 `xxd test.png | head -3` 验证首 8 字节为 `89 50 4E 47 0D 0A 1A 0A`（PNG 魔数）。
  2. 在 `tmpPlan/agent-test/parse_png.py` 用 Python `struct` + `zlib` 手写 PNG 解析：读文件头 → 循环读 chunk `[length:4][type:4][data:length][crc:4]` → 解析 IHDR（13 字节：width/height/bit-depth/color-type/compression/filter/interlace）；`crc32 = zlib.crc32(type + data)` 校验每个 chunk。
