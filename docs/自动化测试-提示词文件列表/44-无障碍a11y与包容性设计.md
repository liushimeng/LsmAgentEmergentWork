# 自动化测试提示词 — 无障碍 a11y 与包容性设计（AS01–AS10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在 **无障碍工程化** 上的动手能力：能写 HTML 静态源 + lint 脚本（img 无 alt、对比度、tabindex、aria 引用）、能用 Python 算 WCAG 对比度比值、能造 a11y 缺陷并修。
所有产物落到 `tmpPlan/agent-test/` 沙盒，不依赖浏览器/外网。
与 README 其它维度互补：R 维度考察 Web 全栈，AS 聚焦"无障碍语义层"——WCAG 规则、ARIA 引用、键盘可达、对比度计算。

---

### AS01 WCAG 2.2 等级与四原则：写 a11y 缺陷注入器
- **预期档位**: simple
- **考察维度**: WCAG 标准 + 等级判定
- **工具链**: Write → Bash → Bash → Read
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/as01/` 写 `bad.html` 故意注入 6 类 WCAG 2.2 A 级问题：`<img src="x.png">`(1.1.1)、`<input type="text">` 无 label(1.3.1)、`<a href=""></a>`(2.4.4)、`<button>` 不可键盘聚焦(2.1.1)、颜色对比 1.5:1(1.4.3)、`<video>` 无字幕(1.2.2)。
  2. 写 `audit.py` 用正则检测这 6 类：`<img(?![^>]*alt=)`（无 alt）、`<input(?![^>]*aria-label|[^>]*id=)`（无 label 关联）、`contrast.*<1.5` 占位、等等；输出 `audit.json` 含每条违例的"rule+line+snippet"。
  3. 跑 `python3 audit.py bad.html`，断言 audit.json 至少 6 个违例（用 `python3 -c "import json; print(len(json.load(open('audit.json'))['violations']))"` ≥ 6）。
  4. 在 `wcag_notes.md` 列出 4 原则 + A/AA/AAA 三个等级的法律对应（A=Section 508 强制、AA=EAA 2025 强制、AAA=企业最佳实践），每原则 1 行。

### AS02 ARIA 角色与属性：写自定义 Tabs 组件
- **预期档位**: medium
- **考察维度**: ARIA 语义 + Tab 模式
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/as02/` 写 `tabs.html`：手写一个 Tabs 组件 HTML，3 个 tab + 3 个 panel；tabs 容器 `role="tablist"`，每个 tab `role="tab" aria-selected="false" aria-controls="panel-1" id="tab-1" tabindex="-1"`，激活的 tab `tabindex="0"`，每个 panel `role="tabpanel" aria-labelledby="tab-1" id="panel-1"`。
  2. 写 `check_tabs.py` 验证：(a) 恰好 1 个 tab `aria-selected="true"`，(b) 激活 tab `tabindex=0` 其他 `tabindex=-1`，(c) 每个 panel 有 `aria-labelledby` 指向存在的 tab id。
  3. 跑测试，输出"3 项断言全过"到 `check.log`；故意把激活 tab 的 aria-selected 改成 false 触发第 1 项失败。
  4. 在 `aria_priority.md` 写"不要使用 ARIA"5 个反模式：`role="button"` 在 `<button>` 上、`aria-label` 覆盖可见 label、`role="presentation"` 在可聚焦元素上、`aria-hidden="true"` 在焦点元素上、`<div role="list">` 包 `<li>` 缺失，每行 1 个。

### AS04 键盘导航：roving tabindex 工具栏
- **预期档位**: medium
- **考察维度**: 焦点可达性 + 焦点陷阱
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/as04/` 写 `toolbar.html`：4 个按钮的 toolbar，容器 `role="toolbar"`，所有按钮 `tabindex="-1"`，激活的按钮 `tabindex="0"`。
  2. 写 `roving.py` 实现 roving tabindex 算法：当前 focus 在第 i 个按钮时，按 → 焦点到第 (i+1)%4 个并把它设为 `tabindex=0` 原按钮设回 `-1`；写单测 4 个移动方向 + 边界回卷。
  3. 跑 `python3 -m unittest roving.py -v`，输出"4 项测试全过"；故意把 %4 去掉，断言越界 case 失败。
  4. 在 `roving_notes.md` 写 Skip Link 实现细节：`<a href="#main" class="skip">` 默认 `position:absolute; left:-9999px`，`:focus` 时 `left:0`，加 `tabindex="0"` 防 IE 旧问题。

### AS05 WCAG 对比度公式：numpy 计算与断言
- **预期档位**: medium
- **考察维度**: 对比度算法 + 色觉模拟
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/as05/` 写 `contrast.py`：实现 `relative_luminance(rgb)` 与 `contrast_ratio(rgb1, rgb2)`，公式按 WCAG 2.x：L = 0.2126*R + 0.7152*G + 0.0722*B（R/G/B 为 sRGB 反 gamma 校正值），比值=(L1+0.05)/(L2+0.05)。
  2. 写 3 对测试：(a) #000 on #fff → 21:1（断言 21±0.1）、(b) #777 on #fff → 4.48:1（断言 AA 大字通过、AA 正文失败）、(c) #0066cc on #ffffff → 5.66:1（断言 AA 通过）。
  3. 跑脚本输出 `ratio.txt`，每行 `pair=... ratio=...`；用 `grep -c 'ratio=2[0-9]' ratio.txt` 断言至少 1 对比值 ≥ 21。
  4. 在 `contrast_notes.md` 写"色盲三重编码"：颜色 + 形状 + 标签（如 error 用红 + ⚠ 图标 + "Error" 文字），给 1 个具体代码片段 5 行。
