# 210 自制操作系统与内核引导编程实战

> 编号段 GV01–GV10 · 聚焦「从空白磁盘到可启动迷你 OS 的全流程编程」：Boot Sector / 实模式到保护模式 / GDT 与 IDT / 中断与键盘驱动 / 物理内存管理 / 二级分页 / 内核堆分配器 / 定时器与抢占调度 / FAT12 内核加载 / 内核 Shell / Multiboot 与 UEFI / 跨平台构建与模拟调试
>
> 与现有维度互补说明：
> - `48-操作系统与内核原理`（AW 维）聚焦**原理讲解**（调度/CFS/内存管理概念）；本文件聚焦**亲手写出可启动的内核代码**，从 512 字节引导扇区起步，是理论的"动手版"。
> - `33-嵌入式系统与物联网开发`（AH 维）聚焦**现成 RTOS 与开发板应用**；本文件聚焦**无任何 OS 依赖的裸机内核自建**，连 printf 都要自己造。
> - `120-模拟器与复古平台编程`（DL 维）聚焦**模拟他人硬件**（CHIP-8/6502）；本文件聚焦**被 QEMU 模拟的 x86 目标机软件本身**，是模拟器的对偶面。
> - `21-系统编程与底层开发`（U 维）聚焦**用户态**系统编程；本文件聚焦**内核态**——自己就是那个被系统调用的一层。
>
> **本文件独特主题**：MBR 0x7C00 与 0xAA55 签名 / BIOS int 10h / A20 地址线 / GDT 段描述符平坦模型 / CR0 PE 位与远跳刷新 / IDT 门描述符 / 8259 PIC 重映射 / 键盘扫描码 Set1 / E820 内存探测 / 位图物理页分配器 / PDE-PTE 二级分页 / kmalloc 空闲链表 / PIT 8253 定时 / 上下文切换现场保存 / FAT12 BPB 与 12 位簇链 / Multiboot2 / GRUB 与 grub-mkrescue / UEFI 长模式 / Limine 协议 / QEMU+GDB 远程调试 / 串口输出 / nasm-qemu 跨平台工具链（macOS/Windows/Ubuntu/CentOS 7 安装差异）。

### GV01 Boot Sector：512 字节的可启动世界

- **预期档位**: simple
- **考察维度**: MBR 结构 / BIOS 约定 / NASM 汇编
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/gv01_boot.asm`：NASM 引导扇区汇编：(a) `org 0x7C00` 与 BIOS 加载约定；(b) 段寄存器清零 + 栈顶指向 `0x7C00`（`xor bp,bp; mov ss,bp; mov sp,0x7C00`）；(c) `lodsb` 循环 + `int 0x10`（AH=0x0E 电传打字）打印 "Hello, laew OS!"；(d) `.halt: cli; hlt; jmp .halt`；(e) `times 510-($-$$) db 0` + `dw 0xAA55` 魔数签名。
  2. Bash：`nasm -f bin tmpPlan/agent-test/gv01_boot.asm -o tmpPlan/agent-test/gv01_boot.img`，断言文件恰好 512 字节（`wc -c`）且末两字节为 `55 AA`（`xxd tmpPlan/agent-test/gv01_boot.img | tail -1`）。
  3. Read 镜像十六进制输出，再 Bash：探测 `command -v qemu-system-i386 || command -v qemu-system-x86_64`，有则 `-drive format=raw,file=...` 启动验证；无则打印四平台安装指引（macOS `brew install qemu` / Ubuntu `apt install qemu-system-x86` / CentOS 7 `yum install qemu-system-x86_64` / Windows `choco install qemu`）并跳过启动。

### GV02 实模式到保护模式切换

- **预期档位**: medium

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/gv02_pmode.asm`：保护模式切换汇编：(a) GDT 三描述符（null + code + data）平坦模型 base=0 limit=0xFFFFF + 粒度位 G=1 得 4GB；(b) 构造 `gdt_descriptor`（limit+base）并 `lgdt`；(c) A20 开启（fast A20：`in al,0x92; or al,2; out 0x92,al`）；(d) `mov eax,cr0; or eax,1; mov cr0,eax` 置 PE 位；(e) `jmp CODE_SEG:init_pm` 远跳刷新预取队列；(f) 32 位下重设段寄存器并直接写 `0xB8000` VGA 文本缓冲打印（不再依赖 BIOS）。

  3. Read 源码，再 Bash 断言：含 GDT 三个描述符、含 A20 开启、含 PE 位置位与远跳、含 0xB8000 直写。
