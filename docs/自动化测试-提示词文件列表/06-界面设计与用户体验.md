## 维度说明
本维度考察 Agent 在**界面设计、TUI/CLI 交互、配色、文案、终端动效**等 UX 场景的动手产出能力。固定 4 轮对话脚本，要求至少 1 轮 Bash 执行并断言、至少 1 轮 Write 落盘产物到 `tmpPlan/agent-test/` 沙盒。所有设计任务必须落到可执行产物：HTML 原型、ASCII 图、bash 动效脚本、文案文件、校验脚本——禁止纯"讲解/讨论/给建议"。衡量重点：把设计方案转化为可在本机跑、可 grep 断落的产物（HTML/MD/脚本），多轮之间通过 Read/Edit 复用前轮产物。
