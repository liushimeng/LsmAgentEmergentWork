### HI01 GEDCOM 行语法解析器

- **预期档位**: medium
- **考察维度**: 层级行语法 / 指针 / 续行
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/hi01_gedcom.py`：GEDCOM 5.5.1 解析器：(a) **行语法** `level [xref] tag [value]`（如 `1 NAME 张 三 /`、`2 DATE 1912-03-10`），按 level 归约成树（level 每深一层 +1，跳层即语法错误）；(b) **指针**：`@I1@` 个体引用 / `@F2@` 家庭引用，解析为强类型节点引用而非字符串；(c) **CONT/CONC**：`CONT` 换行续值、`CONC` 无换行拼接（处理超长 NAME/OCCU 被导出工具硬折行的常见坑——拼回原文）；(d) **容错**：行尾多余空格、CRLF/BOM 输入、未知 tag 警告不报错（前向兼容）；(e) 内置 3 个体 2 个家庭的最小样例（含 CONT/CONC 折行）往返：parse → dump 再 parse 字节级一致。
  2. Bash：跑往返断言输出一致；喂 CRLF+BOM 版本断言解析成功且警告计数 = 未知 tag 数；喂跳层错误样本断言报 `LEVEL_JUMP` 错误行号。
  3. Read 源码，再 Bash 断言：含 CONT 与 CONC 两个分支、含 @I/@F 指针识别、含 BOM 处理。

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/hi04_ahnentafel.py`：祖先编号器：(a) **编号法**：本人 = 1，父 = 2 / 母 = 3，祖父 = 4/5 外祖 = 6/7——编号 n 的父 = 2n、母 = 2n+1，实现 `num→path`（二进制位：0=父支 1=母支）与 `path→num`；(b) **深 k 代完整树**：编号 1..2^(k+1)-1 全枚举与实际家谱比对，缺档位标 UNKNOWN；(c) **pedigree collapse**：同一 INDI 占据 ≥ 2 个编号位（表亲婚配的必然结果），扫描全部编号位找重复个体，计算"理论先人数 vs 实际先人数"与塌缩率；(d) **填充率报表**：按代统计已知/未知比例（第 1 代 100% → 第 5 代常见 < 20%），ASCII 柱状图输出；(e) **Sosa-Stradoniz 注记**：欧洲编号法差异一句话说明。
