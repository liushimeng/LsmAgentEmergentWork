### HD01 VT100 转义序列解析状态机

- **预期档位**: medium
- **考察维度**: 状态机 / CSI 参数 / SGR
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/hd01_parser.py`：转义序列解析器：(a) 状态机：ground / escape（`ESC [` → CSI）/ CSI 参数收集（分号多参 + `?` 私有前缀 + 数字）/ OSC（`ESC ]` 到 BEL 或 ST 结束）/ 单字符转义（ESC 7/8/D/M）；(b) 执行动作分发：CUU/CUD/CUF/CUB（光标移动 n）、ED（清屏 0/1/2 三模式）、EL（清行）、SGR；(c) **SGR 全集**：0 重置 / 1 bold / 30-37 前景 / 90-97 亮色 / 38;5;n 256 色 / 38;2;r;g;b 真彩 / 48 背景 / 39/49 默认；(d) 解析器输出：`[action, params]` 流 + 状态转换日志；(e) **切分安全**：字节流可以任意位置截断重喂（网络分包），部分序列暂存 pending 状态。
  2. Bash：喂 `"\x1b[2J\x1b[1;31m红\x1b[38;5;208m橙\x1b[0m"` 及**拆成 3 段任意大小**重喂，断言两种喂法动作流完全一致、SGR 参数解码正确。
  3. Read 源码，再 Bash 断言：含 4 类状态、含 256 色与真彩、含截断续喂。

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/hd06_pty.py`：PTY 主机端（Linux/macOS，`--simulate` 模式全平台可测）：(a) **四步曲**：`posix_openpt(O_RDWR)` → `grantpt` → `unlockpt` → `ptsname`；(b) fork 子进程：`setsid()` 新会话 + `ioctl(slave, TIOCSCTTY)` 抢控制终端 + dup2 重定向 stdio + `execvp(shell)`（默认 `/bin/sh`，macOS zsh 注记）；(c) 主端数据泵：select/pselectors 循环把主端输出搬给解析器、把用户输入写主端；(d) **UTF-8 部分字节缓冲**（子进程输出的多字节序列跨 read 分包）；(e) 子进程退出：`SIGCHLD` + waitpid 回收、主端 read 返回 EIO 即 EOF 的平台差异；(f) 窗口尺寸初始 `ioctl(TIOCSWINSZ)`；(g) `--simulate`：不起真进程，用内置回声脚本对打状态机（Windows 上也能跑逻辑）。

  3. Read 源码，再 Bash 断言：含四步曲、含 TIOCSCTTY、含 EIO 差异注记。
