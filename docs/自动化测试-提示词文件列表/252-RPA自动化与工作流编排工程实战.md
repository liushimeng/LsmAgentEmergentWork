# 252 RPA 自动化与工作流编排工程实战

> 编号段 RPA01–RPA10 · 聚焦「laew 构建 RPA(机器人流程自动化)与工作流编排系统」:桌面自动化(pyautogui / uiautomation)+ 浏览器自动化(Playwright)+ 邮件 / 文档 / 数据处理自动化 / 定时调度(cron / 触发器)+ 异常处理(重试 / 告警 / 人工介入)+ 日志审计 / 版本管理 / 模板市场 / 可视化编排。

> 与现有维度互补说明:
> - `139-桌面自动化与用户操作回放`(AUTO 维)是**操作录制回放**;本文件是**完整 RPA 工程**。
> - `36-自动化办公与脚本工程`(OFFICE 维)是**办公脚本**;本文件是**企业级 RPA 平台**。
> - `140-团队工作流与运营自动化`(OPS 维)是**运营工作流**;本文件是**RPA + 编排引擎**。
> - `142-边缘函数与事件流集成实战`(EDGE 维)是**事件流**;本文件是**定时 + 触发 RPA**。
> - `229-远程电源与开关机治理实战`(POWER 维)是**电源治理**;本文件是**桌面自动化**。
>
> **本文件独特主题**:pyautogui(鼠标/键盘/截图/像素定位)+ uiautomation(Windows UI 树)+ Playwright(浏览器:登录/填表/抓取/截图)+ 邮件自动化(IMAP/SMTP)+ 文档处理(Excel/Word/PDF 自动化)+ 数据处理(清洗/转换/入库)+ 调度(cron 表达式 + webhook 触发 + 文件触发)+ 异常处理(重试策略 + 截图留证 + 告警通知)+ 人机协作(暂停/恢复/人工决策节点)+ 日志审计(每步操作记录 + 截图)+ 模板市场(共享/评分/一键复用)。
