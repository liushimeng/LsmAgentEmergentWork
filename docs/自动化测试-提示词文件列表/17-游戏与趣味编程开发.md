# 自动化测试提示词 — 游戏与趣味编程开发（Q01–Q10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**游戏开发、编译器、移动端、嵌入式、函数式、宏、设计模式、WebAssembly、区块链、IoT** 等"趣味编程 + 垂直领域工程"中的动手落地能力。**落地策略**：无手机/硬件 → 模拟器或纯 python；WASM 优先 python 模拟栈机或 node 验证逻辑等价实现，避免耗时编译。所有产物落 `tmpPlan/agent-test/`。

### Q06 Rust 宏系统（用 python 演示宏展开等价过程）
- **预期档位**: medium
- **考察维度**: 元编程 / 代码生成思维
- **工具链**: Write → Bash → Bash → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/q06_declarative.py`：用 python 模拟 `macro_rules!` 展开——输入模板 `hash_map!{"a" => 1, "b" => 2}`，输出等价的 `dict(a=1, b=2)` 构造调用字符串；Bash `python3 q06_declarative.py` 断言输出包含 `{"a":1,"b":2}`。
  2. Write `q06_proc_macro.py`：模拟 `#[derive(Builder)]` 过程宏——读入一个 `struct User { name: String, age: u32 }` 的 JSON 描述，生成 builder 模式代码骨架（含 `new / name(impl Into<String>) / age(u32) / build`），落 `q06_generated.rs`。
