### DB09 端到端加密：Signal 协议简化实现

- **预期档位**: hard
- **考察维度**: E2EE / 密钥交换 / 前向保密
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 用 Python 写 `tmpPlan/agent-test/db09/e2ee.py`：简化版 Signal 协议——（1）A/B 用 X25519 ECDH 交换得到共享密钥；（2）HKDF 派生每条消息密钥（对称棘轮链：k_next = HMAC(k, "next")）；（3）AES-GCM 加解密（带 nonce + seqid 防重放）。
  2. 用 Write 构造 `tmpPlan/agent-test/db09/test.py`：A 发 3 条消息（msg_seq=1/2/3），中间按乱序到达（seq=3 → 1 → 2）。
  3. 用 Bash 跑 e2ee.py + test.py，Read 输出 JSON 断言：B 正确解密全部 3 条（含乱序到达）；每条消息密钥不同（前向保密）。
  4. 用 Bash 断言：`python3 -c "from e2ee import *; ...; assert all(decrypt(...) == m for m in msgs), 'B 应能解出全部 3 条'"` 解密正确且乱序兼容则 echo PASS。
