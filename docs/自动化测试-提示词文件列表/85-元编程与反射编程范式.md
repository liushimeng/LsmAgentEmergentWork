## 与 laew 工程的具体对接点

1. **CC01 → 提示词模板系统**：laew 的提示词模板可借鉴同像性设计，把提示词本身作为数据（YAML / JSON），便于运行时操作与生成。
2. **CC03 → ToolRegistry 自省**：Agent 启动时通过反射自动列出所有已注册工具，无需硬编码工具清单。
3. **CC06 → 工具装饰器**：可用 `@tool(description=..., permission=...)` 装饰器替换当前的硬编码 `Tool` trait 实现，简化样板代码。
4. **CC07 → OpenAPI / Anthropic Schema 生成**：从工具结构体定义自动生成 OpenAPI / Anthropic 兼容的 `input_schema`，避免手写 JSON Schema。
5. **CC10 → Agent MOP 扩展**：用户可通过元类机制自定义 Agent 生命周期钩子（before-run / after-run），无需修改 laew 核心代码。
