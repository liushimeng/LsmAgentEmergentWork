> 编号段 GG01–GG10 · 聚焦「字体从编码到渲染的全链路工程」：字体格式解剖 / 文字塑形与复杂文本布局 / 彩色表情字体 / 字体子集化与网页优化 / 字距与连字 / 字体回退栈 / 可变字体 / 字体质检 / 图标字体系统 / 字体版权与授权
>
> 与现有维度互补说明：
> - `28-游戏引擎与图形编程进阶`（AB 维）聚焦**渲染引擎与视觉表现**；本文件聚焦**文字的字形层面工程**（glyph 编码/塑形/定位），属于文字显示的基础设施层。
> - `43-国际化工程与RTL布局`（AR 维）聚焦**应用层国际化**（翻译/RTL/本地化）；本文件聚焦**字体底层的复杂文本布局引擎**（阿拉伯文连写/印度文合字/泰文声调定位），是 i18n 的地基。
> - `111-排版渲染与打印引擎编程`（DH 维）聚焦**页面级排版**（段落/分页/打印）；本文件聚焦**字形级工程**（单个字符的轮廓/度量/塑形），一个管"字怎么排"、一个管"字怎么画"。
> - `49-编译原理与DSL实战`（AX 维）聚焦**编译器前端**；本文件的 font shaping 本质是**文本→glyph 序列的编译过程**（字符码点→塑形查找→定位），领域完全不同。
>
> **本文件独特主题**：TrueType 轮廓与二次贝塞尔 / OpenType 表结构（cmap/glyf/GSUB/GPOS）/ HarfBuzz 塑形三阶段 / 复杂文本布局（CTL）/ GSUB 替换与 GPOS 定位 / COLR/CPAL 彩色分层字体 / CBDT/SVG-in-OpenType 位图与矢量彩色 / WOFF2 压缩与子集化 / 字距对与特性标签 / 字体回退与系统字体栈 / 可变字体与 design axis / 字体校验工具链 / 图标字体与 icon font 生成 / 字体授权与 OFL/商业授权边界。
