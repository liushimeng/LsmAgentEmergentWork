### DC01 断行算法：从贪心到 Knuth-Plass

- **预期档位**: medium~hard
- **考察维度**: 排版算法 / 动态规划 / 中英文断行差异
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 用 Python 写 `tmpPlan/agent-test/dc01/linebreak.py`：实现两种断行算法——（1）贪心：能放就放，放不下换行；（2）简化 Knuth-Plass：每个可行断点是图节点，边的代价 = 行尾剩余空白的立方，动态规划找全局最短路径。
  2. 用 Write 构造 `tmpPlan/agent-test/dc01/text.txt`：一段 50 词的英文段落（混合长短词）。
  3. 用 Bash 跑 linebreak.py 对同一段落用两种算法断行（设行宽 60 字符），Read 输出 JSON 断言：贪心算法最后一行平均宽度 < 50%（留白多）、Knuth-Plass 各行宽度更均衡（方差更小）。
  4. 用 Bash 写中文断行 `tmpPlan/agent-test/dc01/cjk.py`：中文按字符断行 + 禁则规则（标点不出现行首、开括号不出现行尾）；断言标点不出现在行首、括号不出现在行尾则 echo PASS。
