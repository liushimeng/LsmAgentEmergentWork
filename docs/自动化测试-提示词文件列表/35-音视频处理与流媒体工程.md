### AJ01 FFmpeg 命令行：转码、剪辑与滤镜
- **预期档位**: medium
- **考察维度**: 转码管线 + 滤镜图
- **对话脚本**:
  1. 用 FFmpeg 把一个 4K H.264 视频转成 1080p H.265，码率控制在 5Mbps，写出命令并解释每个参数。
  2. 给视频加一个水印（右上角、半透明、随时间淡入），用 filter_complex 实现，画出滤镜图。
  3. 批量处理一个目录的视频：用 shell 循环 + FFmpeg 把所有 .mov 转成 .mp4，并行 4 路，失败重试。
  4. 用 FFmpeg 提取视频中的音频、生成 GIF 缩略图、截取每秒一帧的截图，分别写出命令。
