## 维度说明
本维度考察 Agent 把**跨学科概念（量子/区块链/ML/编译原理/经济/生物等）翻译为可执行代码与可核对产物**的能力。纯讲解轮 ≤1 轮且必须为后续动手铺垫；其余轮次必须落到 Write/Bash/Read 工具，至少 1 轮 Bash 跑示例+断言、至少 1 轮 Write 落盘产物到 `tmpPlan/agent-test/` 沙盒。衡量重点：抽象概念→最小可运行示例（python3/bash/awk/jq 优先）→用脚本对样例跑断言→总结输出。所有产物与断言脚本集中于 `tmpPlan/agent-test/`，无外网依赖。
