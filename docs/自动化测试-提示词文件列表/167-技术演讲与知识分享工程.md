### FG01 演讲选题价值评估

- **预期档位**: simple
- **考察维度**: 选题分析 / 受众匹配 / 价值评估
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/fg01_topic_eval.py`：选题评估器，输入候选演讲主题（标题/摘要/目标受众/时长），评估：新颖性（1-10）+ 实用性（1-10）+ 受众匹配度（1-10）+ 演讲者专业度匹配（1-10），输出：综合评分 + 改进建议 + 竞品分析提示。
  2. Bash：`python3 -m py_compile tmpPlan/agent-test/fg01_topic_eval.py`，断言退出码为 0。
  3. Read `tmpPlan/agent-test/fg01_topic_eval.py`，再 Write `tmpPlan/agent-test/fg01_topics.json`：3 个候选主题（热门但泛/小众但深/新颖且实用），字段沿用第一轮。本轮必须显式复用第一轮的评估维度与评分标准，不允许另起无关主题。
  4. Bash：`python3 tmpPlan/agent-test/fg01_topic_eval.py tmpPlan/agent-test/fg01_topics.json 2>&1 | tee tmpPlan/agent-test/fg01_topic_report.md`，断言 `grep -F '综合评分'` 命中、`grep -F '改进建议'` 命中、`grep -c '新颖性'` ≥ 3。
