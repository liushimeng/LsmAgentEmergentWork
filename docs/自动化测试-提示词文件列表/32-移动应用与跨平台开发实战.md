# 自动化测试提示词 — 移动应用与跨平台开发实战（AF01–AF10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度从 Agent 能力视角考察**移动端工程链路**：无手机/模拟器可用，核心逻辑（状态管理/本地存储/网络层/UI 结构）抽成纯模块用 python3/node 单测验证；UI 层产出代码文件 + 结构校验脚本。覆盖跨平台架构、声明式 UI、混合开发、性能、安全、热更新、持续交付等主题。所有产物落在 `tmpPlan/agent-test/` 沙盒内。

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:

### AF06 移动端网络与缓存策略
- **预期档位**: medium
- **考察维度**: 网络层设计 / 离线优先
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `network_layer.py`：模拟 OkHttp/ Alamofire 拦截器链（日志/鉴权/重试）。纯函数 `chain = [log, auth, retry]` + `request = chain.reduce(execute)`。跑 `python3 network_layer.py` 期望每个拦截器按序执行（日志→鉴权→重试）。

  4. 电量消耗分析：`power_profiler.py` 统计定位/后台任务/网络轮询三类耗电。构造「高频定位 + 后台轮询」场景，跑 `--recommend` 期望推荐「降低定位频率」「用 BGTaskScheduler 替代轮询」。写 `perf-optimization.md` 总结三要素优化顺序。
