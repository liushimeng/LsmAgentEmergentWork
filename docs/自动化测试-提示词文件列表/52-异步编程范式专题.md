# 自动化测试提示词 — 异步编程范式专题（BA01–BA10）

> 使用说明:聚焦各语言/运行时的异步并发范式:Rust tokio / Go goroutine / Node event loop / Python asyncio / Java virtual thread;每条要求 laew 写出可运行最小示例并用真实输出印证(并发顺序、超时取消、回调 vs async/await),不靠口头对比。

## 维度说明
考察 laew 把异步概念落成可跑代码并产出可断言结果的能力:概念→写最小示例(Write)→运行得输出(Bash)→对比印证(Read+Bash)。Rust cargo 例必须控制在小例子(<5 秒编译),Go 用 `go run`,Node/Python 直接解释器;输出可用 stdout 行序与计数断言。
