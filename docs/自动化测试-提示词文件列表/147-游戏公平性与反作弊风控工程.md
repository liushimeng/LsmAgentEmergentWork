# 147 游戏公平性与反作弊风控工程

> 编号段 EM01–EM10 · 聚焦「服务端权威、行为风控、惩罚申诉与回放验证」：围绕游戏运营工程产出可审计资产，而不是做攻击教学。
>
> 与现有维度互补说明：
> - 95 多人游戏服务器偏网络同步与房间；本文件聚焦**作弊证据、误伤控制与处罚治理**。
> - 107 弹性系统偏混沌；本文件只在压测和灰度处交叉。
> - 132 安全审计偏基础设施；本文件聚焦玩家遥测与公平性指标。
>
> **本文件独特主题**：遥测契约 / 物理不变量 / 行为统计 / 匹配公平 / 举报分诊 / 回放确定性 / 处罚阶梯 / 权威端校正 / 灰度评估 / 风控仪表盘。
