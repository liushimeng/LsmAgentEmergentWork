### DX01 Nmap 端口扫描与服务识别

- **预期档位**: medium
- **考察维度**: 端口扫描 / 服务探测 / NSE 脚本
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/dx01_scan.sh`：nmap 扫描脚本——`-sS` SYN 扫描常用端口、`-sV` 服务版本探测、`-O` 操作系统探测、`--script vuln` 漏洞扫描、`-oX` XML 输出、`-oN` 可读输出，目标 127.0.0.1/32。
  2. Bash：`bash tmpPlan/agent-test/dx01_scan.sh --dry-run 2>&1 | tee tmpPlan/agent-test/dx01_scan.log`（模拟），断言 `dx01_scan.log` 含 "nmap" 和 "scan"。
  3. Read dx01_scan.sh，再 Write `tmpPlan/agent-test/dx01_parse.py`：python3 解析 nmap XML 输出——提取开放端口/服务名/版本/漏洞 CVE 列表、生成 Markdown 扫描报告。
  4. Bash：`python3 tmpPlan/agent-test/dx01_parse.py 2>&1 | grep -c 'port\|service\|vuln\|CVE\|report'` 应 ≥ 3。
