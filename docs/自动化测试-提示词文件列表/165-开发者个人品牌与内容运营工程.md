### FE01 技术博客文章结构优化

- **预期档位**: medium
- **考察维度**: 文章结构分析 / SEO 优化 / 可读性提升
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/fe01_blog_optimizer.py`：博客文章优化器，输入原始技术文章，分析：标题吸引力/段落结构/代码块质量/SEO 关键词密度/可读性评分（Flesch 指数中文版），输出：优化建议清单 + 改写后的文章 + SEO 元数据（标题/描述/标签）。
  2. Bash：`python3 -m py_compile tmpPlan/agent-test/fe01_blog_optimizer.py`，断言退出码为 0。
  3. Read `tmpPlan/agent-test/fe01_blog_optimizer.py`，再 Write `tmpPlan/agent-test/fe01_raw_article.md`：一篇待优化的技术博客（含常见 SEO 与结构问题），字段沿用第一轮。本轮必须显式复用第一轮的评分维度与优化规则，不允许另起无关主题。
  4. Bash：`python3 tmpPlan/agent-test/fe01_blog_optimizer.py tmpPlan/agent-test/fe01_raw_article.md 2>&1 | tee tmpPlan/agent-test/fe01_optimized.md`，断言 `grep -F '优化建议'` 命中、`grep -F 'SEO'` 命中、`grep -F '可读性'` 命中。
