# 194 静态站点生成与个人发布工程

> 编号段 GF01–GF10 · 聚焦「静态站点从建站到发布的完整工程」：SSG 选型 / 主题与模板引擎 / 内容模型与 frontmatter / 构建优化 / SEO 与元数据 / RSS 与订阅 / 评论互动系统 / 部署管线 / 图像性能管线 / 多语言站点
>
> 与现有维度互补说明：
> - `165-开发者个人品牌与内容运营工程`（FE 维）聚焦**内容运营**（选题/写作/传播）；本文件聚焦**建站与发布的技术工程**（生成/构建/部署），一个管写什么、一个管怎么发布。
> - `18-Web全栈与前端工程实战`（R 维）聚焦**前端应用开发**（框架/交互/状态）；本文件的静态站是**内容站**（无前端应用逻辑、无 SSR 运行时），工程重心在构建与发布链路。
> - `190-RSS订阅与信息流聚合工程`（GB 维，本批新增）GB08 讲 **feed 文件的生成算法**；本文件 GF06 讲**站点级订阅集成**（多输出格式/发现标签/订阅引导），互为实现与集成关系。
> - `29-云原生与DevOps工程实战`（AC 维）与 `128-CI-CD流水线工程与GitOps实战`（DT 维）是**通用 CI/CD**；本文件 GF08 仅覆盖静态站特有的部署管线（增量上传/CDN 回源/缓存头策略）。
>
> **本文件独特主题**：Hugo/Hexo/Jekyll/Astro 四家选型矩阵 / Go template 与 Nunjucks 模板继承 / frontmatter schema 与内容校验 / 增量构建与产物指纹 / sitemap-robots-OpenGraph 三件套 / feed 自动发现与全文摘要取舍 / giscus 评论数据流 / GitHub Pages 与对象存储双管线 / 缩略图与懒加载与格式选择 / i18n 多语言路由与 hreflang。
