# 自动化测试提示词 — 安全工程与渗透测试（AV01–AV10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。
> 与现有 30 维度「逆向工程与二进制安全」互补：30 偏静态分析/反编译/二进制加固；47 偏动态攻防/漏洞利用/工程安全体系

## 维度说明

本维度考察 Agent 在 **安全工程化** 上的动手能力：SQLi/XSS/SSRF 全部本地靶场（自写带漏洞 python 小应用），构造 payload 在本机进程内触发并断言防御版拦截，密码学用 python hashlib/hmac 验证属性。
所有产物落到 `tmpPlan/agent-test/` 沙盒，不碰系统路径、不装包、不做网络扫描，只针对现场自己写/编译的本地靶场。
与 README 其它维度互补：AD 维度考察逆向与二进制分析，AV 聚焦"本地靶场攻防"——SQLi/XSS/SSRF 漏洞写→payload→防御→拦截验证。

### AV01 安全工程全景：STRIDE 动手验证
- **预期档位**: medium
- **考察维度**: 攻防全景 + 威胁建模基础
- **工具链**: Write → Bash → Bash → Read
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/av01/` 写 `stride.py`：输入一个"功能描述"（如"用户上传头像并公开展示"），输出 6 类威胁各 1 行描述（Spoofing/Tampering/Repudiation/InfoDisclosure/DoS/Elevation），用字典映射实现，用 Write。
  2. 写 `test_stride.py` 用 unittest：输入 5 个功能描述，断言每个输出 6 行且每行含对应威胁关键字（grep 正则计数 ≥ 6）。
  3. 跑 `python3 -m unittest test_stride.py -v`，输出 "5 features × 6 threats = 30 lines all present" 到 `stride.log`，断言 log 含 `OK`。
  4. 在 `stride_notes.md` 写 CIA 三元组 vs Parkerian 六要素差异：CIA 强调状态、Parkerian 强调"拥有/真实性/效用"，各 1 行 + 1 例。

### AV02 Web 渗透测试方法论：PTES 各阶段工具链

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:

### AV03 SQLi 本地靶场：漏洞写→payload→防御
- **预期档位**: hard
- **考察维度**: 注入类漏洞 + 防御策略
- **工具链**: Write → Bash → Bash → Read
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/av03/` 写 `vulnerable_app.py`：用 python 内置 sqlite3 实现 `login(username)`，SQL = `SELECT * FROM users WHERE name='{username}'`（故意拼接）。
  2. 写 `exploit.py`：构造 payload `admin' OR '1'='1`，跑后断言返回所有用户（`len(rows) ≥ 2`）到 `exploit.log`。
  3. 写 `fixed_app.py` 用参数化 `cursor.execute("SELECT * FROM users WHERE name=?", (username,))`，跑 exploit.py 重写 payload 断言只返回 1 行 → "防御成功"。
  4. 在 `sqli_notes.md` 写 SQLi 三类（Union/Boolean/Time-Based Blind）+ NoSQL 注入（MongoDB `$ne/$where` 操作符），各 1 行 + 1 个典型 payload。

### AV04 XSS/SSRF 本地靶场：反射 + URL 校验
- **预期档位**: hard
- **考察维度**: 浏览器端漏洞 + 服务端漏洞
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/av04/` 写 `xss_app.py`：用 http.server 实现 `/?q=hello` 返回 `<h1>hello</h1>`（故意不转义）。
  2. 写 `xss_exploit.py`：构造 `q=<script>alert(1)</script>`，跑后断言响应体含原始 `<script>` 标签（grep 命中）；再写 `xss_fixed.py` 用 `html.escape` 转义，重跑断言响应体含 `&lt;script&gt;` 而非 `<script>`。
  3. 写 `ssrf_app.py`：暴露 `/fetch?url=<url>` 直接 `urllib.request.urlopen(url)`；写 `ssrf_exploit.py` 构造 `url=http://169.254.169.254/latest/meta-data/`（模拟云元数据），断言响应含 `latest`。
  4. 写 `ssrf_fixed.py`：私有 IP 校验（`ipaddress.ip_address(host).is_private` → 拦截），重跑断言返回 `403`；在 `xss_ssrf_notes.md` 写 CSP nonce vs unsafe-inline 安全性差异 1 段。

### AV06 密码学实战：hashlib 验证属性
- **预期档位**: medium
- **考察维度**: 密码学应用 + 常见误用
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/av06/` 写 `hash_props.py`：用 python hashlib 验证 MD5/SHA1/SHA256 三者的"雪崩效应"——翻转输入 1 bit，输出不同 bit 比例应接近 50%；对 100 组输入测平均 bit 差异率，输出 `avalanche.csv`。
  2. 跑脚本后用 `awk` 算三算法均值，断言都在 45-55%（SHA256 可接受 48-52%）。
  3. 写 `hmac_verify.py`：验证 HMAC-SHA256 篡改检测——任意改 1 bit，`hmac.compare_digest` 必返回 False；跑 100 次篡改断言 100/100 检测出。
  4. 在 `crypto_notes.md` 写 bcrypt/scrypt/Argon2 三维权衡（内存-时间-并行度）+ 禁用 MD5/SHA1 密码存储理由（3 行）。
