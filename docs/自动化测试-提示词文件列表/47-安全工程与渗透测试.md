# 47 安全工程与渗透测试

> 编号段 AV01–AV10 · 聚焦 Web 渗透测试、红蓝对抗、漏洞赏金、CTF 安全竞赛、SDL 安全开发生命周期
> 与现有 30 维度「逆向工程与二进制安全」互补：30 偏静态分析/反编译/二进制加固；47 偏动态攻防/漏洞利用/工程安全体系

### AV01 安全工程全景：从攻击面到纵深防御
- **预期档位**: medium
- **考察维度**: 攻防全景 + 威胁建模基础
- **对话脚本**:
  1. 安全工程的本质是什么？为什么说「安全不是产品而是过程」？CIA 三元组（机密性/完整性/可用性）与 Parkerian 六要素的差异。
  2. 画出攻击者视角的 Kill Chain（侦察→武器化→投递→利用→安装→命令控制→行动）和 defender 视角的 Defense-in-Depth 七层。
  3. 用 STRIDE 模型对一个「用户上传头像并公开展示」的功能做威胁建模：每类威胁各举一个具体场景。
  4. OWASP Top 10（2021 版）的 10 类风险在 2026 年的演进：API 时代的新增风险（SSRF、Broken Object Level Authorization）。

### AV02 Web 渗透测试方法论
- **预期档位**: hard
- **考察维度**: PTES 流程 + 渗透测试全链路
- **对话脚本**:
  1. PTES（Penetration Testing Execution Standard）七个阶段是什么？每个阶段产出物与典型工具清单。
  2. 信息收集（Recon）的被动 vs 主动两种方式：shodan/censys/whois/passiveDNS vs nmap/masscan 子网扫描的合法边界。
  3. 漏洞扫描（Nessus / Qualys / Nuclei）的「已知漏洞」与渗透测试「逻辑漏洞」的差异：为什么自动化工具永远找不到业务逻辑缺陷。
  4. 写一份简化版渗透测试报告模板：执行摘要、技术发现（按 CVSS 评分）、复现步骤、影响分析、修复建议、附录（时间线与工具版本）。

### AV03 注入攻击全家福：SQLi / NoSQLi / Command / LDAP
- **预期档位**: hard
- **考察维度**: 注入类漏洞 + 防御策略
- **对话脚本**:
  1. SQL 注入的三大类：经典 Union/Boolean/Time-Based Blind 的原理，sqlmap 怎么探测注入点与提取数据。
  2. 写一段故意有 SQL 注入的 Python 代码（用 sqlite3 拼接），再用参数化查询修复，对比两种写法与攻击 payload。
  3. NoSQL 注入（MongoDB）和 ORM 注入（Hibernate HQL）的特征：$where/$ne/$regex 操作符注入的典型 payload。
  4. 命令注入（OS Command Injection）与 SSTI（Server-Side Template Injection）的区别：Jinja2、Twig、Freemarker 各自的利用手法。

### AV04 XSS / CSRF / SSRF / XXE 现代 Web 三大件
- **预期档位**: hard
- **考察维度**: 浏览器端漏洞 + 服务端漏洞
- **对话脚本**:
  1. XSS 三态：Reflected / Stored / DOM-based 的差异，给一段含 DOM-XSS 的 React 代码并修复。
  2. CSP（Content Security Policy）怎么写？为什么 nonce 比 unsafe-inline 更安全？给出 strict-dynamic 策略示例。
  3. CSRF 在 SameSite=Lax 后还危险吗？给出「登录态 + GET 触发转账」的绕过案例（Clickjacking 协助）。
  4. SSRF（Server-Side Request Forgery）的现代玩法：云元数据 169.254.169.254、内网 Redis/Database 协议利用、DNS rebinding 绕过。

### AV05 认证与授权漏洞：IDOR / 越权 / 会话劫持
- **预期档位**: hard
- **考察维度**: 访问控制 + 业务逻辑漏洞
- **对话脚本**:
  1. IDOR（Insecure Direct Object Reference）是什么？画一个「/api/user/123/order/456」接口的攻击路径，怎么水平越权读到他人订单？
  2. OAuth 2.0 流程中的常见漏洞：redirect_uri 校验绕过、PKCE 缺失、state 缺失带来的会话固定。
  3. JWT 的 5 类攻击：none 算法、密钥爆破、kid 注入、jku 注入、过期绕过，给出每个漏洞的复现思路。
  4. 写一个用 RBAC 修复越权的最小代码：Spring Security / casbin / casdoor 三种方案的对比。

### AV06 密码学实战：从 Hash 到 TLS
- **预期档位**: medium
- **考察维度**: 密码学应用 + 常见误用
- **对话脚本**:
  1. 为什么密码不能用 MD5/SHA1 直接存储？画一个 bcrypt / scrypt / Argon2 的内存-时间-并行度三维权衡图。
  2. TLS 握手 1.2 vs 1.3 的差异：RTT 数、密码套件选择、0-RTT 的安全争议，给出 openssl s_client 的真实抓包分析。
  3. 对称加密（AES-GCM）与非对称加密（RSA/ECC）的混用套路：ECDHE 密钥交换 + AES-GCM 数据加密的完整流程。
  4. 真实事故：Heartbleed、POODLE、ROBOT、Logjam 各自的原理与影响范围，TLS 配置审计的「Mozilla SSL Configuration Generator」推荐配置。

### AV07 漏洞赏金与 SRC：从提交到奖金
- **预期档位**: medium
- **考察维度**: 漏洞赏金生态 + 合规边界
- **对话脚本**:
  1. 主流漏洞赏金平台对比：HackerOne / Bugcrowd / Intigriti / 国内 SRC（阿里/腾讯/字节）的奖金梯度、审核周期、争议解决。
  2. 一个完整漏洞报告的字段：标题、严重等级、复现步骤、影响范围、修复建议、截图视频、参考资料，怎么写 CVSS 3.1 评分。
  3. 漏洞披露的灰色地带：未授权测试的法律边界、「善意」原则在各国法律的差异（《网络安全法》《计算机欺诈与滥用法》CFAA）。

### AV08 容器与云原生安全
- **预期档位**: hard
- **考察维度**: Docker/K8s 攻击面 + 镜像安全
- **对话脚本**:
  1. Docker 容器的攻击面：特权模式、capability、namespace 隔离、socket 挂载的逃逸路径，sysctl 与 seccomp 的最小限制配置。
  2. 镜像漏洞扫描（Trivy / Clair / Anchore）的完整 CI 集成：base image 选型、CVE 阻断规则、SBOM（SPDX/CycloneDX）输出。

### AV10 SDL 安全开发生命周期：左移与右移
