> 编号段 CRAWL01–CRAWL10 · 聚焦「laew 构建爬虫与数据采集系统」:HTTP 客户端(aiohttp / httpx / requests) / HTML 解析(BeautifulSoup / lxml / parsel) / 动态渲染(Selenium / Playwright) / 反反爬(User-Agent 轮换 / 代理池 / 验证码识别) / 速率限制(令牌桶) / 去重(Bloom Filter) / 增量抓取(ETag / Last-Modified) / 数据清洗 / 存储(SQLite / CSV / JSON) / 调度(定时 + 失败重试)。

> 与现有维度互补说明:
> - `36-自动化办公与脚本工程`(AUTO 维)是**办公自动化**;本文件是**网络数据采集**。
> - `203-网络流量分析与NetFlow工程实战`(NET 维)是**流量分析**;本文件是**主动爬取**。
> - `146-网络数据包解码与流量回放工程`(PCAP 维)是**包级解码**;本文件是**应用层爬取**。
> - `190-RSS订阅与信息流聚合工程`(RSS 维)是**RSS 聚合**;本文件是**通用爬虫**。
> - `225-网页存档与数字保全工程`(ARCH 维)是**网页存档**;本文件是**数据采集**。
>
> **本文件独特主题**:aiohttp 异步并发 / BeautifulSoup CSS 选择器 / Playwright 无头浏览器 / 反反爬三件套(UA 轮换 + 代理池 + 验证码) / 令牌桶速率限制 / Bloom Filter 去重 / 增量抓取(ETag/Last-Modified) / 数据清洗管道 / 多存储后端 / 调度器(定时 + 失败重试 + 优先级) / 合规(robots.txt + 速率限制 + 版权)。
