# 自动化测试提示词 — 计算机视觉与图像工程（X01–X10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**图像滤波、边缘检测、特征提取、
目标检测、图像分割、人脸识别、OCR 文字识别、
图像增强、风格迁移、视频处理**等"计算机视觉"垂直领域中的实战表现，
与 G 维度（文件/图片处理）互补：G 考察"图片的批量操作（压缩/格式转换）"，
本维度考察"图像内容的理解与分析"。
所有主题都以"动手写 CV 代码或设计图像处理方案"为核心，强调视觉工程能力。

---

### X01 图像基础：像素、色彩空间与通道
- **预期档位**: simple
- **考察维度**: 图像表示 + 色彩空间 + 通道操作
- **对话脚本**:
  1. 解释数字图像的基本概念：像素、分辨率、位深度、通道（Channel）。RGB 和 RGBA 有什么区别？
  2. 用 Rust 的 `image` crate 实现一个图像处理工具：读取一张图片，分离 R/G/B 三个通道并保存为三张灰度图。
  3. 加上色彩空间转换：把 RGB 图片转为 HSV 色彩空间，调整色相（H）后转回 RGB。
  4. 讨论：为什么图像处理常用 HSV 而不是 RGB？"直方图均衡化"是怎么提升图像对比度的？

### X02 图像滤波：卷积与模糊/锐化
- **预期档位**: medium
- **考察维度**: 卷积运算 + 滤波核 + 图像增强
- **对话脚本**:
  1. 解释卷积（Convolution）运算的原理：滤波核（Kernel）是怎么在图像上滑动的？
  2. 用 Rust 实现一个 3×3 卷积函数：支持自定义滤波核，实现均值模糊（Box Blur）效果。
  3. 加上高斯模糊：生成一个 5×5 高斯核，对比均值模糊和高斯模糊的效果差异。
  4. 讨论：锐化滤波核是怎么设计的？"Unsharp Masking"锐化技术的原理是什么？

### X03 边缘检测：Sobel 与 Canny 算法
- **预期档位**: medium
- **考察维度**: 边缘检测 + 梯度计算 + 非极大值抑制
- **对话脚本**:
  1. 解释边缘检测的意义：为什么边缘是图像中最重要的特征之一？
  2. 用 Rust 实现 Sobel 边缘检测：计算 X 方向和 Y 方向的梯度，合并得到边缘强度图。
  3. 实现 Canny 边缘检测的完整流程：高斯模糊 → 梯度计算 → 非极大值抑制 → 双阈值 → 边缘连接。
  4. 讨论：Sobel 和 Canny 的结果有什么差异？为什么 Canny 通常效果更好但更慢？

### X04 特征提取：SIFT 与 ORB 特征点
- **预期档位**: hard
- **考察维度**: 特征点检测 + 描述子 + 特征匹配
- **对话脚本**:
  1. 解释特征点（Feature Point）的概念：什么样的图像区域适合作为特征点？
  2. 对比 SIFT 和 ORB 两种特征提取算法：原理、性能、专利限制各有什么差异？
  3. 用 Python 的 `opencv` 库实现特征匹配：提取两张图片的 ORB 特征点，用 BFMatcher 匹配并绘制匹配线。
  4. 讨论：特征匹配在什么场景下应用（图像拼接/目标跟踪/三维重建）？"误匹配"怎么过滤（RANSAC）？

### X05 目标检测：YOLO 系列实战
- **预期档位**: hard
- **考察维度**: 目标检测 + 单阶段检测 + 后处理
- **对话脚本**:
  1. 解释目标检测的两阶段（Faster R-CNN）和单阶段（YOLO）方法的区别，为什么 YOLO 更快？
  2. 用 Python 的 `ultralytics` 库加载 YOLOv8 预训练模型，对一张图片做目标检测，输出边界框和类别。
  3. 加上 NMS（非极大值抑制）：解释为什么需要 NMS，它的阈值怎么影响检测结果？
  4. 讨论：YOLO 的"锚框（Anchor Box）"是什么？YOLOv8 为什么改用 Anchor-Free 设计？

### X06 图像分割：语义分割与实例分割
- **预期档位**: hard
- **考察维度**: 像素级分类 + 分割模型 + 后处理
- **对话脚本**:
  1. 解释图像分割的三种类型：语义分割、实例分割、全景分割，各举一个应用场景。
  2. 用 Python 的 `segment-anything` (SAM) 实现自动分割：输入一张图片，输出所有物体的分割掩码。
  3. 加上交互式分割：用户点击一个点，SAM 只分割该点所在的物体。
  4. 讨论：分割模型的评估指标是什么（mIoU / Dice Coefficient）？它们各侧重什么？

### X07 OCR 文字识别：Tesseract 与深度学习 OCR
- **预期档位**: medium
- **考察维度**: OCR 技术 + 文字检测 + 文字识别
- **对话脚本**:
  1. 解释 OCR 的两步流程：文本检测（Text Detection）和文本识别（Text Recognition）。
  2. 用 Python 的 `pytesseract` 库实现 OCR：对一张包含中文和英文的图片做文字识别。
  3. 加上图像预处理：灰度化 → 二值化 → 去噪，对比预处理前后的识别准确率。
  4. 讨论：Tesseract 和深度学习 OCR（如 PaddleOCR）各适合什么场景？手写体识别为什么比印刷体难？

### X08 人脸识别：检测、对齐与特征提取
- **预期档位**: hard
- **考察维度**: 人脸检测 + 特征嵌入 + 人脸比对
- **对话脚本**:
  1. 解释人脸识别的流程：人脸检测 → 人脸对齐 → 特征提取 → 特征比对。
  2. 用 Python 的 `face_recognition` 库实现人脸识别：加载已知人脸库，识别新图片中的人是谁。
  3. 加上活体检测（Liveness Detection）：区分真人照片和打印照片/屏幕翻拍。
  4. 讨论：人脸识别的"误识率（FAR）"和"拒识率（FRR）"怎么权衡？人脸识别技术的隐私风险有哪些？

### X09 图像增强：去噪、超分辨率与修复
- **预期档位**: medium
- **考察维度**: 图像恢复 + 深度学习增强 + 质量评估
- **对话脚本**:
  1. 解释图像增强的三种类型：去噪（Denoising）、超分辨率（Super Resolution）、修复（Inpainting）。
  2. 用 Python 实现一个基于深度学习的超分辨率工具：把低分辨率图片放大 4 倍，对比双三次插值和深度学习的效果。
  3. 加上图像修复：用 `lama` 模型，用户涂抹区域后自动填充合理内容。
  4. 讨论：图像质量的评估指标有哪些（PSNR / SSIM / LPIPS）？为什么 PSNR 高不代表视觉质量好？

### X10 视频处理：帧提取、场景检测与视频摘要
- **预期档位**: medium
- **考察维度**: 视频分析 + 关键帧提取 + 场景分割
- **对话脚本**:
  1. 解释视频处理的基本概念：帧率（FPS）、分辨率、编码格式（H.264/H.265）、关键帧（I-Frame）。
  2. 用 Python 的 `opencv` 实现视频关键帧提取：检测镜头变化，只保存场景切换时的帧。
  3. 加上视频摘要：从 10 分钟视频中自动提取 10 个代表性帧，生成"故事板"拼图。
  4. 讨论：视频处理的性能瓶颈在哪？怎么用 GPU 加速视频解码和推理？
