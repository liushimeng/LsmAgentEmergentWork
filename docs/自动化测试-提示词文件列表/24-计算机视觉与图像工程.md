## 维度说明

本维度考察 Agent 用 **PIL+numpy 现场造测试图**、纯 numpy 写滤波/边缘检测/直方图/模板匹配/帧差，不依赖 OpenCV/预训练模型/GPU——把"图像通道操作/卷积/Sobel&Canny/特征匹配/YOLO NMS 等价/语义分割 mask/SIFT 描述子近似/超分双三次/OCR 模板/视频帧差"做成可 Read 可 Bash 的真实可执行产物——像素统计、文件存在、可执行退出码断言。

### X01 像素/通道/色彩空间：PIL 生成 + numpy 操作
- **预期档位**: simple
- **考察维度**: 通道分离 / HSV / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/x01/` 下写 `gen.py`：用 `PIL.Image.new("RGB", (64,64), ...)` 生成一张左半红、右半蓝的 `rgb.png`；再用 `numpy.array(img)` 拆 R/G/B 三通道并保存为三张灰度图 `r.png g.png b.png`。`python generate.py && ls r.png g.png b.png` 必须三个文件都存在。
  2. 跑 `verify_channels.sh`：用 numpy 检查 `r.png` 左半（x<32）像素均值应 >200、右半像素均值应 <50；`g.png` 全图应接近 0；`b.png` 反之；`python -c "import numpy as np; from PIL import Image; a=np.array(Image.open('r.png')); print(a[:32].mean(), a[32:].mean())"` 输出形如 "200.x 0.x"，断言左 > 右。
  3. 加 HSV 转换：`hsv.py` 用 `PIL.Image.convert("HSV")` 或 numpy 手动 `rgb_to_hsv()`，把 `rgb.png` 转 HSV 后调整 H 通道 +60° 再转回 RGB 保存 `shifted.png`；`verify_shift.sh` 校验 `shifted.png` 左/右像素均值与 `rgb.png` 不同（`diff` 退出码非 0 表示确实不同）。
  4. 加"直方图均衡化"：`eq.py` 实现 numpy 直方方图均衡（`cdf = cumsum(hist) / total, out = cdf[img] * 255`），对一张暗图 `dark.png`（全图值 < 50）均衡化得 `eq.png`；`python eq.py` 后 `numpy.array(Image.open('eq.png')).mean()` 应显著 > `dark.png` 的均值（`awk` 比较）。

### X02 卷积滤波：numpy 手写 3×3 / 5×5 高斯
- **预期档位**: medium
- **考察维度**: 卷积 / 高斯核 / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/x02/` 下写 `gen.py` 生成 `sharp.png`（一个清晰白圆点 + 黑背景 100×100）和 `noisy.png`（同图加 30% 随机噪声）；写 `conv.py` 实现 `conv2d(img, kernel)`（要求 `numpy` + 边界 `pad` 0），`box_blur_3x3` 核 = `[[1/9]*3]*3`。
  2. 跑 `python conv.py --op box_blur noisy.png blurred.png`，`verify_box.sh`：`PIL` 读图比较 `noisy.png` 与 `blurred.png` 的 `numpy.std()`（标准差），期望 blurred < noisy（被平滑）；`awk -v n=$(python -c "from PIL import Image; import numpy as np; print(int(np.array(Image.open('noisy.png')).std()))") ...` 比较整数。
  3. 加高斯模糊：`gen_gaussian.py` 用 `np.exp(-(x^2+y^2)/(2*sigma^2))` 归一化生成 5×5 σ=1 核；跑 `python conv.py --op gaussian sharp.png gauss.png`，期望 `sharp.png` 边缘清晰（灰度方差大）、`gauss.png` 边缘模糊（方差更小）；`verify_gauss.sh`：`python -c "..."` 取两张图中心 30×30 区域 `std()`，断言 gauss < sharp。
  4. 加锐化核 `[[0,-1,0],[-1,5,-1],[0,-1,0]]`：`python conv.py --op sharpen blurred.png sharp2.png`，期望 `sharp2.png` 边缘比 `blurred.png` 强（方差回升），写 `verify_sharpen.sh` 用同样 `std` 比较，失败请 Read `conv.py` 修 conv 计算（pad + flip + sum）重跑。

### X03 Sobel + Canny 等价：梯度 → NMS → 双阈值
- **预期档位**: medium
- **考察维度**: 边缘检测 / NMS / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/x03/` 下写 `gen.py` 生成 `square.png`（黑底白方块）、`circle.png`（黑底白圆）、`noise.png`（白噪声 64×64）；写 `sobel.py` 实现 Sobel：`Gx=[[-1,0,1],[-2,0,2],[-1,0,1]]` `Gy` 转置、`mag=sqrt(Gx^2+Gy^2)`。
  2. 跑 `python sobel.py square.png sobel_square.png`，`verify_sobel.sh` 用 numpy 算 `sobel_square.png` 中心区域（圆内）像素均值应明显高于边缘外（`awk` 比较）；跑 `sobel.py noise.png sobel_noise.png`，期望噪声响应图均值也很高（与方块响应可比）。
  3. 加 Canny 等价：`canny.py` 实现四步——`gauss blur → sobel → nms(沿梯度方向取极值) → 双阈值(low=50, high=150) + 滞后连接`；`verify_canny.sh` 跑 `square.png` 与 `noise.png`，期望 square 的响应图非零像素数远小于 noise（`grep` 等价：`(arr>0).sum()`）；`verify_nms.sh` 故意把 NMS 步骤的"沿梯度方向"改成"沿 x 方向"，跑后边缘变粗（`(arr>0).sum()` 变大），请 Read `canny.py` 改回正确梯度方向重跑。
  4. 写 `verify.sh` 串 3 步：Sobel 梯度幅值 > 0、`square > noise` 或反、Canny 非零像素数 < Sobel；任意失败 exit 1，OK 则写 `OK` 到 `final.out`。

### X04 特征匹配：Harris 角点 + 描述子 + BFMatcher 等价
- **预期档位**: hard
- **考察维度**: 角点 / 匹配 / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/x04/` 下写 `gen.py` 生成 `a.png`（黑底白方块、白圆、白三角三种图元）、`b.png`（a.png 加随机旋转 15° 内 + 50% 噪声）；写 `harris.py` 实现 `R = det(M) - k*trace(M)^2`，k=0.04，非极大值抑制后取 top-50 角点保存到 `a_kp.json`（坐标列表）。
  2. 跑 `python harris.py a.png a_kp.json && jq -e 'length == 50' a_kp.json` 必须通过；`verify_corner.sh` 故意把 `gen.py` 改成全黑图，期望 `a_kp.json length < 5`（角点稀少），请 Read `harris.py` 修阈值重跑。
  3. 写 `match.py` 实现简化描述子：以角点为中心取 8×8 patch 像素作为描述子，BFMatcher 用欧氏距离匹配两图的 patch；`verify_match.sh` 跑 `a.png` ↔ `b.png`，期望正确匹配率 ≥ 60%（角点偏移后多数 patch 仍能匹配上）`grep -c 'matched' out.out` ≥30。
  4. 加"误匹配过滤"（RANSAC 等价）：随机抽 4 对估计仿射变换 + 内核计数；`verify_ransac.sh`：故意把 `b.png` 改成 a.png 的左半 + 噪声（30% 关键点丢失），期望 RANSAC 后正确匹配率反而提升（`awk` 比较 before/after），失败请 Read `match.py` 加迭代次数重跑。

### X05 目标检测后处理：NMS + IoU + 锚框生成
- **预期档位**: medium
- **考察维度**: NMS / IoU / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/x05/` 下写 `detection.py`：`iou(b1, b2) = inter / (area1 + area2 - inter)`；`nms(boxes, scores, iou_thresh=0.5)` 按分数降序贪心抑制；输入一批故意重叠的 boxes（10 个框 3 类真实目标，框间 IoU 0.3~0.8），期望保留 3 个。
  2. 跑 `python detection.py --op nms boxes.json | tee out.out`，`jq -e '.kept | length == 3' out.out` 必须通过；`verify_iou.sh` 故意把 IoU 实现错（写成 `inter / max(area1,area2)`），跑后保留数会变多（5+），请 Read `detection.py` 改回标准公式重跑。
  3. 加"锚框生成"：`gen_anchors.py` 在 32×32/64×64/128×128 三层各生 3 个比例 (0.5, 1.0, 2.0) 锚框 → 共 9×3=27；`python gen_anchors.py | jq -e 'length == 9'` 期望 9 个 anchor 中心点（每层 3 个）。
  4. 加"Anchor-Free 等价"：用中心点 + 宽高直接回归 5 个 box 的 ground truth；`verify_afree.sh` 把 5 个真实 box 的中心点当作锚点直接回归，期望重建 box 与 GT 的 IoU 均 ≥ 0.9，统计 `min_iou >= 0.9`。

### X09 图像增强：双三次插值超分 + PSNR/SSIM
- **预期档位**: medium
- **考察维度**: 插值 / 质量度量 / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/x09/` 下用 PIL 造 `hr.png`（128×128 渐变图）；写 `bicubic.py` 实现**双三次插值**（Bicubic 核 `(a+2)|t|^3 - (a+3)|t|^2 + 1` 当 |t|<=1，否则 `a|t|^3 - 5a|t|^2 + 8a|t| - 4a` 当 1<|t|<2），把 `lr.png`（32×32 双三次下采样到 128×128 即原图）放大 4 倍还原。
  2. 跑 `python bicubic.py lr.png sr.png`，`verify_psnr.sh`：用 `numpy` 实现 PSNR = `10*log10(MAX^2 / mse)`，期望 `sr.png` 与 `hr.png` 的 PSNR ≥ 25 dB（不算差但非完美）。
  3. 加 SSIM：`ssim.py` 实现简化 SSIM（亮度/对比度/结构三项），`verify_ssim.sh`：期望 `sr` 与 `hr` 的 SSIM ≥ 0.8、`sr` 与 `lr` 的 SSIM 显著更高（`awk` 比较两个数）。
  4. 加 LPIPS 近似：用 `numpy` 把 RGB 转 YCbCr 后对 Y 通道算 PSNR（视觉权重近似）；故意把插值核换成"最近邻"跑，PSNR 与 SSIM 都应明显下降，失败请 Read `bicubic.py` 修边界与核公式重跑。

### X10 视频处理：帧提取 + 帧差关键帧
- **预期档位**: medium
- **考察维度**: 帧差 / 关键帧 / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/x10/` 下写 `gen_video.py` 用 PIL 循环生成 `frames/frame_000.png` ~ `frame_029.png`（30 帧，每帧是"缓慢移动的方块"+ 突变点：第 10、20 帧换不同背景）；写 `extract.py` 实现帧差 `diff = mean(abs(frame_t - frame_{t-1}))`，差值 > 阈值标记为关键帧。
  2. 跑 `python extract.py frames/ 0.05 > keys.out`，期望至少 2 个关键帧索引（包括第 10、20 帧），`wc -l keys.out` ≥2；故意把阈值改成 0.5 跑，期望关键帧数变 0（过于宽松），改回 0.05 重跑验证。
  3. 加"故事板拼图"：`storyboard.py` 把关键帧拼成 3×1 网格（用 PIL `Image.paste`），保存 `story.png`；`verify_story.sh`：`python -c "from PIL import Image; im=Image.open('story.png'); print(im.size)"` 应输出 `(384, 128)`（3×128 横向拼接），实际断言宽 = 3×128=384。
  4. 写 `verify.sh`：跑 3 步（帧差关键帧/故事板尺寸/帧数 = 30），任意失败 exit 1；通过写 `OK` 到 `final.out`。
