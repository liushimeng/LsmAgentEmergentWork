# 自动化测试提示词 — 形式化方法与软件验证（AU01–AU10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在 **形式化方法工程化** 上的动手能力：TLA+/Coq 不可用时能用 Python 属性测试（随机输入验证不变量）、能用穷举小状态空间做模型检测、能把符号执行降级为 mini 表达式求值器。
所有产物落到 `tmpPlan/agent-test/` 沙盒，不依赖 TLA+/Coq/Lean/Z3 等重工具。
与 README 其它维度互补：T 维度考察通用测试框架，AU 聚焦"轻量级形式化"——不变量/状态机/属性测试/穷尽枚举。
