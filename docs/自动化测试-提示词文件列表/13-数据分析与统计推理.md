# 自动化测试提示词 — 数据分析与统计推理（M01–M10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**数据分析思维、统计推理、实验设计、指标体系**等场景中的表现，
侧重"用数据说话"的方法论与常见统计陷阱，与 G 维度（文件/格式加工）互补：
G 考察"怎么处理数据文件"，本维度考察"怎么从数据里得出正确结论"。
涵盖 A/B 测试、因果推断、贝叶斯思维、假设检验、抽样问卷、回归预测、
漏斗分析、指标体系、SQL 窗口函数分析等主题。

---

### M01 A/B 测试设计与显著性
- **预期档位**: simple
- **考察维度**: 实验设计 + 统计概念应用
- **对话脚本**:
  1. 我们想把按钮从蓝色改成橙色提升点击率，怎么做一次规范的 A/B 测试？列出关键步骤。
  2. 为什么样本量和测试时长很重要？如果跑了两天发现橙色版领先 5% 就下结论，有什么风险？
  3. 给你一组数据：A 版 10000 次曝光 320 次点击，B 版 10000 次曝光 355 次点击，判断差异是否显著并说明推理过程。
  4. 总结 A/B 测试最常见的三个误区（如中途偷看结果 peeking、多重比较），各给一句规避建议。

### M02 相关不等于因果
- **预期档位**: simple
- **考察维度**: 因果推断 + 批判性思维
- **对话脚本**:
  1. "数据发现：使用功能 X 的用户留存率比不使用的高 30%，所以功能 X 提升了留存"——这个结论有什么问题？
  2. 解释什么是混杂变量（confounder），给上面第 1 问的场景找出至少两个可能的混杂因素。
  3. "冰淇淋销量与溺水人数正相关"是经典案例，用因果逻辑拆解它。
  4. 要证明"功能 X 提升留存"，除了随机对照实验还有什么方法（如断点回归/双重差分）？各用一句话说明适用条件。

### M03 幸存者偏差与辛普森悖论
- **预期档位**: simple
- **考察维度**: 统计陷阱辨识 + 多轮概念串联
- **对话脚本**:
  1. 用二战飞机装甲的故事解释什么是幸存者偏差，再给一个互联网产品里的同类例子。
  2. 什么是辛普森悖论？用"两个分组都占优、合并后反而落后"构造一个最小数字例子。
  3. 幸存者偏差和辛普森悖论在根因上有什么共同点？都和"数据的分组方式"有什么关系？
  4. 基于三轮内容，给数据分析师列一份"看数据前先问自己的三个问题"检查清单。

### M04 北极星指标与指标体系
- **预期档位**: medium
- **考察维度**: 指标设计 + 产品数据思维
- **对话脚本**:
  1. 什么是北极星指标（North Star Metric）？选得不好的典型症状是什么？
  2. 为一个"团队协作笔记产品"设计北极星指标，给出候选指标并论证最终选择。
  3. 围绕选定的北极星指标，搭建三层指标体系（北极星→一级驱动→可操作过程指标），用表格呈现。
  4. 讨论虚荣指标（如累计下载量）为什么危险，把你体系里最容易被误用的一个指标标出来并加护栏说明。

### M05 贝叶斯思维入门 ✅ 已测试 (2026-09-10 第二十九轮 mock 链路完整)
- **预期档位**: simple
- **考察维度**: 概率推理 + 生活化计算
- **对话脚本**:
  1. 用通俗语言解释先验概率、似然、后验概率，贝叶斯公式把三者串成了什么关系？
  2. 经典计算：某病发病率 1%，检测准确率 99%（漏诊 1%、误诊 1%），某人检测阳性，实际患病概率是多少？请写出完整计算。
  3. 上面结果违背直觉的根源是什么？"基率谬误"在生活中还有哪些体现？
  4. 把贝叶斯更新用在产品迭代上：描述"上线新功能→观察数据→修正判断"的贝叶斯式循环。

### M06 假设检验与 p 值
- **预期档位**: simple
- **考察维度**: 统计概念精确理解 + 误区澄清
- **对话脚本**:
  1. 原假设、备择假设、第一类错误、第二类错误分别是什么？用"法庭审判"类比讲解。
  2. p 值到底是什么？"p=0.03 表示原假设有 3% 概率为真"这句话错在哪？
  3. 显著性水平 0.05 是怎么来的？把阈值调到 0.01 会发生什么权衡？
  4. 把三轮内容整理成一段"给工程师的 p 值速通解释"，不超过 200 字。

### M07 抽样方法与问卷设计
- **预期档位**: simple
- **考察维度**: 采样偏差意识 + 调研设计
- **对话脚本**:
  1. 简单随机抽样、分层抽样、整群抽样分别适合什么场景？各举一个例子。
  2. "在 App 内发问卷调研用户满意度"这个做法有什么抽样偏差？如何缓解？
  3. 设计一份 NPS 类满意度问卷：写 3 个问题，并解释为什么不能设诱导性选项。
  4. 回收 200 份问卷后，怎么判断样本是否有代表性？给出 2 个可操作的检验角度。

### M08 回归分析与预测陷阱
- **预期档位**: medium
- **考察维度**: 建模常识 + 过拟合/外推意识
- **对话脚本**:
  1. 线性回归在做什么？R² 是不是越高模型越好？为什么？
  2. 用"房租面积→月租金"的例子解释过拟合：为什么 10 次多项式在训练集上完美却不可用？
  3. 什么是外推陷阱？用面积 50~120 平米的数据预测 500 平米仓库租金会出什么问题？
  4. 给一个"业务方拿着预测数字直接做预算"的场景，列出给数字前必须附上的 3 条免责说明。

### M09 漏斗分析与呈现
- **预期档位**: medium
- **考察维度**: 漏斗拆解 + 文字可视化（界面呈现）
- **对话脚本**:
  1. 电商转化漏斗：访问 10000 → 看商品页 6000 → 加购 2000 → 下单 800 → 支付 640。计算每步转化率与整体转化率。
  2. 哪一步流失最严重？针对该步骤给出 3 个可能原因和对应的验证方法（数据下钻设计）。
  3. 用纯 ASCII 字符把这个漏斗画成漏斗图（每层宽度按人数等比），在等宽终端下不能错位。
  4. 讨论漏斗分析的三个局限（如步骤不可跳过假设、时间窗口、多路径），什么时候该改用路径分析？

### M10 SQL 窗口函数分析
- **预期档位**: medium
- **考察维度**: 分析型 SQL 编写（与 I 维度的优化型 SQL 角度不同）
- **对话脚本**:
  1. SQL 窗口函数和 GROUP BY 聚合的本质区别是什么？各写一个最小示例说明输出行数的差异。
  2. 有一张 `daily_revenue(day, amount)` 表：写出计算"每日收入 + 7 日移动平均"的完整 SQL（用窗口函数）。
  3. 在第 2 问基础上追加一列"环比增长率"（用 LAG），并解释 NULL 首行怎么处理更优雅。
  4. 讨论窗口函数在大表上的性能注意事项，什么时候该预聚合到日汇总表？
