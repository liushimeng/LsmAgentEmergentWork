# 自动化测试提示词 — 数据分析与统计推理（M01–M10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**数据分析与统计推理**中的"用数据说话"能力：现场生成含噪数据 → 写分析脚本 → 用输出印证结论 → 数字断言。与 G 维度（文件/格式加工）互补——G 考察"怎么处理数据文件"，本维度考察"怎么从数据里得出正确结论"。所有产物落 `tmpPlan/agent-test/`。

---

### M01 A/B 测试：实测点击率差异显著性
- **预期档位**: simple
- **考察维度**: 实验设计 / 统计计算闭环
- **工具链**: Write → Bash → Bash → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/m01_ab.py`：用 python3 内置 `random` 模拟 A/B 两组各 10000 次曝光，A 组点击率 3.2%、B 组 3.55%，用 `math.comb` 或正态近似计算 z 统计量与 p 值。
  2. Bash 跑 `python3 m01_ab.py`，断言 stdout 含 `z=...` 与 `p=...`；把 p 值落到 `m01_result.txt`。
  3. 调整 B 组样本量到 500 次（小样本）重跑，断言此时 p > 0.05（不显著），把前后对比落到 `m01_compare.txt`。
  4. 写 `tmpPlan/agent-test/m01_report.md`：列出规范 A/B 测试 5 步、本次两组结果、"样本量与测试时长为何重要"（小样本易受方差影响，需等样本量到位再下结论），并给"中途偷看结果 peeking"的规避建议。

### M02 相关不等于因果：混杂变量实测
- **预期档位**: simple
- **考察维度**: 因果推断 / 混杂检测
- **工具链**: Write → Bash → Bash → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/m02_corr.py`：用 python3 构造一个"冰淇淋销量 vs 溺水人数"的伪造月度数据（共同驱动因子是气温），计算 Pearson 相关系数。
  2. Bash 跑 `python3 m02_corr.py`，断言输出 `r=0.8x` 级别的高相关，但 p 值注明"相关≠因果"。
  3. 加回归控制：把气温作为协变量加入 `y = β0 + β1*icecream + β2*temp + ε`（用 `numpy.linalg.lstsq`），断言控制温度后 `β1` 接近 0 且不再显著。
  4. 写 `tmpPlan/agent-test/m02_report.md`：解释混杂变量（confounder）概念、本次实验如何复现伪相关、证明因果的 3 种方法（RCT / 断点回归 / 双重差分）各一句话适用条件。

### M03 幸存者偏差与辛普森悖论实测
- **预期档位**: simple
- **考察维度**: 统计陷阱辨识 / 数据分组实验
- **工具链**: Write → Bash → Bash → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/m03_paradox.py`：构造辛普森悖论最小数据集（两个分组各自 A 疗法优于 B 疗法，合并后 B 反胜），用 python 计算各组治愈率与合并治愈率。
  2. Bash 跑 `python3 m03_paradox.py`，断言每组 A 的治愈率都高于 B，但合并后 B 治愈率反超 A（具体数字落到 `m03_result.txt`）。
  3. 加"幸存者偏差"实验：从 1000 条记录里仅保留"存活用户"子集，对比全量 vs 存活子集的平均指标，断言存活子集指标虚高。
  4. 写 `tmpPlan/agent-test/m03_report.md`：用二战飞机装甲故事解释幸存者偏差、本次辛普森悖论数据表、给数据分析师"看数据前先问自己三个问题"检查清单（是否幸存者子集 / 是否漏分组 / 基数是否可比）。

### M05 贝叶斯思维：疾病检测计算
- **预期档位**: simple
- **考察维度**: 概率推理 / 数值计算
- **工具链**: Write → Bash → Bash → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/m05_bayes.py`：某病发病率 1%，检测灵敏度 99%、特异度 99%，用贝叶斯公式计算检测阳性者实际患病概率。
  2. Bash 跑 `python3 m05_bayes.py`，断言输出 `P(病|阳) ≈ 50%`（落到 `m05_result.txt`，误差 ±2% 内）。
  3. 把发病率从 1% 改到 0.1% 重跑，断言后验概率降到 ≈ 9%；讨论"基率谬误"为何让多数人直觉答错。
  4. 写 `tmpPlan/agent-test/m05_report.md`：先验/似然/后验三者关系图、本次计算的完整公式、基率谬误在互联网产品中的 2 个体现（如把 CTR 当 CTR 绝对水平忽略曝光基数）、贝叶斯式产品迭代循环（先验假设→观察数据→修正判断）。

### M06 假设检验与 p 值实测

### M08 回归分析：过拟合与外推实测
- **预期档位**: medium

- **工具链**: Write → Bash → Bash → Write
- **对话脚本**:
