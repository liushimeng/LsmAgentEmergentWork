# 自动化测试提示词 — 网络协议与安全基础（J01–J10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**网络协议、安全基础、Web 技术**等方面的表现，
涵盖 HTTP 协议、DNS、TLS/SSL、OAuth、Web 安全、API 设计、网络排查等主题。

---

### J01 HTTP 协议基础
- **预期档位**: simple
- **考察维度**: 协议理解 + 实际应用
- **对话脚本**:
  1. 解释 HTTP 请求的结构：请求行、请求头、请求体各包含什么？
  2. GET 和 POST 有什么区别？什么情况下用 PUT、DELETE、PATCH？
  3. 常见的 HTTP 状态码有哪些？200、301、404、500 各代表什么？
  4. 用 curl 发送一个带自定义 Header 和 JSON body 的 POST 请求。

### J02 DNS 解析原理
- **预期档位**: simple
- **考察维度**: 网络基础 + 解析流程
- **对话脚本**:
  1. 什么是 DNS？用通俗的话解释域名解析的过程。
  2. DNS 解析过程中涉及哪些服务器（根域名、顶级域、权威域名）？
  3. 如何用命令查看一个域名的 DNS 解析结果？介绍 dig 和 nslookup。
  4. DNS 缓存是怎么工作的？如何清除本地 DNS 缓存？

### J03 TLS/SSL 加密
- **预期档位**: medium
- **考察维度**: 加密原理 + 证书机制
- **对话脚本**:
  1. HTTPS 和 HTTP 的区别是什么？TLS 握手过程中发生了什么？
  2. 什么是证书？为什么需要 CA（证书颁发机构）？
  3. 如何用命令查看一个网站的 SSL 证书信息？
  4. 自签名证书和 CA 签发的证书有什么区别？开发环境怎么用自签名证书？

### J04 OAuth 2.0 认证
- **预期档位**: medium
- **考察维度**: 认证流程 + 安全实践
- **对话脚本**:
  1. 解释 OAuth 2.0 的授权码模式（Authorization Code Flow），画出示意图。
  2. 什么是 Access Token 和 Refresh Token？为什么要分开？
  3. PKCE 是什么？它解决了什么问题？
  4. laew 如果要支持 OAuth 登录，应该怎么设计？

### J05 Web 安全基础
- **预期档位**: medium
- **考察维度**: 安全意识 + 防护措施
- **对话脚本**:
  1. 什么是 XSS（跨站脚本攻击）？如何防范？
  2. 什么是 CSRF（跨站请求伪造）？如何防范？
  3. SQL 注入是怎么产生的？如何防范？
  4. 什么是 CSP（内容安全策略）？它解决了什么问题？

### J06 RESTful API 设计
- **预期档位**: medium
- **考察维度**: API 设计规范 + 最佳实践
- **对话脚本**:
  1. 什么是 REST？RESTful API 的设计原则有哪些？
  2. 设计一个用户管理 API：注册、登录、获取信息、更新信息、删除账号。
  3. API 版本号应该怎么设计？对比 URL 路径、Header、Content-Type 三种方式。
  4. API 错误响应应该怎么设计？给出一个标准错误格式示例。

### J07 WebSocket 协议
- **预期档位**: medium
- **考察维度**: 实时通信 + 协议细节
- **对话脚本**:
  1. WebSocket 和 HTTP 的区别是什么？它解决了什么问题？
  2. WebSocket 握手过程是怎样的？为什么需要从 HTTP 升级？
  3. 如何用 JavaScript 建立 WebSocket 连接？写一个简单的客户端示例。
  4. laew 如果要支持实时通知（如任务完成提醒），WebSocket 是好的选择吗？

### J08 网络故障排查
- **预期档位**: medium
- **考察维度**: 排查思路 + 工具使用
- **对话脚本**:
  1. 网站访问不了，完整的排查思路是什么？从本地到远程逐层分析。
  2. ping、traceroute、curl、telnet 各有什么用？
  3. 如何判断是 DNS 问题还是网络连接问题？
  4. 用命令检查一个 URL 的各阶段耗时（DNS、TCP、TLS、首字节）。

### J09 JWT 令牌机制
- **预期档位**: medium
- **考察维度**: Token 认证 + 安全实践
- **对话脚本**:
  1. 什么是 JWT（JSON Web Token）？它的结构是怎样的（Header、Payload、Signature）？
  2. JWT 和 Session-Cookie 认证有什么区别？各有什么优缺点？
  3. JWT 的 Secret 泄露了怎么办？如何设计密钥轮换机制？
  4. 为什么 JWT 不应该存储敏感信息？Base64 编码等于加密吗？

### J10 API 限流与熔断
- **预期档位**: medium
- **考察维度**: 系统保护 + 稳定性设计
- **对话脚本**:
  1. 什么是 API 限流？常见的限流算法有哪些（计数器、滑动窗口、令牌桶、漏桶）？
  2. 什么是熔断器（Circuit Breaker）？它的三种状态是怎么转换的？
  3. laew 调用 LLM API 时，如何实现限流和熔断？
  4. 设计一个简单的限流中间件，支持配置每秒请求数上限。
