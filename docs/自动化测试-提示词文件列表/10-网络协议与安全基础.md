# 自动化测试提示词 — 网络协议与安全基础（J01–J10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**网络协议、Web 技术、安全基础、加密认证**等场景中的表现，
涵盖 HTTP 协议、HTTPS/TLS、DNS、WebSocket、RESTful 设计、认证授权、
密码学基础、安全漏洞、防火墙配置、网络排查等主题。

---

### J01 HTTP 协议深入
- **预期档位**: simple
- **考察维度**: 协议细节 + 实际应用
- **对话脚本**:
  1. HTTP/1.1 和 HTTP/2 的核心区别是什么？多路复用解决了什么问题？
  2. 解释 HTTP 状态码：200/301/302/304/400/401/403/404/500/502/503 各在什么场景返回。
  3. laew 调用 Anthropic API 时，请求的 `Content-Type` 和 `Accept` 头应该设什么？
  4. HTTP 缓存头（Cache-Control/ETag/Last-Modified）是怎么配合工作的？画一个流程图。

### J02 HTTPS 与 TLS 握手
- **预期档位**: simple
- **考察维度**: 加密原理 + 握手流程
- **对话脚本**:
  1. HTTPS 的 TLS 握手过程中，客户端和服务器各做了什么？画出关键步骤。
  2. 对称加密和非对称加密在 TLS 中各扮演什么角色？为什么不全用非对称？
  3. 证书链是怎么验证的？自签名证书为什么浏览器会警告？
  4. laew 如果要实现"证书固定（certificate pinning）"，应该在代码的哪个环节做？

### J03 DNS 解析原理
- **预期档位**: simple
- **考察维度**: 域名系统 + 排查方法
- **对话脚本**:
  1. 输入一个 URL 到页面加载，DNS 解析发生在哪一步？递归查询和迭代查询的区别？
  2. 用 `dig` 或 `nslookup` 查询 laew 相关域名的 A 记录、CNAME、MX 记录。
  3. DNS 缓存污染是什么？怎么防范？DoH 和 DoT 解决了什么问题？
  4. 如果 laew 调用 API 时偶发 DNS 解析失败，设计一个重试 + 降级方案。

### J04 WebSocket 协议实战
- **预期档位**: medium
- **考察维度**: 双向通信 + 协议升级
- **对话脚本**:
  1. WebSocket 的握手过程是什么？为什么从 HTTP 升级而不是直接建连？
  2. WebSocket 和 SSE（Server-Sent Events）各适合什么场景？给出选择决策树。
  3. 如果 laew 要用 WebSocket 实现"实时推送 LLM 流式输出"，设计帧格式和重连机制。
  4. WebSocket 的 ping/pong 心跳帧有什么用？如果 30 秒没收到 pong 应该怎么处理？

### J05 RESTful API 设计

### J06 认证与授权机制

### J07 密码学基础
- **预期档位**: simple
- **考察维度**: 加密算法 + 正确用法

### J08 Web 安全漏洞防护
- **预期档位**: medium
- **考察维度**: 安全意识 + 防护实践
- **对话脚本**:

  2. SQL 注入、XSS、CSRF 三种漏洞各一句话解释，各给出一个最小防护示例。
  3. laew 的 Bash 工具如果直接拼接用户输入执行命令，会有什么注入风险？怎么防？

### J09 防火墙与网络安全

### J10 网络故障排查
- **预期档位**: medium
- **考察维度**: 系统性排查 + 工具链
- **对话脚本**:

  2. `ping`、`traceroute`、`mtr`、`curl -v` 各在排查中承担什么角色？
  3. 用 `tcpdump` 或 `wireshark` 抓包分析一条 HTTP 请求，描述看到的各层协议。
  4. 如果 laew 调用 API 偶发超时，设计一个系统化的排查方案（从客户端到服务端）。
