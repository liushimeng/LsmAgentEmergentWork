- **考察维度**: λ 演算基础 + 命题即类型
- **对话脚本**:

  4. Applicative 为什么介于 Functor 与 Monad 之间？请用"独立计算 vs 依赖计算"的直觉，结合 Rust 的 `Future::join` 与 `Future::then` 给出对照说明。
  5. 在 Haskell 中 `do` 语法是 `>>=` 的语法糖。把下面这段 do 表达式脱糖为 `>>=` 链，再用 Rust 的 `?` 运算符重写：`do { x <- m; y <- f x; return (x + y) }`。
