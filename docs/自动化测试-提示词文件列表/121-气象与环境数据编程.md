### DM06 雷达回波与定量降水估计

- **预期档位**: medium~hard

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:

  2. 动手：在 `tmpPlan/agent-test/dm06_radar_qpe.py` 实现 `radar_qpe`：输入极坐标 dBZ 数组（方位角×距离库），输出 1km 经纬度网格雨强图（极坐标→经纬度重采样：最近邻）+ 区域 1 小时估测雨量；经典马歇尔-帕尔默公式 Z = 200·R^1.6 反解雨强 R。输出到 `tmpPlan/agent-test/dm06_qpe_grid.csv`。
  3. 继续：生成模拟体扫数据到 `tmpPlan/agent-test/dm06_volume_input.json`（python3 写 360×200 极坐标 dBZ，含一个 dBZ=45 的强回波单点），跑 QPE 后读取 CSV 定位回波中心，断言 R 值量级约 50mm/h（误差 <10%，验证 Z-R 反解正确）。
  4. 继续：实现"忽略波束高度"与"高度衰减订正"两版对比：波束高度 `h = sqrt(r^2 + 2·r·R_e·sin(elev) + (R_e/cos(elev))^2) - R_e` 计算后，订正版按高度衰减系数 `exp(-0.0001·h)` 修正 Z；输出两版雨量到 `tmpPlan/agent-test/dm06_qpe_compare.csv`，读取后断言订正版在远距离处雨强更高（补偿波束抬高）。
