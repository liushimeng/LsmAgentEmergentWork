# 201 图像识别与 OCR 文档智能工程实战

> 编号段 GM01–GM10 · 聚焦「从扫描件到结构化数据的文档智能全链路」：图像预处理 / 文字检测 / 文字识别 / 表格结构还原 / 版面分析 / 印章与手写体 / 文档分类 / 关键信息抽取 / 文档比对 / 可访问性转换
>
> 与现有维度互补说明：
> - `24-计算机视觉与图像工程`（Z 维）聚焦**通用视觉任务**（检测/分割/分类/生成）；本文件聚焦**文档图像的专用处理流水线**（OCR/版面/表格），是 CV 在文档场景的垂直应用。
> - `7-文件整理处理与数据加工`（G 维）聚焦**文件批量操作**（重命名/格式转换）；本文件聚焦**文档内容的智能理解**（识别/抽取/结构化），是文件处理的"理解层"。
> - `134-办公自动化与文档处理工程实战`（EE 维）聚焦**办公文档生成**（Word/PDF 创建）；本文件聚焦**扫描文档的理解与抽取**，是办公自动化的"输入层"。
> - `23-自然语言处理与文本工程`（Y 维）聚焦**纯文本处理**；本文件聚焦**从图像到文本的转换**（OCR/版面），是 NLP 的上游感知层。

> **本文件独特主题**：二值化（Otsu/Sauvola）与去噪 / 倾斜校正与透视变换 / 文字检测（EAST/CRAFT/DBNet）/ 文字识别（CRNN/TrOCR/Transformer）/ 表格结构识别（Cell 检测 + 行列表头还原）/ 版面分析（标题/段落/图表/页眉页脚分割）/ 印章检测与手写签名 / 文档分类（发票/合同/身份证/营业执照）/ 关键字段抽取（Key-Info Extraction）/ 表格还原为 Excel / 文档比对 diff / PDF/A 可访问性 / 多语言混合 OCR / 低质量件增强 / OCR 后处理（词典纠错/NER 补全）/ 置信度评估与人工复核队列。
