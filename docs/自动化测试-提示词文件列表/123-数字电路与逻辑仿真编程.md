### DO03 加法器与 ALU：从半加器到带标志的运算单元

- **预期档位**: medium

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 一位半加器（S = A XOR B，C = A·B）→ 全加器（加入进位输入，S = A⊕B⊕Cin，Cout = AB + Cin(A⊕B)）；级联 8 个全加器构成行波进位加法器（RCA），列出超前进位（Carry Lookahead）生成 `G=A·B` 与传播 `P=A⊕B` 的展开式与延迟 O(1) 特性。
  2. 动手：在 `tmpPlan/agent-test/do03_alu.py` 实现 8 位 ALU 仿真器：`alu(a, b, op) -> (result, flags)`，op 含 AND/OR/XOR/ADD/SUB/SLT（比较），标志位 Zero/Carry/Sign/Overflow（V 标志为 `Cin⊕Cout` 于最高位的有符号溢出判别）。
  3. 继续：构造两组用例 `tmpPlan/agent-test/do03_test_cases.json`：`128 + 100`（无符号不溢有符号溢）与 `-128 + (-1)` 即 `0x80 + 0xFF`（有符号溢 C 标志也置位）；跑 ALU 后读取输出文件 `tmpPlan/agent-test/do03_alu_out.json`，断言 V 标志正确置位（两组都触发了有符号溢出）、C 标志与 V 独立（第一组 C=0 V=1、第二组 C=1 V=1）。
  4. 继续：在 ALU 中实现超前进位加法器（4 位 CLU 块，块间行波），对 16 位全 1 加 1（`0xFFFF + 1`）用例，测量延迟（门级求值层数）并与 RCA 比较，输出延迟报告到 `tmpPlan/agent-test/do03_delay.csv`；读取断言超前进位延迟 ≤ RCA 延迟的 50%。
