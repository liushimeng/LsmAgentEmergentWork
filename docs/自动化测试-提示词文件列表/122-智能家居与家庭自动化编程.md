### DN02 Zigbee 网络与异步网关模拟

- **预期档位**: medium
- **考察维度**: Zigbee 拓扑 / Z2M 桥接 / 配对排障
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Zigbee 是 2.4GHz 自组网网状协议：三类角色——协调器（coordinator，全网唯一）、路由器（router，常供电设备负责中继）、终端（end device，电池传感器不能中继）；解释"买一个 Zigbee 插座当路由"为什么常常比买信号放大器更有效。
  2. 动手：在 `tmpPlan/agent-test/dn02_zigbee_gw.py` 用 python3 asyncio 实现 mini 网关：协调器 + N 个设备（每个含 `ieee_address`/`nwk_addr`/`role`/`parent`/`lqi`/`battery`、`last_seen` 时间戳），设备上报消息模拟（`asyncio.sleep` + 随机 LQI/电池波动），输出设备拓扑到 `tmpPlan/agent-test/dn02_topology.json`。
  3. 继续：实现 MQTT 桥接层：把设备消息翻译成 MQTT 主题（`zigbee2mqtt/{friendly_name}` 的 state JSON 与 `set` 命令主题），模拟 `permit_join` 配对窗口（30 秒内允许新设备入网，超时自动关）；输出 10 条 MQTT 消息到 `tmpPlan/agent-test/dn02_mqtt_log.jsonl`，读取断言 pairing 消息含 `permit_join:true→false` 切换。
  4. 继续：实现订阅诊断工具 `tmpPlan/agent-test/dn02_health.py`：列出全网设备与最后消息时间、按消息间隔找出"疑似离线"传感器（last_seen 超阈值）、dump 指定设备完整 state JSON；跑后读取健康报告 `tmpPlan/agent-test/dn02_health_report.json`，注入一个"失联"设备验证被正确标记为 offline。
