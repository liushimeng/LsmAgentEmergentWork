> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**内存布局、并发原语、信号处理、inotify 文件监控、libc 系统调用、mmap 共享内存、原子与内存序、内核模块骨架、C 编译验证、Socket+epoll**等系统级场景下，用 **Python（os/sys/mmap/ctypes）+ gcc 现场编译的小 C 程序**做"写→编译→跑→断言"闭环——产物可见、可 Read、可 Bash 验证；不允许碰真实内核模块加载（仅允许 C 代码+讲解+用户态等价演示）。

### U01 栈 vs 堆：用 Python+小 C 程序演示内存布局
- **预期档位**: simple
- **考察维度**: 内存布局 / 指针验证 / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/u01/` 下写 `stack_heap.c`：`int main() { int a=1; int b=2; int arr[10]; printf("stack &a=%p &arr=%p\n", &a, arr); return 0; }` 用 `gcc -O0 stack_heap.c -o demo` 编译，`./demo` 输出两个栈地址；写 `verify1.sh`：`./demo | awk '{print $2}' | sort -u | wc -l` 必须返回 `2`（两个地址不同），且都形如 `0x7fff...`（栈区）；不通过请 Read 代码确认编译选项。
  2. 写 `heap.c`：`malloc(16)` 取地址、`free`，`%p` 打印；`gcc heap.c -o heap_demo && ./heap_demo`，`verify_heap.sh` 用 `awk '$2 ~ /^0x[0-9a-f]+$/'` 校验输出格式合法，且地址应以 `0x5...` 或 `0x7...` 开头（glibc 堆区）。
  3. 写 `compare.py`：用 `ctypes` 调 libc `malloc(16)` 拿指针 + `id(arr)` 拿 Python 数组地址，写到 `compare.out`；`python compare.py` 输出两行 heap 地址 + 一行 Python `id(...)`（在 P 堆）；期望 Python 对象的 `id` 远大于 C `malloc` 返回值（`awk` 数值比较）。
  4. 写 `verify_final.sh` 串 4 步：编译→跑→保存到 `final.out`→断言含 "stack"、"heap"、"python" 三个标记段；任何编译/运行失败 exit 1 并打印失败步骤名。

  4. 写 `verify.sh` 跑两遍（basic 20000 + timeout ETIMEDOUT），输出 `result.txt` 含 "basic_ok" 与 "timeout_ok" 两行；任何一段失败 exit 1，并打印 Read 提示让 Agent 重读 `bounded_queue.c` 修竞争条件。

### U03 信号处理：SIGTERM 优雅关闭 + SIGHUP 热重载
- **预期档位**: hard
- **考察维度**: 信号安全 / trap 链 / Bash 闭环
- **工具链**: Write → Bash → Bash → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/u03/` 下写 `daemon.c`：起一个 `while(1)` 循环每秒往 `state.log` 写一行 `{ts,count}`，注册 `SIGTERM` 处理函数置 `running=0`，主循环检测到 `running==0` 后写 `goodbye` 到 `state.log` 再 `exit(0)`；`gcc daemon.c -o daemon` 编译通过，`./daemon &` 拿 `$!`。
  2. 写 `verify_sigterm.sh`：sleep 2 → `kill -TERM $!` → sleep 1 → `cat state.log | wc -l` 应 ≥3（多行时间戳）且最后一行必须含 "goodbye"；`kill -0 $!` 期望非 0（进程已退出）；失败请 Read `daemon.c` 修信号 mask 重跑。
  3. 加 SIGHUP 处理：handler 把 `reload=1`，主循环看到后重新读 `config.txt`（一个 KV 文件）写一行 `reloaded: <key>=<value>` 到 `state.log`；`verify_sighup.sh`：`echo "x=1" > config.txt` 启动 → 改 `config.txt` 为 `x=2` → `kill -HUP $!` → sleep 1 → `grep 'reloaded: x=2' state.log` 必命中。
  4. 加"异步信号安全"演示：`verify_safety.sh` 故意在 SIGTERM handler 里调 `printf("bye\n")`（非 async-signal-safe），编译加 `-Wall` 应有 warning（`grep -c 'warning' build.out` ≥1）；改用 `write(1, "bye\n", 4)` 后 warning 消失（grep count = 0）。`bash verify_safety.sh` 全过 → 最后 `kill -9 $!` 兜底。

### U04 inotify 文件监控：Python `inotify_simple` 等价手写
- **预期档位**: medium
- **考察维度**: 文件事件 / 防抖 / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/u04/` 下写 `watcher.py`：用 `ctypes` 调 libc `inotify_init` + `inotify_add_watch` 监控目录 `tmpPlan/agent-test/u04/watched/`（先 mkdir）；事件用 `IN_CREATE/IN_MODIFY/IN_DELETE`，每个事件打 `{ts, mask, name}` 到 `events.log`；后台 `python watcher.py &` 存 PID。
  2. 写 `verify_basic.sh`：touch 一个 `a.txt` → sleep 0.5 → `grep -c 'a.txt' events.log` ≥1；`echo hi > a.txt` → `grep -c 'a.txt' events.log` ≥2；`rm a.txt` → 含 `IN_DELETE` 标记；任何一步不过请 Read `watcher.py` 修事件 mask 重跑。

- **预期档位**: medium

- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:

  2. 加 `O_DIRECT` 大文件测试 `verify_direct.sh`：写 `big.bin`（2MB 随机），用 `posix_memalign` 对齐 buf，`./mini_cat big.bin | md5sum` 与 `md5sum big.bin` 必须一致；失败请 Read `mini_cat.c` 加对齐 buf 重跑。

- **预期档位**: hard

- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:

### U07 原子与内存序：手写无锁 Treiber Stack
- **预期档位**: hard
- **考察维度**: atomic / CAS / 内存序 / Bash 闭环
- **工具链**: Write → Bash → Bash → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/u07/` 下写 `lockfree.c`（gcc 12+）：`struct Node { int v; struct Node *next; };` 用 `__atomic_compare_exchange`（`__ATOMIC_ACQ_REL`）实现 `push` / `pop`；写 `test_basic.c` 单线程 push 100 个、pop 100 个，期望 pop 出来与 push 顺序相反（LIFO）。
  2. `gcc -O2 -pthread lockfree.c test_basic.c -o demo && ./demo | tee out.out`，期望末行 "popped=100" 且退出码 0；故意把 `__ATOMIC_ACQ_REL` 改成 `__ATOMIC_RELAXED` 跑 10000 次 push/pop 单线程，应仍 OK（单线程下放松序可接受），存 `relaxed.out`。
  3. 并发测试 `test_concurrent.c`：4 个 producer + 4 个 consumer 各 push/pop 10000 次；用 `__ATOMIC_SEQ_CST`（保守）跑 10 次取最佳值，期望无 crash、`pop_total==push_total`；`verify_concurrent.sh`：`for i in $(seq 1 10); do ./demo_concurrent; done | tee cc.out`，断言 10/10 退出码 0。
  4. 写 `verify_ordering.sh`：故意改 push 用 `__ATOMIC_RELEASE`、pop 用 `__ATOMIC_ACQUIRE`（半序），并发跑 100 次至少 95 次正确（允许偶发 ABA 但单 int value 不触发）；失败请 Read `lockfree.c` 加 ABA 防护（版本号）或换回 SEQ_CST 重跑。

### U10 Socket + epoll：手写一个高并发 echo server
- **预期档位**: hard
- **考察维度**: epoll / 事件驱动 / Bash 闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
