### GP01 词法/语法分析与 AST 构建

- **预期档位**: simple
- **考察维度**: 分词 / 解析 / 树遍历
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/gp01_lexer.py`：简易 Python 子集 Lexer + Parser（输入代码文本字符串），输出：(a) **Lexer 分词**（正则规则：标识符 `[a-zA-Z_]\w*` / 数字 `\d+(\.\d+)?` / 字符串 `"[^"]*"` / 关键字 `if/else/while/def/return` / 运算符 `== != <= >= = + - * /` / 括号 — 每 token 输出 `Token(type, value, line, col)`）+ (b) **Parser 语法**（递归下降：program → statement* / statement → if_stmt | while_stmt | assign | expr / expr → term (('+' | '-') term)* / term → factor (('*' | '/') factor)* / factor → number | identifier | '(' expr ')'）+ (c) **AST 节点类型**（IfNode/WhileNode/AssignNode/BinOpNode/NumberNode/IdentifierNode — 每节点 type + children 属性）+ (d) **Visitor 模式**（ASTVisitor：visit_If / visit_BinOp / visit_Number — 可扩展求值器/代码生成器/度量统计器 — 示例：求值器 Visit BinOp 返回左右子树计算结果）+ (e) **错误恢复**（词法错误：非法字符标 ERROR token / 语法错误：期望 token vs 实际 — 跳过至下一个同步 token `;` 或 `}` 继续解析）。

  3. Read `tmpPlan/agent-test/gp01_ast.txt`，再 Bash 断言：含 Token 列表、含 IfNode/BinOpNode 类型、含 Visitor 模式。
