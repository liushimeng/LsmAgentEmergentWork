### CP01 Verlet 积分与距离约束求解

- **预期档位**: hard
- **考察维度**: 数值积分对比 + 约束投影迭代
- **对话脚本**:
  1. 位置 Verlet 积分：不用速度显式存储，`new_x = 2x - x_prev + a·dt²`（速度隐含在历史位置差里）；用 Python 写单摆的自由落体对比欧拉积分，展示同样步长下 Verlet 的能量漂移更小、且天然稳定。
  2. 距离约束（两个质点保持距离 d）：每步积分后按质量加权把两点沿连线「投影」回正确距离（`correct = (dist - d) / dist * offset`），单次不精确就迭代 4~8 次松弛；写 `solveDistanceConstraint(p1, p2, d)` 与迭代求解器。
  3. 约束网络：把多个质点用约束连成「布料骨架 / 桥链」，每帧顺序是「积分 → 多轮约束求解 → 碰撞投影」；解释为什么迭代次数与「约束链长度」相关（力沿链条传播需要多次迭代）。
  4. laew 借鉴：约束求解的「迭代直到收敛」对照 Agent 循环的短路退出——laew 已有「连续相同失败 3 次 / 连续无文本收敛 8 次」两类对称短路，讨论物理求解器「达到容差提前退出」与 Agent「达到收敛提前退出」的阈值设计共性。

### CP02 布料模拟：质点弹簧网格与撕裂

- **预期档位**: hard
- **考察维度**: 三类结构约束 + 风力 + 撕裂判定 + 渲染
- **对话脚本**:
  1. 建网格：N×M 质点 + 三类约束——结构约束（横竖相邻，防拉伸）、剪切约束（对角线，防斜切变形）、弯曲约束（隔一点相连，防过度折叠）；用 Rust 写布料初始化与三类约束的生成代码。
  2. 力与固定点：顶行若干质点钉住（pin），加重力与正弦风场 `wind = (sin(t*3 + y*0.5) * 20, 0)`；调质量 / 重力 / 迭代次数参数得到「旗帜」与「丝绸」两种观感，解释参数差异来自哪。
  3. 撕裂：约束当前长度超过静止长度 × 2.5 即移除该约束，被完全孤立的质点转入纯抛体；处理「布料与球体碰撞」（质点被推出球面 + 法向阻尼），写撕裂后网格洞的渲染（动态索引缓冲重建）。
  4. laew 借鉴：布料的「约束断裂阈值」对照 Agent 失败回流——某条约束（任务路径）反复超阈值就该「断裂」换路径而不是无限重试，讨论 laew 的失败回流如何引入「断裂计数」防止 Plan 死循环。

### CP03 绳索、链条与拖拽交互

- **预期档位**: medium~hard
- **考察维度**: Verlet 链 + 鼠标拖拽 + 阻尼与缠绕
- **对话脚本**:
  1. 悬垂绳：20 个质点首尾相连，首点钉在天花板，重力下垂自然形成悬链线；写最小 Verlet 绳 demo（100 行内），调迭代次数观察「拉伸橡皮筋感」的消除过程。
  2. 鼠标拖拽：捕获最近质点跟随鼠标（直接设置位置 + 限速），松手恢复自由；再实现「剪刀点击切断最近一段约束」（联动 CP02 撕裂），这两个交互让绳索立刻「可玩」。
  3. 缠绕与摩擦：绳子绕过圆柱的模拟——质点与圆柱碰撞投影 + 切向摩擦系数（每次投影后衰减切向速度分量 5%）；解释摩擦项为什么能让绳子「挂住」而不是无限滑动。
  4. laew 借鉴：拖拽的「限速跟随」（目标突变也平滑逼近）对照 Yolo 失败回流后的「降档重试」——用户中断 / 任务失败后的重启不应该是位置瞬移（全部重来），讨论带「惯性」的会话续接（保留已完成 SubAgent 产物，只重跑失败单元）。

### CP04 软体与压力模型

- **预期档位**: hard
- **考察维度**: 气体压力外推 + 形变恢复 + 果冻手感
- **对话脚本**:
  1. 压力软体（Pressure Soft Body）：2D 多边形边界一圈质点 + 边约束，内部「气体压力」按 `pressure ∝ (restArea - curArea)` 沿面法向外推所有边界点；用 Python 写会弹跳、会被压扁又恢复的软球。
  2. 形状保持：纯压力模型容易「翻面塌陷」——补「质点到形状匹配」（每点记录相对质心的初始方向，每次求解把点往初始形状的对应位置拉 20%），写 shape matching 项并解释它为什么防塌陷。
  3. 手感调参：果冻感 = 高阻尼 + 低迭代 + 大压力；篮球感 = 低阻尼 + 高迭代 + 恢复系数接近 1；给出三组参数预设并说明「踩上去会陷但不破」的沼泽软体怎么配。
  4. laew 借鉴：shape matching 的「当前状态向初始目标渐进回归」对照 SessionContext 摘要的任务目标锚定——长会话多轮后 Agent 容易偏题，讨论在每轮注入「初始目标向量」（任务一句话摘要）作为形状保持项。

### CP05 流体模拟：SPH 与邻居搜索

- **预期档位**: hard
- **考察维度**: 空间哈希 + 密度压力 + 2D 水面 demo
- **对话脚本**:
  1. SPH 思想：流体离散为粒子，每个粒子受到「压力项（密度高处被推开）+ 粘性项（与邻居速度趋同）+ 重力」；用核函数（如 poly6 / spiky）加权邻居影响，写出密度估计 `ρ_i = Σ m·W(r_i - r_j)` 的代码。
  2. 邻居搜索优化：朴素 O(n²) 在 2000 粒子时崩溃——用空间哈希网格（cell = 2h），只检查相邻 9 格；用 Rust 写 `SpatialHash` 的插入与邻居迭代，测出 2000 粒子从 200ms/帧降到 3ms/帧。
  3. 简化与稳定：真 SPH 参数难调，工程上常用「位置基流体 PBF」或干脆「粒子 + 简单斥力」做卡通水花；给一个「粒子间最小距离斥力 + 表面张力近似」的玩具版水体，说明它适合什么场合（泼溅特效）不适合什么（真实感大片）。
  4. laew 借鉴：邻居搜索的「局部性剪枝」对照 RAG 召回——讨论 laew 若做 `session_memory` 语义检索，同样需要「先粗筛桶（哈希/倒排）再精算核函数」的两阶段结构，避免全库两两比对。

### CP06 Boids 群体行为与空间优化

- **预期档位**: medium
- **考察维度**: 三力模型 + 参数手感 + 复杂度优化
- **对话脚本**:
  1. Boids 三力：分离（避免与过近个体重叠）、对齐（速度趋向邻居平均）、聚集（位置趋向邻居质心）；用 Python + 简易渲染写 60 只鸟的 flocking，每个力带独立权重 `w_sep / w_ali / w_coh`。
  2. 参数手感实验室：分离权重过大 → 互相排斥成「爆炸」；聚集过大 → 挤成一团；对齐过大 → 死板直线；给出「鸟群 / 鱼群 / 蝗虫群」三组预设参数，并解释视野半径（邻居判定距离）对各形态的影响。
  3. 复杂度优化：O(n²) 邻居查询用空间哈希（联动 CP05）+ 视野扇形过滤；再加「捕食者」力（远离鹰位置）与「归巢」力（傍晚回巢），观察涌现出的「散开 - 重聚」行为。
  4. laew 借鉴：Boids 是「简单局部规则涌现复杂群体行为」的典型——对照 laew 多 Agent（Yolo/Plan/Main/Sub/QC 各自只有局部职责）能否涌现出「整体任务完成」这一群体智能，讨论缺了哪个「力」（例如跨 Agent 的对齐力 = 共享目标上下文）。

### CP07 烟花与爆炸特效合成

- **预期档位**: medium
- **考察维度**: 发射器设计 + 加法混合 + 屏幕震动与冲击波
- **对话脚本**:
  1. 烟花两段式：上升段（单粒子 + 重力 + 拖尾）到顶点爆炸段（一帧生成 200 粒子，速度按球面均匀分布 + 随机色相带）；写发射器 `FireworkEmitter`，拖尾用「历史位置渐隐连线」或「残影粒子」两种实现并对比。
  2. 渲染细节：粒子用加法混合（`globalCompositeOperation = 'lighter'`）让重叠区域变亮像发光；颜色随寿命从白热 → 主色 → 暗红渐变（黑体辐射近似）；尺寸随寿命收缩，写出这三条渲染规则。
  3. 冲击波与屏幕震动：爆炸瞬间产生一个扩散圆环（半径增大 + 透明度衰减）+ 摄像机震动（随机偏移按指数衰减 `amp * e^(-6t)`）+ 短暂时间减速（hitstop 60ms）；讨论这三个「廉价技巧」对打击感的贡献比例。
  4. laew 借鉴：粒子「生成 - 衰减 - 消亡」的生命周期对照 Agent-Memory 的保留策略——讨论 `agent_memory` 是否也该有「半衰期」（近期错误权重高、久远成功权重低），避免陈旧记忆淹没新信号。

### CP08 2D 碎裂与破坏效果

- **预期档位**: medium~hard
- **考察维度**: Voronoi 分裂 + 碎片刚体化 + 消融回收
- **对话脚本**:
  1. Voronoi 碎裂：在玻璃窗多边形内撒 N 个随机种子点，每个种子点「拥有」距它最近的区域 → 碎片集合；用 Python（scipy.spatial.Voronoi 或手写半平面切割）实现多边形碎裂，处理窗口边界裁剪。
  2. 碎片刚体化：每块碎片计算质心与转动惯量，受击瞬间获得「从撞击点向外的径向速度 + 随机角速度」，随后走简单抛体 + 地面弹跳；写碎片从「静态多边形」到「动态刚体」的转换。
  3. 消融与回收：碎片落地静止 2 秒后开始淡出（透明度衰减）并归还对象池（联动 AB09 的对象池思想）；控制同屏碎片上限（500），超限优先回收最旧碎片，写这个「带优先级的池回收」。
  4. laew 借鉴：碎裂的「一次事件产生有限碎片 + 有序回收」对照工具输出的分片处理——讨论 BashTool 超长输出（>10000 字符截断为首尾各 500）是否可改为「按行分片 + 优先保留头尾 + 中段按需展开」的 Voronoi 式选择性保留。

### CP09 物理手感调参方法论

- **预期档位**: medium
- **考察维度**: substeps / 阻尼 / 重力缩放 / 手感量化
- **对话脚本**:
  1. 稳定性三件套：substeps（把一帧拆 4 个物理子步，等效 4 倍迭代）、全局阻尼（每步速度 ×0.995 模拟空气阻力）、重力缩放（游戏重力常用真实 9.8 的 1.5~3 倍，因为屏幕尺度小、真实值显得「飘」）；解释三个参数各自解决什么问题。
  2. 手感量化：把「手感」拆成可测指标——输入到响应延迟（ms）、跳跃高度 / 起跳时间比、落地缓冲帧数、最大下落速度（终端速度）；用经典平台跳跃游戏的典型数值范围（跳跃滞空 0.5~0.8s、土狼时间 80~120ms）校准你的参数。
  3. 对照调参实验：同一关卡用「真实物理参数」与「游戏化参数」各录一段操作，统计通关时间与失误率差异；再单独调「跳跃提前输入缓冲（jump buffer 100ms）」观察手感提升，说明为什么缓冲输入比调重力更有效。
  4. laew 借鉴：手感量化对照 Agent 的「体验指标」——laew 的等价物是首 token 延迟 / 工具调用确认轮次 / 失败重试次数，讨论把这些显式建模为 QC 的检查项（像游戏 QA 测手感一样测 Agent 手感）。

### CP10 物理引擎选型与自制的边界

- **预期档位**: hard
- **考察维度**: 引擎对比 + 确定性需求 + 自制成本评估
- **对话脚本**:
  1. 2D/3D 引擎对比：Box2D 系（b2-rs / planck）、Rapier（Rust 原生、并行友好）、bevy_rapier / bevy_xpbd、Jolt（3D、战地出品）——从「语言绑定 / 确定性 / 连续碰撞 / 文档」四个维度做选型矩阵，给三个典型项目（平台跳跃 / 物理解谜 / 多人对抗）各推荐一个。
  2. 确定性硬需求：联机帧同步（联动 CM04）要求物理引擎跨平台 bit 级确定性——浮点差异、迭代顺序、SIMD 差异都会破坏；说明哪些引擎明确支持确定性（Rapier 的 determinism 文档 / Box2D 限定平台），以及定点数改造的代价。
  3. 自制评估清单：什么时候该手写而不是引入引擎——只需要「Verlet 约束 + 圆碰撞」（几百行）vs 需要「多形状 / 关节 / CCD / 车辆」；给出「自制 ROI 计算表」（需求条数 × 引擎超额复杂度 vs 自研工时）。
  4. laew 借鉴：引擎选型对照 laew 的「不引入新 crate（crossterm 已满足）」约定——讨论这条约定的适用边界：当 TUI 需求增长到表格 / 滚动 / 拼写检查时，自研成本曲线何时反转，以及用什么信号判断（重复造轮子的工时占比）。
