### BO01 Windows PowerShell 日常：从 cmd 思维切换
- **预期档位**: simple
- **考察维度**: PowerShell 核心 cmdlet + 管道对象化
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 下 Write `ps_pipeline.py`：用 Python 模拟 PowerShell 的「面向对象管道」——定义 `Process` 类（name, cpu, id），实现 `where(lambda)` 返回过滤后列表、`select(fields)` 返回字段子集，演示 `Process.all().where(lambda p: p.cpu>50).select(['name','cpu'])`。
  2. Bash 跑 `python3 tmpPlan/agent-test/ps_pipeline.py`，断言输出只含 `name` 和 `cpu` 字段且 cpu>50 的进程（grep 校验），印证「PowerShell 管道传递结构化对象而非纯文本」。
  3. Read `ps_pipeline.py` 确认 `where` 和 `select` 两个方法存在。再 Write `ps_cmdlet_map.py`：用 dict 实现 PowerShell cmdlet 与 cmd 命令对照表（`Get-ChildItem↔dir`、`Select-String↔grep`、`Get-Service↔sc query`），查询输入 `grep` 返回 `Select-String`。
  4. Bash 跑 `python3 tmpPlan/agent-test/ps_cmdlet_map.py`，断言输入 `grep` 输出 `Select-String`、输入 `dir` 输出 `Get-ChildItem`（grep -F 校验），用输出印证「cmd 到 PowerShell 的思维切换」。
