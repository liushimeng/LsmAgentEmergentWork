# 自动化测试提示词 — 学习成长与职业发展（N01–N10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**求职面试、学习规划、职业转型、知识管理**等"个人成长"场景下把"建议/方法论"变成**可落盘素材 + 可自测脚本**的能力。所有产物落 `tmpPlan/agent-test/`。

---

### N01 简历项目经历打磨：STAR 版与量化维度自检
- **预期档位**: simple
- **考察维度**: 结构化表达 / 量化自检闭环
- **工具链**: Write → Bash → Write → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/n01_raw.txt`：放一条原始描述"负责公司订单系统的开发与维护"（待改写素材）。
  2. Write `n01_star.txt`：把第 1 轮素材按 STAR（情境-任务-行动-结果）四段改写 200 字以内，关键数字用 `[待核实]` 占位（如 `["30%"提升 性能 + 待核实]`）。
  3. Write `n01_dual_target.md`：同一段经历投两个岗位（电商后端/平台基础架构），写两条简历侧重要点各 5 条；附"量化成果"五维（性能/成本/效率/质量/业务）自检表，用 `grep -c "^[|]- " n01_dual_target.md` 断言至少 12 个 bullet。
  4. Bash 跑 `python3 -c "open('n01_star.txt').read().count('[待核实]')"` 统计未核实项，断言 ≥ 2（提醒后续补事实），把统计结果落 `n01_report.txt`。
