# 72 密码学与隐私计算

> 编号段 BU01–BU10 · 主题：密码学原语与隐私增强计算（对称/非对称加密、零知识证明、同态加密、安全多方计算、TLS 1.3、数字签名、后量子密码、Rust crypto 生态）
> 互补性：与已有「安全渗透/网络协议/操作系统安全/区块链」文件严格区分——本文件聚焦**密码学算法原理、协议正确性、隐私计算范式与工程实现**，不覆盖应用层渗透、漏洞利用、链上共识等攻击面。
> 覆盖维度：对称加密（AES-GCM/ChaCha20-Poly1305）、非对称（RSA/ECC/Ed25519）、哈希与 KDF（SHA-3/KMAC/Argon2）、TLS 1.3 握手与 0-RTT、零知识证明（zk-SNARK/zk-STARK）、同态加密（BFV/CKKS）、安全多方计算（混淆电路/秘密共享）、数字证书与 PKI、后量子密码（Kyber/Dilithium）、Rust crypto 生态实战。
