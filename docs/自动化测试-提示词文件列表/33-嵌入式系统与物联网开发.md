# 33 嵌入式系统与物联网开发

> 编号段 AH01–AH10 · 聚焦嵌入式、RTOS、物联网协议与边缘计算

### AH01 从裸机到 RTOS：任务调度入门
- **预期档位**: medium
- **考察维度**: 任务模型 + 调度策略
- **对话脚本**:
  1. 裸机"超级循环 + 中断"和 RTOS 多任务在思路上有什么本质差异？什么场景下必须上 RTOS？
  2. 用 FreeRTOS 创建两个任务：一个读传感器、一个上报数据，通过队列通信，写出完整代码。
  3. 优先级反转是什么？用上面两个任务举例，再用互斥量的优先级继承机制解释怎么解决。
  4. 对比 FreeRTOS、Zephyr、RT-Thread 三款 RTOS 的调度器实现与生态，给出选型建议。

### AH02 Arduino 到 ESP32：物联网节点实战
- **预期档位**: medium
- **考察维度**: 传感器 + 无线通信
- **对话脚本**:
  1. 用 ESP32 读取温湿度传感器 DHT22 数据，通过 Wi-Fi 上报到 MQTT broker，画出硬件接线图与软件流程。
  2. 实现低功耗：深度睡眠 30 秒 → 唤醒 → 采集 → 上报 → 再睡眠，估算一节 18650 电池能用多久。
  3. OTA 固件升级：ESP32 的 OTA 分区方案、断点续传、签名验证、回滚机制分别怎么实现？
  4. 对比 ESP32、STM32WL（LoRa）、nRF52（BLE）三款芯片在物联网场景的适用边界。

### AH03 嵌入式 C：寄存器操作与位域
