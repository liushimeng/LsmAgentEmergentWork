### FK01 批量文件重命名器

- **预期档位**: simple
- **考察维度**: 正则命名 / 编号 / 撤销
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/fk01_rename.py`：批量文件重命名器，支持：(a) 编号模式 `{n:03d}_{name}` / (b) 时间模式 `{year}-{month}-{day}_{original}` / (c) 正则替换模式 / (d) 模板模式（来自 EXIF 或 ID3）。生成 dry-run 预览（before → after） + 撤销脚本（rename_records.json 反向操作）。跨平台用 pathlib，不依赖 shell 通配符。
  2. Bash：`python3 -m py_compile tmpPlan/agent-test/fk01_rename.py`，断言退出码为 0。
  3. Read `tmpPlan/agent-test/fk01_rename.py`，再 Write `tmpPlan/agent-test/fk01_rename_request.json`：5 个文件清单 + 模式=编号模板 `{n:03d}_photo.jpg`。本轮必须显式复用第一轮的预览与撤销机制。
  4. Bash：`python3 tmpPlan/agent-test/fk01_rename.py tmpPlan/agent-test/fk01_rename_request.json --dry-run 2>&1 | tee tmpPlan/agent-test/fk01_rename_preview.txt`，断言 `grep -F 'before'` 命中、`grep -F 'after'` 命中、`grep -F '撤销\|undo\|rename_records'` 命中、`grep -F '001_'` 命中（编号格式正确）。
