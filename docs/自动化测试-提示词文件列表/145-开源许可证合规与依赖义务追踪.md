# 145 开源许可证合规与依赖义务追踪

> 编号段 EK01–EK10 · 聚焦「SPDX 清单、兼容性、NOTICE、来源与治理门禁」：让 Agent 产出可审计的合规资产，而不是复述许可证条文。
>
> 与现有维度互补说明：
> - 53 软件供应链偏 SBOM、来源与漏洞；本文件聚焦**开源许可证义务与法律边界自动化**。
> - 128 CI/CD 偏流水线；本文件只在发布门禁处交叉，输入是许可证决策而非构建状态。
> - 54 技术写作偏文档；本文件聚焦 NOTICE、归属与整改报告的可验证生成。
>
> **本文件独特主题**：SPDX 归一 / 许可证兼容矩阵 / NOTICE 生成 / 许可证文本漂移 / 策略门禁 / vendored 来源 / 商标与文档义务 / 替代包建议 / 合规证据包 / 发布前审计。
