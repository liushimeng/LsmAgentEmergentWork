### HA01 tilemap 数据模型与多图层

- **预期档位**: simple
- **考察维度**: chunk / 图层 / 翻转位
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/ha01_tilemap.py`：tilemap 核心数据模型：(a) **chunk 分块**（32×32 tile/块）按需分配，稀疏地图只存非空块，内存估算（整图 vs 分块对比）；(b) **多图层**（ground/decoration/collision 三层）独立网格 + z-order 渲染序；(c) tile id 编码：低 10 位 id + **翻转位**（水平/垂直/对角 3 bit，Tiled 规范）；(d) get/set 接口带越界保护（越界读返回 0、写忽略）；(e) 导出 JSON（含 chunk 索引 + 版本号 + 图层元数据）；(f) 无限地图：新块懒分配 + 视口裁剪遍历接口。
  2. Bash：构造 100×100 三层地图写入再读回，断言每层 tile 一致、翻转位正确往返、100×100 全量 vs chunk 化内存占用统计输出。
  3. Read 源码，再 Bash 断言：含 chunk 分块、含三层、含翻转位编码。

- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:

  3. Read 源码，再 Bash 断言：含 Bresenham、含队列版 flood、含访问计数。

### HA03 命令栈与撤销重做

- **预期档位**: medium
- **考察维度**: Command 模式 / coalesce / 上限
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/ha03_undo.py`：撤销系统：(a) Command 接口 `do()/undo()` + EditStack（undo/redo 双栈）；(b) **coalesce 合并**：300ms 内同图层的连续绘制合并为一条命令（绘制中途反复 Ctrl+Z 不逐格回退）；(c) **宏命令**（一次粘贴 50×50 区域 = 1 条宏，内含子命令序列倒序撤销）；(d) 栈上限 100 条（FIFO 淘汰最老 + 内存估算）；(e) redo 失效规则：新命令入栈清空 redo 栈；(f) 非对称命令（删除选区 vs 重建）与快照型命令（大范围修改直接存前后网格 diff）的选择策略。

  3. Read 源码，再 Bash 断言：含 coalesce、含宏倒序、含 redo 清空规则。
