> - `143-技术知识库与可验证问答工程`(KB 维)是**知识库问答**;本文件是**RAG 管线工程**。

> - `201-图像识别与OCR文档智能工程实战`(OCR 维)是**OCR**;本文件是**RAG 全链路**。
>
> **本文件独特主题**:PDF(pymupdf) / DOCX(python-docx) / HTML(BeautifulSoup) / Markdown 解析 / 分块(固定/递归/语义/滑动窗口) / Embedding(OpenAI / bge / e5) / 向量库(FAISS / Chroma / Qdrant) / 检索(cosine / dot / hybrid BM25+vector / reranker) / 提示组装(context 压缩 + 引用标注) / 评估(Recall@k / MRR / Faithfulness) / 增量更新(变更检测 + 增量 embed)。
