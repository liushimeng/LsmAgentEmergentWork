## 维度说明

本维度考察 Agent 在**文件处理、数据加工、批量操作、格式转换**等场景中的表现，
涵盖文件重命名、格式转换、日志分析、数据清洗、CSV/JSON 处理、图片处理等主题。

### G01 批量文件重命名
- **测试状态**: ✅ 已测试 (G01_q1.md, 通过 — mock 链路 Yolo→SubAgent→QC→SessionContext 完整跑通; -f 文件模式读取正常, 详见 `tmpPlan/2026-09-10_20-A09-G01-I04-自动化测试与TUI验证方案.md`)
- **预期档位**: medium
- **考察维度**: 批量操作 + 安全确认
- **对话脚本**:
  1. 我有一百个照片文件，命名格式不统一（IMG_001.jpg、photo(1).jpg、2024-01-01.jpg），请设计一个统一重命名方案。
  2. 写一个 bash 脚本实现这个方案，要求先 dry-run 预览，确认后再执行。
  3. 如果重命名过程中出现文件名冲突，应该怎么处理？
