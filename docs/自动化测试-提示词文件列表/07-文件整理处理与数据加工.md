## 维度说明
本维度考察 Agent 在**批量文件处理、数据清洗、格式转换、日志分析、图片/Markdown 加工等**场景的动手产出能力。固定 4 轮对话脚本，要求至少 1 轮 Bash 执行并断言、至少 1 轮 Write 落盘产物到 `tmpPlan/agent-test/` 沙盒。所有任务必须落到可执行产物（脚本 + 输入数据现场生成 + 输出文件 + 断言）。衡量重点：批量操作必须带 dry-run 预览与 undo 机制，数据清洗必须产出质量报告 + 校验脚本，多轮之间通过 Read/Edit 复用前轮产物。
