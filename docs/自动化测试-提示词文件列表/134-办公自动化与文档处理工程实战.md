### DZ01 Excel 报表自动生成

- **预期档位**: medium
- **考察维度**: openpyxl / 样式 / 公式 / 图表
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/dz01_report.py`：python3 用 openpyxl 生成销售报表——创建工作表、写入表头（加粗/背景色/边框）、填充数据行、添加 SUM/AVERAGE 公式、创建柱状图（BarChart）、冻结首行、自动列宽。
  2. Bash：`python3 tmpPlan/agent-test/dz01_report.py 2>&1 | tee tmpPlan/agent-test/dz01_gen.log`，断言 `dz01_gen.log` 含 "saved" 或 "ok" 或 "success"，且 `test -f tmpPlan/agent-test/sales_report.xlsx`。
  3. Read dz01_report.py，再 Write `tmpPlan/agent-test/dz01_style.py`：样式工厂函数——header_style（字体加粗+居中+背景蓝）、data_style（边框+数字格式）、total_style（加粗+顶部边框+底色），在报表中复用。
  4. Bash：`python3 tmpPlan/agent-test/dz01_style.py 2>&1 | grep -c 'style\|format\|header\|border\|font'` 应 ≥ 3。
