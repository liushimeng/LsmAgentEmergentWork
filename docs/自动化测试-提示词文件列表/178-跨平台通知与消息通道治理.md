# 178 跨平台通知与消息通道治理

> 编号段 FQ01–FQ10 · 聚焦「桌面通知、邮件、Webhook、模板、重试、免打扰与审计」的多操作系统一致性。
>
> 与现有维度互补说明：
> - `130-日志分析与监控告警工程实战` 偏服务指标、告警规则与监控平台；本文件偏用户可感知消息通道。
> - `140-团队工作流与运营自动化` 偏组织流程；本文件聚焦通知投递协议、模板治理和端侧体验。
> - `142-边缘函数与事件流集成实战` 偏事件架构；本文件把通知当作可验证的跨端交付产品。
>
> **本文件独特主题**：通知清单 / 渠道路由 / 模板变量 / 严重级映射 / 免打扰窗口 / 幂等重试 / 去重聚合 / 本地邮件草稿 / Webhook 签名 / 多端审计。
>
> 环境约束：不联网、不安装依赖、不注册系统服务、不发送真实消息。Windows 可用 Git Bash/WSL 执行 POSIX 示例；Python 仅用标准库，`python3` 不存在时可等价使用 `python`。

- **预期档位**: medium
- **考察维度**: event inventory / channel matrix / ownership
- **工具链**: Write → Bash → Read → Write

  4. Bash：`python3 -m json.tool tmpPlan/agent-test/fq01_matrix.json >/dev/null`，断言第二轮产物 JSON 有效。
