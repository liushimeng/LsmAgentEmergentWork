- **预期档位**: medium
- **考察维度**: MIDI 二进制 / VLQ 变长编码 / 事件模型
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write 在 `tmpPlan/agent-test/df01/` 写 `gen_midi.py`：手写 MIDI 字节（Header Chunk MThd + Track Chunk MTrk），包含 4 个 note on/off 事件（C4/E4/G4 三和弦），delta time 用 VLQ 编码；Bash 跑脚本生成 `chord.mid`，`file chord.mid` 断言是 `Standard MIDI data`。
  2. Write 写 `parse_midi.py`：读 MThd 解析格式/轨道数/ticks_per_beat，读 MTrk 解析 VLQ delta time + 事件类型（note on/off、meta tempo），输出事件列表到 `events.tsv`；Bash 跑：`python3 parse_midi.py chord.mid > events.tsv`、`wc -l events.tsv` 断言 ≥ 8 行（4 个 note on + 4 个 note off）。
