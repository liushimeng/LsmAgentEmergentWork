### HX01 Git 状态采集与分支检测

- **预期档位**: simple
- **考察维度**: git 分支/commit/脏文件检测 / 非仓库静默降级
- **工具链**: Bash(git 命令) → Read(workspace snapshot)
- **对话脚本**:
  1. Bash:`git branch --show-current` → 返回当前分支(如 `main`);`git rev-parse --short HEAD` → 返回短 commit hash;`git status --porcelain` → 返回脏文件列表。
  2. 在非 git 目录运行 → 静默降级(返回空 snapshot,不报错)。
  3. 断言:git 仓库返回 branch/commit/dirty_files;非仓库返回空 snapshot 不崩溃。
