## 与 laew 工程的具体对接点

1. **CB01 → TUI 信息架构**：当前 TUI 主屏信息密度可能过高（横幅 + 项目说明 + 历史 + 输入），可应用 CLT 原则分层呈现：默认只显示核心层，用户按 `Tab` 渐进展开高级信息。
2. **CB03 → `/focus` 模式**：可参考深度工作方法论在 TUI 加 `/focus` 命令（番茄钟 + 屏蔽通知 + 完成后生成时段报告）。
3. **CB04 → 自动 bisect**：SubAgent 报告「昨天还好今天坏了」时可自动建议 `git bisect` 流程，辅助定位引入问题的提交。
4. **CB06 → `/arch <repo>` 命令**：可作为新命令扩展（参考 79 的「Agent 记忆与上下文工程」），分析任意仓库输出鸟瞰报告。
5. **CB10 → 规格优先模式**：SubAgent 默认拒绝执行模糊任务（"帮我写个登录"），必须先有 acceptance criteria，强制用户想清楚（降低被 AI 替代的风险）。
