> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明
本维度考察 Agent 在**技术文档撰写、方案设计、调研报告、ADR/Changelog、白皮书/演讲稿**等"长文结构化输出"场景的动手能力。固定 4 轮对话脚本，要求至少 1 轮 Bash 执行并断言、至少 1 轮 Write 落盘产物到 `tmpPlan/agent-test/` 沙盒。所有"文档任务"必须落到可执行的产物（Markdown + 校验脚本/grep 断言/字数/标题数/锚点），禁止纯"列大纲/给建议"。衡量重点：把抽象文档任务转化为可在本机 grep 校验/字数限制/标题计数/锚点检查的结构化产物，多轮之间通过 Read/Edit 复用前轮产物。
