# 176 医疗健康与生物信息工程实战

> 编号段 FP01–FP10 · 聚焦「医疗健康信息系统 + 生物信息学应用 + 医疗设备集成 + 健康数据分析」：HIS/EMR 电子病历系统 / DICOM 医学影像处理 / HL7/FHIR 互穿戴设备数据采集 / 基因测序临床解读 / 远程医疗平台 / 健康风险评估模型 / 药物相互作用检查 / 医疗数据隐私合规
>
> 与现有维度互补说明：
> - `113-生物信息学与基因数据编程`（DE 维）聚焦**基础生物信息学算法**（序列比对/BLAST/组装）；本文件聚焦**临床级应用**（EMR/影像/远程医疗），是该维度的医学应用延伸版。
> - `72-密码学与隐私计算`（BU 维）聚焦**通用隐私计算**（同态加密/零知识证明）；本文件聚焦**医疗数据 HIPAA/GDPR 合规**，是该维度的医疗垂直版。
> - `32-移动应用与跨平台开发实战`（AF 维）聚焦**通用移动端**（React Native/Flutter）；本文件聚焦**移动医疗 mHealth**（穿戴设备接入/健康监测），是该维度的医疗应用版。
> - `176` 不与 `80-隐私计算与数据合规工程` 重叠：80 维聚焦**通用数据合规**；本文件聚焦**医疗行业特有法规与系统**。
>
> **本文件独特主题**：HL7 v2/v3 与 FHIR R4 互操作 / DICOM 解析与窗宽窗位 / 电子病历 CDA 文档 / 穿戴设备 BLE 数据采集 / 基因变异 VCF 临床注释 / 远程医疗 WebRTC 实时通信 / 药物-药物相互作用（DDI）知识图谱 / 医疗数据脱敏与 HIPAA 合规 / AI 辅助诊断模型集成 / 医院信息平台集成引擎。
