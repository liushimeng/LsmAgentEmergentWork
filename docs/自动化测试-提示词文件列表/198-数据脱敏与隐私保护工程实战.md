### GJ04 差分隐私机制与实现

- **预期档位**: hard
- **考察维度**: Laplace / Gaussian / ε 预算
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/gj04_dp.py`：差分隐私机制演示器（输入查询函数 + 隐私预算），输出：(a) **差分隐私定义**（相邻数据集 D/D' 差一条记录 / 算法 M 满足 ε-DP：Pr[M(D)∈S] ≤ e^ε × Pr[M(D')∈S] + δ — 直觉：任何单条记录的加入移除不显著改变输出分布）+ (b) **Laplace 机制**（适用于计数/求和查询 / 噪声 ~ Laplace(0,b=b=Δf/ε) / 敏感度 Δf = max_{D~D'} ||f(D)-f(D')||_1 / 代码：np.random.laplace(0, sensitivity/epsilon, size) + 示例：COUNT(*) Δf=1 / SUM(薪资) Δf=max_salary）+ (c) **Gaussian 机制**（松弛 (ε,δ)-DP / 噪声 ~ N(0,σ²) / σ ≥ c×Δ₂f / √(2ln(1.25/δ)) — 与 Laplace 的 MSE 对比：高斯 MSE=2σ² 通常更优但放宽了 δ）+ (d) **预算组合**（顺序组合：k 次查询各 ε_i → 总 ε_total = Σ ε_i / 高级组合定理：√(2k ln(1/δ'))ε + kε(e^ε−1) / 预算耗尽时拒绝查询 + RDP zCDP 现代组合更紧界）+ (e) **实用建议**（ε=1 强隐私 / ε=10 弱隐私 / 先加噪声再取整 / 敏感度裁剪裁剪薪资到 [0,500000] 防单条主导 / DP 直方图与热力图的应用）。
