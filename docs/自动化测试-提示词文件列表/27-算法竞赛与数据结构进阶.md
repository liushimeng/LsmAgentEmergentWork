# 自动化测试提示词 — 算法竞赛与数据结构进阶（AA01–AA10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度从 Agent 能力视角考察**算法实现与对拍验证**链路：每条都要求写出至少两版（暴力基线 + 优化算法），用同一随机数据 diff 验证正确性，并在大数据量下计时验证性能优势。覆盖 DP、图论、网络流、字符串、树结构、几何、数论、博弈论等竞赛核心主题。所有产物落在 `tmpPlan/agent-test/` 下，仅使用 python3/bash/awk 等本机工具。

### AA01 动态规划：背包 + 树形 DP
- **预期档位**: simple
- **考察维度**: DP 状态设计 / 对拍验证
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 下用 Write 产出 `knapsack.py`：包含暴力版 `brute_01(items, cap)`（枚举所有 2^n 子集求最大价值）与滚动数组版 `dp_01(items, cap)`（一维数组逆序遍历）。造 50 组小数据 (n≤15, cap≤30, w/v≤10) 用 Bash 跑 `python3 knapsack.py --test small`，期望两版输出逐行一致且 `wc -l diff.out == 0`。
  2. Bash 跑大数据性能断言：`python3 knapsack.py --bench` 生成 n=5000 随机物品，期望 `dp_01` < 200ms 而 `brute_01` 报 `infeasible` 或超时（耗时不做硬要求但相对差应 > 100x）。Read `knapsack.py` 验证逆序遍历那行确实存在。
  3. 加 `complete_knapsack`（完全背包）+ `brute_complete`（带重复枚举），同样 50 组小数据对拍，再加 n=2000 跑性能测试，期望完全背包 < 100ms。Read 验证遍历顺序与 01 背包相反。
  4. 在 `tree_dp.py` 实现「没有上司的舞会」：暴力版 `brute(root, parent, adj)` 枚举每个节点选/不选子树所有 2^k 组合 vs 树形 DP `dp(root)` 后序遍历两状态。随机生成 200 节点树对拍 20 组，再加 n=2000 单链测性能，期望 DP 版 < 50ms；写 `tree-dp-notes.md` 总结记忆化 vs 递推的取舍。

### AA02 最短路：堆优化 Dijkstra + 0-1 BFS
- **预期档位**: medium
- **考察维度**: 图论实现 / 复杂度可断言
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `dijkstra.py`：含 `brute_ssp(n, edges, src)`（Bellman-Ford O(VE)）与 `heap_dijkstra(n, edges, src)`（邻接表 + heapq O((V+E)logV)）。Bash 跑 `python3 dijkstra.py --test` 对拍 100 组随机 n≤30 / 边权 1~10 / E≤n*2 无负权图，期望两版 `dist` 数组逐元素相等。
  2. 加反例：故意构造 n=4 的一条负权边图，期望 `heap_dijkstra` 警告 `negative edge detected` 但继续返回（值可能错），`brute_ssp` 给正确值。Read `dijkstra.py` 验证负权检测分支存在。
  3. 性能断言：n=10000, E=50000 随机正权图，期望 `heap_dijkstra < 200ms`、`brute_ssp` 显式提示 `skip(O(VE) too slow)` 但仍能跑（用 `time` 命令记录 wall）。
  4. 加 0-1 BFS：对边权仅 0/1 的图，期望实现 `deque_01bfs` 与 `heap_dijkstra` 输出一致（100 组对拍）。对 n=20000 单链 0-1 图跑性能，期望 `deque_01bfs < 100ms`；写 `01bfs-vs-dijkstra.md` 说明优先级退化。

### AA03 网络流：Dinic 最大流 + 最小割验证
- **预期档位**: hard
- **考察维度**: 网络流建模 / 失败-修复闭环
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `dinic.py`：暴力版 `brute_maxflow`（反复 DFS 找任意增广路 O(E·maxflow)）与 Dinic 版（`bfs_level` 分层 + `dfs_iter` 阻塞流）。先故意把 Dinic 版的 BFS 分层写错（缺少 `level[v] = level[u]+1` 边界），跑 `python3 dinic.py --test` 期望 100 组随机数据全部对拍失败，输出 `MISMATCH group=3 expected=7 got=8`。
  2. Read 定位 bug：分层 BFS 起始 `level[src]=0` 没错但 `level[neighbor]` 没在 `if not visited` 分支内赋值。修复后重跑，期望 0 mismatch。把 bug 描述与修复 commit 写到 `dinic-bugfix.md`。
  3. 性能断言：n=200, E=2000, 容量 1~100 的稠密图，期望 `dinic < 500ms`、`brute_maxflow` 报 `timeout/too slow` 但仍能出值；用 `time -v` 记录 max RSS。
  4. 实现最小割验证：在 4 节点星形图上跑 Dinic 得最大流 7，再用 BFS 在残余网络从 src 出发找 `min_cut = [S-reachable]`。Bash 期望 `assert sum(cut_edges) == maxflow` 通过；写 `maxflow-mincut.md` 附 ASCII 图说明构造思路。

### AA04 字符串：KMP + AC 自动机
- **预期档位**: medium
- **考察维度**: 字符串算法 / 工程落地
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `kmp.py`：暴力版 `brute_search(text, pattern)`（逐位滑 O(nm)）与 KMP 版 `kmp_search(text, pattern)`（先算 `next` 数组线性扫）。Bash 跑 `python3 kmp.py --test` 对拍 200 组（text 长度 1000 随机、pattern 长度 1~50 随机），期望两版 hit 位置列表逐元素相等。
  2. 故意构造 KMP 的 next 数组越界 bug（`next[0]` 写成 `next[-1]`），跑对拍期望失败；Read 定位（边界未保护），修复后重跑通过。写 `kmp-bugfix.md`。
  3. 性能断言：text=1_000_000 字符、pattern=1000 字符，期望 KMP < 300ms，暴力版跳过或显式 `slow` 标签但能跑出正确结果做对照。
  4. 加 AC 自动机：在 `ac.py` 实现多模式匹配（5~10 个模式串），对拍 `brute_multi_search`（每个模式单独跑 brute）+ AC 版（build fail tree 后单次扫描）。构造敏感词替换场景：输入 50KB 文本 + 5 个敏感词，期望 AC 版 < 200ms 且替换后文本中敏感词全部消失（`grep -c "敏感词A" cleaned.txt == 0`）。

### AA05 线段树：懒标记区间更新
- **预期档位**: hard
- **考察维度**: 区间算法 / 对拍闭环
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `seg_tree.py`：暴力版 `brute_update_query(arr, ops)`（每次操作直接改数组 O(n)）与懒标记版 `seg_lazy(arr)`（`push_down` 复合加乘懒标记）。先故意把 `push_down` 顺序写反（先加后乘），跑 `python3 seg_tree.py --test` 100 组（n=100, 操作数 50 随机加乘查），期望 mismatch 出现。
  2. Read 定位乘法分配律 bug，修复后再跑，期望 0 mismatch。把 bug 写 `seg-bugfix.md`。
  3. 性能断言：n=10_000、操作数 100_000（区间加 + 区间求和），期望懒标记版 < 500ms，暴力版显式 `slow` 跳过但提供 1000 操作版本对照。
  4. 加「区间赋值 + 区间最大值」覆盖懒标记（lazy=assign 覆盖 add）：同样 100 组对拍。再加值域 10^9 离散化：随机生成 1000 个点 (x∈[0,1e9])，离散化后跑线段树与暴力对拍期望一致。写 `seg-dynamic.md` 总结动态开点 vs 离散化的瓶颈差异。

### AA06 树状数组与逆序对
- **预期档位**: medium
- **考察维度**: 前缀和结构 / 离散化
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `bit.py`：暴力版 `brute_prefix(arr, i)`（循环求和 O(n)）与 BIT 版 `bit_prefix(arr, i)`（O(log n)）。Bash 对拍 200 组（n≤500, 随机 1000 次单点加 + 前缀查询），期望两版输出一致。
  2. 写 `inversions.py`：暴力版 `brute_inv(perm)`（双重循环 O(n²)）与 BIT 版 `bit_inv(perm)`（离散化 + 单点加求前缀）。对 n=500 随机排列 50 组对拍；n=10_000 随机排列性能测试，期望 BIT 版 < 50ms、暴力版 `slow` 但能跑出值。
  3. 加「动态逆序对」（支持删除）：BIT 版 + 链表存值位置，删除时 O(log n) 更新。n=1000 跑 100 次随机删 + 查逆序对，期望与重新计算的 brute 对拍一致。Read `inversions.py` 验证删除更新走 BIT 单点加 -1。
  4. 与归并排序版 `merge_inv(perm)` 对拍：n=100_000 随机排列跑性能，期望 BIT 版与 merge 版 < 100ms 且两者结果完全相等（`assert bit_inv(p) == merge_inv(p)`）。写 `inv-compare.md` 总结 3 版耗时。

### AA07 并查集：带权 + 扩展域
- **预期档位**: medium
- **考察维度**: 并查集变体 / 关系推理
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `dsu.py`：基础版 `dsu_basic(n)`（无路径压缩）与优化版 `dsu_opt(n)`（路径压缩 + 按秩合并）。Bash 对 1000 次 `find/union` 随机操作计数 find 递归深度，期望 `dsu_opt` 平均深度 < 2 且 `dsu_basic` 平均深度 > 5（证明优化有效）。
  2. 加食物链题（带权 DSU）：暴力版 `brute_foodchain`（维护三元组 + 类型传播 BFS）vs 带权版（`weight[i]` 存到根的模 3 距离）。100 组 n=100, 操作数 200 随机（`X eat Y` / `X same Y`），期望两版判定一致。

### AA09 数论：快速幂 + 模逆元 + CRT
- **预期档位**: simple

- **对话脚本**:

### AA10 博弈论：Nim + SG 函数
- **预期档位**: medium
- **考察维度**: 博弈组合 / 程序验证
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. 在 `tmpPlan/agent-test/` 写 `nim.py`：暴力版 `brute_nim(heaps)`（递归枚举所有走法判必胜）vs 公式版 `nim_xor(heaps)`（`xor all == 0` 必败）。Bash 对拍 500 组 (堆数 1~5、每堆 0~10) 期望两版判定一致。

  3. 实现阶梯 Nim：把每堆石子按奇偶台阶重映射回标准 Nim，期望与 brute 阶梯版判定一致（100 组 n=4 阶梯对拍）。
  4. 写终端小游戏 `nim_play.py`：人类输入取石子数 vs AI 走 SG 最优策略。脚本里让 AI 必胜位走必胜、必败位逼人类犯错；自动跑 100 局，期望 AI 全胜（除非人类输入非法）；用 `diff` 对比 100 局日志，统计人类胜率 < 5%。写 `nim-bot.md` 说明 SG 必胜走法的判定准则。
