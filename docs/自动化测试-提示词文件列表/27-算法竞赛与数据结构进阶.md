# 自动化测试提示词 — 算法竞赛与数据结构进阶（AA01–AA10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 对**进阶算法与数据结构**的掌握与讲解能力：动态规划、最短路、
网络流、字符串匹配、线段树、树状数组、并查集、计算几何、数论、博弈论。
与 E04（LRU 缓存）的单点考察互补，本维度系统性覆盖竞赛级主题，
每条都要求"可运行代码 + 复杂度证明"双重产出，考察深度编程功底。

---

### AA01 动态规划：背包与树形 DP
- **预期档位**: medium
- **考察维度**: DP 状态设计 + 滚动数组
- **对话脚本**:
  1. 讲解 0-1 背包与完全背包的状态设计与转移方程，说明一维滚动数组为什么可行、两者遍历顺序为什么相反。
  2. 用 Rust 分别实现两版背包，附 3 组边界测试：容量为 0、所有物品都超重、恰好装满。
  3. 进阶到树形 DP：用"没有上司的舞会"（选了父节点不能选子节点）讲状态设计，并给出实现。
  4. 对比记忆化搜索与递推两种写法：什么时候记忆化更自然？把上面的树形 DP 改写成记忆化搜索版本。

### AA02 最短路：堆优化 Dijkstra 与 0-1 BFS
- **预期档位**: medium
- **考察维度**: 图论 + 正确性证明
- **对话脚本**:
  1. Dijkstra 为什么不能处理负权边？用反例说明"贪心选取当前最近点"的正确性依赖什么性质。
  2. 用邻接表 + 二叉堆实现 O((V+E)logV) 的 Dijkstra，并用一个 5 节点带权图手工演算每一轮堆的变化过程。
  3. 边权只有 0 和 1 时可以用双端队列 BFS：实现它，并解释为什么它是 Dijkstra 优先级的退化特例。
  4. 基于以上讨论：如果图里有少量负边但无负环，怎么改造？（提示 Johnson 重标号思路）

### AA03 网络流：Dinic 最大流与最小割建模
- **预期档位**: hard
- **考察维度**: 网络流建模 + 实现
- **对话脚本**:
  1. 讲清流网络、残余网络、增广路径三个概念；为什么"反向边"是算法正确性的关键？
  2. 实现 Dinic 算法（BFS 分层 + DFS 找阻塞流），分析它的时间复杂度上界是多少、为什么。
  3. 最大流最小割定理：把"任务选择收益最大化"问题建模成最小割，写出完整的建图方法。
  4. 构造一个 4 节点的流量问题，用你写的 Dinic 求解，并人工找出一个割验证割值等于最大流。

### AA04 字符串：KMP 与 AC 自动机做敏感词过滤
- **预期档位**: hard
- **考察维度**: 字符串算法 + 工程落地
- **对话脚本**:
  1. 手推 KMP 的 next 数组：以 "ABABCA" 为例逐位计算，并解释失配跳转的含义。
  2. 实现 KMP 并测试：主串 100 万字符、模式串 1000 字符，验证线性复杂度。
  3. 把 KMP 扩展成 AC 自动机：多模式串同时匹配的 fail 树怎么构建？
  4. 用 AC 自动机实现一个敏感词过滤服务：输入文章输出命中词与位置，并讨论 DFA 转移表的内存优化（next 数组压缩）。

### AA05 线段树：懒标记与区间更新
- **预期档位**: hard
- **考察维度**: 区间数据结构 + 对拍验证
- **对话脚本**:
  1. 讲解线段树的单点修改与区间查询实现，画出一棵 [1,8] 区间树对 [2,7] 查询的分解过程。
  2. 加"区间加 + 区间求和"的懒标记下传；解释复合操作（又乘又加）时标记为什么必须"先乘后加"。
  3. 实现"区间赋值 + 区间最大值"版本，跑 10 万次随机操作与暴力程序对拍验证正确性。
  4. 讨论动态开点与离散化：值域 10^9 的区间问题怎么落地？两种技术各自解决什么瓶颈？

### AA06 树状数组与逆序对
- **预期档位**: medium
- **考察维度**: 前缀和结构 + 离散化
- **对话脚本**:
  1. 讲清树状数组的 lowbit 与前缀和查询原理；它比线段树轻在哪、弱在哪？
  2. 实现单点加 + 前缀和查询，再用它统计一个排列的逆序对（配合离散化），讲清为什么等价于"数比它大且在它前面"。
  3. 把逆序对统计升级为"动态逆序对"（支持删除元素），需要什么额外结构？给出思路即可。
  4. 写一个对拍程序：验证树状数组版逆序对与归并排序版结果一致，并给出两者在 10^5 规模下的耗时对比。

### AA07 并查集进阶：带权与扩展域
- **预期档位**: hard
- **考察维度**: 并查集变体 + 关系推理
- **对话脚本**:
  1. 路径压缩 + 按秩合并的并查集为什么接近 O(α(n))？先实现这个基础版并解释 α 是什么。
  2. 带权并查集：节点到根的权值在路径压缩时怎么维护？用它解决"食物链"经典题（三种动物的捕食关系推理）。
  3. 扩展域（拆点）并查集：把同一实体拆成多个副本表达"同类/敌对"约束，与带权版各适合什么题面？
  4. 讨论"可撤销并查集"：为什么它不能路径压缩？离线动态连通性问题怎么配合线段树分治解决？

### AA08 计算几何：凸包与最近点对
- **预期档位**: hard
- **考察维度**: 几何算法 + 精度处理
- **对话脚本**:
  1. 用叉积解释"左转/右转"判定，实现 Andrew 单调链算法求二维点集凸包。
  2. 判断点是否在多边形内：射线法与转角法的原理各是什么？点恰好在边上这类边界情况怎么处理？
  3. 平面最近点对的分治算法：按 x 排序、递归求解中线两侧后怎么合并？为什么检查带内只需看常数个点？
  4. 把凸包结果用文件保存，再写一个独立校验脚本：验证输出点序确实是凸的且覆盖了全部输入点。

### AA09 数论：快速幂、模逆元与中国剩余定理
- **预期档位**: medium
- **考察维度**: 数论算法 + 教学关联
- **对话脚本**:
  1. 快速幂为什么是 O(log n)？实现迭代版，并用费马小定理说明它在大数模幂中的用途。
  2. 模逆元的两种求法（扩展欧几里得 / 费马小定理）各自的前置条件是什么？实现两版并互验结果。
  3. 中国剩余定理：先用手工解一个"物不知数"式的小例子，再实现通用版解同余方程组。
  4. 用上面三件套实现一个教学用途的 RSA 玩具版（小素数即可），说明加解密每一步用到了哪个数论结论。

### AA10 博弈论：Nim 游戏与 SG 函数
- **预期档位**: medium
- **考察维度**: 组合博弈 + 程序验证
- **对话脚本**:
  1. Nim 游戏的必胜判定为什么是"各堆异或和为零"？用数学归纳法给出证明。
  2. SG 函数的定义与 mex 运算是什么？实现一个记忆化求解任意有向图游戏 SG 值的函数。
  3. 用 SG 定理解"阶梯 Nim"：新规则怎么映射回标准 Nim 模型？
  4. 设计一个可以在终端双人游玩的小游戏，并让其中一方用 SG 策略自动应答，运行对局验证它必胜。
