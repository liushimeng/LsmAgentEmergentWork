### FI01 照片精确与模糊去重

- **预期档位**: medium
- **考察维度**: 哈希算法 / 相似度 / 空间节省
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `tmpPlan/agent-test/fi01_dedup.py`：照片去重器（输入目录），三级去重：(1) sha256 完全一致 → 直接列重复组；(2) 视觉精确（pHash 或 dHash 距离 ≤ 5）→ 列相似组；(3) 视觉相似（pHash 距离 6~12）→ 列近邻组并标"需人工确认"。每组保留 1 张（按拍摄时间最早 + 体积最大优先），其余输出删除候选清单。脚本可 dry-run 与 apply 双模式。
  2. Bash：`python3 -m py_compile tmpPlan/agent-test/fi01_dedup.py`，断言退出码为 0。
  3. Read `tmpPlan/agent-test/fi01_dedup.py`，再 Write `tmpPlan/agent-test/fi01_photos_meta.json`：10 张假照片清单（路径 + sha256 + pHash + 拍摄时间），故意构造 1 组完全相同、1 组相似、1 组完全不同。本轮必须显式复用第一轮的三级阈值与保留优先级。
  4. Bash：`python3 tmpPlan/agent-test/fi01_dedup.py tmpPlan/agent-test/fi01_photos_meta.json --dry-run 2>&1 | tee tmpPlan/agent-test/fi01_dedup_report.md`，断言 `grep -F '完全一致'` 命中、`grep -F '视觉精确'` 命中、`grep -F '视觉相似'` 命中、`grep -F '保留'` 命中。
