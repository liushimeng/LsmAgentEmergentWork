### FA01 分支剧情引擎骨架与图校验

- **预期档位**: medium
- **考察维度**: 剧情图建模 / 可达性与死节点 / 断链检测
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `fa01_validate.py`：剧情图加载器+校验器，python3 标准库实现（PyYAML 可用则用之，缺失时回退内置受限解析，只需支持本文件约定的两级缩进子集）。校验四条规则：从 start 出发 BFS 可达所有节点、无死节点（无出边且未标 `ending: true` 的节点报错）、`choices[].next` 引用必须存在、节点 id 唯一。有违规则输出中文清单并以退出码 1 结束，全部通过输出 OK 退出码 0。
  2. Bash：`python3 -m py_compile fa01_validate.py`，断言退出码为 0。
  3. Read `fa01_validate.py`，再 Write `fa01_story.json`：8 节点小剧情（字段与第一轮一致：id/text/choices[{text,next}]/ending），其中故意埋一处断链（某个 next 指向不存在的节点）和一个非结局死节点。本轮必须显式复用第一轮的字段命名与校验规则，不允许另起无关主题。
  4. Bash：`python3 fa01_validate.py fa01_story.json 2>&1 | tee fa01_report.txt`，断言退出码非 0、`grep -F '断链'` 命中、`grep -F '死节点'` 命中且两个问题节点 id（以第三轮产物为准）都在报告中。

### FA03 简式文字解析器

- **预期档位**: hard
- **考察维度**: 动词-宾语-介词短语 / 同义词归一 / 非法输入容错
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `fa03_parser.py`：把一行输入解析为单行 JSON：`go north`（动词）、`take key`（动词+宾语）、`use key on door`（动词+宾语+介词+目标）三态；同义词映射归一（n/north/北 → north，等）；未知动词、残缺宾语等非法输入不抛异常，输出 error 为中文提示字符串（合法输入 error 为 null）。从 argv 读取待解析句子。
  2. Bash：`python3 -m py_compile fa03_parser.py`，断言退出码为 0。
  3. Read `fa03_parser.py`，再 Write `fa03_inputs.txt`：恰好 10 行输入：8 行合法（覆盖三种形态与同义词缩写）+ 2 行故意非法（如 `fly moon`、残缺的 `take`）。本轮必须显式复用第一轮的 JSON 字段（verb/object/prep/target/error）与同义词表，不允许另起无关主题。
  4. Bash：`while read -r line; do python3 fa03_parser.py "$line"; done < fa03_inputs.txt | tee fa03_out.jsonl`，断言 `wc -l` 为 10、逐行经 `python3 -m json.tool` 校验有效、`grep -c '"error": "'` 恰为 2、`grep -F '"object": "north"'` 命中（同义词已归一）。

### FA04 时间树存档与回滚

- **预期档位**: medium

- **工具链**: Write → Bash → Read → Write
- **对话脚本**:

  4. Bash：`python3 fa04_timetree.py fa04_case.json | tee fa04_result.json`，断言输出经 `python3 -m json.tool` 校验有效、终态 node 与第三轮写的期望节点 id 一致（`grep -F` 命中）、`grep -F '"branches": 1'` 命中。

### FA10 剧情黄金快照回归

- **预期档位**: hard
- **考察维度**: 分支路径生成 / 快照对比 / 循环剧情检测
- **工具链**: Write → Bash → Read → Write
- **对话脚本**:
  1. Write `fa10_regression.py`：遍历所有选择分支生成测试路径集（按 (node,flags) 状态去重）；`--update` 把每条路径的关键输出（结局 id+结局文本）写入黄金基线文件；默认模式逐条对比基线，报告哪些结局输出发生变化并退出码 1，无变化退出码 0；遍历中同一状态第二次出现时打印「循环警告」。
  2. Bash：`python3 -m py_compile fa10_regression.py`，断言退出码为 0。
  3. Read `fa10_regression.py`，再 Write `fa10_story.json`：含 2 个结局与一个可选支线的小剧情（沿用 id/text/choices/ending 字段），其中一个结局的文本里必须含词「黎明」。本轮必须显式复用第一轮的基线格式与去重规则，不允许另起无关主题。
  4. Bash：先 `--update` 生成基线并 `test -s` 断言非空；再 `cp` 出 `fa10_story_v2.json` 并 `sed -i 's/黎明/黄昏/'`；跑回归 `| tee fa10_diff.txt`，断言退出码非 0 且 diff 报告指明被改结局的 id（`grep -F` 命中该 id）。
