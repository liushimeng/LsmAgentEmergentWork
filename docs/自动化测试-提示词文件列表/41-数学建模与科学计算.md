# 41 数学建模与科学计算

> 编号段 AP01–AP10 · 聚焦数学建模、数值计算、仿真与科学计算工程

### AP01 数值线性代数：矩阵运算与分解
- **预期档位**: medium
- **考察维度**: 矩阵计算 + 数值稳定性
- **对话脚本**:
  1. 用 NumPy 实现矩阵乘法、转置、逆、行列式，解释为什么实际工程中很少直接求逆。
  2. LU 分解、QR 分解、SVD 分解各自解决什么问题？用 NumPy 的 `linalg` 模块演示。
  3. 条件数（Condition Number）是什么？为什么病态矩阵求逆会放大误差？给出一个具体例子。
  4. 用 SciPy 的稀疏矩阵模块处理一个 10000x10000 的对角占优矩阵：对比稠密与稀疏存储的内存占用。

### AP02 优化问题：从梯度下降到凸优化
- **预期档位**: medium
- **考察维度**: 优化算法 + 收敛性
- **对话脚本**:
  1. 用 NumPy 实现批量梯度下降（BGD）、随机梯度下降（SGD）、小批量梯度下降，对比收敛曲线。
  2. 学习率对收敛的影响：太大发散、太小慢，怎么用学习率衰减策略（step/exp/cosine）改善？
  3. 用 SciPy 的 `minimize` 求解一个带约束的优化问题：目标函数、不等式约束、等式约束分别怎么表达。
  4. 凸优化 vs 非凸优化：为什么神经网络的损失函数是非凸的？局部最优在实践中为什么常常够用？

### AP03 微分方程数值解：ODE 与 PDE

  2. 用 SciPy 的 `solve_ivp` 求解洛伦兹吸引子（Lorenz attractor）：写出方程、初始条件、可视化相图。
