### HL01 WARC 记录格式解析

- **预期档位**: hard
- **考察维度**: WARC 结构 / 记录类型 / HTTP 重组
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/hl01_warc.py`：WARC 解析器（纯文本演示格式，gzip 概念注记）：(a) **记录结构**：`WARC/1.1` 版本行 + 头部（`WARC-Type/WARC-Target-URI/WARC-Date/WARC-Record-ID/Content-Type/Content-Length`）+ 空行 + 内容块 + CRLF CRLF 分隔——按 Content-Length 精确切分（不按空行猜）；(b) **四记录类型**：`warcinfo`（卷元信息：软件/操作员）、`response`（含完整 HTTP 响应字节：状态行+头+体）、`revisit`（内容未变的省略引用——指向等价前记录 ID）、`request`（可选保存的请求侧）；(c) **HTTP 重组**：从 response 内容块剥出状态码/头/HTML 体；(d) **读器**：顺序迭代全部记录返回结构化对象；**写器**：结构化对象回写 WARC 文本——读写往返字节一致；(e) 注记：真实 WARC 常为逐记录 gzip（`WARC-Type: continuation` 略），本实现处理明文形态，格式骨架与标准一致。
  2. Bash：构造含 1 warcinfo + 3 response（一个含完整 HTTP 头）+ 1 revisit 的样本，断言：读出 5 记录、HTTP 重组出状态码 200 与体长、revisit 引用 ID 与被引记录一致、往返字节一致。
  3. Read 源码，再 Bash 断言：含 Content-Length 切分、含四类型分支、含 gzip 注记。

### HL03 MHTML 解析

- **预期档位**: hard
- **考察维度**: multipart boundary / Content-Location / QP 解码
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write `tmpPlan/agent-test/hl03_mhtml.py`：MHTML 解析器：(a) **顶层头**：`MIME-Version` + `Content-Type: multipart/related; boundary="----X"` 提取 boundary；(b) **分部件**：按 `--boundary` 切分，每部件 `{Content-Type/Content-Location/Content-Transfer-Encoding}` + 体；(c) **两种传输编码**：base64 解码与 **quoted-printable**（`=XX` hex 解码 + `=\r\n` 软换行删除——软换行是 QP 最易错点，写专门断言）；(d) **根部件定位**：`Content-Type: text/html` 的部件即根，其余按 Content-Location 建 URL→资源映射（浏览器导出 MHTML 的资源定位机制）；(e) **渲染回放**：根 HTML 中引用替换为本地文件名，落盘资源目录，输出回放清单；(f) 构造含 QP 编码长中文行的完整 mock MHTML 往返。
  2. Bash：解析 mock 断言：部件数正确、QP 软换行还原后行数 < 原始行数（软换行合并）、中文内容解码无损（与原文 grep -F 比对）、回放清单含根文件名。
  3. Read 源码，再 Bash 断言：含 boundary 提取、含 `=\r\n` 软换行分支、含 Content-Location 映射。

Write `tmpPlan/agent-test/hl06_manifest.py`：清单与完整性引擎：(a) **manifest 格式**：每文件一行 `{path, size, sha256, url_origin, saved_at}`（用 `hashlib.sha256` 分块读大文件——**跨平台不依赖 sha256sum/shasum 差异**）；(b) **校验器**：全量重算比对，输出 `OK/BITROT(哈希不符)/MISSING/EXTRA(清单外文件)` 四态；(c) **修复策略**：BITROT → 若有多副本（三副本布局 `archive/{a,b,c}/`）从健康副本恢复，输出恢复动作清单；无副本 → 标记损失并评估（该 URL 可重抓？联动 HL05 存活状态）；(d) **并行加速**：多文件校验按 4 一批（线程池概念用简单分批模拟），输出批次进度；(e) **密封**：全量 OK 后生成 `manifest.sha256`（清单自身的指纹）+ 时间戳，作为"冻结点"。
