# 自动化测试提示词 — 桌面应用与跨平台开发（Y01–Y10）

> 使用说明见同目录 `README.md`。每条提示词在同一 Session 内按轮次顺序喂入。

## 维度说明

本维度考察 Agent 在**不真编译 Electron/Tauri**前提下，把"窗口与事件循环/状态管理/后台任务调度/IPC 协议/数据持久化/JSON/CSV 导出/无障碍焦点栈/CLI 桌面小工具/打包配置"等桌面应用任务，做成可 Read 可 Bash 的真实可执行产物——纯 JS（node 跑）+ 纯 Python 写"框架替身"+ 核心逻辑纯函数单测，覆盖"项目骨架 + 配置 + 核心逻辑 + 关键断言"。

  4. 故意把 `ipcMain.on` 错写成同步直接调，期望 "data:1" 出现在 "ready" 之前（顺序错）；请 Read `ipc.js` 改成事件驱动（`setImmediate`/`process.nextTick`）重跑，期望事件顺序正确，写 `verify_event_order.sh` 用 grep -E 校验时序。
