- **预期档位**: medium
- **考察维度**: L 系统 + 字符串重写 + 乌龟图形 SVG
- **工具链**: Write → Bash → Read → Bash
- **对话脚本**:
  1. Write L 系统分形树脚本 `tmpPlan/agent-test/cj01_lsystem.py`：实现 (a) 字符串重写引擎（公理 + 规则 + 迭代次数）生成字符串 (b) 乌龟图形解释器（`F` 前进画线、`+/-` 转向 22.5°、`[` `]` 入栈/出栈状态）将字符串转为折线段列表 (c) 输出 SVG 文件。公理 `F`，规则 `F → F[+F]F[-F][F]`，迭代 4 次。

  4. Bash 复检：`grep -c '^| ' tmpPlan/agent-test/cj01_note.md` ≥ 4 行（迭代 vs 段数表），`grep -F '<svg' tmpPlan/agent-test/cj01_tree.svg` 应 = 1（合法 SVG）。
