### CJ02 Shader 编程：GPU 上的实时艺术

- **预期档位**: hard
- **考察维度**: GLSL + 片段着色器 + Shadertoy
- **对话脚本**:
  1. Shader 编程是用 GLSL（OpenGL Shading Language）在 GPU 上编写小程序的技术。渲染管线：(a) 顶点着色器（Vertex Shader，处理顶点位置）；(b) 片段着色器（Fragment Shader，处理像素颜色）；(c) 几何着色器（Geometry Shader，处理图元）；(d) 计算着色器（Compute Shader，通用计算）。请解释为什么「片段着色器」适合生成艺术（每个像素独立计算，天然并行）。
  2. GLSL 基础：(a) 内置变量（`gl_FragCoord` 像素坐标 / `gl_FragColor` 输出颜色）；(b) 内置函数（`sin` / `cos` / `noise` / `fract` / `mix` / `clamp`）；(c) Uniform 变量（外部传入：时间 / 分辨率 / 鼠标位置）；(d) `main()` 函数（每个像素执行一次）。请写一个最简单的着色器：根据 x 坐标渐变（`gl_FragColor = vec4(gl_FragCoord.x / resolution.x, 0, 1, 1)`）。
  3. Shadertoy 深入：(a) `iTime`（时间 uniform）；(b) `iResolution`（分辨率 uniform）；(c) `iMouse`（鼠标 uniform）；(d) `fragCoord`（像素坐标）；(e) 经典效果（射线行进 / SDF / 分形）。请描述「射线行进」（Ray Marching）如何渲染 3D 场景（沿射线逐步前进，检测与场景的距离）。
  4. laew 的 Shader 编程支持：laew 如何帮助 Shader 编程：(a) 生成 Shadertoy 代码片段；(b) 解释 GLSL 函数和技巧；(c) 调试 Shader（常见错误：精度问题 / 未初始化变量）；(d) 优化 Shader（减少分支 / 降低精度）。讨论 laew 作为「Shader 编程助手」的价值。

### CJ03 分形几何：数学之美的可视化

- **预期档位**: medium
- **考察维度**: 分形理论 + Mandelbrot + 实现
- **对话脚本**:
  1. 分形（Fractal）是「自相似 + 无限细节」的几何形状。特征：(a) 自相似（部分与整体相似）；(b) 无限细节（放大永远有新细节）；(c) 分数维度（如 Koch 曲线维度 ≈ 1.26）。请解释为什么「分形」在自然界无处不在（海岸线 / 雪花 / 山脉 / 血管 / 闪电）。
  2. Mandelbrot 集合：(a) 公式 `z(n+1) = z(n)^2 + c`；(b) 迭代直到 `|z| > 2` 或达到最大迭代次数；(c) 不发散 → 属于集合（黑色）；(d) 发散速度 → 颜色。请描述如何用像素坐标映射到复平面（x → 实部，y → 虚部）。
  3. Julia 集合：(a) 公式 `z(n+1) = z(n)^2 + c`（c 为常数）；(b) 不同 c 值产生不同形状；(c) Mandelbrot 集合的「地图」（每个 c 对应一个 Julia 集合）；(d) 连通的 Julia 集合 ↔ c 在 Mandelbrot 集合内。请讨论 Mandelbrot 与 Julia 集合的关系。
  4. laew 的分形生成：laew 如何帮助用户生成分形：(a) 生成 Mandelbrot / Julia 集合代码；(b) 调整参数（c 值 / 迭代次数 / 颜色映射）；(c) 深度缩放（任意精度计算）；(d) 导出高分辨率图片。讨论 laew 作为「数学可视化助手」的价值。
