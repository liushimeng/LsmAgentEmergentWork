## 2. 关键数据结构

### 2.1 `sse.rs` 公共类型

```rust
/// 一个完整的 SSE 事件(Spec 形式):
/// event: <event>
/// data: <data line 1>
/// data: <data line 2>
/// (空行)
///
/// 注释行 (`:` 开头) 与 id/retry 行均忽略。
#[derive(Debug, Default, Clone)]
pub struct SseEvent {
    pub event: Option<String>,
    pub data: String,        // 已用 '\n' 拼接多行 data
    pub id: Option<String>,
    pub retry: Option<u32>,
}

/// 字节流 → 事件流的异步迭代器
pub struct SseStream {
    state: SseState,                    // Idle | InEvent
    buf: Vec<u8>,                       // 行缓冲
    pending_event: Option<SseEvent>,    // 攒事件
    max_buf: usize,
}

impl SseStream {
    pub fn new() -> Self;
    pub fn with_max_buffer(max: usize) -> Self;
    /// 喂入一块字节,内部按 \n 切行,按 \n\n 切事件。
    /// 返回 0 个或多个事件(不阻塞)。
    pub fn push(&mut self, chunk: &[u8]) -> Result<Vec<SseEvent>>;
    /// 标记流结束,把残留的最后一个事件吐出来(若缓冲区非空)。
    pub fn finish(&mut self) -> Result<Option<SseEvent>>;
}
```

> 为何不直接用 futures_core::Stream?—
> `reqwest::bytes_stream()` 返回 `impl Stream<Item = reqwest::Result<Bytes>>`,
> 在 `async fn complete()` 中 `.try_fold(|sink, bytes| async move { ... })` 的回调里同步消费字节最简单;
> 我们把 `SseStream` 做成**同步的字节 → 事件**转换器,放在 `try_fold` 里调用,避免引入新的异步 trait。

### 2.2 `Completion` 与 `Usage`

```rust
// llm/mod.rs
#[derive(Debug, Default, Clone, Copy)]
pub struct Usage {
    pub input_tokens: u32,
    pub output_tokens: u32,
    /// Anthropic cache 命中 / OpenAI cached_tokens
    pub cache_read_input_tokens: u32,
    /// Anthropic cache 写入(可选)
    pub cache_creation_input_tokens: u32,
}

#[derive(Debug, Default, Clone)]
pub struct Completion {
    pub text: String,
    pub tool_calls: Vec<ToolCallReq>,
    pub usage: Usage,
    pub stop_reason: Option<String>,

```

> `Completion` 的所有新增字段都设默认值,不会破坏既有的 `Default` 构造。
> 公开 `LlmClient::complete()` 签名**保持不变**;`NoopLlm` 也不变(只多一个 `..Default::default()` 即可)。

### 2.3 协议解析器

两协议各持一个**有状态**的解析器,消费 `SseEvent` 产生**统一**的 `DeltaEvent`,并把 `DeltaEvent` 推入一个**协议无关**的 `ParseSink`,由 `ParseSink` 维护最终 `Completion`。

```rust
// sse.rs 顶部
#[derive(Debug, Clone)]
pub enum DeltaEvent {
    /// 输入侧 usage(来自 message_start / 末尾 usage chunk)
    InputUsage { input_tokens: u32, cache_read: u32, cache_creation: u32 },
    /// 文本增量
    TextDelta(String),
    /// 工具调用开始(Anthropic content_block_start 含 id/name;OpenAI 首 chunk 含 id/name)
    ToolCallStart { id: String, name: String },
    /// 工具调用的 JSON 参数增量(原始 partial 字符串)
    ToolCallJsonDelta(String),
    /// 工具调用结束信号(Anthropic content_block_stop / OpenAI finish_reason)
    ToolCallEnd,
    /// 终止信号(Anthropic message_stop / OpenAI [DONE] / message_delta)
    Stop { stop_reason: Option<String> },
    /// 上游显式 error(目前只有 Anthropic 流)
    Error(String),
}

pub struct ParseSink {
    text: String,
    /// key = (content_block_index, tool_call_id)
    in_flight: HashMap<(u32, String), InFlightToolCall>,
    ordered: Vec<String>,   // 维护 tool_call 顺序
    usage: Usage,
    stop_reason: Option<String>,
    errored: Option<String>,
}

struct InFlightToolCall {
    id: String,
    name: String,
    json_buf: String,
}

impl ParseSink {
    pub fn new() -> Self;
    pub fn feed(&mut self, ev: DeltaEvent) -> Result<()>;
    pub fn finish(self) -> Result<Completion>;
}
```

> **顺序保证**:Anthropic 的 `index` 在一个流里单调;OpenAI 的 `tool_calls[].index` 同理。我们在解析器侧把 `index` 透传到 `DeltaEvent` 的"工具块上下文"——具体做法见 §3.2 / §3.3。

## 3. 协议解析器

### 3.1 Anthropic

```rust
// anthropic.rs (内部)
struct AnthropicParser {
    block_index: u32,
    block_kind: Option<String>,   // "text" | "tool_use" | "thinking"
    block_id: Option<String>,
    block_name: Option<String>,
}

impl AnthropicParser {
    /// 把一个 SseEvent 翻译成 0..N 个 DeltaEvent,并喂给 sink
    fn feed(&mut self, ev: &SseEvent, sink: &mut ParseSink) -> Result<()> {
        let Some(event) = ev.event.as_deref() else { return Ok(()); };
        let v: Value = serde_json::from_str(&ev.data)
            .map_err(|e| AgentError::Llm(format!("Anthropic SSE data 非 JSON: {e}")))?;

        match event {
            "message_start" => {
                let msg = &v["message"];
                let usage = &msg["usage"];
                sink.feed(DeltaEvent::InputUsage {
                    input_tokens: usage["input_tokens"].as_u64().unwrap_or(0) as u32,
                    cache_read: usage["cache_read_input_tokens"].as_u64().unwrap_or(0) as u32,
                    cache_creation: usage["cache_creation_input_tokens"].as_u64().unwrap_or(0) as u32,
                })?;
            }
            "content_block_start" => {
                let block = &v["content_block"];
                let kind = block["type"].as_str().unwrap_or("").to_string();
                self.block_index = v["index"].as_u64().unwrap_or(0) as u32;
                self.block_kind = Some(kind.clone());
                if kind == "tool_use" {
                    let id = block["id"].as_str().unwrap_or("").to_string();
                    let name = block["name"].as_str().unwrap_or("").to_string();
                    self.block_id = Some(id.clone());
                    self.block_name = Some(name.clone());
                    sink.feed(DeltaEvent::ToolCallStart { id, name })?;
                }
            }
            "content_block_delta" => {
                let delta = &v["delta"];
                match delta["type"].as_str() {
                    Some("text_delta") => {
                        if let Some(text) = delta["text"].as_str() {
                            sink.feed(DeltaEvent::TextDelta(text.to_string()))?;
                        }
                    }
                    Some("input_json_delta") => {
                        if let Some(pj) = delta["partial_json"].as_str() {
                            sink.feed(DeltaEvent::ToolCallJsonDelta(pj.to_string()))?;
                        }
                    }
                    // thinking_delta / signature_delta 本期忽略
                    _ => {}
                }
            }
            "content_block_stop" => {
                if self.block_kind.as_deref() == Some("tool_use") {
                    sink.feed(DeltaEvent::ToolCallEnd)?;
                }
                self.block_kind = None;
            }
            "message_delta" => {
                let usage = &v["usage"];
                if let Some(out) = usage["output_tokens"].as_u64() {
                    // 覆盖式累计
                    sink.usage.output_tokens = out as u32;
                }
                if let Some(sr) = v["delta"]["stop_reason"].as_str() {
                    sink.feed(DeltaEvent::Stop { stop_reason: Some(sr.to_string()) })?;
                }
            }
            "message_stop" => {
                // 终止哨兵;若 message_delta 已 Stop 过,这里幂等
                sink.feed(DeltaEvent::Stop { stop_reason: sink.stop_reason.clone() })?;
            }
            "ping" => {}
            "error" => {
                let msg = v["error"]["message"].as_str().unwrap_or("unknown").to_string();
                sink.feed(DeltaEvent::Error(msg))?;
            }
            _ => {}
        }
        Ok(())
    }
}
```

要点:

- `output_tokens` 是**累计值**,直接覆盖;不维护自身 delta。
- `message_delta` 可能先于 `message_stop` 给 `Stop`;`message_stop` 再来一次也幂等(`ParseSink` 用 `errored.is_some()` 防止重复 emit)。
- 真正的错误流(`event: error`)由 `sink` 在 `finish()` 时返回 `Err`。

### 3.2 OpenAI

```rust
// openai.rs (内部)
struct OpenAiParser {
    /// 记录"当前正在累积哪个 tool_call (按 chunk 里的 index)"
    in_flight: HashMap<u32, InFlightToolCall>,
    /// 保持 chunk index 顺序
    order: Vec<u32>,
    finish_reason: Option<String>,
}

struct InFlightToolCall {
    id: String,
    name: String,
    json_buf: String,
}

impl OpenAiParser {
    fn feed(&mut self, ev: &SseEvent, sink: &mut ParseSink) -> Result<()> {
        let data = ev.data.trim();
        if data == "[DONE]" {
            sink.feed(DeltaEvent::Stop { stop_reason: self.finish_reason.take() })?;
            return Ok(());
        }
        let v: Value = serde_json::from_str(data)
            .map_err(|e| AgentError::Llm(format!("OpenAI SSE data 非 JSON: {e}")))?;

        // 尾部 usage chunk(可能在 [DONE] 之前)
        if v.get("usage").map(|u| !u.is_null()).unwrap_or(false) {
            let u = &v["usage"];
            sink.feed(DeltaEvent::InputUsage {
                input_tokens: u["prompt_tokens"].as_u64().unwrap_or(0) as u32,
                cache_read: u["prompt_tokens_details"]["cached_tokens"].as_u64().unwrap_or(0) as u32,
                cache_creation: 0,
            })?;
            if let Some(out) = u["completion_tokens"].as_u64() {
                sink.usage.output_tokens = out as u32;
            }
        }

        // 文本 + tool_calls + finish_reason
        if let Some(choices) = v["choices"].as_array() {
            for c in choices {
                let delta = &c["delta"];
                if let Some(text) = delta["content"].as_str() {
                    if !text.is_empty() {
                        sink.feed(DeltaEvent::TextDelta(text.to_string()))?;
                    }
                }
                if let Some(tcs) = delta["tool_calls"].as_array() {
                    for tc in tcs {
                        let idx = tc["index"].as_u64().unwrap_or(0) as u32;
                        let entry = self.in_flight.entry(idx).or_insert_with(|| {
                            if !self.order.contains(&idx) { self.order.push(idx); }
                            InFlightToolCall { id: String::new(), name: String::new(), json_buf: String::new() }
                        });
                        if let Some(id) = tc["id"].as_str() { entry.id = id.to_string(); }
                        if let Some(name) = tc["function"]["name"].as_str() { entry.name = name.to_string(); }
                        if let Some(args) = tc["function"]["arguments"].as_str() {
                            entry.json_buf.push_str(args);
                        }
                    }
                }
                if let Some(fr) = c["finish_reason"].as_str() {
                    self.finish_reason = Some(fr.to_string());
                }
            }
        }
        Ok(())
    }

    fn finish(self, sink: &mut ParseSink) -> Result<()> {
        // 把累积的 in_flight tool_calls 按 order 灌入 sink
        for idx in &self.order {
            if let Some(call) = self.in_flight.get(idx) {
                sink.feed(DeltaEvent::ToolCallStart {
                    id: call.id.clone(),
                    name: call.name.clone(),
                })?;
                if !call.json_buf.is_empty() {
                    sink.feed(DeltaEvent::ToolCallJsonDelta(call.json_buf.clone()))?;
                }
                sink.feed(DeltaEvent::ToolCallEnd)?;
            }
        }
        Ok(())
    }
}
```

要点:

- OpenAI 中"工具调用开始"通过 `delta.tool_calls[].id`/`function.name` 出现时触发 `ToolCallStart`,因此解析器不主动 emit `ToolCallStart`,而是在收完所有 chunk 后由 `finish()` 把所有 `in_flight` 一次性 flush 给 sink。这样**能容忍乱序**(以 `index` 为 key 的 HashMap)。
- `ToolCallEnd` 也由 `finish()` 在每个 tool_call 之后发一次,让 sink 知道完整 JSON 已就绪。
- `InputUsage` 的两个来源:message_delta / 尾部 usage chunk。前者会出现多次(sink 覆盖),后者覆盖即用。

## 4. ParseSink 行为细节

```rust
impl ParseSink {
    pub fn feed(&mut self, ev: DeltaEvent) -> Result<()> {
        match ev {
            DeltaEvent::InputUsage { input_tokens, cache_read, cache_creation } => {
                // 覆盖式:message_start 给一次,后续可能由 usage chunk 覆盖
                self.usage.input_tokens = input_tokens;
                self.usage.cache_read_input_tokens = cache_read;
                self.usage.cache_creation_input_tokens = cache_creation;
            }
            DeltaEvent::TextDelta(s) => self.text.push_str(&s),
            DeltaEvent::ToolCallStart { id, name } => {
                let key = (self.next_block_index, id.clone());
                self.in_flight.insert(key.clone(), InFlightToolCall { id, name, json_buf: String::new() });
                self.next_block_index += 1; // 单调递增;OpenAI 也用同一计数
            }
            DeltaEvent::ToolCallJsonDelta(s) => {
                // 找到"最近一个还没 End 的 in_flight"
                if let Some((_, v)) = self.in_flight.iter_mut().find(|(_, v)| v.json_buf.is_empty() && /* 最近一个 */) {
                    v.json_buf.push_str(&s);
                } else if let Some(last_key) = self.last_in_flight_key() {
                    self.in_flight.get_mut(&last_key).unwrap().json_buf.push_str(&s);
                }
            }
            DeltaEvent::ToolCallEnd => {
                // 把"最近一个 in_flight" 标记完成并尝试 parse json_buf → 输出到 ordered list
                if let Some(key) = self.last_in_flight_key() {
                    if let Some(call) = self.in_flight.remove(&key) {
                        let args = serde_json::from_str(&call.json_buf)
                            .unwrap_or_else(|_| json!({ "_raw": call.json_buf }));
                        self.tool_calls.push(ToolCallReq { id: call.id, name: call.name, arguments: args });
                    }
                }
            }
            DeltaEvent::Stop { stop_reason } => {
                self.stop_reason = stop_reason;
                self.finished = true;
            }
            DeltaEvent::Error(msg) => {
                self.errored = Some(msg);
            }
        }
        Ok(())
    }

    pub fn finish(self) -> Result<Completion> {
        if let Some(msg) = self.errored {
            return Err(AgentError::Llm(format!("upstream SSE error: {msg}")));
        }
        // 收尾时把尚未 ToolCallEnd 的 in_flight 也强 parse 一次(防止上游没发 stop_signal)
        // (略)
        Ok(Completion {
            text: self.text,
            tool_calls: self.tool_calls,
            usage: self.usage,
            stop_reason: self.stop_reason,
        })
    }
}
```

**为什么允许 `ToolCallEnd` 重复**:`message_stop` 会再来一次 `Stop`,sink 只在第一次记录 `stop_reason`,后续幂等。

## 5. 请求侧改造

### 5.1 Anthropic

```rust
let resp = self.http.post(&self.url).headers(headers).json(&req).send().await?;
let status = resp.status();
if !status.is_success() {
    let body = resp.text().await.unwrap_or_default();
    return Err(AgentError::Llm(format!("HTTP {status}: {body}")));
}
let mut sse = SseStream::with_max_buffer(64 * 1024);

let mut sink = ParseSink::new();
let mut byte_stream = resp.bytes_stream();
use futures_util::StreamExt;
while let Some(chunk) = byte_stream.next().await {
    let bytes = chunk.map_err(|e| AgentError::Llm(format!("SSE 传输中断: {e}")))?;
    for ev in sse.push(&bytes)? {
        parser.feed(&ev, &mut sink)?;
        if sink.finished() { break; }
    }
}

    parser.feed(&ev, &mut sink)?;
}

```

### 5.3 依赖决策

`reqwest::bytes_stream()` 依赖 `futures-util` 的 `Stream` trait。**两种方案**:

| 方案 | 代价 | 备注 |
|------|------|------|
| A. 增加 `futures-util` 依赖 | +1 crate,但写法标准 | `reqwest` 的 stream 默认 feature 不提供 `StreamExt::next()` |
| B. 手写 poll: `tokio::time::timeout` + `resp.chunk()` 阻塞读 | 0 新依赖,代码略繁琐 | `reqwest::Response::chunk()` 自带超时控制 |

**选 B**(符合 CLAUDE.md "不引入新 crate" 的精神):

```rust
loop {
    match resp.chunk().await {
        Ok(Some(bytes)) => {
            for ev in sse.push(&bytes)? { ... }
        }
        Ok(None) => break,  // EOF
        Err(e) => return Err(AgentError::Llm(format!("SSE 传输中断: {e}"))),
    }
}
if let Some(ev) = sse.finish()? { parser.feed(&ev, &mut sink)?; }
sink.finish()
```

> 注:CLAUDE.md "不引入新 crate" 是针对 `tui/` 的;llm 模块原则相同。若团队后续想用 SSE 多路复用,再切回方案 A。

## 8. 兼容性 & 回退

- `LlmClient::complete()` 签名**不变**(返回值类型 `Completion` 也不变,仅多字段)。
- `agent::Agent::run_session` / `run_once` 的返回值类型变化 — 已在 §6 列出 3 处同步点。
- `NoopLlm::complete` 增加 `usage: Default::default()`。
- 若某中转网关在 `stream: true` 时**仍返回整段 JSON**,`SseStream::push()` 把整个 JSON 当成一行 `data:`,后续 `serde_json::from_str` 失败 — 协议 parser 失败时返回 `AgentError::Llm`,**不会**丢已有行为(以前是直接 `text()` + 解析,本次失败时反而比旧路径更精确)。

  缓解策略:**失败**后,`LlmClient::complete()` 不再自动 fallback(避免静默);
  若后续需要,可以扩展 `client_from_record` 增加 `stream_fallback: bool` 字段。

## 10. 性能与稳定性

- **零拷贝拼接**:`text` 拼接走 `String::push_str`(`reqwest` body 已经是 `Bytes`,直接喂给 `SseStream::push`)。
- **行缓冲**:`buf: Vec<u8>` 容量默认 64 KiB,超限即报错并提前终止流(避免恶意 / 故障上游把内存吃光)。
- **JSON 解析成本**:每个 chunk 调一次 `serde_json::from_str`,对 1k tokens 输出 ≈ 几十次调用,可接受;若后续成为瓶颈,把"纯 data: {...}"的 JSON 解析改为 `serde_json::Deserializer::from_slice(&data).into_value()` 增量消费,但**本期不做**。
- **tracing**:`info!` 仅记录(协议, event_count, usage);`debug!` 记录每个事件类型(便于排错但默认不打开)。
