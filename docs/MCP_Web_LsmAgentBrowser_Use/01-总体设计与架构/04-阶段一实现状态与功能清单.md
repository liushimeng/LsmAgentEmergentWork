## 十、已知边界（阶段一）

1. ~~**不执行页面自身脚本**~~ → 阶段二第一步已补齐(内联/外链/注入多轮)。
2. **无原生窗口**：`headed` 回退无头；人工可视化在阶段三。
3. **简化布局/渲染**：截图按块级流式布局绘制，与真实浏览器视觉不一致；自动化优先用 selector 而非坐标。
4. **OCR 为布局文本**：不是像素 OCR；验证码识别需要阶段五接入真实 OCR/视觉模型。
5. ~~**JS 为快照桥**~~ → 阶段二起 eval_js 走持久线程(全局保留、DOM 修改回写);快照桥保留为回退。
6. ~~**CSS 子集**~~ → 阶段二第二步已补齐级联/继承/单位/媒体查询/`var()`;动画、过渡、伪元素仍 ⏳。
7. **无缓存/无子资源加载**：每次导航重新请求主文档;外链 `<script>` 会加载,图片/样式资源仍不自动拉取(阶段四)。
8. **V8 未启用**：默认 Boa；`rusty_v8` 预编译产物需可访问 GitHub Releases。
