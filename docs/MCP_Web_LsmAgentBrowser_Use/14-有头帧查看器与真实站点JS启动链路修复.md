# 14 - 有头帧查看器与真实站点 JS 启动链路修复

**轮次**:2026-10-21(百度地图任务实测驱动) · **提交**:7389dbc

## 一、有头帧查看器(`src/agent/browser/view/`)

### 架构

```
LsmAgentBrowser 引擎进程(零 UI 依赖)
   │ render.rs 软件渲染(RGBA→PNG)
   │ view::ViewSink(stdin 长度前缀帧协议,写失败静默降级)
   ▼
laew __browser-view 查看器子进程(隐藏子命令,与 __hitl-dialog 同模式)
   ├─ macOS:AppKit FFI(NSWindow+NSImageView+NSTimer 100ms 轮询帧槽)
   └─ Windows:Win32(RegisterClass+WM_TIMER+StretchDIBits 32bpp DIB)
```

### 帧协议(stdin,小端)

`[u32 总长][u8 kind][payload]`;kind `'i'`=PNG、`'t'`=标题 JSON、`'c'`=关闭。

### 关键决策

| 决策 | 理由 |
|------|------|
| 子进程而非引擎线程跑 UI | AppKit/Win32 事件循环不进 tokio;崩溃隔离;与 HITL 弹窗同一铁律 |
| 默认档按交互性判定 | `LAEW_BROWSER_MODE` 未设置时:stdin/stdout 均 TTY → `headed`(终端用户直接看到窗口);管道/cargo test/CI → `hidden`(零影响)。显式 env 仍精确覆盖 |
| 查看器失败静默降级 | spawn/写管道失败 → 纯无头,工具行为完全不受影响 |
| 推帧时机 | open/navigate 完成布局后、JS 动作应用重排后、视口变更、滚动、截图顺带(所见即所得) |
| 窗口尺寸单一真源 | 内容尺寸=视口 argv,**永不回读**窗口 frame(human_ui 第 137 轮铁律同源) |

## 二、JS 启动链路七处根治(通用性 bug,非站点特判)

| # | 根因 | 修复 |
|---|------|------|
| 1 | 外链脚本每轮重复执行(`executed` 只记内联,不记外链 URL)→ 页面启动时序被重复初始化破坏 | collect_scripts 按 URL 指纹去重 + 管线执行后记账;轮次 24→64、预算 20s→40s(`LAEW_WEB_SCRIPT_PIPELINE_MS` 可调) |
| 2 | `__lsmRefresh` 每次请求把 readyState 打回 "loading" | 删除该重置;生命周期属页面会话,换页重建线程天然回 loading |
| 3 | Boa 0.20 `for(x in null)` 违反规范抛错(应零次迭代) | `for_in_guard.rs` 源码级等价改写 `for(H in E)→for(H in (E||{}))`,字符串/注释安全,7 组单测;管线脚本+fetch JS 响应体双入口 |
| 4 | 快照元素缺 `ownerDocument.defaultView`(标准取样式路径断) | `__mk`/`__newEl` 补 ownerDocument,`document.defaultView=window` |
| 5 | DOM 写入延迟可见(appendChild 后 children[0] undefined) | `__mk` 动态子节点覆盖层(dynKids/htmlCleared);detached 工厂 children 反射 __kids |
| 6 | 缺 insertAdjacentHTML/getElementsByTagName;className 赋值不回传宿主 | 两工厂补齐;className 反射 class 属性并推 set_attr |
| 7 | AMD 装载器缺 CommonJS 特殊依赖注入(require/exports/module);resourceMap 忽略 pkg;URL 双重 `.js` | 按 AMD 约定注入+导出合并优先级;pkg→包 URL;`.js` 结尾不重复拼接 |

配套:`__lsmRunScript` 执行包装(JS 侧 catch e.stack 回传,压缩脚本可定位);
`element_json` 文本复用 `visible_text_of`(inspect 不再泄漏 script 源码)。

## 四、已知剩余缺口(下一轮目标 R13)
