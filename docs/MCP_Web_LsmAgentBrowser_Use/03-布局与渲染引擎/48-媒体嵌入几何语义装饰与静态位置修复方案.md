# 48-媒体/嵌入几何、语义装饰与绝对定位静态位置修复方案

> 2026-10-30 | `src/agent/browser/layout/`、`src/agent/browser/style/values.rs`、`src/agent/browser/images.rs`
>
> 本轮只补「可见显示异常」：媒体/嵌入控件不再塌成错误盒、语义装饰可见、
> `absolute` 无 inset 时取静态位置。Shadow DOM / sticky / CSS 动画仍列为后续路线。

## 一、问题现象

| 现象 | 旧行为 | 根因 |
| --- | --- | --- |
| `<video width=320 height=180>` 整体错位 | 盒约 `22×16` | `video/audio/object/embed` 未进替换元素口径，只按普通行内近似 |
| `<video poster=…>` 播放器首帧空白 | 只有空盒 | 图片预取链只扫 `<img>`/CSS `url(...)`，poster 不进 `ImageStore` |
| `<iframe>`/`<svg>`/`<object>` 空盒与「页面本身空白」分不清 | 纯白板 | 无能力边界占位 |
| `<hr>` 水平线消失 | 0 高无边框 | 通用块级路径 `content_h=0`，UA 无专用绘制 |
| `<fieldset>` 无边框、`<legend>` 逐字 inline | 语义结构不可见 | UA 样式缺 fieldset 边框/legend 块级 |
| `<del>/<ins>/<u>/<abbr>/<mark>` 与 Chrome 差异大 | 只有纯文本 | 文本装饰只解析进 `extra`，渲染层无消费者 |
| `position:absolute` 无 `left/top` 的角标贴包含块左上角 | 与 Chrome 静态位置不符 | `layout_abs` 直接取 `(cx,cy)` |

## 二、本轮落地

### 2.1 媒体/嵌入替换元素口径

- `layout/helpers.rs::is_replaced_tag_name`：新增 `video | audio | object | embed`。
- `layout/mod.rs::replaced_size`：媒体/嵌入缺省固有尺寸 `300×150`；HTML `width/height` 与 CSS 尺寸照旧优先。
- `layout/inline.rs`：媒体/嵌入走行内原子盒（占宽、断行、基线对齐），不再退化成普通行内近似。
- `images.rs::collect_image_urls`：补 `video[poster]` / `object[data]` / `embed[src]` 预取。

### 2.2 空盒能力边界占位

- 新增 `DisplayKind::MediaFrameNote { pale, tag }`。
- `emit_element` 对 `iframe/svg/video/object/embed` 在无像素时发射淡底虚线占位，文案点明「子文档/媒体/SVG 光栅化未实现」，避免与真实空白混淆。
- `video[poster]` 已解码时走既有 `object-fit` 贴图路径。

### 2.3 语义装饰与高亮

- `TextLine` / `InlineRun` 增加 `decor: TextDecor` 与 `highlight`。
- `TextDecor::from_css` 解析 `line-through` / `underline` / `underline dotted`。
- UA 语义：`del|s|strike` 删除线；`u|ins` 下划线；`abbr` 虚线下划线；`mark` 高亮背景。
- 新增 `DisplayKind::TextDecor`，光栅层按基线补画装饰线。
- `summary` 补 disclosure triangle（复用 `WidgetGlyphKind::Caret`）。

### 2.4 UA 缺省样式补齐

- `hr`：上边框 + 灰底 + `height:2px` + 上下 margin，不再 0 高。
- `fieldset`：四边边框 + padding + 上下 margin；`legend` 纳入块级并给左右 padding。
- `blockquote` / `figure` 补左右 `40px` 缩进；`dd` 补左 `40px`。
- `address` 记 `font-style:italic` 到 extra（斜体字形链未就绪，不伪造斜体）。

### 2.5 绝对定位静态位置

- 新增 `DeferredBox { node, style, static_x, static_y }`。
- `layout_children` 在收集 absolute/fixed 时记录 `(pen + margin_left, self.y + margin_top)`。
- `position::layout_abs` 无 `left/right` 时取 `static_x`；无 `top/bottom` 时取 `static_y`。
- flex/grid 的 deferred 收集同步改为 `DeferredBox`。

## 四、边界与后续

- 仍不实现音视频解码/播放器控件、iframe 子文档隔离、SVG path/text 光栅化。
- `sticky` 仍按 `relative`；CSS `transition`/`@keyframes` 仍无帧插值。
- Shadow DOM / Web Components 仍是硬缺口，单独立项。
