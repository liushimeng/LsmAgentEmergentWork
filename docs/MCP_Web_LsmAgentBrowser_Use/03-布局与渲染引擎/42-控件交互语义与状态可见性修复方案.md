# 42 - 控件交互语义与状态可见性修复方案

## 一、背景

第 41 轮已经把控件内置 UI、运行时伪类、表格格式化上下文、dialog/select 顶层浮层与列表 marker
落到真实布局与像素。第 42 轮针对《Web 端控件全量清单与渲染设计要点》复核后发现:**继续新增控件
图元之前,必须先修已落地链路里的实际断点**:

1. `DisplayItem.layer` 已有顶层档位,但终排仍以 `z` 为第一键,高 `z-index` 定位广告层可以盖住
   `dialog` / `select` 面板;
2. 页面脚本 `dialog.showModal()` / `close()` 被定义成存取器属性,真实调用会拿到 `undefined` 并抛
   `TypeError`,标准模态链路不可用;
3. `:indeterminate` 只有 JS 选择器口径,Rust 样式引擎不匹配,`input:indeterminate + label` 失效;
4. `:active` 点击后滞留、`:hover` 不命中祖先链、页面脚本 `focus()` 不进伪类状态;
5. select 浮层只是视觉预览:点击控件不展开、点击 option 不选中、选中项按重复 label 高亮、option
   没有几何盒;
6. 行内 button/textarea 文本重复绘制,长 placeholder 固有宽只有 40px,`input[type=image` 是空边框;
7. inspect 只暴露字符串 `value` 与内核私有 `data-lsm-*` 属性,没有一等控件状态字段。

本轮全部复用既有架构,不另起第二套状态模型:

```
TabState.form_values / widget_open / pseudo_states
    -> Document::apply_widget_state(临时解析树属性覆盖)
    -> StyleEngine + layout/widgets + layout/top_layer
    -> DisplayItem(z / layer / seq / rank)
    -> raster / screenshot / inspect
```

状态口径沿用第 40/41 轮:**只有 DOM 可见或动作返回成功不算「显示已实现」**,必须核对
DOM/inspect、几何布局、像素绘制、Agent 交互、默认行为、JS 状态同步与自动化测试。

标记含义:

- ✅ 已实现并有测试;
- 🆕 本轮新增/修复;
- 🟡 部分实现,必须读边界;
- ⛔ 未实现;
- 🚫 本轮明确非目标。

## 二、本轮修复与新增

### F1 顶层绘制排序修复(P0)

| 能力 | 语义 | 状态 |
| --- | --- | --- |
| 绘制大层 `paint_tier` | 常规流 `0` / 定位层 `1` / 顶层 `2`;负 `z-index` 定位内容沉回常规流档 | 🆕 |
| top layer 压过普通 z | `dialog` / `select` 面板最后绘制,高 `z-index` 定位兄弟不能遮挡 | 🆕 |
| 负 z 沉底近似 | `z < 0` 的定位项仍先于常规流绘制,不因 layer=1 被整档抬高 | 🆕 |

落点:`src/agent/browser/render/display.rs::DisplayItem::paint_tier`、`sort_items`。
排序键为 `(paint_tier, z, layer, seq, rank)`,稳定排序保持同键发射序。

### F2 dialog 方法桥修复(P0)

| 能力 | 语义 | 状态 |
| --- | --- | --- |
| `dialog.showModal()` | 写 `open` + `data-lsm-modal`,进入顶层并铺 `::backdrop` | 🆕 |
| `dialog.show()` | 只写 `open`,非模态显示,不铺遮罩 | 🆕 |
| `dialog.close()` | 移除 `open` 与 `data-lsm-modal` | 🆕 |
| 阶段一回退桥 | `js.rs` 同步提供三个普通函数,两套 JS 环境不漂移 | 🆕 |

落点:`script/prelude.rs::__mk`、`js.rs::__mk`。方法必须是普通函数属性;第 41 轮的
defineProperty 存取器写法会让 `dialog.showModal()` 调用 getter 返回值而不是方法。

### F3 `:indeterminate` 样式命中(P0)

- Rust 选择器新增 `Pseudo::Indeterminate`;
- `input` / `progress` 按 `indeterminate` 属性匹配,与 JS 选择器桥同口径;
- 特异性计入伪类列。

落点:`style/selector.rs`。页面脚本 `el.indeterminate = true` 继续经既有 `set_attr` /
`remove_attr` 动作写宿主 DOM。

### F4 指针与焦点状态语义(P1)

| 能力 | 语义 | 状态 |
| --- | --- | --- |
| hover 祖先链 | 目标与全部祖先同时命中 `:hover`,支持 `.parent:hover .child` | 🆕 |
| active 生命周期 | 点击分发期间可见,动作收尾释放(mouseup 语义),不再永久滞留 | 🆕 |
| 页面脚本 focus/blur | 与工具 `focus` / `blur` 一样写 `pseudo_states`,样式与截图立即可见 | 🆕 |
| upload 后重排 | `upload_file` 写入文件名后立即重排推帧,截图不再停留「选择文件」 | 🆕 |
| disabled 守卫 | disabled 控件点击返回 `clicked:false + disabled:true`,不分发 JS、不执行默认行为 | 🆕 |
| readonly 守卫 | `input_text` / `clear_input` 对 readonly 输入返回 2002 | 🆕 |
| 按钮默认行为收窄 | `button[type=button|reset]`、`input[type=button|reset]` 不再触发表单提交 | 🆕 |

落点:`api.rs::set_hover_chain`、`release_active`、`click_inner`、`act_input`、`act_clear`、
`act_upload`、`apply_js_reply`。

边界:`reset` 目前只是「不提交」,尚未执行本地表单重置;disabled 有交互守卫,但控件内置图元仍

### F5 select 浮层从视觉预览升级为可选(P1)

| 能力 | 语义 | 状态 |
| --- | --- | --- |
| 点击 select | 展开/收起浮层面板,并收起其它已开面板 | 🆕 |
| 点击 option | 写入运行时值、分发 select `change`、自动收起面板 | 🆕 |
| `select_option` | 显式选择后自动移除 `widget_open` | 🆕 |
| 选中高亮 | 按 option 位置 / `selected` 属性判定,重复 label 不再高亮错项 | 🆕 |

### F6 控件几何与文本唯一绘制(P1)

| 能力 | 语义 | 状态 |
| --- | --- | --- |
| 文本输入固有宽 | value / placeholder / `size` 属性参与宽度,长提示不再挤在 40px 盒里 | 🆕 |
| textarea 固有尺寸 | `rows`(默认 2)/ `cols`(默认 20)参与固有高宽 | 🆕 |
| `input[type=image]` | 绘制 alt/value,缺省显示「图片按钮」占位,不再是空边框 | 🆕 |
| 行内控件文本唯一源 | button/textarea 等控件子文本不再被普通行内缓冲二次绘制 | 🆕 |
| 浮动控件路径 | 同样跳过子文本收集,避免控件内容脱离盒几何 | 🆕 |

落点:`layout/inline.rs::inline_box_size` / `collect_inline` / `layout_inline_float`、
`layout/widgets.rs::emit_form_control_text`。

### F7 inspect 状态可见性(P1)

`inspect(elements)` 每个元素新增一等 `state` 对象:

```json
{
  "checked": false,
  "selected": false,
  "disabled": false,
  "readonly": false,
  "indeterminate": false,
  "open": false,
  "select_open": false,
  "focused": false,
  "hovered": false,
  "active": false
}
```

- 调用方不再需要理解 checkbox 的 `value == "true"` 字符串协议;
- 也不需要从内核私有 `data-lsm-*` 属性反推运行时状态;
- 默认交互候选集纳入 `option`、`summary`、`label`、`[tabindex]`、`[contenteditable]` 与常见
  ARIA widget role,select 展开后的 option / details 开关可被默认发现。

落点:`document.rs::element_json`、`document::INTERACTIVE_DEFAULT`、`inspect.rs::inspect_elements`。

## 四、显示异常排查映射

| 现象 | 优先检查 |
| --- | --- |
| dialog/select 面板被高 z 广告层盖住 | `DisplayItem.paint_tier` 是否为 2;`sort_items` 是否以 tier 为第一键 |
| `dialog.showModal()` 报 not a function | 是否误用 defineProperty 存取器;必须在元素对象上是普通函数 |
| `showModal()` 后整页变灰 | 是否误把普通 `open` 当模态;backdrop 只看 `data-lsm-modal` |
| `input:indeterminate` 样式不生效 | `style/selector.rs` 匹配;属性是否落到临时解析树 |
| `.parent:hover .child` 不命中 | hover 是否写祖先链;inspect `state.hovered` 查父元素 |
| 点击后按钮一直保持按下态 | click 收尾是否调用 `release_active` |
| `el.focus()` 后无焦点样式 | 页面脚本 reply 是否写 `pseudo_states`;回退桥是否回写真实 tab |
| 上传后截图仍显示「选择文件」 | `act_upload` 后是否 `relayout_and_push` |
| 点击 select 不展开 | `widget_open` 是否写入;`data-lsm-select-open` 是否进临时树 |
| 点击 option 无选中结果 | 面板是否处于展开态;option 是否已有 `ElementBox` |
| 重复 label 高亮错项 | 选中判定必须按 option 位置/`selected`,不能比文本 |
| 长 placeholder 只显示几个字 | `inline_box_size` 是否计入 value/placeholder/size |
| button/textarea 文本重影 | 行内路径是否跳过控件子文本收集 |
| disabled 控件仍可操作 | click/input 入口守卫;返回应带 `disabled:true` |
| inspect 看不出控件状态 | 读 `state` 字段,不要解析 `data-lsm-*` 私有属性 |

## 六、后续路线

1. **浮层语义**:popover API、dialog focus trap、backdrop 点击关闭、`close(returnValue)`、多顶层元素栈序。
2. **select 完整形态**:multiple/size 列表、>8 行滚动、optgroup 标题、键盘导航。
3. **表单编辑态**:光标、选区、编辑历史、reset 本地重置、number 步进、range 拖拽/点击设值。
4. **控件视觉**:disabled/readonly UA 灰化、meter low/high/optimum 分段、progress 不确定态、
   `accent-color`/`color` 接入控件图元、baseline 对齐。
5. **媒体与资源**:`@import` 接入主管线、srcset/picture/currentSrc、图片圆角与 object-position、
   SVG 子集、video poster。
6. **结构性大项**:iframe 子文档、Shadow DOM/slot 分发、完整 stacking context、内部滚动容器、
   CSS 动画帧同步、DPR。
7. **性能**:脏子树、样式缓存、显示列表 diff;在正确性缺口收束后独立成轮。
