# MCP_Web_LsmAgentBrowser_Use 知识库索引

`MCP_Web_LsmAgentBrowser_Use` 工具的底层是 **LsmAgentBrowser**——一个**进程内自研浏览器内核**
（HTTP(S) 网络栈 / DOM / CSS / 布局 / 软件渲染 / JS 执行全部在本进程，**没有 Chrome、没有 CDP、没有外部浏览器进程**）。
本目录是内核 + 兼容层 + 阶段路线图 + 站点实战根因的完整知识库。

## 阅读顺序建议

1. 先读 `01-总体设计与架构/01-总体设计与分阶段路线图.md`（全局地图）与 `01-总体设计与架构/03-MCP_Web_LsmAgentBrowser_Use兼容层设计.md`（工具契约）。
2. 涉及真站问题，**先在 `06-站点实战根因/` 里搜站点名**（百度地图 / liepin / zhipin），命中即按该篇的根因链排查，勿重复试错。
3. 仍无结论，按现象进 `02`/`03`/`04`/`05` 对应分册；每册 `README.md` 有本册文档一句话索引。

## 约定

- 文件名前缀数字 = **开发轮次顺序**（历史沿革），不是章节号；`21b` / `34b` 为同轮次并列篇。

- 真站实测结论受时间与风控策略影响，**不复测的结论会显式标注「按停测要求未继续」**。
