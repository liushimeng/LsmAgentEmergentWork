# 21 - Boa 0.22 升级与重站点异步模块启动链修复

**轮次**:2026-10-23(第 178 轮,百度地图路线规划实测驱动)

## 一、现象

`https://map.baidu.com/` 在本内核里:外壳(搜索框/路线按钮)可见、可点击,但

* `#MapHolder` 只有 `#platform` + `#mask` + 空 div,没有瓦片、没有缩放控件;
* `document.body.innerText` 只有「百度地图」4 字;
* `window.map` 已构建、`map.getCenter()/getZoom()` 正常、`map.loaded=true`、
  `tileMgr.tileLayers.length=1`,瓦片 URL(`getTilesUrl`)也能生成;
* 瓦片层的 `tilesDiv` 已在 JS 侧建成(18 个子节点),但 `parentNode` 为空、
  宿主 DOM 里看不到。

结论:**不是地图构造失败,而是异步模块装载链与动态子树回写链先后断掉**。

## 二、根因

### 2.1 Boa 直接 eval 缺陷(主因)

百度地图的模块装载器 `cG.run` 用**直接 eval**执行模块代码,依赖 `initmap`
闭包变量(`aI` / `x` / `aV` 等):

```js
run: function(id, code) {
  try { eval(code) } catch (e) { return }   // 异常被吞
  ... // 标记 COMPLETED、触发回调
}
```

| 版本 | 行为 |
|------|------|
| Boa 0.20 | 直接 eval 解析闭包变量时 **panic**:`index out of bounds: the len is 0 but the index is 0` |
| Boa 0.21 | 单次闭包读取可用;但**同一函数作用域内第二次 eval 声明同名 `var`** 抛 `ReferenceError: cannot assign to uninitialized binding`。BMap 的 `oppc` / `control` 模块会被重复装载,正好命中 |
| Boa 0.22 | 两类问题均修复(实测 `f("var q=1"); f("var q=2")` 连续 eval 通过) |

因为 `cG.run` 自己 `try/catch` 吞错,上层只看到「模块没加载」的静默失败。

### 2.2 首屏脚本预算与 JS 事件循环 deadline 不一致

* `run_scripts` 末尾的 `event_loop()` 用 `LAEW_WEB_SCRIPT_BUDGET_MS`(默认 10s)
  作为 JS 侧 deadline。百度首屏 60+ 脚本执行常超过 10s,脚本跑完时 deadline
  已过 → `cG.load` 里的 `setTimeout(...,1)` 永不执行 → `getjsmods` 异步模块
  脚本从不注入。
* `JsHandle::request` 同样按 10s 等整批 RunScripts,重站点会被误判超时。

### 2.3 缺失浏览器全局

* 反爬脚本 `abclite-2059-s.js` 读 `window.Document.prototype.createElement`;
  缺 `Document` 构造器时属性链在 `undefined` 上取成员 → `TypeError: cannot
  convert 'null' or 'undefined' to object`,整段脚本中断,`SECKEY` 不落地。
* 站点脚本直接 `new MouseEvent(...)` / `new KeyboardEvent(...)`,此前
  `ReferenceError`。

### 2.4 `new Image()` 没有 load 语义

BMap 瓦片/图标装载器全部依赖
`new Image; img.onload = ...; img.src = url` 推进。旧实现是纯数据对象,
`onload` 永不触发;`<img>` 动态元素也没有 load 事件。

### 2.5(剩余)动态子树不回写宿主 DOM

游离元素挂载后继续 `appendChild` 只进 JS 局部子树(`__newEl` 的
`appendChild` 刻意不产生宿主动作),瓦片 `tilesDiv` 的 18 个子节点因此
全部停留在 JS 侧。这是渲染层下一阶段工作,见 §五。

## 四、验证(2026-10-23)

真实站点探针(Boa 0.22):

* `abclite` 不再报错,`window.SECKEY` 落地;
* `cG.load` → `/?qt=getjsmods...` 真实请求发出(状态 200);
* `_jsload('oppc', 41648 字符)` / `_jsload('control', 34641 字符)` 均被调用,

* `BMap` / `map` / `tileMgr` / `stdMapCtrl` 全部构建;
  `map.getTilesUrl({x:1,y:1},12)` 返回
  `https://maponline2.bdimg.com/tile/?qt=vtile&x=1&y=1&z=12&...`;
* 宿主 DOM 仍无瓦片/控件 → 由 §2.5 动态子树回写缺口解释。

`cargo test --lib`:2376 passed;5 个集成测试文件 60 passed。
