# 31 - 猎聘登录链路五根因与交互脚本预算修复

> 对应方案:`tmpPlan/20261028_110816_猎聘登录链路布局吞噬与交互脚本预算修复.md`
> 场景:第 174 轮真机(`Dir_LsmAgentBrowser_liepin_03`,`--debug -f` 内置浏览器采集任务),
> wf-1「人工登录猎聘」16 分钟未破:登录弹层永远不出现、入口 0×0、探测 API 集体误导。

## 一、诊断顺序与证据

1. 时间线:`open`(76s,200)→ 控制台 138 条事件中出现
   **`脚本管线达到墙钟预算(8000ms),已停止继续取回模块`** → SubAgent 14 轮探测全部落空。
2. `SPAN#header-quick-menu-login` **0×0**、父 LI **1px 宽**:合成事件五连发与原生
   `s.click()` 都打不开弹层 —— 点击坐标 (1,1) 落在死区。
3. **离线二分定位**(真站 HTML+CSS 落盘 → 单测复现 → 规则级删除最小化):
   45 条 header 规则即可复现,最小杀死规则对只有 2 条 ——
   `position:relative` 的 LI + `position:absolute;right:30px` 的无宽 `<svg>` 徽标。
   与 JS 无关,纯 CSS 布局缺陷。
4. 机制:`measure_content` 以 `MAX_CONTENT_WIDTH=100000` 为语境调 `layout_deferred`,
   脱流 svg 盒坐标 = 100000−30−28 = **99942**;flex 条目基础宽聚合把该盒当内容
   (`b.x + b.w`)→ 基础宽 ≈ 99970 → flex 收缩把后续条目压到 **1.19px**(x=1910 出视口)。
5. 同轮发现的伴生缺口(全部有真机证据):
   - `performance.getEntriesByType('resource')` 是空数组桩 → 误判「0 个脚本加载」;
   - `document.createTreeWalker` / `document.createRange` 未实现 → 探测脚本直接断;
   - `Array.from(el.attributes)` 在 Proxy get 陷阱 `Number(Symbol)` 处 TypeError;
   - 每条 eval_js 25-35s(每次全价支付图片扫描+全量重排+8s 补齐管线);
   - 跨域 iframe(wow.liepin.com 页脚模板,曾被误判为登录页)0×0 且无能力边界告知;
   - SVG data-URL 图标全部「图片解码失败」刷屏,woff 字体也被塞进图片解码器。

## 二、修复(全部为通用浏览器语义,无站点特判)

### 1. 脱流元素不参与内在尺寸(布局正确性)

- `ElementBox` 新增 `out_of_flow` 标记:`position.rs::layout_abs` 发射的 abs/fixed 盒
  及其注入片段盒统一置真;
- 五处内在尺寸聚合点(flex 行主轴基础宽 / flex 列交叉宽 / grid 条目宽 /
  `layout_abs` 自身 content_w / 行内块 auto 宽)跳过 `out_of_flow` 盒;
- 渲染零变化:脱流盒照常发射、照常 translate 注入,只是不再喂给尺寸求解。
- 回归:`绝对定位徽标不吞噬flex后续条目`(猎聘真实结构最小复现)。

### 2. 交互脚本补齐预算 8s→30s、12→24 轮,截断可见

- `api.rs::interaction_budget_ms()`:`LAEW_WEB_SCRIPT_INTERACT_MS` 覆盖(下限 2000),
  默认 30s;重站懒加载 chunk 链(登录弹层/hero 组件)一次装完,不再反复截断;
- `PipelineOut` 新增 `budget_cut` / `pending_scripts`(截断时统计剩余脚本数);
- `eval_js` 结果、`inspect(info=page_health)` 均带 `script_pending` / `script_budget_cut`,
  page_health 对截断态给出明确诊断(「加载中而非故障,先 wait 再试」)。

### 3. eval 提速:变更检测短路

- `apply_js_reply`:DOM html 未变化的 eval 跳过图片扫描与全量重排
  (纯读取探测占 Agent 操作大头,重页单条 eval 25-35s → 亚秒级);
- `run_pending_scripts`:先做一次廉价「解析+收集」预检,无待执行脚本直接返回,
  不再空转管线;有待执行脚本才用 30s 预算跑完。

### 4. 诊断 API 补齐(PRELUDE)

- `performance.getEntriesByType('resource'|'response')` 由宿主网络台账
  (`tab.network` 最近 120 条 → `PageEnv.resources` → `__lsmMeta.resources`)注入,
  含 name/duration/transferSize/responseStatus;`getEntries` / `getEntriesByName` 同源;
- `document.createTreeWalker` / `createNodeIterator`:快照索引树文档序遍历,
  SHOW_TEXT 合成伪文本节点(快照文本合并存储,逐段还原不现实,文档化近似),
  TreeWalker 支持 nextNode/previousNode/parentNode/firstChild/nextSibling;
- `document.createRange`:selectNode/selectNodeContents + getBoundingClientRect
  (文本节点取父盒近似)+ getClientRects;
- `__attrMap` 补 `Symbol.iterator`(Attr 形状),Proxy get 陷阱对 symbol 键
  提前返回,不再 `Number(Symbol)` 抛错。

### 5. 能力边界如实上报

- `<iframe>` 按替换元素参与布局,无 CSS/属性尺寸时取建议缺省 **300×150**
  (不再 0×0);`open` 结果 `capability_gaps` 与 `page_health` 均带 iframe 计数与
  「内核不渲染 iframe 内容;登录/验证码请顶层 navigate 到其 src 或改用 Chrome 工具」;
- 图片收集跳过非图像 `data:` MIME(`application/font-woff` 等字体);
  SVG 图片(data: 与外链)失败收口为每页一条统计告警,不再逐图刷屏。
