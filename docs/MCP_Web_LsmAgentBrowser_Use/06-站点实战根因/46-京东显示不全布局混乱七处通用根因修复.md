## 一、根因与修复

### 1. `box-sizing` 初始值违反 CSS 标准(文案截断主犯)
- 现象:「品类齐全，轻松购物」末字被裁半截;`.mod_service_txt` 盒宽 135px。
- 机制:旧默认 border-box;`.mod_service_unit{width:180px;padding-left:45px}`
  未声明 box-sizing,Chrome 按初始值 content-box 给内容宽 180,内核扣成 135,
  nowrap 162px 文本被 overflow 硬裁。凡未声明 box-sizing 的 width+padding 盒
  **全站偏窄**。
- 修复:`values.rs` 默认 `box_sizing_content:true`;显式声明照旧。
- 验证:`tests_jd_display::京东服务承诺_unit宽180含padding45…` 红→绿;
  修复后真站探针实测 `p.mod_service_txt w=180.0` ✓。

### 2. `*` 通配选择器解析被丢弃(全局重置全灭)
- 机制:`parse_compound` 尾部「全空 compound 判非法」守卫把裸 `*`(合法通配)
  当非法丢弃 → `*{box-sizing:border-box}` 类全局重置**整条失效**。
  旧默认 border-box 恰好掩盖了它,根因 1 翻转后立刻暴露。
- 修复:解析到裸 `*` 置 `universal` 标志放行(特异性仍 (0,0,0))。
- 排查口诀:**测试假绿可能只是两个 bug 互相抵消**——默认值翻转类修复要连带
  排查「以前恒真/恒假的守卫」。

### 3. 脚本管线超时截断后无人收尾(显示不全主犯)
- 现象:React 分类侧栏(`.jd-main-category-wrapper`)、促销楼层不挂载;
  `<html>/<body>` 能力类名(`root61/o2_wide/new_version/better_style`,由
  index.chunk.js 在初始化链深部设置)缺失 → `body.better_style` 限定的
  几十条 CSS 全失效(搜索栏 `width:calc(100% - 652px)!important` 不生效,
  输入框吃到 1920 全宽越界到 2237)。
- 机制链(三层):
  1. `run_pipeline` 预算耗尽/轮次超时即 `break`,剩余脚本永不执行;
  2. 超时轮次外链脚本**未记账**,后续轮次会重收重跑(双执行风险);
  3. 补泵 `run_pending_scripts` 预检「无待执行脚本」直接返回 ——
     **线程迟到轮次的动作堆在回复邮箱(`pending_replies`)里等下一次请求合并
     带回,跳过 = 永不出邮箱**(探针实测 `script_pending=0 + budget_cut=true`
     无人收割)。
- 修复(三件套):
  1. 外链**发送即记账**(超时:线程仍会跑完本轮,迟到动作经邮箱合并回流;
     线程已退出才回退不记);
  2. 中断按截断上报(`budget_cut/pending_scripts`);
  3. 预检补洞:`script_budget_cut` 时即使无待执行脚本也进空轮收割邮箱;
     wait/inspect/screenshot 三类观察入口全部挂补泵。
- 验证:`web_script_drain.rs` 端到端(重脚本超时→观察动作补泵→挂载动作回流);
  `tests_jd_compat::管线超时中断后补泵收尾且不双执行`。

### 4. 缺字形 raster 跳过且 pen 不推进(行内错位)
- 现象:图标字体(@font-face 尚未实现)码位无字形 → 图标消失后**后续文字
  整体左移**,行内几何与像素错位。
- 机制:`render/raster.rs` 缺字形 `continue` 不画也不推 pen;布局侧
  `char_width` 按回退宽照常占位。`draw_overlay_text` 一直是对的,
  页面文本两条路径语义不一致。
- 修复:缺字形按 `font.char_width`(与布局同源的回退宽)推进 pen,
  主绘制与 text-shadow 蒙版两路径同修。

### 5. JS 懒加载图片不预取(动态图空白)
- 机制:`images.rs` 只扫 `src/srcset`;站点动态图用 `data-src`/`data-lazyimg`
  族等 IntersectionObserver 换源,脚本链一断就永不显示。
- 修复:预取与显示取址(`image_src`/`image_display_src`)兜底
  `data-src/data-lazy-src/data-lazyimg/data-original/data-url`,
  `data-lazyimg` 的 JSON 形态(`{"src":...}`)宽松抽取(`urlutil::lazy_attr_url`);
  `src` 在场时仍显示 `src`(与真实浏览器换源前一致)。

### 6. 横向滚动不进光栅化
- 机制:`rasterize` 只收 `scroll_y`;横滚后截图/查看器帧纹丝不动。
- 修复:scroll_x 与 scroll_y 同构贯穿(Mapper 逆映射/scissor/裁剪窗口),
  fixed 项两轴滚动量同时归零。

### 7. 整页截图宽度恒视口宽(横向溢出永远不可见)
- 机制:宽度 `viewport_w.clamp(...)`,内容溢出右缘部分在任何截图里被硬裁。
- 修复:full_page 宽度取 `max(视口宽, 显示项最右缘)`,40M 像素预算照旧钳制。

## 三、排查方法沉淀

1. **真 Chrome 参照系**:同页 computed style / rect 对照一锤定音
   (box-sizing/content-box、`body.better_style` 类名、`#J_cate{display:none}`
   是故意弃用而非 bug);注意 puppeteer 默认 800×600 视口会触发响应式隐藏,
   先 `launchOptions.defaultViewport` 调 1920。
2. **DUMP_HTML 逐属性 grep**:类名设置点要区分「CSS 规则」与「JS 设置」——
   `new_version/better_style` 字面量只在 CSS 里出现 ≠ 有设置代码,设置代码在
   外链 bundle(curl CDN 静态资源不受页面级风控影响)。
3. **最小夹具不复现 ≠ 根因不存在**:登录 tab 最小夹具绿,说明真实页还有
   JS 重渲染/append CSS 叠加;把「最小夹具 + 全量真实 CSS」两级都跑。
4. **测试假绿警惕**:两个默认值 bug 互相抵消(旧 border-box 默认 × `*` 解析
   丢弃),修一个才暴露另一个;翻默认值时全量测试只红一例也要追到底。
5. **回复邮箱语义**:`merge_pending_into` 把多轮迟到回复**合并成单条**回灌,
   不会溢出丢动作;真正的坑是「没人发请求」——补泵预检必须给截断态放行。
