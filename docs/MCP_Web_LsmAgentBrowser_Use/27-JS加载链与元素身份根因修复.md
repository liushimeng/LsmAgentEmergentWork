## 二、根因链(逐条实测)

### R1 控制台把 Error 记成 `{}`

`JSON.stringify(new Error("x"))` → `{}`(Error 属性不可枚举),页面真实异常被抹平。

**修复**:`prelude.rs::__str` 对 Error 形态(鸭子类型,兼容跨 realm)走 `__lsmErrText`,
输出 `name / message / stack`。

### R2 永久动画定时器无界快进

虚拟时钟会把站点的永久 `setInterval`/动画链一次快进数百帧,单次工具动作 ~20s,
并让站点 `filter` 样式字符串持续膨胀。

**修复**:`runtime.rs::MAX_TIMER_CALLBACKS` 256 → 64,判定改为 `>=`(原先 `>` 会多跑一批)。
新增单测「永久定时器_单请求快进次数有硬上限」。

### R3 内核预置的 AMD 抢走 UMD 的浏览器全局导出

UMD 判据是 `"function"==typeof define&&define.amd`。内核的最小 AMD 装载器在**空页面**
就带 `define.amd={}`,于是 `MapLogReport.min.js` 走模块分支,不再注册 `window.MapLogReport`,
站点随后 `ReferenceError`。

**修复**(`env_js.rs`):空页面**不预置全局 `define`**;兜底 `define` 只在 `loadModule()`
内部求值期间临时安装,站点自己的 AMD 装载器一旦接管就保留站点实现。

### R4 FIS `define` 包装凭空补 `amd`

`__lsmWrapAmdDefine` 里 `wrapped.amd = orig.amd || {}` 会在原始 `define` 没有 `amd` 时补一个,
同样把 UMD 导走。**修复**:仅当原始 `define.amd` 存在时才透传。

### R5 动态脚本 `load` 回调键不匹配

注册按元素原始 `src`(`/pkg/route.js`),宿主触发时按绝对 URL,键对不上 → 站点 AMD 的
`onload` 回调永远不触发。

**修复**(`prelude.rs::__lsmScriptKey`):相对/根相对/协议相对/绝对统一归一为绝对 URL。
归一**不依赖 `URL` 构造器**——实测百度地图页面环境里 `new URL(...)` 会抛错(站点脚本影响),
一旦抛错就退化成原样,归一失效。改用纯字符串解析(`__lsmMeta.protocol/host/origin/url`)。

### R6 元素身份随 DOM 变化漂移(本轮最关键)

快照用**数组下标**标识节点;站点脚本插入/删除节点后下标错位,上一轮捕获的元素包装器
会指向**别的元素**。百度地图首屏因此:`find(".right-button")` 落空 → `offset()` 返回
`undefined` → 读 `s.left` 抛 `TypeError` → 搜索框整块初始化失败 → 地图控件与面板全缺。

**修复**(`prelude.rs`):
- `__lsmCurrentIdx(node)`:按**稳定选择器**(`node.sel`)在当前快照里重新定位,元素身份与
  DOM 变化解耦;
- 元素级 `querySelector/querySelectorAll/getElementsByTagName/matches` 全部改用当前下标;
- 补 `parentNode`/`parentElement`(按当前树实时解析)与 `compareDocumentPosition`。

**单测**:`元素身份跨DOM变化保持稳定_作用域查询不串位`。

### R7 缺 `contains()`

事件委托 `parent.contains(target)` 抛错 → 点击路线按钮**零 DOM 变化**(旧文档里
「路线面板点不开」的成因之一)。**修复**:快照节点、动态节点、`document` 全部补 `contains`。

### R8 缺 `scrollLeft/scrollTop`

站点 `offset()` 读 `docElement.scrollLeft` 得 `undefined` → 坐标算成 `NaN` → 定位全失效
(实测 `offset` 返回 `{left:null,top:null}`)。**修复**:元素字面量补零值。

### R9 单轮外链脚本上限过小

百度地图 widget 层一个包就注入数百模块脚本,上限 64 会让排在后面的脚本(地图图层面板
依赖的 `getjsmods`)永远取不到。**修复**:外链 64 → 512、内联 32 → 128(耗时仍由墙钟预算兜底)。

### R10 零字节占位脚本把管线拖到空转

站点会注入 **200 但零字节**的占位脚本(百度地图的 `com-conf_d41b8cd.js`,`d41b8cd` 正是
空内容的 MD5)。内核「内容为空就不执行、也不记账」→ 它们每轮被重新收集 → 管线反复
空转到墙钟预算耗尽,后面的模块脚本永远轮不到。

**修复**(`script/mod.rs`):外链记账改为覆盖**本轮收集到的全部外链**(含空内容),
网络失败允许重试一次再放弃。

## 三、调试手段(本轮沉淀)

| 手段 | 作用 |
| --- | --- |
| `LAEW_DOM_TRACE=1` | 逐轮打印「收集到多少脚本 / 已执行跳过多少 / 上限截断多少」,并列出本轮取回的外链 URL |
| `LAEW_JS_TRACE_TOOBJ=1` | 记录真实抛错的 ToObject 调用点 |
| `LAEW_JS_TRACE_STMT=1` | 逐条语句标记 AMD 工厂体 |
| `LAEW_DUMP_HTML=<路径>` | 管线后的整页 HTML 落盘(可离线数标签、看脚本 src) |
| 页面内 `eval_js` 探针 | 直接读 `__lsmScriptCbs` / `__lsmListeners` / `window.map._panes` 等运行期状态 |

新增(调试开关下):
- `script/mod.rs`:每轮 `collected / external / executed` 账目;
- `script/dom_ops.rs`:`scanned / skipped_executed / capped` 账目 + 本轮取回的外链 URL。

**重要经验**:`console`/`inspect` 的「页面文本为空」不等于「DOM 为空」——站点大量用
`innerHTML` 模板与 `data-title` 承载控件,必须同时看 DOM 节点数、监听器表与可见文本数。

## 五、遗留边界(如实记录)

1. **地图核心区域仍无像素**。地图实例已存在(`renderType=dom`、缩放 12),但 `#platform`
   下**没有 `.mapPane`、没有瓦片 `<img>`**:
   - 内核无 WebGL(`getContext('webgl')` 返回 null),站点的矢量渲染器不产出内容;
   - DOM 渲染器的图层面板由站点 `oppc` 模块创建,该模块的加载链在真站环境里仍未走完
     (模块已取回、`load` 已触发,但图层面板未出现在 DOM)。
   完整软件 WebGL / 2D canvas 光栅化是独立大工程,不能用站点专用补丁伪装。
2. **路线面板 DOM 未成形**:站点已进入路线态(`state=route`),但面板模板(起终点输入框、
   出行方式标签)没有落到可见布局,截图里只剩一个空条与按钮。
3. **Windows / Linux 未真机验证**:本轮改动全在 JS 运行时(跨平台),真机验证仅 macOS。

## 六、给后续的提示

1. Boa 报错文案有歧义:`cannot convert 'null' or 'undefined' to object` **优先怀疑「读 undefined 的属性」**
   (本轮 `s.left` 就是这一类),再用 `LAEW_JS_TRACE_TOOBJ` 复核。
2. 内核里任何「按 URL/下标记录东西」的地方,都要考虑 **DOM 变化后身份是否还成立**:
   下标会漂移,必须用稳定选择器或内容指纹。
3. 站点注入的**零内容脚本**是常见件;不记账就会变成取回死循环。
