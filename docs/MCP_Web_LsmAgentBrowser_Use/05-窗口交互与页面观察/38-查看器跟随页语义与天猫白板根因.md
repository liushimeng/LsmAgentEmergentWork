## 现象与终止

wf-1 人工登录环节 `control(request_human, reason=login)` 弹 HITL 后,人工看查看器窗口:
**页面区近全白(仅顶部极淡文本行)**,回复「画面是白板」,登录无法进行。引擎侧全程正常
(取证截图 204KB 全彩首页、761 可见盒)——纯显示层故障。

## 根因链(三层实证)

1. **真机日志+截图**:引擎截图有内容 / 屏幕抓取白板 / 查看器进程存活未重生;
   白板期间 11:04–11:05 的管线日志是人工点「刷新」自救触发的 www.tmall.com 重导航。
2. **复现探针**(单例管理器=心跳在跑):
   - A 开彩色页 → 四色带满幅显示(帧管线正常);
   - B **再开 about:blank → 色带全灭**(新页 open 抢前台,查看器跟随切换);
   - C 对彩页 eval 后等 3s → **仍白板**(1Hz 心跳用前台白页持续覆盖工作页帧)。
   - 对照组 `new()`(self_weak 死→心跳不跑)时 C 阶段彩页停留——反证覆盖源就是心跳。
3. **代码定位**:
   - `mod.rs` open 路径:新页 `foreground=true`、旧页全 false(前台抢占);
   - `page_bars.rs::bars_tick`(1Hz):`find(|t| t.foreground && headed)` **盲推前台页**;
   - 动作收尾 `refresh_view` 只推一帧目标页,下一秒即被心跳的前台帧盖回;
   - `navigate` 路径无加载首帧(只有 open 路径有)→ 长重导航画面冻结旧帧,人工误判去点刷新。

| # | 根因 | 后果 |
| --- | --- | --- |
| R1 | 查看器显示跟随「前台页」(=最近 open 的页)而非「Agent 工作页」 | 侦察页(骨架屏/错误页,近白)劫走人工视口,Agent 回工作页也被每秒盖回 |
| R2 | request_human 未固定查看器显示目标页 | 人工该看的登录页永远看不见 → HITL 事实上不可用 |
| R3 | navigate 无加载首帧 | 长重导航冻结旧帧,人工自救点刷新雪上加霜 |

## 修复:跟随页(view_follow)显示语义

**核心**:显示跟随「最近一次有意义交互的页」,而非「最近 open 的页」。

```rust
pub(crate) enum ViewFollow {
    Page(String),                    // 跟随指定标签页(不在场回退前台)
    PendingLoading { since_ms },     // 加载首帧在位:心跳暂停推送,TTL 360s 防孤儿
}
```

落账点(全部为「显示意图」语义点):

| 挂点 | 行为 |
| --- | --- |
| `push_frame`(唯一推帧口) | 推帧即声明:跟随 = 被推的页(open/navigate 收尾、api.rs 七处交互补泵点全部经此自动落账) |
| `note_action_begin/end`(工具层落账) | 动作一开始就把显示切到目标页(90s 的 health 期间人工全程可见);open 的输出页在 end 落账 |
| `handle_view_command`(人工工具栏/地址栏) | 人工操作哪个页,显示跟哪个页 |
| `ensure_loading_view` | 置 `PendingLoading`:加载首帧不被旧页帧 1 秒后盖掉;open/navigate 收尾 `ensure_view`→`push_frame` 落回 `Page` 恢复 |

心跳选页收敛为纯函数 `pick_display_tab`(单测四态):

```
PendingLoading 未超 TTL → 不推 | 跟随页在场+headed → 该页
→ 回退:前台 headed → 任一 headed → 不推
```

**HITL 固定免费获得**:request_human 是带 page_id 的 control 动作,note_action_begin 即置
`Page(目标页)`;HITL 等待期心跳持续推目标页(蒙层已撤帧)——人工全程看得见要操作的页,
无需独立 pin 状态机。

**navigate 补加载首帧**:重导航管线启动前 `ensure_loading_view`(headed),人工看到
「正在打开」而非冻结旧帧。

**不改的**(明确边界):open 抢前台语义保留(与真浏览器一致,跟随页让显示在下一个动作
回到工作页);地址栏 EDITING 不覆盖(编辑保护);查看器页面级键鼠转发仍属 P2 立项。

## 指纹速查

| 现象 | 根因 |
| --- | --- |
| 引擎截图有内容、查看器近全白、查看器进程活着 | 心跳盲推前台页(本号修复前) |
| Agent 工作页帧一闪又被白页盖回 | 同上(动作收尾单帧 vs 1Hz 心跳) |
| 重导航期间画面冻结在旧帧 | navigate 路径无加载首帧(本号修复前) |
| 加载页闪一下变旧页 | 心跳盖掉加载帧 → PendingLoading 暂停(本号引入) |
