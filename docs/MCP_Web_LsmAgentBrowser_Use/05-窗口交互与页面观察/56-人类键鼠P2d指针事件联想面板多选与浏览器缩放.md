## 0. 一句话

把「只挂 pointer 监听」的现代图表库、JS 悬停菜单、滚轮缩放、`<input list>`
联想、`select multiple` 多选、number 步进、浏览器 Ctrl+加减零缩放全部补齐到
人工键鼠通道;并把成对兼容事件的派发合并进**单次 JS 往返**,不回归连击窗口。

## 1. 七项落地

### 1.1 pointer 兼容事件(图表/拖拽库的静默断链根因)

现代库(ECharts/Chart.js/d3/swiper)特性检测 `window.PointerEvent` 后**只挂
pointer 监听**——内核此前只派发 mouse 系事件,这类站点的人工交互整条链静默失效
(构造器 shim 早已在 `env_js.rs`,缺的是**真实派发**)。本轮:

- `human_down/up/move` 按 Chrome 兼容事件顺序派发
  `pointerdown→mousedown`、`pointerup→(click)`、`pointermove→mousemove`;
- hover 目标切换:旧目标 `pointerout→mouseout`、新目标 `pointerover→mouseover`
  (JS 驱动的悬停菜单/tooltip 由此前置不可用);
- Agent 原子点击(`click_inner` kind=="click")在 `click` 前补
  `pointerdown→pointerup`(与人工路径严格互斥,防双发);
- 载荷在 mouse 字段上追加 `pointerId:1/pointerType:"mouse"/isPrimary/pressure
  (按下 0.5)/width/height/tiltX/tiltY`(`human_input/pointer.rs::pointer_payload`);
- PRELUDE 补 `Element.setPointerCapture/releasePointerCapture/hasPointerCapture`
  no-op stub(d3-drag 等库调用缺方法会抛错断链;内核无捕获语义,事件本就按
  命中元素派发)。

**工程要点:成对事件一次 JS 往返。** 每个事件一次 `js_dispatch` 的固有成本
(快照 refresh + eval + 事件循环泵)在重站/调试构建下可达数百毫秒——
`双击选词_三击全选` 用例实测回归(连击窗口 1500ms 被逐事件往返吃掉,基线
17.7s → 23s 且误判)。新增 `JsRequest::DispatchSeq` + PRELUDE
`__lsmDispatchSeq(sel, [[type, detail], ...])`:pointerdown+mousedown、
pointermove+mousemove、pointerup+click(Agent: pointerdown+pointerup+click)
各合并为**一次往返**,顺序保持指针事件先行。落地后手势往返数与 P2c 基线持平。

### 1.2 wheel 事件(自定义滚动/图表滚轮缩放)

`human_wheel` 先派发 `wheel`(载荷 `deltaX/deltaY/clientX/clientY`,cancelable),
**`preventDefault` → 跳过原生滚动**(Chrome 语义);未拦截照旧元素内/视口滚动。
超时上限 2s(与 `js_dispatch_bounded_with` 同口径),超时按未拦截放行
(fail-open,慢监听器不拖死滚动链;dispatch 固有往返在 debug/高负载下远超
数百毫秒,上限太小会让 preventDefault 语义随机失效)。

### 1.3 datalist 联想面板

Chrome 语义近似:`<input list>` 聚焦展开全量、键入按 **value/label 包含匹配**
(大小写不敏感,空查询全量,上限 10 行)重过滤;`↓/↑` 循环高亮、`Enter` 应用
高亮项(无高亮则走原生提交语义)、`Esc` 只关面板、点击面板项应用、外部点击/
焦点移出 light dismiss;应用 = 写值 + `input`/`change` 事件 + 光标归尾。

实现完全复用 select 面板机制:**状态(`TabState.datalist: Option<DatalistState>`)
经 `apply_widget_state` 落内核私有属性**(`data-lsm-datalist-open` 落 input、
`data-lsm-dl-hit` 落命中 option、`data-lsm-dl-idx` 落 input),布局层
`top_layer::emit_datalist_panel` 只认 DOM 标记,与 `emit_select_panel` 同构
(顶层 layer=2、下缘放不下上翻、行盒 `out_of_flow` 登记可点击)。
聚焦钩子 `on_focus_maybe_datalist` 挂在 human_down 聚焦与 Tab 焦点循环上,
带**廉价预过滤**(页面 HTML 无 `<datalist`/`list=` 直接跳过文档解析,
无 datalist 的页面零开销)。

### 1.4 select[multiple] 人工多选

此前 option 点击单值覆盖(「最后点击获胜」),且 Ctrl+点击被 `_blank` 语义吃掉。
本轮(`human_input::multi_pick` 纯函数,单测覆盖):

- **普通点击 = 独占**;**Ctrl/Cmd+点击 = 翻转该项**(option 目标不走新标签语义);
- **Shift+点击 = 锚点闭区间**(锚点 = 上次普通/Ctrl 点击项,无锚点退化为独占);
- 值 = **DOM 序 CSV** 存 `form_values`(`select.value` = 首个选中值,与 Chrome 一致);
  `apply_widget_state` 对 `select[multiple]` 给集合内**全部** option 置 `selected`
  (列表形态的勾选视觉直接点亮);
- 表单序列化对多 select **每值一对**(Chrome URLSearchParams 语义);
- 事件:`input` + `change`。

### 1.5 input[number] 上下方向键步进

ArrowUp/Down 在 number 聚焦时按 `step`(默认 1)步进、`min/max` 钳制
(**number 的 min/max 缺省无界**,与 range 缺省 0..100 不同;空值从 0 起步)、
派发 `input`。左右方向键仍是移光标;微调箭头(`widgets.rs` spinner)仍纯视觉。

### 1.6 浏览器级缩放(查看器侧实现,双平台)

`⌘/Ctrl + =/-/0`(macOS 键码 24/27/29,Windows 0xBB/0x6B/0xBD/0x6D/0x30),
档位 `[0.5 … 2.0]`(Chrome 步进)。**设计:缩放完全在查看器进程生效,宿主零
渲染改动**——Chrome 缩放语义 = CSS 像素变大、可视 CSS 视口变小(媒体查询重估),
由查看器把上报视口改为 `内容区 ÷ 缩放` 实现;帧的等比居中绘制(macOS 既有
letterbox / Windows `paint` 本轮改为等比 `StretchDIBits`)天然完成放大。
输入逆映射:鼠标坐标/滚轮档位 `÷ 缩放` 后上行;窗口标题叠加 `[125%]`。
上行 `{"cmd":"zoom","z":…}` 仅供宿主记账(`TabState.human_zoom`),
`inspect(info=page_health)` 的 `human_zoom`/`zoom_note` 如实上报——Agent 能
解释「为什么视口比窗口小、断点变了」;**截图取证仍是未缩放基准**(与状态栏/
查找栏同哲学:人工辅助层不进取证路径)。

### 1.7 顺带修复的三个既有缺陷(本轮发现)

1. **Windows 查看器自 P2c 起编不过**:`Mutex::new("default".to_string())`
   (非 const)与 `MutexGuard<bool>.take()` 两处在 rustc 1.91 下必然编译失败
   ——本机 macOS 从不编译该文件所以长期未暴露(交叉验证壳见文末)。
   修:`LazyLock` + `std::mem::take(&mut *guard)`。
2. **监听器 `this` 未绑定**:`__fire` 直接 `L.fn(ev)`,`this` 是 undefined,
   原生写法 `el.addEventListener('input', function(){ this.value })` 一读就
   undefined。修:`L.fn.call(ev.currentTarget, ev)`(浏览器语义)。
3. **option 命中被样式层拦死**:option 的 UA 默认 `display:none`(布局层靠
   控件内部浮层/列表形态发射真实盒),`human_hit_test` 的 `is_rendered` 过滤
   把 option 全部跳过——**任何 option 的人工点击此前都落不到 option 上**
   (下拉面板用例只测了 Esc 收起,没测点选)。修:hit-test 对 `option` 豁免
   `is_rendered`(盒子存在即代表可见)。

## 3. 边界(如实,不做静默近似)

- pointer 事件对象仍是 `__mkEvent` 普通对象(`instanceof PointerEvent` false,
  与 mouse 事件同边界);pointer capture 是防崩 no-op(无捕获语义);
  pointerenter/leave(不冒泡)未派发;
- `select.value` 在快照桥上读不到选中值(多选用例改按 option state 断言);
- datalist 匹配只认 value/label 包含;面板只键盘+点击(无 hover 高亮跟随);
- 缩放帧是逻辑分辨率光栅,>1.25 放大有拉伸柔化(无矢量重渲);状态栏/
  进度栏/查找栏画在帧内会随缩放同步放大(浏览器 chrome 完美不缩放不做);
  Windows 缩放/缩放后命中精度待真机回归(与既有 Windows 待验口径一致);
- IME/日期面板/Ctrl+P/文件与颜色原生选择器/长按/触控板捏合:仍列 P2e+ 规划。
