## 二、设计要点

### 2.1 块级堆叠（CSS 2.1 8.3.1 简化）

- `LayoutCtx.pending_margin_bottom: f64`：前块 `margin_bottom` 暂存，下一兄弟 `margin_top` 取 `collapse_margin(a,b)`（皆非负 `max`，任一负 `a+b`）落地。
- **穿出/收编**：子容器无 `padding-bottom`/下边框/`overflow` 裁剪（BFC）时末子块 margin-bottom **穿出**本盒（经典 `<section><p>` 段距语义），否则收编进内容高；穿出值再与本盒自身 margin 折叠。
- 收编点：行盒落地（`push_line`/占位 run）前；flex/grid 容器入口（容器边距不参与兄弟折叠，保持求和语义）。
- 不消费点：浮动盒整支路存还（浮动 margin 不影响流）；绝对/固定定位子树布局前后存还（脱流不碰流内 pending）。
- 已知近似：**父-首子 margin-top 穿出未实现**（嵌套块顶部 margin 仍计入父内容高）；父-末子穿出仅在上述收编边界判定，BFC 细分（inline-block 父等）未全覆盖。

### 2.2 行内共享行盒（layout/inline.rs）

- 收集期：`InlineBuf`/`InlineRun`（样式 run，可合并同款）；排布期：`Seg`（样式段）→ 视觉行。
- 同一行多段：x 连续流动（段首 = `max(流点, run.x)`，行首段 = `run.x` 缩进语义）；行高 = 段间 `line_height` 最大值；同基线（大字号定基线，小字号下移补齐，单段行退化为旧行为）。
- 换行：run 边界与 run 内部均可断；`nowrap`/`pre` run 自身不宽度断行。
- 空白折叠：非 preserve 语义按**行边**裁剪（首段 ltrim、末段 rtrim），段间空格保留；全空白行不落地不推进游标。
- 占位 run（替换元素预留高度）：只抬当前视觉行高；无行在建时独占推进游标。

### 2.3 文本 x 基准

- `push_styled` 语义：`x_base` = 元素 **margin-box x**，run x = `x_base + margin_left + padding_left`（内容起点）。
- 块级文本：x_base = 容器内容 x − 容器 margin − padding（即容器 margin-box x）；行内文本：x_base = `collect_inline` 传入的 margin-box 基准（own_box 盒回退自身偏移）。
- `text_base` 字段整体删除（175 轮 body-margin 修复的遗留半边）。

### 2.4 跨平台字体回退链（render/mod.rs FontSet）

- `fonts: Vec<Font>` 链式加载（≤3），**覆盖探针达标即停**（`lookup_glyph_index('A') != 0 && != 0 for '中'`）：
  - macOS Arial Unicode / Windows msyh 均单字体即停（零额外启动开销）；
  - Linux DejaVu 无 CJK → 继续载 Noto/文泉驿/DroidSansFallback（**CJK 候选提前于拉丁备选**，此前排第 3 永远加载不到 → 中文豆腐块根因）。
- `pick(ch)` = 首个覆盖字体；全链无覆盖 → 启发式宽度 / 栅格跳过（不再画 tofu 框）。
- TTC 字体集合：fontdue `collection_index` 天然支持（Menlo.ttc/HelveticaNeue.ttc/msyh.ttc 实测可解析），无需额外处理。
- **度量/栅格双缓存**（`Mutex<HashMap>`，容量 4096 整体清空）：`text_width` 换行热点、`rasterize_glyph` 重绘热点（page_bars 1Hz/截图重渲染）。
- Linux 候选补常见发行版安装位 + 有界目录扫描（深度≤3、48 文件、CJK 偏好名优先）。

## 四、验证

- 单测：`相邻兄弟外边距折叠取最大值` / `空块与零高块不产生幽灵高度` / `负下边距把兄弟上移` / `行内样式段共享同一行盒` / `嵌套块文本x按包含块内容盒定位` + 字体链四用例；
- 端到端：富视觉页像素断言（渐变/圆角/阴影/裁剪/transform/多背景/text-shadow）全绿；
- 全量 `cargo test --no-fail-fast`：仅存量 `macos_ax_smoke` 1 例环境失败（TCC），照旧放行。
