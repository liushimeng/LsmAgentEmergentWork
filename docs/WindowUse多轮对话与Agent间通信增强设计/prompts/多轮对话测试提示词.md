# WindowUse 多轮对话与 Agent 间通信 —— 测试提示词(WU-MT01 ~ WU-MT10)

> 配套设计:`../01-设计与解决方案.md`。
> 考察 WindowUse Agent 的跨轮会话连续性、操作历史回溯、跨应用操作、Agent 间消息传递。
> 每条提示词在同一 Session 内按轮次顺序喂入,验证「第 N 轮注入第 N-1 轮状态」的连续性。
> 平台约束同 `../prompts/window_use测试提示词.md`(Windows UIA / macOS AX / Linux fallback)。

## 维度说明

| 维度 | 说明 |
|------|------|
| 跨轮窗口状态 | 第 2+ 轮无需用户重复描述窗口,自动引用上一轮操作对象 |
| 操作历史回溯 | 路径失效时参考历史选择相近路径,而非盲目重试 |
| 跨应用连续性 | 从 A 读取 → 写入 B 的端到端连续操作 |
| Agent 间消息 | WindowUse 读取数据后传递给 SubAgent 处理 |
| 状态注入幂等 | 多次注入不产生重复上下文 |

---

### WU-MT01 跨轮窗口连续性(核心)
- **预期档位**: medium
- **考察维度**: 第 2 轮自动引用第 1 轮的窗口,无需重复描述
- **工具链**: WindowList → WindowInspect → WindowAction(多轮)
- **对话脚本**:
  1. [第 1 轮] 打开一个记事本,在编辑区输入「第一轮输入的文本」。
  2. [第 2 轮] 再在那个窗口里追加一段「第二轮追加的文本」。(验证:无需说「刚才的记事本」,Agent 应自动定位同一窗口)
  3. [第 3 轮] 把编辑区当前的全部内容读出来。(验证:能看到两轮输入的叠加)

### WU-MT02 操作历史回溯
- **预期档位**: medium
- **考察维度**: 路径失效时参考操作历史
- **工具链**: WindowList → WindowInspect → WindowAction(路径失效)→ 历史回溯 → 重新操作
- **对话脚本**:
  1. [第 1 轮] 打开计算器,点击「1」「2」「3」,然后读取结果显示区。
  2. [第 2 轮] 把计算器关掉重开,再点击「4」「5」。(验证:Agent 不应使用第 1 轮的旧 path,应重新检视;但应记住「上次操作的是计算器」)

### WU-MT03 跨应用连续操作
- **预期档位**: hard
- **考察维度**: 从应用 A 读取 → 写入应用 B
- **工具链**: WindowList ×2 → WindowInspect ×2 → WindowAction(read) → WindowAction(write)
- **对话脚本**:
  1. [第 1 轮] 打开两个记事本(A 和 B),在 A 中写入「跨应用测试数据」。
  2. [第 2 轮] 读取记事本 A 编辑区的内容,把它写入记事本 B 的编辑区。(验证:中间数据应在窗口状态中传递,不需要用户复述)

### WU-MT04 Agent 间消息传递
- **预期档位**: hard
- **考察维度**: WindowUse 读到文本后传递给 SubAgent 处理
- **工具链**: WindowList → WindowInspect → WindowAction(get_text) → [Agent 消息] → SubAgent(处理)
- **对话脚本**:
  1. [第 1 轮] 读取记事本窗口编辑区里的文本(假设是一段 JSON),告诉我这段 JSON 有几个字段。
     (验证:WindowUse 读 JSON → 发 AgentMessage → SubAgent 分析字段数 → 结果返回给用户)

### WU-MT05 状态注入幂等
- **预期档位**: medium
- **考察维度**: 状态注入多次不产生重复上下文
- **工具链**: WindowList(验证 prompt 中状态段只出现一次)
- **对话脚本**:
  1. [第 1 轮] 列出当前窗口。
  2. [第 2 轮] 再次列出当前窗口。(验证:第 2 轮的系统提示词中「窗口会话上下文」段只出现一次,无重复)

### WU-MT06 窗口别名记忆
- **预期档位**: medium
- **考察维度**: 用户自定义窗口别名跨轮保持
- **工具链**: WindowList → WindowInspect
- **对话脚本**:
  1. [第 1 轮] 把标题含「记事本」的窗口记为「我的记事本」,告诉我它的控件列表。
  2. [第 2 轮] 操作「我的记事本」窗口,点击它的「文件」菜单。(验证:Agent 识别别名并定位窗口)

### WU-MT07 多窗口并发操作(安全互斥)
- **预期档位**: hard
- **考察维度**: 多个窗口操作时的状态隔离
- **工具链**: WindowList → WindowAction(多窗口)
- **对话脚本**:
  1. [第 1 轮] 在窗口 A(记事本)输入「A」,在窗口 B(计算器)点击「1」。
  2. [第 2 轮] 同时在窗口 A 追加「B」,在窗口 B 点击「+」「2」「=」。(验证:两个窗口的状态独立,互不干扰)

### WU-MT08 失败恢复与状态保留
- **预期档位**: medium
- **考察维度**: 操作失败后,成功操作的状态仍保留
- **工具链**: WindowList → WindowAction(成功)→ WindowAction(失败)→ WindowAction(继续)
- **对话脚本**:
  1. [第 1 轮] 在记事本输入「第一步成功」。
  2. [第 2 轮] 点击一个不存在的 path(模拟失败),然后再输入「第二步成功」。(验证:第 1 轮状态在第 2 轮失败后仍可用,不会因失败清空)

### WU-MT09 待处理数据传递
- **预期档位**: hard
- **考察维度**: pending_data 在跨 WorkFlow 间传递
- **工具链**: WindowAction(get_text) → [WF 依赖] → WindowAction(set_text)
- **对话脚本**:
  1. [第 1 轮] 从源窗口读取文本。
  2. [第 2 轮] 打开目标窗口,把刚才读取的内容写入。(验证:即使目标窗口在第 2 轮才打开,pending_data 仍可从状态中取到)

### WU-MT10 跨会话隔离
- **预期档位**: medium
- **考察维度**: 不同 Session 的窗口状态不互相泄漏
- **对话脚本**:
  1. [Session A 第 1 轮] 打开记事本 A,输入「SessionA 数据」。
  2. [Session B 第 1 轮] 打开记事本 B,输入「SessionB 数据」。
  3. [Session A 第 2 轮] 读取记事本 A 的内容。(验证:看到的是「SessionA 数据」,不会看到 Session B 的内容)
