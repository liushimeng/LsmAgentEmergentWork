# 02 - 屏蔽页面状态栏与进度栏（双浏览器工具统一落地）

> 2026-10-23 · 适用 `MCP_Web_Chrome_Use`（Chrome/CDP）与 `MCP_Web_LsmAgentBrowser_Use`
> （进程内 LsmAgentBrowser 内核）· 历史单侧实现见
> [`docs/MCP_Web_Chrome_Use/24-屏蔽页面状态栏与进度栏.md`](../MCP_Web_Chrome_Use/24-屏蔽页面状态栏与进度栏.md)
> （描述的是 `reference实现归档/` 里的旧实现,本文是双浏览器新架构下的重写落地）

## 一、术语定名（本工程统一叫法）

Agent 打开浏览器窗口后,页面覆盖区（历史称「屏蔽页面控件」「蒙层」「告知栏」）的两条常驻
告知栏,自本文起定名并全库统一:

| 定名 | 位置 | 回答的问题 | 内容结构 |
| ---- | ---- | ---------- | -------- |
| **屏蔽页面状态栏** | 窗口**右上角** | 谁在控制 / 控制成什么样 / 人工怎么配合 | ① `LAEW Agent 控制中 · <具体Agent名>` ② 管控档位行 ③ **静态注意事项**(固定文案) ④ 自定义 note(可选) |
| **屏蔽页面进度栏** | 窗口**左下角** | 正在干什么 / 进度到哪 / 刚发生了什么 | ① 当前动作(阶段·动作·工具) ② 迭代/会话/耗时 + 进度条 ③ 任务摘要(用户原文,截断) ④ 最近 6 条事件时间线 |

**分工铁律**:固定文案(注意事项/声明/档位说明)一律在**状态栏**;进度栏只放**动态**内容
(当前动作、迭代进度、任务目标、事件时间线),长文本按宽度截断(`…`),不得撑破页面布局。

## 二、要解决的问题

1. 旧徽标只写「LAEW Agent 控制中」,看不出**是哪个 Agent**(Yolo / Plan / Main-Work /
   SubAgent-Work / 动态子 Agent 全一个样);多窗口并行(天猫一窗 + 京东一窗)时人工无法判断归属。
2. 旧左下角状态条全是静态文字,看不到正在干什么、第几轮迭代、任务目标、刚发生过什么。
3. 双浏览器工具拆分(`docs/双浏览器工具架构/01`)后,Chrome 侧重写的基础框架
   (`src/agent/chrome_browser/`)尚无任何告知栏;Lsm 侧 `guard`/`overlay` 仅记录不显示。
   两条栏需要在**两个引擎**上以各自最自然的方式落地,并共享同一份「谁在干什么」数据源。

## 三、总体架构

```
Agent 循环埋点                       数据面                        呈现层(两引擎各一套)
─────────────────          ─────────────────────────      ──────────────────────────────
agent_loop.rs               src/agent/web_activity.rs      Chrome: chrome_browser/status.rs
  begin(profile.name,…)     task_local 活动台账              注入 JS(closed Shadow DOM)
  set_iter(N, 阶段)    ───▶  (agent/session/iter/    ───▶   右上 host + 左下 host,
tool_exec.rs                 task/phase/tool/started_ms)    pointer-events:none
  set_tool(工具标签)                                          页面侧 500ms 自刷新耗时
浏览器工具 execute           Lsm: TabState.bars(PageBars)    Lsm: browser/page_bars.rs
  note_action_begin/end ──▶  快照落 tab + 事件环形账    ──▶   push_frame 渲染后小图元合成
                             (Chrome 无需落账,             (fontdue 文本 + tiny-skia 圆角矩形)
                              JS 侧自持 events 环)
```

- **唯一数据真源** = `web_activity.rs` 活动台账(`tokio::task_local`)。工具执行发生在
  Agent 自己的任务树内,task_local 随 `.await` 传递,**并行 SubAgent 各自读到自己的快照**;
  若用全局 `Mutex` 会互相覆盖(A 窗口显示 B 子 Agent 名字,人工据此做的判断全错)。
- **杀开关**:`LAEW_PAGE_BARS=off|0|false|no` 全关两条栏(两工具同参,默认开启)。

## 四、状态栏 / 进度栏内容规格（两引擎一致）

### 4.1 状态栏（右上角,四行）

| 行 | 内容 | 数据来源 |
| -- | ---- | -------- |
| ① | `LAEW Agent 控制中 · LsmAgentEmergentWork-SubAgent-Work` | `AgentProfile.name`,经活动台账;无台账回退 `LAEW Agent` |
| ② | Chrome:`页面开放 · 人工可直接操作`(基础框架无输入拦截,如实);Lsm:`页面已锁定(仅观看)`(进程内查看器为被动帧显示,人工确实只能观看) | 引擎能力如实描述,不虚标档位 |
| ③ | 静态注意事项(固定文案):Chrome=「Chrome 由 LAEW Agent 驱动;人工可直接操作本窗口;如需 Agent 配合请在终端对话中说明」;Lsm=「反-反爬进程内内核;页面交互由 Agent 工具执行;如需人工介入请在终端对话中说明」 | Rust 侧常量,**由原左下角状态条整体迁入** |
| ④ | `guard_note` 自定义提示(`open(guard_note=…)` / `set_guard(note=…)`),≤60 字符,可选 | `TabState.guard.note` / 载荷 note 字段 |

### 4.2 进度栏（左下角,四行 + 进度条)

| 行 | 内容 | 数据来源 |
| -- | ---- | -------- |
| ① | `▶ 第 3/12 轮 · 执行工具 · open https://www.example.com/list`(阶段·浏览器动作·工具标签,任一为空不产生多余分隔符;全空时占位「待命中 · 等待下一次浏览器动作」) | `phase`(台账)+ `action`(动作标签)+ `tool`(台账) |
| ② | `迭代 3/12 · 会话 4f2a · 已用 1分12秒` + 蓝色进度条(`iter/max_iter` 百分比) | 台账 iter/max_iter/started_ms |
| ③ | `任务:调研天猫京东双站 20 款笔记本电脑价格…`(用户原文,≤120 字符截断) | 台账 task(首条非注入块 user 消息) |
| ④ | `10:12:03 ✓ open 0.8秒 · 10:12:20 ✗ click 12.0秒`(最近 6 条事件时间线,滚动丢弃) | 工具 execute 前后埋点 |

任务摘要取 Session 上下文**第一条非注入块** user 消息(跳过 `<<<LAEW:PROJECT_CONTEXT>>>` /
`<<<LAEW:ATTACHMENTS>>>` / `<<<LAEW:WORKSPACE>>>` / `<<<LAEW:SESSION_HISTORY>>>`),
否则进度栏显示的是工程说明而不是任务。

## 五、Chrome 侧实现（`src/agent/chrome_browser/status.rs`）

从归档 `browser_status.rs` 按新框架裁剪移植,保留全部实测教训:

| 机制 | 说明 |
| ---- | ---- |
| closed Shadow DOM | 品牌文本留在 light DOM 会被页面 `document.body.innerText` 采集(实测京东风控据此判自动化);`attachShadow` 不可用 fail-open 回退 light DOM |
| 顶层 frame 门 | `addScriptToEvaluateOnNewDocument` 注入每个新文档(含跨域 iframe);天猫 baxia 滑块 iframe(~390px)内长出状态栏会把挑战控件罩死 —— 两条栏一律 `window.top === window` 门控 |
| 版本化单实例 | 脚本多通道重注入,闭包状态(events/visible)不能被后注入者重置;`StatusRev` 版本门,同版本仅补 DOM 自愈 |
| 独立 fixed 角落 host | 不共用全屏 `inset:0` 宿主(会被页面 transform 劫持 `position:fixed` 包含块,Windows 1080p 实测「显示不出来」);右上 host + 左下 host 各自锚定 |
| `pointer-events:none` | 纯告知,绝不参与 hit-test |
| 长文本截断 | `max-width:min(vw,px)` + `text-overflow:ellipsis` + `title` 悬浮全量 |
| 页面侧 API | `{ns}StatusUpdate`(全量刷新)/`{ns}StatusVisible` /`{ns}StatusSuspend`(截图避让)/`{ns}StatusEnsure`(DOM 自愈)/`{ns}StatusProbe`(影子树自探,测试用);ns 随机化 + 不可枚举 |
| 耗时自刷新 | 页面侧 `setInterval(500ms)`,Rust 不为秒数跳动反复推 |
| SPA 自愈 | `MutationObserver` 监视 documentElement,host 被整树替换冲掉时重建 |

接线:

| 位置 | 改动 |
| ---- | ---- |
| `open` 成功后 | `AddScriptToEvaluateOnNewDocument` 注入模板(`run_immediately` 立即执行)+ 推一次全量载荷 |
| 每次工具 execute 前后 | `broadcast_start(动作标签)` / `broadcast_done(标签, ok, 耗时)` 遍历全部存活页面(无浏览器实例零开销返回) |
| screenshot 前后 | `set_suspended(true)` → 拍照取证 → 拍完恢复(证据图不入镜两条栏) |
| 注入条件 | 仅 headed(`ChromeMode::Headed`)且 `LAEW_PAGE_BARS` 未关;hidden 无人工观看,零注入零开销 |

动作标签 `describe_web_action` 把参数渲染成人读标签(`open https://…` / `control click selector=#buy` /
`inspect elements`),≤90 字符截断。

## 六、Lsm 侧实现（`src/agent/browser/page_bars.rs`）

进程内内核**不走页面注入**(注入 DOM 会触发 MutationObserver、污染页面状态、进截图证据),
两条栏在**查看器帧合成层**绘制:

- `TabState.bars: PageBars` 持快照(agent/session/iter/max_iter/task/phase/tool/action/
  started_ms) + 事件环形账(≤6 条)。工具 execute 前后 `note_action_begin/end` 更新
  (Some(page_id) 精准落账,None 广播全部标签页)。
- `push_frame`(`browser/mod.rs`,仅 headed 查看器路径)在 `render_pixmap` 之后、`encode_png`
  之前调用 `page_bars::draw`:tiny-skia 画半透明圆角底(`rgba(15,23,42,0.88)`),fontdue
  栅格化文本逐行绘制(fontdue 无彩色 emoji,行首标记用文本而非 emoji,缺字形自动跳过)。
  文本按可用宽度截断(基于 `FontSet::text_width` 逐字裁剪补 `…`)。
- **截图证据零污染**:两条栏只在查看器帧(`push_frame`)合成,`screenshot_locked` 取证路径
  不经过该层,inspect(control) 截图永远干净。
- **1Hz 心跳重绘**:查看器存活时独立任务每秒重推前台标签页帧(耗时行「已用 1分12秒」要跳动);
  `bars_ticker_started` 原子位保证全进程单实例,查看器退场后任务自行收尾。
- Lsm 状态栏第②行档位文本 = `页面已锁定(仅观看)`:查看器是被动帧显示窗,人工确实不能操作
  页面(工具栏/地址栏除外),如实描述;`guard_note` 读 `TabState.guard.note`。

## 八、约束(不可回退)

1. closed Shadow DOM(Chrome)/ 帧合成层(Lsm)——两条栏文本不得进入页面可枚举 DOM。
2. 只在顶层 frame / 查看器窗口渲染;子 frame(挑战 iframe)零渲染。
3. `pointer-events:none` / 帧合成层绘制,绝不遮挡人工操作与取证截图。
4. 长文本截断(状态栏/进度栏都不允许把布局撑破);任务摘要 ≤120 字符,动作标签 ≤90 字符。
5. 导航不丢:Chrome 靠 `AddScriptToEvaluateOnNewDocument` 自动重挂;Lsm 快照在 TabState,
   导航换页保留。
6. hidden(headless)/无浏览器实例零注入零开销;`LAEW_PAGE_BARS=off` 全关。
7. 无活动台账(非 Agent 工具路径,如单测直调)回退静态文案,不报错。
