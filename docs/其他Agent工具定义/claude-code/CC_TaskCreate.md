# TaskCreate 工具说明
```json
{
    "name": "任务创建",
    "description": "使用本工具为当前编码会话创建结构化任务列表。便于跟进进度、梳理复杂工作，也能让用户感知工作细节。
    同时可帮助用户了解单项任务进展以及整体需求的完成情况。

    ## 适用场景
    出现以下情况，请主动使用本工具：
    - 多步骤复杂任务：任务包含3个及以上独立步骤或操作
    - 高难度复杂任务：需要周密规划、涉及多项操作的任务
    - 规划模式：启用规划模式时，创建任务列表以跟进工作
    - 用户明确要求：用户主动要求生成待办清单
    - 多项任务需求：用户给出多条待办事项（带序号或逗号分隔形式）
    - 收到新指令：接到新需求后，立即将需求整理为任务
    - 开始执行任务：正式动工前，将任务状态标记为进行中
    - 任务完成后：将任务标记为已完成，并补充执行过程中发现的后续新任务

    ## 不适用场景
    以下情况无需使用本工具：
    - 仅有单一简单任务
    - 任务难度低，跟踪记录无实际整理价值
    - 任务可通过少于3个简单步骤完成
    - 纯对话、信息咨询类内容

    注意：若仅存在一项简单任务，请勿使用本工具，直接执行即可。

    ## 任务字段说明
    - **subject**：简洁的行动式标题，采用祈使句式（示例：修复登录流程中的身份验证漏洞）
    - **description**：具体工作内容说明
    - **activeForm**（选填）：任务处于进行中状态时，加载动画展示的现在进行时文案（示例：正在修复身份验证漏洞）。若留空，加载动画将直接展示标题内容。

    所有新建任务默认状态为待处理。

    ## 使用提示
    - 任务标题需清晰具体，明确工作目标
    - 任务创建完成后，如需设置依赖关系（前置/后置任务），可使用任务更新工具配置
    - 先查看现有任务列表，避免重复创建",
```
