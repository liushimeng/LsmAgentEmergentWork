    ## 运行说明
    - 处于 Git 仓库内：会在 `.claude/worktrees/` 目录下基于新分支创建 Git 工作区。分支基准由配置项 `worktree.baseRef` 控制：`fresh`（默认）基于远端默认分支新建分支；`head` 基于本地当前代码版本新建分支。
    - 非 Git 仓库环境：会调用工作区创建/删除钩子，实现通用版本控制隔离。
    - 会话的工作目录会自动切换至新工作区。
    - 会话中途可使用 ExitWorktree 工具退出工作区，并选择保留或删除。会话结束时若仍处于工作区，会弹窗询问用户是否保留。

    ## 进入已有工作区
    传入 `path` 参数而非 `name`，可直接切换到当前仓库下已存在的工作区（例如通过 `git worktree add` 提前创建的工作区）。该路径必须能被当前仓库的 `git worktree list` 命令识别，非本仓库已注册的工作区路径会被拒绝。
    通过该方式进入的工作区，执行退出操作时不会被删除，需设置 `action: "keep"` 回到原目录。

    即便当前会话已在某个工作区中，仍可通过 `path` 切换至其他已有工作区：原有工作区会保留在磁盘中且不受改动，仅新工作区会纳入会话退出清理范围。对于启动时固定工作目录的代理（子代理隔离、指定工作目录场景），同样支持路径切换，且仅作用于当前代理，不会影响父会话。
    多次切换后，此前访问过的工作区将失去写入权限，如需再次使用，需重新通过 `path` 调用 EnterWorktree 进入。
