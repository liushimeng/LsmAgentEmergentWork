# TaskList 工具定义
```json
{
    "name": "TaskList",
    "description": "使用本工具列出任务列表中的所有任务。

    ## 适用场景
    - 查看可执行任务（状态为待处理、未分配负责人、无前置阻塞）
    - 查看项目整体进度
    - 找出被阻塞、需要先解决依赖项的任务
    - 完成一项任务后，查看解除阻塞的新任务或承接下一个可执行任务
    - 存在多个可执行任务时，**优先按任务ID顺序执行（ID从小到大）**，靠前的任务通常会为后续任务铺垫前置环境

    ## 输出内容
    返回每项任务的概要信息：
    - **id**：任务标识（可用于任务查询、任务更新工具）
    - **subject**：任务简述
    - **status**：任务状态，可选值：待处理、进行中、已完成
    - **owner**：已分配则为代理ID，未分配则为空
    - **blockedBy**：需优先完成的未结束任务ID列表（存在前置阻塞的任务，需解除依赖后才能承接）

    如需查看任务详情（包括详细说明和备注），请使用任务查询工具并传入对应任务ID。",

        "properties": {},

    }
}
```
