# 阶段四：资源加载、缓存与安全

> 状态标记：✅ 已实现；🟡 部分实现/有边界；⏳ 未实现。
> 本阶段目标：让 LsmAgentBrowser 能加载完整页面资源（字体、CSS @import、JS）、
> 缓存重复访问的资源、执行基本安全策略（同源/CORS/CSP）。

```
│  └─────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

### 1.1 设计原则

- **契约不变**：`MCP_Web_Use` 工具名/action/参数/信封/错误码不变
- **全内存**：缓存、资源、安全上下文全部内存驻留，进程退出即清空
- **无外部浏览器进程**：不引入 Chrome/CDP
- **跨平台**：macOS/Windows/Linux 同一套 Rust 代码
- **单文件 ≤ 1800 行**：超线按功能拆目录

### 2.3 核心接口

```rust
/// 资源加载器：管理页面所有子资源的加载、缓存与优先级。
pub struct ResourceLoader {
    /// 已加载资源缓存：URL → LoadedResource
    resources: HashMap<String, LoadedResource>,
    /// 加载中的请求（用于去重与取消）
    inflight: HashMap<String, Arc<InflightRequest>>,
    /// 并发信号量
    semaphore: Arc<tokio::sync::Semaphore>,
}

pub struct LoadedResource {
    pub url: String,
    pub content_type: String,
    pub bytes: Vec<u8>,
    /// 字体解码后的 Font 对象（仅字体资源）
    pub font: Option<fontdue::Font>,
    /// 加载耗时
    pub elapsed_ms: u64,
}

impl ResourceLoader {
    /// 加载单个资源（带缓存）。
    pub async fn load(&mut self, url: &str) -> Result<Arc<LoadedResource>, String>;
    
    /// 批量加载资源（按优先级排序）。
    pub async fn load_batch(&mut self, urls: Vec<String>) -> Vec<Result<Arc<LoadedResource>, String>>;
    
    /// 取消指定 URL 的加载。
    pub async fn cancel(&mut self, url: &str);
    
    /// 清空缓存。
    pub fn clear(&mut self);
}
```

### 2.4 字体加载

```rust
/// 加载并解码字体文件。
/// 支持 TTF/OTF/WOFF/WOFF2（依赖 fontdue 能力）。
```

**边界**：
- WOFF2 需要 brotli 解码，当前 `image` crate 已引入 brotli，可复用
- 字体文件上限 32MB（与主文档一致）
- 字体加载失败不阻塞页面渲染，回退系统字体

### 2.5 CSS @import 递归

```rust
/// 解析 CSS 中的 @import 规则，递归加载所有依赖。
/// 返回内联后的 CSS 文本（@import 替换为实际内容）。
pub async fn resolve_imports(css: &str, base_url: &str) -> Result<String, String>;
```

**边界**：
- 最大递归深度 8 层
- @import 必须出现在 CSS 规则之前（浏览器语义）
- 循环引用检测（已访问 URL 集合）

### 2.6 优先级调度

| 优先级 | 资源类型 | 说明 |
| --- | --- | --- |
| 0（最高） | 主文档 HTML | 阻塞解析 |
| 1 | 阻塞渲染的 CSS | `<link rel=stylesheet>` |
| 2 | 字体 | `@font-face` |
| 3 | 图片 | `<img>`/`background-image` |
| 4 | 脚本 | `<script>`（async/defer 可降级） |
| 5（最低） | 预加载 | `<link rel=preload/prefetch>` |

**实现**：
- 使用 tokio Semaphore 控制并发（默认 6 个并发）
- 同优先级按 FIFO
- 高优先级可抢占低优先级的信号量槽位

### 3.3 核心接口

```rust
/// 全内存 HTTP 缓存：强缓存 + 协商缓存 + LRU 淘汰。
pub struct HttpCache {
    /// 缓存条目：URL → CacheEntry
    entries: HashMap<String, CacheEntry>,
    /// LRU 访问顺序（最近访问在末尾）
    lru: VecDeque<String>,
    /// 当前缓存大小（字节）
    size: usize,
    /// 大小上限（默认 128MB）
    max_size: usize,
}

struct CacheEntry {
    pub url: String,
    pub status: u16,
    pub headers: Vec<(String, String)>,
    pub bytes: Vec<u8>,
    /// 缓存时间（Unix 毫秒）
    pub cached_at_ms: u128,
    /// 强缓存过期时间（Unix 毫秒），None 表示无强缓存
    pub expires_ms: Option<u128>,
    /// ETag（协商缓存）
    pub etag: Option<String>,
    /// Last-Modified（协商缓存）
    pub last_modified: Option<String>,
    /// 访问计数（用于统计）
    pub hits: u64,
}

impl HttpCache {
    /// 尝试从缓存获取。返回 None 表示未命中或已过期。
    pub fn get(&mut self, url: &str) -> Option<&CacheEntry>;
    
    /// 存入缓存（LRU 淘汰）。
    pub fn put(&mut self, entry: CacheEntry);
    
    /// 验证缓存是否可用（协商缓存：返回 304 或 200）。
    pub async fn validate(&mut self, url: &str, client: &HttpClient) -> Result<ValidationResult, String>;
    
    /// 清空缓存。
    pub fn clear(&mut self);
    
    /// 缓存统计。
    pub fn stats(&self) -> CacheStats;
}

pub enum ValidationResult {
    /// 缓存有效，直接使用
    Fresh(&CacheEntry),
    /// 需要重新验证（发送 If-None-Match/If-Modified-Since）
    Revalidate(&CacheEntry),
    /// 缓存不存在或已过期
    Miss,
}

pub struct CacheStats {
    pub hits: u64,
    pub misses: u64,
    pub size_bytes: usize,
    pub entry_count: usize,
}
```

### 3.5 LRU 淘汰

- 超过 `max_size` 时，从 LRU 头部淘汰
- 每次访问将条目移到 LRU 尾部
- 淘汰时触发回调（用于资源清理）

### 4.2 SameSite 语义

| 值 | 行为 |
| --- | --- |
| `Strict` | 仅同站请求携带；跨站导航不携带 |
| `Lax` | 同站携带；跨站顶级导航的 GET 请求携带；跨站 POST/iframe/图片不携带 |
| `None` | 所有请求携带（需同时设置 Secure） |

### 4.3 实现

```rust
/// 判断请求是否应携带 Cookie（SameSite 检查）。
pub fn should_send_cookie(
    cookie: &Cookie,
    request_url: &str,
    is_top_level_nav: bool,
    is_get: bool,
    is_same_site: bool,
) -> bool {
    match cookie.same_site {
        Some(SameSite::Strict) => is_same_site,
        Some(SameSite::Lax) => is_same_site || (is_top_level_nav && is_get),
        Some(SameSite::None) => true, // 需 Secure
        None => true, // 默认 Lax（现代浏览器行为）
    }
}
```

```rust
/// 判断两个 URL 是否同源。
pub fn is_same_origin(a: &str, b: &str) -> bool {
    let ua = url::Url::parse(a).ok();
    let ub = url::Url::parse(b).ok();
    match (ua, ub) {
        (Some(a), Some(b)) => a.origin() == b.origin(),
        _ => false,
    }
}
```

## 九、风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 字体文件过大 | 内存占用 | 32MB 上限 + 失败回退 |
| 缓存膨胀 | 内存占用 | 128MB 上限 + LRU 淘汰 |
| CSP 解析错误 | 脚本被阻止 | 解析失败默认允许（fail-open） |
| CORS 误判 | 跨域请求被阻止 | 严格模式 + 可配置白名单 |
