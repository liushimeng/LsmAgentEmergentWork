# 全功能浏览器能力矩阵与后续阶段实施方案

> 本文把 `基于 V8 引擎的全功能浏览器 完整功能清单.md` 的十一大域逐项映射到
> LsmAgentBrowser 的落地阶段与代码落点,作为后续每轮开发的**总账**。
> 单项阶段性设计见 `01`~`06` 号文档;本文只回答「做什么、在哪做、什么时候做」。
>
> 状态标记:✅ 已实现;🟡 部分实现/有边界;⏳ 未实现。

## 一、总体判断

一个完整浏览器 90% 的工作量在 V8 之外。LsmAgentBrowser 的定位不是替代桌面浏览器,
而是**给 Agent 一个可控、可观测、全内存、无外部进程的页面运行时**。因此优先级按
「Agent 任务收益 / 实现成本」排序:

1. **能读懂页面**(DOM/CSS/文本/结构化抽取)——已基本完成;
2. **能完成交互**(点击/表单/脚本/动态 DOM)——已基本完成;
3. **能看对页面**(布局/渲染/截图一致)——阶段三重点;
4. **能上复杂站点**(子资源/缓存/存储/反爬兼容)——阶段四;
5. **能跑重前端**(Web API/Canvas/Worker/V8)——阶段五;
6. **能人工可视化与调试**(原生窗口/DevTools)——阶段三/六;
7. **音视频/WebRTC/WebXR 等**——仅在确有 Agent 场景时按需实现。

## 三、后续阶段实施顺序

0. **Flex 布局 + 定位体系(已完成,见 08 号文档)**:`layout.rs` 已拆分为
   `layout/` 目录(mod/flex/grid/position/tests);`ComputedStyle` 新增

   `getComputedStyle` 全程可见;块级流引入 `measure_content`/`Fragment`

1. **Grid 布局(已完成,见 09 号文档)**:`layout/grid.rs` 显式/隐式网格 +
   轨道尺寸(px/%/fr/auto/min-content/max-content/minmax/repeat)+
   自动(sparse)/显式放置(线号/span)+ gap + 条目/轨道级对齐;
   `measure_content` 对嵌套 flex/grid 条目走对应格式化上下文。
2. ~~图片渲染~~ ✅ 已完成(10 号文档):`<img>`/`background-image` 解码(全内存缓存 +
   尺寸约束)+ `object-fit` 渲染;
3. 原生窗口:`winit` 或 macOS AppKit / Windows Win32(沿用 `human_ui` 的平台经验),

**验收**:同一页面截图与真实浏览器布局差异可量化(关键元素坐标/尺寸误差阈值);
headed 模式可人工操作完成一次登录+点击流程。

### Phase 4 — 资源、缓存、会话与安全

1. 资源加载器:图片/字体/媒体/`@import`,优先级、并发上限、取消与超时;
2. 全内存 HTTP 缓存:强缓存/协商缓存、LRU、大小上限;
3. Cookie 完整属性与第三方隔离;SameSite;
4. 同源策略/CORS/CSP 执行;混合内容拦截;
5. 下载管理(进度/暂停/取消/重试);剪贴板/权限模型基础。

**验收**:重复访问静态站点命中内存缓存;跨域 fetch 行为与浏览器一致;
CSP 可阻止内联脚本并有结构化报告。

### Phase 5 — JS/Web API 扩展(进行中)

0. **观察者系列 + 就绪判定(第一步,已完成,见 17 号文档)**:MutationObserver /
   IntersectionObserver / ResizeObserver 真实派发;宿主侧变更经快照 diff 合成
   mutation 记录;`wait` 支持 selector+state / text / js / network_idle 组合判定。
1. 切换 V8 后端(`v8-backend`)或评估其它可离线编译引擎;
2. Canvas 2D + 图片编解码;Web Audio/媒体按需;

**验收**:常见 SPA(React/Vue)可完成首屏渲染与路由跳转;图表/画布站点可截图。

## 四、工程约束(所有阶段)

- **契约不变**:`MCP_Web_Use` 工具名/action/参数/信封/错误码由兼容层保证;
- **全内存**:不写磁盘缓存/配置;产物只落 `artifact_root` 明确目录;
- **无外部浏览器进程**:不引入 Chrome/CDP/调试端口;
- **跨平台**:macOS/Windows/Linux 同一套 Rust 代码,平台差异仅在字体/窗口驱动;
- **单文件 ≤ 1800 行**,超线按功能拆目录;测试与实现同轮交付;
- **默认特性离线可编译**,重量级后端(V8)作为可选特性。
