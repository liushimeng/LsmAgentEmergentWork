## 一、实测暴露的三个问题

Dir03 实测百度地图路线规划任务(`laew -debug -f`),链路走通但视觉输出近乎全白:

| 问题 | 根因 | 修复 |
|------|------|------|
| 页面高度塌陷 44px(视口 720)→ 截图全白 | 样式层解析了 `height_percent` 但**全仓库无消费方**;`html,body,#container{height:100%}` 链整链退化为 auto | 布局层百分比高度求解 + 视口→html→body 确定高传播 |
| 有布局几何但渲染全白(搜索框/面板不可见) | 渲染器只画背景/图/文字:**无边框、无阴影**;裸表单控件连 UA 描边都没有 | border 结构化解析 + 四边绘制;box-shadow 偏移实心矩形近似;表单控件 UA 默认 1px 灰边白底 |
| `--debug` 日志 3 分钟 19MB,工程事件被淹没 | 文件日志过滤器只按级别过滤,html5ever 逐 token DEBUG 全量落盘 | DEBUG 级只放行本工程 target(`lsm_agent`/`laew`),第三方一律 WARN+ |

## 二、百分比高度求解(布局层)

新增 `layout/mod.rs::definite_height(style, parent_definite)`:显式 `height` 直接确定;
`height_percent` 仅在父高确定时解析(`p% × 父内容高`),否则按 CSS 语义退化为 auto。

- `compute_full` 入口:视口高 → html 确定高 → body 确定高,作为 ICB 高度传入
  (替代原 `UNKNOWN_CB_H`);
- `layout_children` 块分支:盒高先于子代布局求出(显式/百分比不依赖内容);
  auto 高占位 0,子代布局后用内容高回填;
- 子代 cb 高度传播:**当前盒 auto 高时必须传 `UNKNOWN_CB_H`,不得把祖父确定高
  透传给孙代**(CSS:百分比高度只相对父内容高)。

实测:百度地图 `page_health.page_height` 44 → 738。

## 三、边框与外阴影绘制(渲染层)

### 样式层(`style/values.rs`)

- `ComputedStyle` 新增 `border_widths[4]` / `border_drawn[4]` / `border_colors[4]`
  (`BorderColor::CurrentColor | Rgba`,transparent 归一 alpha=0)、`box_shadow: Vec<BoxShadow>`;
- 解析:`border` 速写(`<width>||<style>||<color>` 任意序,仅样式时线宽回落 medium=3px)、
  `border-width/color/style` 四值速写(1/2/3/4 值铺边)、`border-top/right/bottom/left`
  单边速写、`border-*-width/color/style` 单属性、`box-shadow` 多层;
- 切分器 `split_ws_tokens`:括号内(`rgba(...)`)不切开;box-shadow 层间按**括号外逗号**切分
  (教训:`split(',')` 会把 `rgba(0,0,0,.15)` 拆成四层,颜色静默丢失);
- `box-shadow`:`inset` 层与 transparent 层解析期丢弃;`blur` 保留字段、渲染近似 0。

### 布局层(`layout/mod.rs`)

- `Layout` 新增 `borders: Vec<BorderDraw>` / `shadows: Vec<ShadowDraw>`(绘制指令,
  **不占布局几何**);currentColor 在布局期代入文字色;
- 块分支与行内可寻址盒(input/button 等)入队;relative/sticky 整体偏移同步平移;
  Fragment(measure_content/flex)贯通 split_off/translate/append;
- `ua_default`:input/textarea/select/button 默认 1px 灰边(`#767676`)+白底
  —— 页面未自定义控件样式时输入框在截图中可见。

### 渲染层(`render.rs`)

绘制序:外阴影(背景之下)→ 背景 → 边框(背景之上、文字之下)→ 图像 → 文字。
tiny_skia `Pixmap::data()` 字节序实测为 RGBA(写像素断言时注意通道顺序)。

## 四、运行日志降噪(`logging.rs`)

`file_fmt_layer` 过滤函数:`level < meta.level()` 直接拒;`meta.level() <= DEBUG` 时
仅放行 target 前缀 `lsm_agent`/`laew`,第三方 crate(html5ever 等)一律 WARN+ 落盘。
INFO 及以上行为不变。实测百度地图任务日志从 19MB 回落到 KB 级。

## 六、已知剩余缺口(如实记录)

- **FIS 动态模块链(R13 深水区)**:`?qt=getjsmods` 的 `_jsload` JSONP 在 Boa 下抛
  "cannot convert 'null' or 'undefined' to object"(Boa TypeError 无 stack),widget 层
  (含路线规划面板)不注册;路线规划任务仍不可达,需最小可复现脚本 + shim 清单或 V8 后端;
- **canvas/WebGL 地图瓦片**:地图主体由 canvas 绘制,本引擎无 canvas 实现;
- alog 统计脚本报错无害,忽略;
- box-shadow blur 未实现高斯模糊(实心偏移矩形近似)。
